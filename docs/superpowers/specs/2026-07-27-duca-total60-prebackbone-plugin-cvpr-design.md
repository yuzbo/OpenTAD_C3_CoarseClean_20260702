# DUCA 总计 60 轮纯前置选帧插件实验设计

## 1. 文档状态

- 日期：2026-07-27
- 状态：`user_approved / designed / implementation_not_started`
- 任务：离线时域动作检测
- 目标：在不改动后续检测器主体的前提下，以严格固定帧预算学习任务感知选帧，并在统一的 60 轮检测器训练预算内证明性能、机制和可迁移性。
- 既有 30+60 轮 K=384 与 K=192 课程继续作为超预算诊断，不进入公平主结果。

## 2. 论文方法边界

主方法是位于重型主干网络之前的选帧插件。它可以：

1. 使用低成本、部署时可见的时序证据；
2. 在长度为 T 的候选网格上输出严格 K 个有序、唯一位置；
3. 使用统一的单调坐标适配器把选中序列的预测映回原视频；
4. 在训练时接收分类、边界回归和经过验证的检测任务监督。

主方法不得修改后续检测器的主干、投影、标签分配、检测头、分类/回归损失或非极大值抑制。向检测器内部注入真实时间坐标只作为诊断或增强集成，不支撑“纯前置插件”的主要声明。

## 3. 两种均匀下采样语义

为避免再次混淆，实验同时保留两种语义并分别命名。

### 3.1 窗口预算匹配均匀采样

- 原始候选范围固定为 768 个位置；
- K=384 时规则选择 384 帧，K=192 时规则选择 192 帧；
- 检测器接收紧凑的 K 槽序列；
- 标注按规则采样的仿射映射转换；
- 不加载 DUCA 学习式 selector，不改后端检测结构。

这是与固定预算 DUCA 最直接、最公平的均匀基线。

### 3.2 整视频降帧率基线

- 对整段视频做规则二分之一或四分之一下采样；
- 对动作标注做相同的全局仿射重映射；
- 后续仍使用干净的官方 AdaTAD 数据和检测流程；
- 检测器单窗口输入长度和后端配置保持官方设置，因此一个窗口覆盖的原始时间范围分别扩大约 2 倍或 4 倍；
- 优先直接索引原始解码帧，避免视频重编码造成额外压缩误差。

它用于复现历史 1/2、1/4 结果，但不能与“同一 768 点范围压缩为 K 点”的固定预算结果混称。

### 3.3 包装路径一致性对照

使用完全相同的均匀帧索引和同一模型权重，分别通过：

1. 干净数据层固定采样路径；
2. 当前 DUCA 选中轴包装路径。

检查选中 RGB、有效掩码、标注映射、预测逆映射和最终指标。若相同输入不能产生一致结果，必须先定位包装器或后端扩展造成的差异，不能把差值归因于学习式选帧。

## 4. 主模型：有界单调密度传输

低成本证据产生正时间密度 rho(t)，累积分布 F(t) 通过固定分位点解码 K 个位置：

```text
低成本时序证据
  -> 正密度 rho(t)
  -> 累积分布 F(t)
  -> F^{-1}((j + 0.5) / K)
  -> 严格 K 个有序唯一位置
  -> 原样的后续时域动作检测器
```

模型必须满足：

- 常数密度严格退化为均匀采样；
- 精确 K、唯一、有序；
- 对相邻间隔、最大未覆盖区间和累计坐标偏移施加显式上界；
- 贡献监督优先学习排序和质量传输，不拟合未校准的绝对梯度幅值；
- 检测梯度只有在离散换帧一致性通过后才能启用。

## 5. 连续代理与真实离散收益验证

### 5.1 为什么单帧交换仍然必要

单帧一进一出是保持精确 K 预算的最小离散扰动。它最接近连续代理所描述的局部方向，因此用于回答：

> 连续梯度在当前位置附近，是否至少能预测一个最小离散变化的损失方向？

单帧交换不能独自证明梯度能指导完整策略。最终结论必须同时依赖多尺度扰动。

### 5.2 四层扰动

所有扰动保持精确 K、位置唯一、顺序合法，并满足主模型的覆盖与最大间隔约束。

1. **单帧交换**：m=1，一进一出，验证局部有限差分。
2. **分散多帧交换**：替换约 1%、5%、10% 的已选位置。K=384 对应约 4、19、38 帧；K=192 对应约 2、10、19 帧。
3. **连续片段交换**：在相同替换比例下移动或替换连续小片段，重点覆盖动作边界、微簇和长背景区域。
4. **全局密度步进**：沿连续代理方向以 0.25、0.5、1.0 三种强度更新密度，再重新执行完整硬解码，检验局部信号组合后是否仍能改善真实硬策略。

单帧层检验局部正确性，多帧和全局层检验可组合性。若只通过单帧而多帧失败，只能声称局部相关，不能让直接检测梯度进入最终模型。

### 5.3 真实收益与代理收益

冻结一个检测器和 selector 检查点。对硬选帧集合 S 及合法扰动 S'：

```text
真实收益 = L_detector(S) - L_detector(S')
代理收益 = - <dL/dz, z' - z>
```

分别记录分类、边界回归和总检测损失。数据只来自训练侧固定留出集合，至少覆盖 64 个视频、128 个窗口，并按动作长度、边界密度和背景比例分层。官方测试标注不得参与候选生成、阈值冻结或模型选择。

### 5.4 统计量和空对照

每个扰动尺度报告：

- Spearman 等级相关；
- Kendall 等级相关；
- 收益方向正确率；
- 前 10% 候选的真实收益；
- 相对随机候选的归一化遗憾；
- 按视频成组的 95% bootstrap 置信区间。

空对照包括随机分数、视频内打乱梯度和反向梯度。

### 5.5 检测梯度准入门

直接检测梯度进入 60 轮主模型前必须同时满足：

1. 单帧和 5% 多帧交换的 Spearman 相关置信区间下界大于 0；
2. 汇总方向正确率置信区间下界大于 0.5；
3. 前 10% 代理候选的真实收益显著优于随机候选；
4. 10% 多帧和全局密度步进不得出现稳定反相关；
5. 分类与回归至少一项分别显示正对齐，不能只依赖总损失抵消。

若未通过，直接检测梯度臂停止。最终方法保留分离式、归一化的贡献排序教师。

## 6. 时间扭曲和贡献监督消融

### 6.1 时间几何

在相同 K、训练预算和后端下比较：

- 规则均匀位置；
- 当前无累计偏移上界的学习式密度；
- 有最大间隔和累计偏移上界的单调密度；
- 相同硬选帧加检测器内部真实时间坐标，仅作诊断。

报告平均检测性能、高重叠阈值性能、短动作性能、相邻间隔分布、最大未覆盖区间、累计坐标偏移和标注/预测往返误差。

### 6.2 贡献监督

依次比较：

- 无贡献监督；
- 仅分类贡献；
- 仅边界回归贡献；
- 分类与回归共同贡献；
- 当前原始幅值监督；
- 归一化排序或传输监督。

原始损失数值不能直接判断优化支配性。必须记录贡献项和检测项在 selector 共享参数上的梯度范数、梯度夹角与稳定性。归一化监督的候选梯度比例为检测任务梯度的 0.1、0.25、0.5；只在训练侧固定留出集合上按对齐度和数值稳定性冻结一个比例，不使用官方测试指标调参。

## 7. 公平的总计 60 轮主比较

所有臂共享官方检测器训练日程、最大 6000 次成功更新、验证频率、训练侧 checkpoint 选择规则和官方测试次数。

| 编号 | 模型 |
|---|---|
| A0 | 干净窗口预算匹配均匀采样 |
| A1 | 有界密度传输，从零联合训练 60 轮 |
| A2 | 前 10 轮严格均匀，后 50 轮释放有界密度传输 |
| A3 | A2 加归一化分类与回归贡献传输 |
| A4 | A3 加通过离散换帧准入门的检测梯度 |

若检测梯度未通过准入门，A4 不运行，不能用减弱阈值或更换测试集合补救。分类/回归单独贡献臂用于机制归因，在 A3 第一粒种子显示正收益后补齐。

允许选择中间 checkpoint，但每个臂必须使用同一个训练侧留出集合、同一评估频率、同一选择指标和同一最大 60 轮预算。官方测试集只评估按该规则选中的 checkpoint；若无法建立无泄漏留出集合，则所有臂统一使用第 59 轮滑动平均模型。

## 8. 执行顺序

### 阶段 A：基线恢复

1. 使用上游官方来源复核 dense 69.03；
2. 建立窗口预算匹配 50% 与 25% 均匀基线；
3. 复现整视频 1/2 与 1/4 降帧率基线；
4. 完成干净路径与包装路径的一致性检查。

基线不闭合时，不解释 DUCA 相对收益。

### 阶段 B：机制准入

1. 完成四层离散扰动验证；
2. 完成时间扭曲消融；
3. 完成贡献梯度范数、夹角和归一化比例冻结。

这些是决定模型构成的科学实验，不是最终平均检测性能的替代品。

### 阶段 C：第一粒种子总计 60 轮

按 A0 到 A4 顺序运行。第一粒种子若不能清楚超过干净均匀基线，停止扩大矩阵，回到时间扭曲、贡献教师保真度和密度塌缩分析。

### 阶段 D：论文稳定性

第一粒种子出现明确收益后，再补：

- 两次独立运行及均值、波动；
- K=192；
- 第二种时域动作检测器；
- 分类和边界贡献的独立归因。

### 阶段 E：真正免训练模式

冻结已发布检测器和 selector，不做目标域优化，仅使用部署可见的低成本证据生成密度并直接评估。该模式与任务适配主结果分开报告。

## 9. 成功标准和声明边界

- 官方 dense 评估未复核到与 69.03 一致的口径前，不解释本地 dense 差距；
- 主模型必须在同一 60 轮预算下超过干净 50% 均匀基线；
- 继续多种子和第二检测器的最低条件是第一粒种子至少提高 0.5 个百分点，且高重叠阈值没有系统性下降；
- 强目标是以 50% 帧预算接近或达到 69%；
- 检测梯度不通过多尺度离散对齐时，不得进入最终方法或论文主张；
- 检测器内部真实时间改造即使有效，也只能标为增强集成；
- 现有 65.385724% K=384 结果仍是 90 轮超预算诊断，不是本文设计的最终主结果。

## 10. 最小实现范围

实施只允许增加直接服务上述判断的最小表面：

- 干净固定均匀采样配置；
- 有界单调密度解码与约束；
- 多尺度合法硬交换及真实损失评估；
- 归一化贡献监督和共享参数梯度统计；
- 五个总计 60 轮主配置；
- 必要的坐标、无泄漏和 exact-K focused tests。

不建设新的通用编排平台，不扩展与模型判断无关的日志框架，也不把版本治理当作论文贡献。

## 11. 实施拆分

本设计分为四个独立实施计划，按准入关系推进：

1. **P1 官方基线与路径一致性**：dense 69.03 口径、窗口预算匹配 50%/25%、整视频降帧率、原生路径与包装路径一致性。
2. **P2 多尺度离散对齐与贡献审计**：四层硬扰动、真实有限差分、梯度范数/夹角、贡献归一化比例冻结。
3. **P3 有界密度模型与总计 60 轮五臂**：只有 P1、P2 通过后才实施并投递 A0-A4。
4. **P4 论文稳定性与免训练模式**：只有第一粒种子显示明确收益后才进行多种子、K=192、第二检测器和 frozen-detector 即插即用。

下一步只为 P1、P2 编写实施计划，不提前启动 P3/P4。
