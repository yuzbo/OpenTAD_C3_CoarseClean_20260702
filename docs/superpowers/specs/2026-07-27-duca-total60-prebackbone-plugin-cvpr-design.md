## 2. 论文方法边界

主方法是位于重型主干网络之前的选帧插件。它可以：

1. 使用低成本、部署时可见的时序证据；
2. 在长度为 T 的候选网格上输出严格 K 个有序、唯一位置；
3. 使用统一的单调坐标适配器把选中序列的原始预测映回原视频，并在物理时间轴上执行
   参数不变的官方后处理；
4. 在训练时接收分类、边界回归和经过验证的检测任务监督。

主方法不得修改后续检测器的主干、投影、标签分配、检测头、分类/回归损失或非极大值抑制
算法。非线性时间变换不保持区间 IoU，因此预测逆映射必须作用于 NMS 之前的 raw proposals：

```text
detector raw proposals in warped time q
  -> plugin inverse map q to physical time t
  -> unchanged official NMS in t
```

训练真值在插件接口处从物理时间映到 warped time，映射对 selector stop-gradient；标签分配器和
检测损失代码本身不改。向检测器内部注入真实时间坐标只作为诊断或增强集成，不支撑“纯前置
插件”的主要声明。

## 3. 两种均匀下采样语义

为避免再次混淆，实验同时保留两种语义并分别命名。

### 3.1 窗口预算匹配均匀采样

- 原始候选范围固定为 768 个位置；
- K=384 时规则选择 384 帧，K=192 时规则选择 192 帧；
- 检测器接收紧凑的 K 槽序列；
- 标注按规则采样的仿射映射转换；
- 不加载 DUCA 学习式 selector，不改后端检测结构。

这是与固定预算 DUCA 最直接、最公平的均匀基线。

### 3.2 整视频降帧率基线

- 对整段视频做规则二分之一或四分之一下采样；
- 对动作标注做相同的全局仿射重映射；
- 后续仍使用干净的官方 AdaTAD 数据和检测流程；
- 检测器单窗口输入长度和后端配置保持官方设置，因此一个窗口覆盖的原始时间范围分别扩大约 2 倍或 4 倍；
- 优先直接索引原始解码帧，避免视频重编码造成额外压缩误差。

它用于复现历史 1/2、1/4 结果，但不能与“同一 768 点范围压缩为 K 点”的固定预算结果混称。

### 3.3 包装路径一致性对照

使用完全相同的均匀帧索引和同一模型权重，分别通过：

1. 干净数据层固定采样路径；
2. 当前 DUCA 选中轴包装路径。

检查选中 RGB、有效掩码、标注映射、预测逆映射和最终指标。若相同输入不能产生一致结果，必须先定位包装器或后端扩展造成的差异，不能把差值归因于学习式选帧。

## 4. 主模型：有界单调密度传输

低成本证据产生正时间密度 rho(t)，累积分布 F(t) 通过固定分位点解码 K 个位置：

```text
低成本时序证据
  -> 正密度 rho(t)
  -> 累积分布 F(t)
  -> F^{-1}((j + 0.5) / K)
  -> 严格 K 个有序唯一位置
  -> 原样的后续时域动作检测器
```

模型必须满足：

- 常数密度严格退化为均匀采样；
- 精确 K、唯一、有序；
- 对相邻间隔、最大未覆盖区间和累计坐标偏移施加显式上界；
- 贡献监督优先学习排序和质量传输，不拟合未校准的绝对梯度幅值；
- 检测梯度只有在离散换帧一致性通过后才能启用。

在任何正式实现和长训练前，必须把以下映射冻结为唯一、可测试的数学合同：

```text
低成本证据 e
  -> 正、归一化的离散密度 p
  -> 单调累计映射 F
  -> 固定分位连续位置 y
  -> 确定性 exact-K 整数集合 S
```

合同必须显式定义：

- 密度正性、上下界和累计偏移界；
- 常数 logits 到 canonical exact-uniform 的严格恒等路径；
- 首尾覆盖、内部最大洞、位置唯一性和相对 uniform anchor 的偏移；
- 整数冲突、代价相同 tie-break 和不可行输入的 fail-closed 行为；
- `t -> q -> t` 的往返误差；
- raw proposal 逆映射与 NMS 的先后关系。

审阅提出的 `p_i in [1/(2T), 2/T]`、累计偏移 `4/K`、最大洞
`ceil(2T/K)`、anchor 偏移 `ceil(4T/K)` 和确定性 DP 是首个候选，而不是当前冻结常数。
这些数值只能在训练侧开发数据和几何可达性分析中一次性冻结，正式结果后不得回调。
任何冲突处理必须是上述唯一解码器的一部分；禁止解码后另加未登记的补洞、膨胀或
uniform scaffold。

### 4.1 理论证明义务

最终规范至少应证明以下克制命题，而不能声称它直接保证 mAP。设连续密度满足：

```text
0 < m <= rho(t) <= M
||F - I||_infinity <= delta
G = F^{-1}
```

则应证明：

```text
|G(q) - q| <= delta

|q2 - q1| / M
  <= |G(q2) - G(q1)|
  <= |q2 - q1| / m

|(G(q2)-G(q1)) - (q2-q1)| <= 2 delta
```

若整数解码中心相对连续分位的最大误差为 `r`，还应给出位置偏移和最大相邻间隔界；
若 detector 在 q 轴的边界误差为 `epsilon_q`，映回原时间后的误差应满足形如
`epsilon_q / m + r_map` 的上界。

该命题只证明局部伸缩、累计偏移、区间长度扭曲和边界误差放大受控。它不证明语义在
warp 后完全不变，也不证明检测性能提高；后两者必须由 high-tIoU、短动作、边界误差和
跨 detector 实验验证。

## 5. 连续代理与真实离散收益验证

### 5.1 为什么单帧交换仍然必要

单帧一进一出是保持精确 K 预算的最小离散扰动。它最接近连续代理所描述的局部方向，因此用于回答：

> 连续梯度在当前位置附近，是否至少能预测一个最小离散变化的损失方向？

单帧交换不能独自证明梯度能指导完整策略。最终结论必须同时依赖多尺度扰动。

### 5.2 四层扰动

所有扰动保持精确 K、位置唯一、顺序合法，并满足主模型的覆盖与最大间隔约束。

1. **单帧交换**：m=1，一进一出，验证局部有限差分。
2. **分散多帧交换**：替换约 1%、5%、10% 的已选位置。K=384 对应约 4、19、38 帧；K=192 对应约 2、10、19 帧。
3. **连续片段交换**：在相同替换比例下移动或替换连续小片段，重点覆盖动作边界、微簇和长背景区域。
4. **全局密度步进**：沿连续代理方向以 0.25、0.5、1.0 三种强度更新密度，再重新执行完整硬解码，检验局部信号组合后是否仍能改善真实硬策略。

单帧层检验局部正确性，多帧和全局层检验可组合性。若只通过单帧而多帧失败，只能声称局部相关，不能让直接检测梯度进入最终模型。

### 5.3 真实收益与代理收益

冻结一个检测器和 selector 检查点。对硬选帧集合 S 及合法扰动 S'：

```text
真实收益 = L_detector(S) - L_detector(S')
代理收益 = - <dL/dz, z' - z>
```

分别记录分类、边界回归和总检测损失。数据只来自训练侧固定留出集合，并按动作长度、
边界密度和背景比例分层。统计单位是视频，同一窗口中的多个候选不得当成独立样本。
`64` 个视频、`128` 个窗口只作初始下限，最终数量必须由视频聚类方差和预先功效模拟
冻结。官方测试标注不得参与候选生成、阈值冻结或模型选择。

### 5.4 统计量和空对照

每个扰动尺度报告：

- Spearman 等级相关；
- Kendall 等级相关；
- 收益方向正确率；
- 前 10% 候选的真实收益；
- 相对随机候选的归一化遗憾；
- 按视频成组的 95% bootstrap 置信区间。

空对照包括随机分数、视频内打乱梯度和反向梯度。

### 5.5 双准入门

#### `G_rank`：贡献排序教师

`G_rank` 判断 detached 分类/回归贡献排序是否能预测真实硬换帧收益。其主终点、效应量和
安全终点必须在看正式结果前冻结，至少要求：

1. 5% 多帧交换的逐视频 Spearman 显示具有实际意义的正相关；
2. 回归收益方向率高于随机水平；
3. 前 10% 代理候选的真实收益优于 matched random；
4. 10% 多帧和全局密度步进不出现稳定反相关；
5. 分类与回归分别报告，不能只依赖总损失抵消。

审阅提出的 `Spearman 95% LCB > 0.10`、方向率 `LCB > 0.52` 是待功效模拟确认的
`designed_reviewer_proposal`，不是当前冻结阈值。`G_rank` 失败时，当前由连续梯度
产生的贡献教师和 RDD 长训练全部停止。

#### `G_direct`：直接检测梯度

`G_direct` 在 `G_rank` 之上进一步判断连续梯度的多尺度可组合性、共享 selector 参数上的
梯度范数/夹角/有限性，以及一个严格同起点的短程 on/off 配对收益。只有 `G_direct` 通过，
直接检测梯度才能进入 A4。

`G_direct` 失败但 `G_rank` 通过时，删除 A4，保留 detached、归一化的贡献排序教师。
短程配对只作开发门；若通过，正式 A4 仍必须从统一初始化开始，在总计 6,000 次更新内训练，
不得在完成的 A3 之后额外增加 1,000 次更新作为主结果。

## 6. 时间扭曲和贡献监督消融

### 6.1 时间几何

在相同 K、训练预算和后端下比较：

- 规则均匀位置；
- 当前无累计偏移上界的学习式密度；
- 有最大间隔和累计偏移上界的单调密度；
- 相同硬选帧加检测器内部真实时间坐标，仅作诊断。

报告平均检测性能、高重叠阈值性能、短动作性能、相邻间隔分布、最大未覆盖区间、累计坐标偏移和标注/预测往返误差。

### 6.2 贡献监督

优先比较：

- 无贡献监督；
- 仅分类贡献；
- 仅边界回归贡献；
- 分类与回归共同贡献；
- 当前原始幅值监督，仅作历史负面对照；
- rank-normalized distribution distillation（RDD）；
- 视频内打乱 RDD、简单 motion prior 或 no-RDD 中的最小必要机制控制。

原始损失数值不能直接判断优化支配性。必须记录贡献项和检测项在 selector 共享参数上的
梯度范数、梯度夹角与稳定性。RDD 是当前主候选，不是未经验证的唯一正确目标；必须先通过
`G_rank`，并检查 ties、teacher 非平稳及 cls/reg 冲突。若启用 direct gradient，只允许
一个按共享参数梯度范数自动归一的固定目标比例；比例在训练侧一次冻结，不枚举多个比例后
按官方 mAP 选择。

## 7. 公平的总计 60 轮主比较

所有臂共享官方检测器训练日程、最大 6,000 次成功更新、验证频率、训练侧 checkpoint
选择规则和官方测试次数。第一枚运行固定为 development screening seed，不进入论文最终
均值、方差或置信区间。

| 编号 | 模型 | 唯一问题 |
|---|---|---|
| A0 | 干净窗口预算匹配 exact-uniform | 公平性能底线 |
| A1 | 无累计/局部界的 monotone density + 通过 `G_rank` 的 RDD，从零释放 | 学习密度是否有价值 |
| A2 | bounded density + 同一 RDD，从零释放 | 几何约束是否有价值 |
| A3 | A2 + 总预算内的 uniform warmup/ramp | 课程是否有价值 |
| A4 | A3 + 通过 `G_direct` 的检测梯度 | 直接梯度是否有额外价值 |

若 `G_rank` 未通过，A1 至 A3 按上述定义均不运行；不能假装 density 有一个已经成立的学习
目标。若 `G_direct` 未通过，A4 不运行，不能用减弱阈值或更换测试集合补救。

贡献必要性使用预先冻结的最小控制，例如视频内 shuffled-RDD、简单 motion prior 或短程
no-RDD；不得在 A3 正向后才选择性补某个容易得到正结论的长训练臂。

A3 的首个课程候选为：updates 0 至 999 使用严格均匀硬前向，1000 至 1499 线性释放
密度，1500 至 5999 完全使用 learned density。该边界仍须在训练侧开发阶段一次冻结，
正式结果后不得改写。

若没有与官方测试完全隔离的训练侧模型选择集合，所有臂统一使用第 6,000 次成功更新后的
EMA。若能建立该集合，则允许选择中间 checkpoint，但每个臂必须使用同一留出集合、
同一评估频率、同一指标和同一最大 6,000-update 预算。官方测试只在结构、超参数和
checkpoint 规则冻结后评估一次。

## 8. 执行顺序

### 并行工作流 A：基线恢复

1. 使用上游官方来源复核 dense 69.03；
2. 建立窗口预算匹配 50% 与 25% 均匀基线；
3. 复现整视频 1/2 与 1/4 降帧率基线；
4. 完成干净路径与包装路径的一致性检查。

基线不闭合时，不解释 DUCA 相对收益。

### 并行工作流 B：唯一数学模型

1. 冻结密度可行域、连续映射、确定性 exact-K 解码和 tie-break；
2. 冻结 `t -> q` 真值映射、raw proposal `q -> t` 逆映射和 pre-NMS 接口；
3. 完成 constant-uniform identity、极端密度、首尾覆盖、最大洞和 round-trip tests。

该工作流可以与基线恢复并行，但任何 learned-selector 长训练都必须等待 clean/wrapper
parity 与 decoder/coordinate contract 通过。

### 并行工作流 C：机制准入

1. 运行 `G_rank` 四层离散扰动和空对照；
2. 运行 `G_direct` 的多尺度可组合性、共享梯度审计和短程配对门；
3. 完成视频聚类功效模拟，冻结主终点、效应量和安全终点。

这些是决定模型构成的科学实验，不是最终平均检测性能的替代品。

### 阶段 D：development seed 总计 60 轮

按通过门禁后的 A0 至 A4 运行。该种子只用于冻结模型结构，不进入最终统计。若不能清楚
超过干净均匀基线，停止扩大矩阵，按 A1/A2/A3 的因果差值裁决密度、几何约束和课程，
不得直接增加新损失或新模块。

### 阶段 E：论文稳定性

结构冻结后，再用未参与开发的预登记种子补：

- A0 与主模型的三种子均值、波动和视频级配对区间；
- K=192；
- 第二种时域动作检测器；
- 预先确定的最小机制归因。

### 并行次路线：真正免训练模式

在 clean parity 和共享 decoder/coordinate contract 通过后，可以并行建立一个最小
frozen-detector 基线。冻结已发布检测器和 selector，不做目标域优化，仅使用部署可见
的低成本证据生成密度并直接评估。该模式与任务适配主结果分开报告，不阻塞主模型。

## 9. 成功标准和声明边界

- 官方 dense 评估未复核到与 69.03 一致的口径前，不解释本地 dense 差距；
- 主模型必须在同一 60 轮预算下超过干净 50% 均匀基线；
- 强目标是以 50% 帧预算接近或达到 69%；
- development seed 的继续门、高重叠阈值和短动作安全门必须在 clean baseline 与
  视频级功效模拟后冻结；审阅提出的 `+0.5pp` 开发门、最终 `+1.0pp`、40% dense-gap
  recovery、第二检测器 `+0.5pp` 暂为 reviewer proposal；
- 69 至 70 不是信息上界或硬发表门，不得以其倒推额外训练、测试集选择或后端改造；
- `G_rank` 不通过时，当前贡献教师不得进入最终方法；`G_direct` 不通过时，直接检测
  梯度不得进入最终方法；
- 检测器内部真实时间改造即使有效，也只能标为增强集成；
- 现有 65.385724% K=384 结果仍是 90 轮超预算诊断，不是本文设计的最终主结果。

## 10. 最小实现范围

实施只允许增加直接服务上述判断的最小表面：

- 干净固定均匀采样配置；
- 有界单调密度解码与约束；
- 多尺度合法硬交换及真实损失评估；
- 归一化贡献监督和共享参数梯度统计；
- 五个总计 60 轮主配置；
- 必要的坐标、无泄漏和 exact-K focused tests。

不建设新的通用编排平台，不扩展与模型判断无关的日志框架，也不把版本治理当作论文贡献。

## 11. 实施拆分

本设计分为四个独立实施面，按科学依赖推进：

1. **P1 官方基线与路径一致性**：dense 69.03 口径、窗口预算匹配 50%/25%、整视频降帧率、原生路径与包装路径一致性。
2. **P2 唯一数学模型与坐标合同**：密度投影、exact-K 解码、warped-time adapter、pre-NMS inverse map 和 property tests。
3. **P3 双门与总计 60 轮因果臂**：`G_rank` 只解锁 RDD 臂，`G_direct` 只解锁 A4；长训练还必须通过 P1 parity 和 P2 contract。
4. **P4 论文稳定性与免训练模式**：development seed 正向后进行未参与开发的三种子、K=192 和第二检测器；最小 frozen-detector 模式可在共享解码器稳定后并行。

P1、P2 和双门统计工具可以并行实现。当前不启动 A1 至 A4 长训练；A0 clean baseline
属于 P1 本身。PR 清理并行处理，不进入上述模型科学关键路径。
