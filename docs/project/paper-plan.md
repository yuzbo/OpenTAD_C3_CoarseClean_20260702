# 论文定位：定位价值驱动的条件计算

修订日期：2026-09-08，吸收用户关于 A/MoD＋TIA、B/不完整证据、C/共享更新及 LITE 的两次修正。历史方案保留；今后论文主张按本修订解释。现行训练模型仍为 M=b70ae056c495b43ca3f305fe438926b97b2723b5，旧 340a3541 不是当前源码。

## 工作标题与核心问题

**GeoSparse-TAD: Localization-Value Routing for Efficient End-to-End Temporal Action Detection**

中文：**面向高效端到端时序动作检测的定位价值路由**。

在已有条件计算能够保留密集时间状态的前提下，怎样把有限的 Heavy 计算分配给更有助于分类、起止边界和区间完整性的操作？

这是研究问题。低成本观测能否预测这种收益、收益校准是否胜过强任务适配近邻、以及实际执行是否更快，均需独立证据。A 仍是预指定主执行路线，B/C 保持完整平行挑战；不依据测试成绩静默更换主路线。三条路线是同一研究原则的三个执行器，不作为三项全新基础架构贡献。

## 正式撤回的对立与保留的边界

MoD 使用残差路径保留跳过计算的 token，并允许其后续重新参与。它不要求永久删位置。CoDA 已将全量轻 Adapter 与条件执行的冻结 Heavy 结合。因此，保留状态、gather/scatter、identity skip 均不作为 A 独有的网络原语。MoD 的原始实验也包含全量层与路由层交替，不能只比较一个不利的全层稀疏版本。[MoD 原文](https://arxiv.org/html/2404.02258v1)、[CoDA 原文](https://arxiv.org/html/2304.04947v2)。

完整原生网格上的 TIA 可提供给两类路由；它是本研究的公共时间建模基础。坐标和 mask 正确保证解释一致，不保证关键证据已经充分。AdaTAD 的原始 block 顺序及 TIA 作用域须按源码保留。[AdaTAD 原文](https://arxiv.org/html/2311.17241v2)。

VideoLLM-MoD 是相关视频工作，但它在视频语言系统的语言模型内路由视觉 token，与本项目的原始视频 VideoMAE 编码路径不同；这种应用位置差异也不能单独证明创新。[VideoLLM-MoD 原文](https://arxiv.org/html/2408.16730v1)。

ASL 已研究分类与定位对帧的不同敏感性；因此不声称首次发现两者不同。[ASL 原文](https://arxiv.org/html/2305.15701v2)。动态特征选择也已有基于当前可用信息决定下一项获取内容的研究，其条件互信息目标与这里的有限模型反事实风险不是同一个量。[动态特征选择原文](https://arxiv.org/abs/2301.00557)。

## B/C 与价值学习的新增边界

B 的密集 query、稀疏表示与时间重对齐已有 Coarse-Fine、mTAN、Perceiver IO、TokenFuser、LookupViT 等近邻；AdaSpot 也提供了视频定位中的轻分支和高分辨率 ROI 先例。C 的粗细选择、合并处理再恢复及保留 residual，有 MSViT、ToMeSD 和密集分割合并方法等近邻。事实与任务边界统一见[原文核对](prior-art-bc-lite.md)，不因它们尚非当前 THUMOS 配置就认定创新。

LITE 已把梯度价值代理、轻量 selector 与自适应预算用于视频理解，并有 AVA 迁移。因此，“从 motion 转向任务价值”也不足以单独成立；应检验实际操作的有符号条件收益、成本一致替换、区间风险及正确反事实图是否有独立作用。[LITE 原文](https://arxiv.org/html/2411.13626v2)。

|执行器|待检验的问题|不再使用的独占主张|
|---|---|---|
|A|哪一次 Heavy 更新更能降低区间风险？|首次保留状态并 gather/scatter、首次与完整 TIA 组合。|
|B|如何利用不完整 Heavy 语义而不错误扩张动作区间？|首次用 dense query 恢复 sparse evidence；加时间戳即有独立创新。|
|C|何时可以共享 Heavy 更新；计算近似变化是否损伤时间判别？|首次 coarse/fine、逐层恢复即信息无损、共享 residual 差值为独有性质。|

这些问题均需强控制；不预设边界外推或模式切换伪边界已经发生。当前 C 已有普通检测 loss 下的 signed coarse→fine gain，不能把它全部说成未来方法；现行 B 的锚点与完整编码依赖也不能混称。实现边界见[B/C 方法说明](../methods/evidence-and-shared-updates.md)。

## 可以进入论文的无结果摘要

端到端时序动作检测需要同时识别动作并确定区间边界。已有条件执行、粗细融合与 token 合并提供了降低表征成本的基础，但有限计算如何保留区间判断所需的证据与时间变化仍需研究。本文以合法视频计算操作的条件任务价值为统一研究对象，采用稀疏更新、稀疏证据接收和混合尺度共享更新三种执行器。现行实现使用当前检测模型的有符号损失变化提供反馈；研究设计进一步区分固定预算替换与动态预算获取，并检验不完整证据外推和计算模式变化两类潜在定位误差。比较向条件执行、时间接收、token 合并和价值代理近邻提供一致的时间建模、目标与成本核算，分别测量选择、使用和近似的贡献。评价覆盖平均与高 tIoU 检测、短动作、起止误差、预算分布及同设备延迟。本文当前为方法与实验设计稿；新增机制、错误假设及性能优势尚需相应实现与完整实验证据。

## 结果决定能够写到哪里

|实际证据|允许的解释|
|---|---|
|A2 在成本可比时改善定位指标，且控制支持归因|定位价值校准和前置规划有相应条件下的收益；分别说明各因素贡献。|
|M3 与 A2 均改善且接近|价值学习可增强不同条件计算骨架；A 是一种实现。|
|M2 达到 A2|风险目标可能已足够；评估是否移除无独立收益的校准开销。|
|强 MoD＋TIA 与 A 相当或更好|当前 A 尚未建立优越性；不能靠几何或任务名称维持创新主张。|
|只有中期 mAP 或理论 MAC|只能报告训练观察或计算量；不能宣称最终提升、定位机制成立或真实加速。|

这些情况决定结果解释，不是后续实验的成绩准入门槛。证据不要求“A 必须胜过 MoD”；若两者都受益，方法贡献可以属于路由学习原则。

## 现有训练与新增方案的边界

本次采纳统一论文定位及强比较原则；区间风险、等成本 swap、M0–M3/A2、B 新校准及新的合并/价值代理迁移仍是待落实设计。现行 M 的 A/B 为普通检测损失下的 acquisition，C 的对应干预为 coarse→fine；均不能把继续训练的 checkpoint 改称新风险或新校准结果。

保留已授权的 A/B/C 固定 .5 与动态预算、seed0、两服务器并行优先级。原 1545 项登记和已提交补充作业不因叙事修订删除、重复或重新编号。新增设计没有完整配置与正确性凭证时不提交假作业；实现就绪后排队不以已有 mAP 或 Oracle 为条件。

新增训练若改变风险、路由或校准，须以独立修订配置和新任务身份执行；符合现行 A1 定义的已有运行优先复用。固定 .5 是选择预算标签，绝不自动等于 50% Heavy MAC 或 50% 总延迟。正文不把任何预设工作点当作结果。
