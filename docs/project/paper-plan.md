# 论文定位：定位价值驱动的条件计算

修订日期：2026-09-08，依据用户本轮关于 Route A、MoD＋TIA 和定位价值的明确修正。历史方案保留；今后论文主张按本修订解释。现行训练模型仍为 M=b70ae056c495b43ca3f305fe438926b97b2723b5，旧 340a3541 不是当前源码。

## 工作标题与核心问题

**GeoSparse-TAD: Localization-Value Routing for Efficient End-to-End Temporal Action Detection**

中文：**面向高效端到端时序动作检测的定位价值路由**。

在已有条件计算能够保留密集时间状态的前提下，怎样把有限的 Heavy 计算分配给更有助于分类、起止边界和区间完整性的操作？

这是研究问题。低成本观测能否预测这种收益、收益校准是否胜过强 MoD＋TIA、以及实际执行是否更快，均需独立证据。A 仍是预指定主执行路线，B/C 保持完整平行挑战；不依据测试成绩静默更换主路线。

## 正式撤回的对立与保留的边界

MoD 使用残差路径保留跳过计算的 token，并允许其后续重新参与。它不要求永久删位置。CoDA 已将全量轻 Adapter 与条件执行的冻结 Heavy 结合。因此，保留状态、gather/scatter、identity skip 均不作为 A 独有的网络原语。MoD 的原始实验也包含全量层与路由层交替，不能只比较一个不利的全层稀疏版本。[MoD 原文](https://arxiv.org/html/2404.02258v1)、[CoDA 原文](https://arxiv.org/html/2304.04947v2)。

完整原生网格上的 TIA 可提供给两类路由；它是本研究的公共时间建模基础。坐标和 mask 正确保证解释一致，不保证关键证据已经充分。AdaTAD 的原始 block 顺序及 TIA 作用域须按源码保留。[AdaTAD 原文](https://arxiv.org/html/2311.17241v2)。

VideoLLM-MoD 是相关视频工作，但它在视频语言系统的语言模型内路由视觉 token，与本项目的原始视频 VideoMAE 编码路径不同；这种应用位置差异也不能单独证明创新。[VideoLLM-MoD 原文](https://arxiv.org/html/2408.16730v1)。

ASL 已研究分类与定位对帧的不同敏感性；因此不声称首次发现两者不同。[ASL 原文](https://arxiv.org/html/2305.15701v2)。动态特征选择也已有基于当前可用信息决定下一项获取内容的研究，其条件互信息目标与这里的有限模型反事实风险不是同一个量。[动态特征选择原文](https://arxiv.org/abs/2301.00557)。

## 可以进入论文的无结果摘要

端到端时序动作检测需要同时识别动作并确定区间边界。已有条件计算方法可以跳过部分重型更新，同时保留完整位置状态，但如何分配计算以控制区间定位风险仍需研究。本文将该问题表述为合法视频计算操作的条件任务价值预测，在原生视频网格上保留轻量时间交互，并以 MoD/CoDA 风格的稀疏执行器落实 Heavy 计算减少。我们以当前检测模型的有符号损失变化作为价值反馈，进一步提出区分固定预算替换与动态预算获取的校准方案。研究设计将相同 TIA、检测器、风险目标及执行约束提供给逐层 MoD 路由和前置 Scout 路由，分别检验路由可预测性、定位质量和实际延迟。评价同时覆盖平均与高 tIoU 检测指标、短动作召回、起止误差、预算分布及同设备准确率—延迟关系。本文当前为方法与实验设计稿；新增校准机制及其优势须由实际实现和实验确认。

## 正文推进顺序

1. 已有条件计算提供少算机制；说明 MoD、CoDA 与本项目的关系。
2. TAD 的类别、边界、短动作及多实例完整性可能需要不同证据；提出可证伪假设。
3. 按[方法规格](../methods/localization-value-routing.md)定义操作价值、实际计算范围和成本，区分现行实现与增强方案。
4. 按[比较计划](../evaluation/mod-tia-comparison-plan.md)向强对照提供同等时间建模和目标，检验显式校准的独立作用。
5. 用[证据图](../evaluation/localization-value-figures.md)说明受益位置、失败类型和真实执行取舍，不用 attention 图替代因果干预。

## 结果决定能够写到哪里

|实际证据|允许的解释|
|---|---|
|A2 在成本可比时改善定位指标，且控制支持归因|定位价值校准和前置规划有相应条件下的收益；分别说明各因素贡献。|
|M3 与 A2 均改善且接近|价值学习可增强不同条件计算骨架；A 是一种实现。|
|M2 达到 A2|风险目标可能已足够；评估是否移除无独立收益的校准开销。|
|强 MoD＋TIA 与 A 相当或更好|当前 A 尚未建立优越性；不能靠几何或任务名称维持创新主张。|
|只有中期 mAP 或理论 MAC|只能报告训练观察或计算量；不能宣称最终提升、定位机制成立或真实加速。|

这些情况决定结果解释，不是后续实验的成绩准入门槛。证据不要求“A 必须胜过 MoD”；若两者都受益，方法贡献可以属于路由学习原则。

## 现有训练与新增方案的边界

本次采纳论文定位及比较原则；区间风险、等成本 swap 和 M0–M3/A2 仍是待落实的增强设计。现行 M 的 A 为普通检测损失、PG 与 signed acquisition；不能将其继续训练的 checkpoint 改称 A2。

保留已授权的 A/B/C 固定 .5 与动态预算、seed0、两服务器并行优先级。原 1545 项登记和已提交补充作业不因叙事修订删除、重复或重新编号。新增设计没有完整配置与正确性凭证时不提交假作业；实现就绪后排队不以已有 mAP 或 Oracle 为条件。

新增训练若改变风险、路由或校准，须以独立修订配置和新任务身份执行；符合现行 A1 定义的已有运行优先复用。固定 .5 是选择预算标签，绝不自动等于 50% Heavy MAC 或 50% 总延迟。正文不把任何预设工作点当作结果。
