G. **最终论文故事与创新点**

DUCA-TAD 的合理论文问题是：

**Temporal Action Detection 的 sparse acquisition 不应只学 actionness，而应学习 detector-specific value of observation：哪些时间片段会真正提升 detector 的边界定位、proposal ranking 和 high-IoU mAP。**

它和普通 `p_action` / actionness 选帧的区别应是：

`p_action` 只回答“这里像不像动作”；DUCA 应回答“看这个片段是否会改善 detector 的 proposal、边界、排序或背景抑制”。这才是 detector-utility calibrated acquisition 的核心。

它和普通 adaptive inference / frame selection / token pruning 的区别应是：

普通方法多优化分类准确率、token efficiency 或视觉冗余；DUCA 应显式绑定 TAD detector 的 proposal-level utility、TrueTime geometry、high-IoU localization 和 sparse ledger/runtime hard selector。

**CVPR 潜力取决于一个硬条件：teacher utility oracle 必须显著优于 uniform/random，并且 observable selector 能保留相当比例的 utility。**
如果 mAP 不提升，论文故事必须收缩为：一个严谨的 negative study / diagnostic framework，证明 actionness-based acquisition 不足，并提出 detector-utility evidence protocol，而不是声称 SOTA sparse TAD。

**4. dynamic gain calibration loss**

```python
def dynamic_gain_calibration_loss(pred_gain, teacher_gain, video_ids):
    # ranking within video
    rank_loss = pairwise_rank_loss(pred_gain, teacher_gain, group=video_ids)

    # calibration across videos
    gain_loss = torch.nn.functional.smooth_l1_loss(
        pred_gain, teacher_gain.clamp(min=-1.0, max=1.0)
    )

    # budget regularization
    entropy_loss = -selection_entropy(pred_gain)
    collapse_penalty = budget_collapse_penalty(pred_gain)

    return rank_loss + 0.5 * gain_loss + 0.05 * collapse_penalty - 0.01 * entropy_loss
```

```python
class SparseDetectorDistillLoss(nn.Module):
    def forward(self, sparse_outputs, dense_teacher_outputs, truetime_meta):
        loss_cls = kl_logits(
            sparse_outputs["proposal_logits"],
            dense_teacher_outputs["proposal_logits"],
            mask=truetime_meta["visible_or_transport_mask"],
        )
        loss_reg = boundary_distribution_loss(
            sparse_outputs["boundary_dist"],
            dense_teacher_outputs["boundary_dist"],
            truetime_meta,
        )
        loss_quality = smooth_l1(
            sparse_outputs["proposal_quality"],
            dense_teacher_outputs["proposal_quality"],
        )
        loss_rank = proposal_rank_distill_loss(
            sparse_outputs["ranking_scores"],
            dense_teacher_outputs["ranking_scores"],
        )
        return loss_cls + loss_reg + loss_quality + loss_rank
```

```python
def validate_metric_claim(packet):
    required = [
        "repo_sha",
        "config_sha256",
        "checkpoint_sha256",
        "dataset_sha256",
        "ledger_sha256",
        "eval_command",
        "mAP_by_tIoU",
        "compute_accounting",
    ]
    for k in required:
        if not packet.get(k):
            raise ValueError(f"metric claim missing {k}")

    if packet.get("precheck_only"):
        raise ValueError("PRECHECK_ONLY result cannot unlock mAP claim")

    if packet.get("uses_placeholder_evidence"):
        raise ValueError("placeholder evidence cannot unlock claim")

    if packet.get("split") not in {"val", "test"}:
        raise ValueError("invalid eval split")
```
