# 2. 一页式执行结论

## 唯一裁决

`DESIGN_PROPOSAL`

**选择路线 C：统一层级模型。**

外层在训练期锁定的平均端到端预算下，独立为每个视频分配 (K_v)；内层在原始物理时间上执行定位保持、严格 exact-(K_v)、嵌套的帧传输。

动态 (K) 应成为论文主模型的必要组成部分，但论文创新不能写成“我们首次使用动态 (K)”或“评分器加 ILP”。真正可辩护的中心必须升级为：

> **在预注册的平均端到端成本和逐视频定位风险约束下，学习嵌套的物理时间观测阶梯；以多尺度硬反事实估计新增真实帧对分类、边界回归和高 tIoU 区间的保守边际价值，并用训练期锁定的对偶价格决定每个视频何时停止观测。**

我建议把胜出方法暂称为：

## **DUCA-METER**

### Marginal Evidence Transport with Endpoint Risk

其核心不是“预测哪里密集”，而是：

[
\boxed{
\text{hard marginal detection value}
+
\text{paired-boundary risk}
+
\text{physical-time transport}
+
\text{batch-independent budget stopping}
}
]

## 动态 (K) 的地位

`DESIGN_PROPOSAL`

动态 (K) 不能被预先降级为附录，也不能无条件保留。它必须通过四个停止门：

1. **Oracle headroom 门**：真实 per-video 动态预算在匹配平均成本下，必须明显优于最佳固定 (K)。
2. **边际效用可预测门**：评分器必须在多尺度硬 swap 上预测真实离散收益，而不只是相关于 actionness。
3. **定位风险门**：动态方法必须修复宽双边界支持和最大空洞，而非进一步恶化。
4. **真实成本门**：加入 probe、评分器、求解器、padding 和视频解码后，必须仍有端到端节省。

若任一决定性门失败，正确动作不是把动态 (K) 偷偷放进附录，而是**停止“动态预算是主创新”的当前路线**。

## 最终项目状态

[
\boxed{\textbf{重大重构后继续}}
]

不是“继续把当前 density transport 调好”，而是推翻当前以局部密度富集为中心的目标，重建为**风险约束的边际时序证据分配**。

# 3. 当前模型为什么还不是 CVPR 方法

## 3.1 它还没有解决一个 TAD 特有的问题

`DOCUMENTED_RESULT`

当前选择器能提高动作内部富集和局部边界邻域命中，却降低宽范围双端支持并增大最大时间空洞。这个结果说明当前目标更接近：

[
\text{找到动作相关帧}
]

而不是：

[
\text{以有限物理观测保持完整区间的可定位性}
]

对 TAD 而言，动作内部的高 actionness 不能替代起点和终点的成对证据。一个只看到动作中段的采样器可能改善分类，却会系统性损害高 tIoU 定位。

## 3.2 “密度预测 + 累积分布逆采样”不足以构成主创新

`PAPER_FACT`

MGSampler 已经使用运动显著性构造累积运动分布，并按该分布进行覆盖式采样；它强调 motion-sensitive 与 motion-uniform，且作为可插入现有视频模型的采样器提出。因而，神经网络输出一条密度，再通过 inverse-CDF/systematic sampling 取点，天然会被审稿人视为 MGSampler 的任务化变体。 ([Open Access CVF][3])

`DESIGN_PROPOSAL`

DUCA 的创新不能位于“如何把一条密度变成 (K) 个点”；必须位于：

* 密度之外的**集合边际效用**；
* 起点—终点的**互补而非独立支持**；
* 非均匀采样下的**物理时间失真约束**；
* 在动态预算下的**风险满足后停止**。

## 3.3 动态 (K) 本身也不新

`PAPER_FACT`

AdaFrame 已经针对视频识别预测“继续看更多帧”的未来效用，并进行输入自适应的停止与 lookahead；AdapTok 已经预测多预算质量并在总体平均 token 预算下进行整数分配；EVATok 进一步学习最佳 token assignment 和轻量 router；A-ViT、DynamicViT 等则在网络内部进行自适应 token halting/pruning。 ([Open Access CVF][4])

因此，论文绝不能声称：

> “首次对视频进行动态预算。”

最小可辩护命题必须是：

> **首次把动态物理帧预算写成高 tIoU 定位风险下的边际证据分配，并同时解决视频级预算和帧级位置。**

## 3.4 当前连续代理没有连接到真实硬收益

`DOCUMENTED_RESULT`

当前贡献蒸馏、ST 或软分数尚未证明能预测真实帧组被替换后的检测变化。一帧 swap 对长视频太局部，且噪声可能大于效应。没有多尺度硬反事实证据，不能使用“task-aware”“detector-utility-aligned”或“end-to-end learned sampling”作为强 claim。

## 3.5 当前物理时间合同仍不完整

`CODE_FACT`

当前路径先在 selected-axis 上 NMS，再映回物理时间。即使修正顺序，仍有更深层问题：未修改的检测器在 selected-axis 上进行卷积、特征金字塔和边界回归，内部默认相邻位置具有近似均匀物理间隔。仅在输出端映回时间，不能自动修复内部时标扭曲。

`DESIGN_PROPOSAL`

因此，最大空洞、累计漂移和局部密度比必须成为硬约束。否则，“纯前置插件”与“高度非均匀采样”本身存在结构性冲突。

## 3.6 当前结果不构成公平论文证据

`DOCUMENTED_RESULT`

现有 (K=384) 与 (K=192) 都是 90 轮课程结果；干净 dense、50%、25% 均匀零点仍未恢复；没有正式动态 (K)；没有 matched average-budget 对照；没有真实成本。现在最多能写一份有价值的负结果诊断，不能写方法主表。

# 4. AdapTok 正文、补充材料和代码的完整逆向工程

## 4.1 表征结构：块因果、1D 潜在序列和随机尾部丢弃

`PAPER_FACT`

AdapTok 将 (16\times128\times128) 视频按 (4\times8\times8) patch 划分，形成 1024 个视频 patch，再用可学习 latent queries 把每个时间块编码为一维潜在 token 序列。编码器、解码器和评分器采用 block-causal attention：当前块可以访问当前及过去块，而不能访问未来块。 ([arXiv][5])

`PAPER_FACT`

训练时，每个块随机采样保留长度 (\ell_i)，只保留该块前 (\ell_i) 个 latent token，尾部全部丢弃。正式实验使用 4 个块、每块最多 512 个 token，保留长度来自截断高斯：

[
\ell_i\sim\operatorname{TruncNormal}
(\mu=256,\sigma=128,[32,512]).
]

同一 tokenizer 因而被迫让较短前缀形成粗表示、后续 token 逐步补充细节。 ([arXiv][5])

`CODE_FACT`

代码中同时存在均匀采样版本 `_left_masking_by_group` 和实际启动脚本使用的截断高斯版本 `_left_masking_by_group_normal`。两者都构造严格左前缀 mask；`diff_batch=False` 时，同一个 mask 会复制给整个 batch，`diff_batch=True` 时才逐样本生成。

`PAPER_FACT`

附录图 7 和图 12 表明早期 token 更偏全局结构，后期 token 更偏局部细节；但这只是经验可视化，并不是“任何更长前缀必然带来更高质量”的定理。事实上，表 4 中在 1024-token 条件下，单独加入随机 mask sampler 的 rFVD 从 37.13 恶化到 38.79，只有再加自适应评分器后才改善到 36.36。 ([arXiv][5])

### 对 DUCA 的含义

`DESIGN_PROPOSAL`

可迁移的不是“随机丢掉尾部帧”，而是：

> 构造同一视频的嵌套观测阶梯，使较小预算是较大预算的严格前缀或子集，从而能定义稳定的新增证据边际值。

物理帧不像 latent token。新增 latent token 主要细化表征；新增真实帧还会改变检测器输入长度、邻接关系和物理时间映射。因此，DUCA 必须显式约束时间几何，而不能机械复制 tail drop。

## 4.2 真实多预算质量标签如何生成

`PAPER_FACT`

AdapTok 的 scorer 并不是用重建网络的梯度或 attention 当“贡献”。它在每次训练中随机选一个目标块 (q)，复制 latent 表征，对该块施加一组不同前缀长度 mask，分别解码，并计算目标块的感知重建损失。该组真实损失形成不同 token 数的质量曲线 (s(\ell))。评分器预测整个曲线，并用 MSE 拟合。 ([arXiv][5])

`CODE_FACT`

`AdapTokScoreLabeler.get_scores_from_tokenizer` 遍历候选 token 数；`get_scores_by_fixed_toks` 固定前缀 mask，完整解码视频，只在对应目标时间块计算 MSE、LPIPS、PSNR、SSIM 及判别器输出。

`CODE_FACT`

代码支持两种 scorer 训练：

* `_train_scorer_step`：从磁盘读取预生成并标准化的 score 曲线，用 MSE 训练 scorer；
* `_train_online_scorer_step`：随机选块，将同一 latent 复制成多个候选预算，执行多次 decoder forward，在线生成感知损失标签，再拟合 scorer。

实际公开启动脚本覆盖配置为 `train_online_scorer` 和 `perceptual`。

### 对 DUCA 的含义

`DESIGN_PROPOSAL`

AdapTok 最值得迁移的原则是：

> **预算评分器必须由不同硬预算下的真实任务结果监督，而不是由连续分数自我蒸馏。**

但 DUCA 的标签不能是重建 LPIPS。必须是成组真实换帧后产生的：

[
\Delta L_{\mathrm{cls}},\quad
\Delta L_{\mathrm{reg}},\quad
\Delta \mathrm{Recall}*{\tau},\quad
\Delta R*{\mathrm{pair}},\quad
\Delta U_{\mathrm{high\text{-}tIoU}}.
]

---

## 4.3 `TransformeScorer` 的输入输出

`CODE_FACT`

`TransformeScorer` 将连续 latent 与量化 latent 在通道维拼接，通过线性投影、可学习位置编码和多层 Transformer，再输出每个候选 token 长度对应的标量。输出按 `step` 下采样，因此 scorer 实际预测的是离散预算网格，而非每一个 token 数。

`CODE_FACT`

`AdapTok.decode_scorer` 会先按当前 latent mask 将连续和量化 latent 清零，并构造对应 attention mask，然后调用 scorer。其预测值是重建损失，数值越低越好。

`DESIGN_PROPOSAL`

DUCA 不应只输出单一“总检测质量”。建议输出多头曲线：

[
\widehat{\Delta U}^{\mathrm{cls}}*{v,m},\quad
\widehat{\Delta U}^{\mathrm{reg}}*{v,m},\quad
\widehat{\Delta U}^{\mathrm{prop}}*{v,m},\quad
\widehat{\Delta R}^{\mathrm{pair}}*{v,m},\quad
\widehat{\sigma}_{v,m}.
]

高 tIoU 风险应作为硬约束或风险上界，而不是被一个大权重揉进总分。

## 4.4 IPAL/ILP 的实际作用域

`PAPER_FACT`

论文公式在一个固定时间块内，对当前 mini-batch 的每个样本选择一个 token 数，约束所有样本 token 总数等于：

[
|\mathcal B|\times N_b.
]

因此，“global”指的是**当前块、当前 mini-batch 内跨样本联合分配**，不是跨整个测试集，也不是一次联合优化所有时间块。 ([arXiv][5])

`CODE_FACT`

`solve_ilp_min` 输入形状为 (N\times K) 的预测损失矩阵，为每一行建立一个 one-hot 二元选择变量，同时强制所选列索引之和等于目标预算；使用 PuLP CBC 求解。

`CODE_FACT`

`AdapTok.encode_eval` 依次处理每个时间块：先根据之前块的已分配长度形成 mask，再预测当前块的质量曲线，随后对当前 mini-batch 调用 `solve_ilp_min`。所以预算结果依赖当前 batch 中有哪些视频。

### 直接答案

[
\boxed{
\text{IPAL 的真实分配作用域是：固定 block }\times\text{当前 mini-batch}
}
]

不是数据集级，不是单视频独立，也不是全视频所有块的一次性联合 ILP。

---

## 4.5 Fixed、BiThr、BiDelta、ILP

`PAPER_FACT`

* **Fixed**：所有样本和块使用相同 token 数。
* **BiThr**：寻找绝对质量阈值，每个样本选使预测损失低于阈值的最小 token 数，再通过二分使平均预算匹配。
* **BiDelta**：对相邻预算预测损失的差分做阈值，近似“新增 token 的边际收益”。
* **ILP/IPAL**：直接在 batch 内求解最小总预测损失的离散分配。

附录算法 2 给出了 BiThr/BiDelta，表 6 在相同平均 token 数下报告 ILP 最好，BiDelta 次之，BiThr 更差。 ([arXiv][5])

`PAPER_FACT`

表 6 的 rFVD 分别约为：

[
\text{Fixed}=38.79,\quad
\text{BiThr}=42.12,\quad
\text{BiDelta}=38.13,\quad
\text{ILP}=36.36.
]

这说明边际差分比绝对阈值更合理，但预测全曲线后联合分配仍更强。 ([arXiv][5])

### 对 DUCA 的裁决

`DESIGN_PROPOSAL`

“检测质量曲线 + ILP”必须作为**AdapTok-style direct transfer baseline**，不能作为 DUCA 的核心创新。

DUCA 主方法必须替换其中三点：

1. 标量重建质量 → 分类/回归/高 tIoU/双端风险分解；
2. batch ILP → 训练集校准、测试逐视频独立的对偶价格；
3. latent token 数 → 外层视频预算和内层物理帧位置的双层问题。

---

## 4.6 感知损失为何在 AdapTok 中合理，但不能迁移为 TAD 效用

`PAPER_FACT`

表 7 比较 SSIM、PSNR、MSE 和 perceptual loss。感知损失在 rFVD 和 LPIPS 上总体最好，但各指标往往在自身对应评价量上更有优势。论文并未证明感知损失是一般意义上的最优“信息价值”。 ([arXiv][5])

`DESIGN_PROPOSAL`

这对 DUCA 的启示不是“寻找一个更好的单一检测 loss”，而是：

* 分类和边界回归贡献必须分开；
* 非可微的高 tIoU 命中和提议召回必须通过硬反事实测量；
* 双边界风险应优先作为可行性约束；
* 总分只用于风险满足后的预算排序。

---

## 4.7 训练和推理的真实额外成本

`PAPER_FACT`

论文附录表 8 报告 tokenizer 为 195M 参数、训练 250 轮、32 GPU、112 小时；scorer 为 89M 参数、训练 20 轮、32 GPU、9 小时。 ([arXiv][5])

`UNRESOLVED`

公开 scorer 启动脚本写的是 `max_epoch 150`，而论文表 8 报告 20 轮。可能存在最佳 checkpoint、外部覆盖或最终实验脚本差异；固定代码本身没有充分信息解释这一差异。

`PAPER_FACT`

IPAL 的开销并非始终“可忽略”：平均 512 token 时，batch size 8 的 IPAL 时间约占总推理时间 42.2%；batch size 128 时约为 15.8%。平均 1024 token 时也呈相似趋势。 ([arXiv][5])

`CODE_FACT`

`decode_with_drop` 会把变长 token 序列整理并补齐到当前 batch 的最大有效长度，然后再调用 decoder。这意味着平均 token 数下降不必然带来与其成比例的实际批处理节省。

`DESIGN_PROPOSAL`

DUCA 必须报告：

[
C_{\mathrm{total}}=
C_{\mathrm{decode}}
+C_{\mathrm{probe}}
+C_{\mathrm{selector}}
+C_{\mathrm{solver}}
+C_{\mathrm{backbone}}
+C_{\mathrm{detector}}
+C_{\mathrm{padding}}.
]

只报告平均 (K) 或理论 GFLOPs 不足以支持效率 claim。

# 5. AdapTok 对 DUCA 的启发、竞争、不可迁移假设和新颖性红线

## 5.1 迁移矩阵

| AdapTok 机制    | DUCA 候选对应物                            |       可直接借鉴？ | 必须改写的原因                          | 可形成的新命题      |
| ------------- | ------------------------------------- | -----------: | -------------------------------- | ------------ |
| 随机尾部 token 丢弃 | mixed-(K) 训练                          |           部分 | 帧位置和坐标随 (K) 改变                   | 嵌套物理观测阶梯     |
| 嵌套 latent 前缀  | (S_{K_1}\subset\cdots\subset S_{K_m}) |            是 | 要加入覆盖与最大空洞                       | anytime 定位保持 |

| 因果 scorer     | cheap evidence scorer                 |      不必照搬因果性 | DUCA 是离线 TAD，可用全局 cheap evidence | 离线全局风险估计     |

| 全局平均 token    | 平均实际帧/成本                              |            是 | 必须包含 probe、padding、I/O           | 完整端到端成本约束    |

| 块级 token 分配   | 视频级预算 + 帧级位置                          |            否 | AdapTok 不选择真实时间位置                | 双层时域分配       |

## 5.2 哪些机制已经被 AdapTok 占据

`PAPER_FACT`

AdapTok 已经占据以下抽象：

[
\text{多预算质量标签}
\rightarrow
\text{质量曲线评分器}
\rightarrow
\text{离散平均预算优化}.
]

因此，DUCA 若仅把 LPIPS 换成检测 loss，把 token 数换成帧数，再运行 ILP，审稿人完全有理由称之为**任务平移**。 ([arXiv][5])

`PAPER_FACT`

EVATok 又进一步占据了“估计最佳 token assignment、训练轻量 router、在生成质量和 token 成本之间分配预算”的空间；MeToM 则已占据“利用 codec metadata、免训练地进行逐帧动态 token 分配”的一部分空间。简单 router 或简单 codec-complexity 动态预算也不能成为 DUCA 的中心。 ([Open Access CVF][6])

## 5.3 不可迁移的核心假设

`DESIGN_PROPOSAL`

以下 AdapTok 假设不能直接用于 DUCA：

1. **重建质量近似随 token 数平滑改善**；检测结果可能因候选匹配和 NMS 发生离散跳变。
2. **latent token 是可排序的粗到细表示**；真实帧的价值由其物理位置决定。
3. **增加 token 不改变时间坐标系**；增加帧会改变 selected-axis 与物理时间映射。
4. **单块质量可局部计算**；动作起点和终点可能跨很远时间，具有非局部互补性。
5. **batch 内联合预算可部署**；TAD 服务不应因同批其他视频改变某个视频的 (K)。
6. **因果 scorer 是必要属性**；DUCA 主任务是离线 TAD，强制因果反而会丢失全局 cheap evidence。
7. **padding 到 batch 最大长度仍能带来足够收益**；重型视频骨干的真实吞吐可能严重受 padding 影响。

## 5.4 新颖性红线

`DESIGN_PROPOSAL`

以下内容必须放入 baseline 或 related work，不能写成自己的核心创新：

* mixed-(K) 或随机预算训练；
* 多预算 scalar quality scorer；
* BiThr/BiDelta；
* test-batch ILP；
* inverse-CDF/systematic sampling；
* 单纯 motion/scene-complexity 动态预算；
* Transformer token pruning/halting；
* “简单视频少看、困难视频多看”。

可保留为 DUCA 独占中心的只有：

[
\boxed{
\begin{aligned}
&\text{硬反事实的 TAD 边际证据价值}\
+&\text{起点—终点成对风险}\
+&\text{非均匀物理时间失真约束}\
+&\text{测试批次无关的动态停止}\
+&\text{外层预算与内层位置的统一层级求解}
\end{aligned}
}
]

## 5.5 为什么 AdapTok 能被 CVPR 2026 接收

`PAPER_FACT`

AdapTok 的创新密度来自一个完整闭环，而不是单独的 ILP：

* 适配可变长度的 block-causal 1D tokenizer；
* tail-drop 训练；
* 多预算真实重建标签；
* causal scorer；
* IPAL；
* reconstruction 与 AR generation 两条下游证据；
* Fixed/BiThr/BiDelta/ILP 对照；
* 训练和推理成本分析。

它在低 token 区间的改善尤其明显；同时，表 4 也诚实展示了 tail-drop 在较高预算下单独使用可能变差。 ([arXiv][5])

`UNRESOLVED`

其最弱环节是 batch-dependent allocation、额外 scorer/label 成本、变长 padding 和对重建质量代理的依赖。这些弱点恰好应成为 DUCA 的设计分界，而不是被复制。

# 6. 重新定义后的论文问题与中心命题

## 6.1 真正值得发表的科学问题

`DESIGN_PROPOSAL`

当前最强问题定义不是：

> 如何从长视频中选择重要帧？

而是：

> **在预注册的平均端到端计算预算和逐视频最大预算下，如何估计每一组新增真实观测对时域动作检测的边际价值，并在不破坏成对边界、最大空洞和物理时间连续性的前提下，同时决定每个视频看多少帧以及看哪些帧？**

这一定义包含四个 TAD 特有要素：

1. **区间而非标签**：必须同时支持 start 和 end。
2. **高 tIoU 风险**：局部动作富集不足以保证精确定位。
3. **物理时间度量**：非均匀采样会扭曲检测器内部时标。
4. **集合互补性**：起点帧和终点帧联合有价值，单独一个可能价值很低。

## 6.2 动态 (K) 为什么不是普通超参数

`DESIGN_PROPOSAL`

固定 (K) 假设每个视频的边际收益曲线相同。动态 (K) 的科学问题是：

[
\Delta U_v(K)
=============

U_v(K+\Delta K)-U_v(K)
]

是否随视频内容、动作数量、动作时长、边界模糊度和背景结构显著变化。

若不同视频的 (\Delta U_v(K)) 基本相同，动态 (K) 没有必要；若差异显著，固定 (K) 会把帧浪费在已经饱和的视频上，同时让高边界风险视频预算不足。

因此，动态 (K) 的必要性必须由 **Oracle headroom + utility heterogeneity** 证明，而不能由直觉宣布。

## 6.3 中心命题

`DESIGN_PROPOSAL`

> **DUCA-METER 将离线 TAD 的帧压缩重写为定位风险约束下的边际物理证据分配：模型构造可随时截断的嵌套帧阶梯，以训练视频上的多尺度硬换帧结果监督新增帧价值，并使用预先校准的对偶价格独立决定每个视频的停止预算；固定 (K)、动态 (K) 和免训练模式仅对应不同的预算制度或效用来源。**

## 6.4 “纯前置插件”的严格定义

`DESIGN_PROPOSAL`

允许的主链为：

[
\text{raw video}
\rightarrow
\text{cheap evidence}
\rightarrow
(K_v,S_v)
\rightarrow
\text{unchanged backbone/detector/head}
\rightarrow
\text{raw selected-axis proposals}
\rightarrow
\text{physical-time remap}
\rightarrow
\text{unchanged official NMS}.
]

必须区分：

* **架构兼容的 task-adapted plugin**：允许训练 selector 和重新训练检测器权重，但不改结构与损失；
* **严格 plug-and-play**：冻结检测器，selector 不使用目标标签；
* **非插件**：向检测器注入专用时间编码、修改 head、修改 loss 或定制 NMS。

输出坐标适配是必要接口，不是后端方法创新；但只有在 selected-axis 扭曲被硬约束时，才有资格声称插件对检测器假设近似透明。

# 7. 十二条实质不同的候选模型路线

## R1：边际检测效用传输

`DESIGN_PROPOSAL`

中心：直接预测从 (K_m) 增加到 (K_{m+1}) 的真实检测收益。

[
\widehat{\Delta U}_{v,m}
========================

g_\phi(z_v,S_v(K_m),S_v(K_{m+1})).
]

(K_v) 由 (\widehat{\Delta U}/\Delta C) 与对偶价格比较产生；位置由受约束集合求解器产生。监督来自多尺度硬 swap。固定 (K) 通过锁定预算退化得到；免训练模式可用无标签 proxy 替换 (g_\phi)。

与 AdapTok 的重合在“质量曲线”，区别在真实检测反事实、物理帧和双端风险。最可能提高平均 mAP/Pareto；最可能失败于 utility rank 不可预测。最小证伪：Oracle 动态预算有头room，但 scorer rank correlation 不显著。成本中等。

## R2：高 tIoU 风险约束分配

`DESIGN_PROPOSAL`

中心：不直接最大化平均收益，而是最小化成本，使预测失败风险低于阈值：

[
K_v^\star
=========

\min_K C_v(K)
\quad
\text{s.t.}\quad
\widehat{\Pr}(\mathrm{tIoU}<\tau\mid z_v,S_v(K))
\le\epsilon.
]

位置由降低高 tIoU 风险的内层求解器产生。监督是边界误差、提议命中和高 tIoU 失败。固定 (K) 是去掉停止规则；零样本可用几何上界，但任务风险需要监督。

与 AdapTok 区分度高，TAD 特异性强。最可能改善 mAP@0.6/0.7；失败点是风险校准困难。最小证伪：预测风险 ECE 高、风险满足视频仍频繁高 tIoU 失败。成本中等。

## R3：边界对覆盖模型

`DESIGN_PROPOSAL`

学习起点—终点联合分布：

[
\hat q_v(a,b\mid z_v),\qquad a<b,
]

并最小化：

[
R_{\mathrm{pair}}(S)
====================

\mathbb E_{(a,b)\sim\hat q_v}
\left[
\rho(d(a,S))+
\rho(d(b,S))+
\eta\rho(\max(d(a,S),d(b,S)))
\right].
]

(K) 由尚未覆盖的边界对概率质量决定，位置由成对覆盖 DP 产生。它直接解释“动作内部富集但宽双端恶化”。失败点是 cheap evidence 无法可靠预测边界对。最小证伪：pair-risk 与真实双端支持无相关。成本中等。

## R4：主动感知/信息价值停止

`DESIGN_PROPOSAL`

从小预算开始，逐轮揭示帧：

[
\mathrm{VOI}_{v,m}
==================

\mathbb E[
H(p(y,\mathcal I)\mid S_m)
--------------------------

H(p(y,\mathcal I)\mid S_{m+1})
].
]

当 VOI 低于成本且定位风险满足时停止。帧位置由最大后验信息增益选择。与 AdaFrame 的自适应 lookahead 高度相关，但目标改为区间后验。

高风险在于需要多轮推理或强后验模型，真实时延可能抵消节省。最小证伪：主动多轮成本超过一次性重骨干节省。暂不作为主方法。

## R5：嵌套多分辨率时间格

`DESIGN_PROPOSAL`

构造优先序列 (\pi_v)，使：

[
S_v(K_m)={\pi_{v,1},\ldots,\pi_{v,K_m}},
\qquad
S_v(K_m)\subset S_v(K_{m+1}).
]

可用 dyadic interval refinement 或 constrained insertion。动态 (K) 只截断同一阶梯，不重新替换帧。监督可来自任意 utility/risk 头。

它提供 anytime、一致边际、mixed-(K) 和缓存复用，但单独不构成足够新颖的方法。最小证伪：嵌套约束显著损害同预算性能且不能换来动态稳定性。成本低，作为主方法基础设施保留。

## R6：潜变量预算后验与 CVaR

`DESIGN_PROPOSAL`

学习：

[
q_\phi(K_v\mid z_v),
]

并最小化成本加尾部风险：

[
\mathbb E[D_v]
+
\beta\operatorname{CVaR}_{q}
(D_v)
+
\lambda\mathbb E[C_v].
]

预算来自后验采样或 MAP，位置由固定内层 selector。适合表达预算不确定性，但容易退化成一般动态计算方法。最小证伪：后验熵与真实预算错误无关，CVaR 不改善长尾高 tIoU。成本中等偏高。

## R7：次模集合效用与背包优化

`DESIGN_PROPOSAL`

定义覆盖减冗余集合函数：

[
F_v(S)=
\sum_t \max_{s\in S}w_v(t,s)
----------------------------

\gamma\sum_{s\ne s'}\operatorname{sim}(s,s').
]

若 (F) 单调次模，可用贪心获得 (1-1/e) 近似。动态 (K) 由边际收益与价格停止。

问题是成对边界具有互补性：只有同时观察 start 和 end 才产生高价值，这常违反次模的边际递减假设。最小证伪：实测大量正互补，次模不等式高频失败。作为理论对照，不作主方法。

## R8：双层动态规划/最优传输

`DESIGN_PROPOSAL`

外层选择 (K_v)，内层在时间有序图上求：

[
S_v^\star(K)
============

\arg\max_{S\in\mathcal F_v(K)}
M_v(S)-\alpha R_v(S).
]

内层可用 min-cost flow 或带最大间隔状态的 DP；外层使用对偶价格。它能严格实现 exact-(K)、密度上下界、累计漂移和最大间隔。

若没有 TAD 特有 utility/risk，它只是通用求解器，接近 AdapTok/最优传输工程。作为胜出方法的求解骨架保留，不单独作为贡献。

## R9：严格免训练风险感知动态预算

`DESIGN_PROPOSAL`

只使用 codec residual、motion vector、场景变化、低分辨率时序新颖度和模糊度，构造：

[
U_v^0(K,S),\quad R_v^0(S).
]

不使用目标标签、检测器教师、特征缓存或验证集调参。预算和位置仍使用同一对偶与几何求解器。

MeToM 已占据 codec metadata 动态 token 分配，因此仅靠 metadata 不新；必须证明物理帧选择和双端风险对 TAD 的独特作用。最小证伪：不如匹配均匀采样。成本低，适合作为附加模式。

## R10：反事实联盟价值/Shapley 近似

`DESIGN_PROPOSAL`

将帧组视为 coalition，估计：

[
\phi(G)=
\mathbb E_{A}
[D(A)-D(A\cup G)].
]

它能捕捉边界对互补，理论上比单帧梯度可靠。预算由 coalition marginal value 停止，位置由高价值 coalition 组合。

最大问题是重骨干前向次数爆炸。最小证伪：低秩或 Monte Carlo 近似不能在可承受样本数下稳定排序。高风险高成本，仅用于小规模 Oracle 分析。

## R11：保形风险校准停止

`DESIGN_PROPOSAL`

在训练校准集上为 endpoint-risk 建立 conformal upper bound：

[
\overline e_v(K)
================

\hat e_v(K)+q_{1-\delta}.
]

当该上界足以满足目标 tIoU 且新增效用低于价格时停止。它提供可解释的风险覆盖声明和 batch-independent 预算。

风险是分布漂移和 action-duration 估计误差。最小证伪：校准集覆盖在测试分布严重失效。作为高风险高收益理论方向保留。

## R12：最坏情况定位失真鲁棒采样

`DESIGN_PROPOSAL`

不预测具体动作，而对任意可能边界最小化最坏距离：

[
\min_{S:|S|=K}
\max_{t\in[0,T_v]} d(t,S)
-------------------------

\eta M_v(S).
]

动态 (K) 取满足最大空洞或最短动作尺度要求的最小预算。它可以严格保证时间覆盖，是当前 density-collapse 的强纠偏。

缺点是过于保守，可能接近均匀采样。最小证伪：风险改善但始终不能提高任务 Pareto。作为保守备选的几何底座保留。

# 9. 胜出方法的完整数学定义

## 9.1 基本变量

`DESIGN_PROPOSAL`

对视频 (v)：

[
x_v={x_v(t)}_{t\in[0,T_v]},
]

候选物理时间网格：

[
\mathcal G_v=
{t_{v,1}<\cdots<t_{v,N_v}}.
]

cheap evidence：

[
z_v=h_\psi(x_v^{\mathrm{cheap}}).
]

候选预算集合：

[
\mathcal K=
{K_0<K_1<\cdots<K_M}.
]

嵌套选择集合：

[
S_v(K_m)\subset\mathcal G_v,\qquad
|S_v(K_m)|=K_m,
]

[
S_v(K_m)\subset S_v(K_{m+1}).
]

## 9.2 成本

[
C_v(K)=
C_v^{\mathrm{decode}}
+C_v^{\mathrm{probe}}
+C_v^{\mathrm{select}}
+C_v^{\mathrm{backbone}}(K)
+C_v^{\mathrm{detector}}(K)
+C_v^{\mathrm{padding}}(K).
]

`DESIGN_PROPOSAL`

论文主协议必须以测得的 (C_v(K)) 为准，而不是假定 (C\propto K)。帧数是解释变量，真实延迟、显存和能耗是效率证据。

## 9.3 任务效用

令检测风险为：

[
D_v(S)=
\widetilde L_{\mathrm{cls}}(S)
+\widetilde L_{\mathrm{reg}}(S)
+\widetilde L_{\mathrm{prop}}(S)
+\widetilde L_{\mathrm{high}}(S),
]

其中各项先按训练集 MAD 或 robust scale 标准化。

定义从预算级 (m-1) 增加到 (m) 的真实硬边际效用：

[
\Delta U_{v,m}
==============

## D_v(S_v(K_{m-1}))

D_v(S_v(K_m)).
]

模型预测：

[
\widehat{\Delta\mathbf U}_{v,m}
===============================

\left(
\widehat{\Delta U}^{\mathrm{cls}},
\widehat{\Delta U}^{\mathrm{reg}},
\widehat{\Delta U}^{\mathrm{prop}},
\widehat{\Delta U}^{\mathrm{high}}
\right),
]

并预测不确定性 (\widehat\sigma_{v,m})。

保守效用：

[
\underline{\Delta U}_{v,m}
==========================

\widehat{\Delta U}*{v,m}
-\kappa\widehat\sigma*{v,m}.
]

## 9.4 几何与双边界风险

定义最近观测距离：

[
d(t,S)=\min_{s\in S}|t-s|.
]

最大空洞：

[
g_{\max}(S)
===========

\max_i(s_{i+1}-s_i).
]

相对均匀量化点：

[
u_i(K)=
\frac{i-\frac12}{K}T_v.
]

累计漂移：

[
d_{\mathrm{drift}}(S)
=====================

\max_i
\left|
\frac{s_i}{T_v}
-\frac{i-\frac12}{K}
\right|.
]

cheap evidence 预测起点—终点联合分布：

[
\widehat q_v(a,b\mid z_v),\quad a<b.
]

双边界风险：

[
R_v^{\mathrm{pair}}(S)
======================

\mathbb E_{(a,b)\sim\widehat q_v}
\left[
\rho!\left(\frac{d(a,S)}{b-a}\right)
+
\rho!\left(\frac{d(b,S)}{b-a}\right)
+
\eta
\rho!\left(
\frac{\max{d(a,S),d(b,S)}}{b-a}
\right)
\right].
]

总几何风险：

[
R_v(S)
======

R_v^{\mathrm{pair}}(S)
+\gamma_g
\left[\frac{g_{\max}(S)}{T_v}-\bar g_K\right]*+^2
+\gamma_d d*{\mathrm{drift}}(S)^2
+\gamma_a R_v^{\mathrm{anchor}}(S).
]

## 9.5 推荐原始问题

`DESIGN_PROPOSAL`

相比“效用减风险罚项”，更推荐把关键几何风险写成硬约束：

[
\max_{{K_v,S_v}}
\sum_v
\left[
\widehat U_v(K_v,S_v)
-\kappa\widehat\sigma_v(K_v)
\right]
]

满足：

[
\frac1{|\mathcal V|}
\sum_v C_v(K_v)
\le B,
]

[
R_v^{\mathrm{pair}}(S_v)\le\epsilon_{\mathrm{pair}},
]

[
g_{\max}(S_v)\le G(K_v),
]

[
d_{\mathrm{drift}}(S_v)\le\delta(K_v),
]

[
S_v\in\mathcal F_v(K_v),\qquad
|S_v|=K_v,
]

[
K_{\min}\le K_v\le K_{\max}.
]

原因是当前负结果已经证明：若几何只是一项可交易的软惩罚，优化器会用双边界覆盖换取动作内部富集。

## 9.6 内层严格 (K) 传输

对每个候选预算：

[
S_v^\star(K)
============

\arg\max_{S\in\mathcal F_v(K)}
M_v(S)-\alpha R_v^{\mathrm{pair}}(S),
]

其中可行域包括：

[
\sum_{t\in\mathcal G_v}x_t=K,
]

[
\ell_j(K)
\le
\sum_{t\in I_j}x_t
\le
u_j(K),
]

[
g_{\min}(K)
\le s_{i+1}-s_i
\le g_{\max}(K),
]

[
|s_i-u_i(K)|\le\delta_i(K),
]

以及对高置信度边界锚点的距离约束。

`DESIGN_PROPOSAL`

求解采用**嵌套 constrained insertion DP/min-cost flow**：

1. 从最小预算的覆盖骨架开始；
2. 每一级只添加帧，不删除已有帧；
3. 按预测边际效用与边界风险降低选择新增帧组；
4. 在时间有序 DAG 中满足 gap、drift、density 和 exact-(K)。

## 9.7 外层对偶预算

总体分布式问题写为：

[
\max_\pi
\mathbb E_{v\sim P}
[J_v(K_v)]
\quad
\text{s.t.}\quad
\mathbb E_{v\sim P}C_v(K_v)\le B,
]

其中：

[
J_v(K)=
\widehat U_v(K,S_v^\star(K))
-\kappa\widehat\sigma_v(K)
-\alpha R_v(S_v^\star(K)).
]

拉格朗日对偶：

[
\min_{\lambda\ge0}
\left[
\lambda B
+
\mathbb E_v
\max_{K\in\mathcal K}
{J_v(K)-\lambda C_v(K)}
\right].
]

测试时逐视频独立：

[
K_v^\star
=========

\arg\max_{K\in\mathcal K}
\left[
J_v(K)-\lambda^\star C_v(K)
\right].
]

(\lambda^\star) 只在训练校准集上通过二分或一维搜索锁定。

# 10. 定理、证明草图和经验假设

## 命题 0：非平凡动态预算必须允许预算位于平均值两侧

`THEOREM_CANDIDATE`

若：

[
K_v\le \bar K\quad\forall v
]

且：

[
\mathbb E[K_v]=\bar K,
]

则：

[
K_v=\bar K\quad\text{几乎处处成立}.
]

证明：(\bar K-K_v\ge0)，但其期望为 0，因此该非负随机变量几乎处处为 0。

### 直接后果

若主平均预算是 384，而候选集合最大值也是 384，则所谓动态 (K) 必然退化为所有视频 (K=384)。

因此建议：

[
\mathcal K_{50}
===============

{256,320,384,448,512},
\qquad
\mathbb E[K]=384,
\qquad
K_{\max}=512.
]

25% 协议可用：

[
\mathcal K_{25}
===============

{128,160,192,224,256},
\qquad
\mathbb E[K]=192.
]

## 命题 1：测试 batch 组成不变性

`THEOREM_CANDIDATE`

若 (\lambda^\star) 在测试前固定，且：

[
K_v^\star=f(z_v;\lambda^\star)
]

只依赖视频自身，则任意 batch size、batch permutation 或其他同批视频都不会改变 (K_v^\star)。

证明直接来自函数的逐样本可分性。

这应作为论文正式命题，用来与 AdapTok batch ILP 区分。

## 命题 2：对偶价格的预算单调性

`THEOREM_CANDIDATE`

定义：

[
K_v(\lambda)
============

\arg\max_K[J_v(K)-\lambda C_v(K)],
]

并在并列时选择成本更低的解，则 (C_v(K_v(\lambda))) 关于 (\lambda) 单调不增。

证明可由 (\lambda_1<\lambda_2) 下两组最优不等式相加得到。

因此，可通过一维二分在训练校准集上寻找满足目标平均成本的 (\lambda^\star)。

## 命题 3：精确任意测试集平均预算与非平凡独立决策不可兼得

`THEOREM_CANDIDATE`

假设对任意可能测试集合 (\mathcal T)，都要求：

[
\frac1{|\mathcal T|}
\sum_{v\in\mathcal T}K_v=B
]

精确成立，同时 (K_v=f(v)) 独立于集合组成。取任意单元素集合 ({v})，即得：

[
f(v)=B,\quad\forall v.
]

因此，任何非平凡动态预算都不可能同时满足：

1. 对每个任意测试集合精确平均；
2. 每视频独立；
3. 非常数预算。

正式协议应要求训练校准的**期望预算**和测试实际预算容差，而不是测试 batch ILP 的精确预算。

## 命题 4：物理时间映射误差上界

`THEOREM_CANDIDATE`

设选中时间节点 (s_i) 与相同 rank 的参考均匀节点 (u_i) 满足：

[
|s_i-u_i|\le\delta,\quad\forall i.
]

对两组节点分别构造分段线性映射 (\Phi_S) 与 (\Phi_U)，则：

[
\sup_x|\Phi_S(x)-\Phi_U(x)|\le\delta.
]

证明：每个分段内两映射之差是端点误差的凸组合。

这说明累计漂移约束可以严格控制输出端坐标扭曲；但“检测器内部特征完全不受影响”仍是经验假设。

## 命题 5：端点误差与 tIoU 下界

`THEOREM_CANDIDATE`

真实区间长度为 (L)，若预测起点、终点的绝对误差均不超过 (\varepsilon<L/2)，则一个保守下界为：

[
\mathrm{tIoU}
\ge
\frac{L-2\varepsilon}{L+2\varepsilon}.
]

要保证 (\mathrm{tIoU}\ge\tau)，充分条件为：

[
\varepsilon
\le
\frac{L(1-\tau)}{2(1+\tau)}.
]

例如：

[
\tau=0.7
\Rightarrow
\varepsilon/L\le0.0882.
]

因此，高 tIoU 预算停止条件可以写成：

[
\overline\varepsilon_v(K)
\le
0.0882,\widehat L_{\min,v}
]

并同时要求最大空洞和双端支持约束满足。

## 命题 6：凹边际条件下的价格停止

`THEOREM_CANDIDATE`

若嵌套阶梯的保守效用增量满足边际递减：

[
\Delta J_{v,1}\ge\Delta J_{v,2}\ge\cdots,
]

且增量成本为正，则选择所有满足：

[
\frac{\Delta J_{v,m}}{\Delta C_{v,m}}\ge\lambda^\star
]

的前缀是对应拉格朗日子问题的最优解。

`EMPIRICAL_HYPOTHESIS`

检测效用不保证天然单调或凹。论文必须报告：

* 非单调视频比例；
* 边际递减违反率；
* 是否需要 isotonic/concave calibration；
* 校准前后决策变化。

不能把凹性写成未经验证的事实。

## 仍需实验验证的核心假设

`EMPIRICAL_HYPOTHESIS`

1. 多尺度硬 swap 的效用可由 cheap evidence 预测；
2. 视频之间确实存在足够大的最优预算差异；
3. 双边界风险头能修复宽双端支持；
4. 嵌套约束不会牺牲过多同预算性能；
5. bounded time warp 足以让未修改检测器适应非均匀输入；
6. 对偶价格在训练到测试分布间保持预算校准；
7. zero-shot proxy 与真实 TAD 效用存在稳定关系。

# 11. 总计 60 轮的训练算法与伪代码

## 11.1 预算集合与训练曝光

`DESIGN_PROPOSAL`

统一模型支持：

[
\mathcal K=
{128,160,192,224,256,320,384,448,512}.
]

每个 detector update 只抽取一个 (K) 运行重骨干，避免一次更新运行多个完整检测器。

训练预算分布：

* Epoch 1–20：在 (\mathcal K) 上近似均匀；
* Epoch 21–45：50% 均匀，50% 集中于 192/384 附近；
* Epoch 46–60：仍保留至少 30% 全预算覆盖，其余按部署目标分布采样。

这样同一个 60 轮模型支持固定 25%、固定 50% 和动态预算，不再需要 30+60 课程。

## 11.2 60 轮阶段

| 阶段             | Epoch | 作用                                                     |
| -------------- | ----: | ------------------------------------------------------ |
| 几何暖启动          |   1–8 | uniform nested skeleton，训练 detector 对 mixed-(K) 的基本稳定性 |
| 硬效用接入          |  9–20 | scorer 学习多尺度硬反事实，selector 不接 direct gradient           |
| 主联合训练          | 21–48 | mixed-(K)、硬 rank、pair-risk、检测损失联合                      |
| 冻结 selector 稳定 | 49–54 | 固定选择策略，继续训练 detector                                   |
| 终端稳定           | 55–60 | 固定训练合同，禁止中途挑 test checkpoint                           |

对偶价格 (\lambda^\star) 在 epoch 60 后，使用训练集预留 calibration split 锁定，不更新模型。

## 11.3 推荐总损失

不采用用户给出的全部六项。建议删除显式 `budget loss` 和 `nested loss`：

* 预算由对偶价格校准，不需要反向预算损失；
* 嵌套由结构硬保证，不需要软正则；
* direct gradient 默认关闭。

最终：

[
\mathcal L
==========

\mathcal L_{\mathrm{det}}
+
\lambda_\Delta\mathcal L_{\mathrm{hard\text{-}utility}}
+
\lambda_R\mathcal L_{\mathrm{pair\text{-}risk}}
+
\lambda_C\mathcal L_{\mathrm{curve\text{-}calibration}}
+
\mathbf 1_{G_{\mathrm{direct}}}
\lambda_D\mathcal L_{\mathrm{direct}}.
]

其中：

[
\mathcal L_{\mathrm{hard\text{-}utility}}
=========================================

\operatorname{Huber}
(\widehat{\Delta\mathbf U},\Delta\mathbf U)
+
\beta
\mathcal L_{\mathrm{pairwise\ rank}}.
]

[
\mathcal L_{\mathrm{pair\text{-}risk}}
======================================

\operatorname{BCE/Focal}(\hat p^{s},p^{s})
+
\operatorname{BCE/Focal}(\hat p^{e},p^{e})
+
\operatorname{CE}(\hat q(a,b),q(a,b)).
]

[
\mathcal L_{\mathrm{curve\text{-}calibration}}
==============================================

\operatorname{Huber}
(\hat U(K),U(K))
+
\operatorname{NLL}(\hat U,\hat\sigma).
]

## 11.4 量纲和梯度路由

`DESIGN_PROPOSAL`

* 所有硬 utility 目标按训练集 MAD 标准化；
* cls/reg/proposal/pair-risk 分头预测，不用原始量级直接相加；
* detector 参数只接收 (\mathcal L_{\mathrm{det}})；
* utility/risk 头接收辅助损失；
* selector 的 direct detector gradient 只有在 (G_{\mathrm{direct}}) 通过后开放；
* 辅助梯度范数硬限制为 detector 主梯度范数的 25%；
* 若 raw contribution distillation 再次达到 5–6 而检测损失约为 (O(1))，直接视为门禁失败。

## 11.5 单步训练伪代码

```python
for step, batch in enumerate(train_loader):           # 总计 6000 次
    video, gt = batch

    # 1. 低成本全局证据
    z = cheap_probe(video)

    # 2. 一次构造完整嵌套阶梯
    ladder, utility_curve, pair_risk = selector(z)

    # 3. 每个 detector update 只采一个预算
    K = sample_mixed_budget(step)
    S = ladder[K]

    # 4. 主检测前向
    raw_proposals, det_losses = detector(video[S], gt)
    loss_det = normalized_detection_loss(det_losses)

    # 5. 低频硬反事实；主 S 的前向已可作为对照
    loss_aux = 0
    if step % 4 == 0:
        S_alt = matched_group_swap(
            S,
            scales=[1, 2, 4, 8, 16],
            preserve_geometry=True,
        )
        with no_grad():
            alt_outputs = detector(video[S_alt], gt)

        hard_target = decompose_hard_delta(
            main=raw_proposals,
            alternate=alt_outputs,
            components=[
                "classification",
                "boundary_regression",
                "proposal_recall",
                "high_tiou_hit",
                "paired_boundary_risk",
            ],
        )

        loss_aux = utility_and_risk_loss(
            prediction=(utility_curve, pair_risk),
            target=hard_target,
        )

    # 6. 受保护梯度路由
    total_loss = loss_det + projected_auxiliary_loss(
        loss_aux,
        max_aux_grad_ratio=0.25,
        direct_gradient_enabled=G_direct_passed,
    )

    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
```

`DESIGN_PROPOSAL`

硬反事实额外前向发生在 25% 更新上，因此约增加 25% 的训练重前向成本。该成本必须在训练成本表中单列；不能像 AdapTok 一样只展示 scorer 很轻，而忽略标签生成。

## 11.6 checkpoint 和评估规则

`DESIGN_PROPOSAL`

* 所有正式模型 60 轮、6000 次成功 detector updates；
* 验证只在 epoch 20、40、60 运行；
* 主结果固定使用 epoch 60 terminal checkpoint；
* 禁止在测试集挑中间轮次；
* 每个模型只运行一次正式 test；
* 所有 arms 使用相同增强、优化器、学习率、更新数和评估次数；
* 90 轮历史结果单列为 diagnostic，不进入主表。

# 12. 动态预算推理算法与伪代码

## 12.1 主推理协议

```python
# 训练期已经锁定：
# lambda_star, candidate_K, cost_table, risk_thresholds

def infer_video(video):
    # 1. 与 K 无关的低成本证据
    z = cheap_probe(video)

    # 2. 一次生成所有预算共享的嵌套阶梯和效用曲线
    ladder = nested_selector(z)
    utility, uncertainty = utility_head(z, ladder)
    pair_risk = boundary_risk_head(z, ladder)

    candidates = []

    for K in candidate_K:
        S = ladder[K]

        feasible = (
            pair_risk[K] <= PAIR_RISK_MAX
            and max_gap(S) <= MAX_GAP[K]
            and cumulative_drift(S) <= DRIFT_MAX[K]
            and len(S) == K
        )

        if feasible:
            robust_value = (
                utility[K]
                - KAPPA * uncertainty[K]
                - lambda_star * measured_cost(K)
            )
            candidates.append((robust_value, K, S))

    # 3. 风险全部不可行时，回退 Kmax 而不是偷偷修补
    if not candidates:
        K = max(candidate_K)
        S = ladder[K]
    else:
        _, K, S = max(candidates, key=lambda x: x[0])

    # 4. 只对 exact-K 原始帧运行重骨干与原检测器
    raw_segments, scores, labels = detector.raw_forward(video[S])

    # 5. 在 NMS 前映回原物理时间
    physical_segments = map_selected_axis_to_physical_time(
        raw_segments,
        selected_times=S,
    )

    # 6. 完全未修改的官方 NMS
    detections = official_nms(
        physical_segments,
        scores,
        labels,
    )

    return detections, {
        "K": K,
        "selected_times": S,
        "probe_cost": measured_probe_cost(),
        "solver_cost": measured_solver_cost(),
    }
```

## 12.2 复杂度

`DESIGN_PROPOSAL`

* cheap probe：(O(N_vd))；
* 嵌套 selector：目标为 (O(N_vd+K_{\max}\log N_v))；
* 有界 DP/min-cost flow：最坏 (O(K_{\max}N_vW))，其中 (W) 是最大允许前驱窗口；
* 外层预算：(O(|\mathcal K|))；
* 重骨干：只运行一次，输入 (K_v) 帧；
* 不运行 test-batch ILP；
* 不为每个候选 (K) 重跑 backbone。

## 12.3 变长批处理

`DESIGN_PROPOSAL`

正式实现必须使用：

* 按 (K) 分桶；
* ragged batch；
* 或将 padding 限制在小区间。

应额外报告：

[
\text{padding ratio}
====================

\frac{\text{实际计算的 padded 帧总数}}
{\sum_v K_v}.
]

若 padding ratio 高到使动态方法与 (K_{\max}) 近似等价，则动态计算 claim 失败。

# 14. 多尺度硬反事实与 (G_{\mathrm{rank}}/G_{\mathrm{direct}}) 证明方案

## 14.1 扰动尺度分布

`DESIGN_PROPOSAL`

建议尺度抽样概率：

| (\Delta K) |   概率 |
| ---------: | ---: |
|          1 | 0.10 |
|          2 | 0.10 |
|          4 | 0.25 |
|          8 | 0.30 |
|         16 | 0.25 |

理由：

* 单帧只保留 10%，用于局部灵敏度；
* 4–8 帧最接近可观测的结构变化；
* 16 帧用于检测长区间覆盖变化；
* 避免结论完全由单帧噪声支配。

在每个尺度内：

* 30% 独立高/低分帧交换；
* 25% 连续短片段替换；
* 25% 起点—终点配对替换；
* 10% 动作内部 ↔ 背景替换；
* 10% matched random。

所有主要对比要求保持：

[
|S|,\quad
g_{\max},\quad
d_{\mathrm{drift}}
]

尽量匹配，从而把“任务效用”与“几何变化”分离。

## 14.2 五类真实硬目标

`DESIGN_PROPOSAL`

1. 总检测损失变化：
   [
   \Delta L_{\mathrm{det}}.
   ]

2. 分类与边界回归分别变化：
   [
   \Delta L_{\mathrm{cls}},
   \quad
   \Delta L_{\mathrm{reg}}.
   ]

3. 提议和高 tIoU：
   [
   \Delta\mathrm{Recall}@\tau,
   \quad \tau\in{0.5,0.6,0.7}.
   ]

4. 双端风险：
   [
   \Delta R_{\mathrm{pair}},
   \quad
   \Delta d_{\mathrm{start}},
   \quad
   \Delta d_{\mathrm{end}}.
   ]

5. 预算 regret：
   [
   \mathrm{Regret}_v(K)
   ====================

   ## U_v(K,S_v^{\mathrm{oracle}})

   U_v(K,S_v^{\mathrm{pred}}).
   ]

第五类比现有贡献蒸馏更可靠，因为它直接衡量当前 selector 相对可达 hard alternative 的损失。

## 14.3 视频级交叉拟合

`DESIGN_PROPOSAL`

训练视频划分为 5 folds：

1. 在 4 folds 上训练 utility/risk scorer；
2. 在第 5 fold 上生成硬扰动并评估 rank；
3. 循环五次；
4. 汇总只使用 out-of-fold prediction；
5. validation/test 标签从不用于 utility target 或阈值校准。

检测器可使用训练 split 训练，但 scorer 的相关性和校准必须在未参与 scorer 拟合的视频上计算。

## 14.4 (G_{\mathrm{rank}}) 门

`DESIGN_PROPOSAL`

连续代理合格的最低标准：

* (\Delta K=4) 和 8 上，视频级 Spearman (\rho\ge0.25)；
* 95% bootstrap CI 下界 (>0)；
* Kendall (\tau\ge0.15)；
* top-decile hard utility enrichment ≥ matched random 的 1.5 倍；
* 正负收益符号准确率 ≥60%；
* cls、reg、pair-risk 中至少两项独立通过；
* 不能只在总 loss 上通过、却在高 tIoU 风险上失败。

若未通过：

[
\boxed{\text{删除 ST/连续贡献的 task-aware claim}}
]

然后转为硬反事实监督的 scorer + 无梯度组合求解。

## 14.5 (G_{\mathrm{direct}}) 门

`DESIGN_PROPOSAL`

比较：

* 相同 hard-rank scorer，不开 direct gradient；
* 开启受保护 direct detection gradient；
* 相同 6000 updates、相同预算、相同初始化。

最低通过条件：

* 首粒种子平均 mAP 至少额外 +0.30；
* mAP@0.7 不下降超过 0.10；
* 双端支持和最大空洞不恶化；
* selector direct-gradient 与 hard utility gradient 的平均余弦为正；
* direct auxiliary gradient 范数始终不超过 detector 主梯度的 25%。

若失败：

[
\boxed{\text{永久删除 direct/ST 路径，保留硬监督 scorer}}
]

## 14.6 动态预算必要性门

`DESIGN_PROPOSAL`

先计算预算 Oracle：

[
K_v^{\mathrm{oracle}}
=====================

\arg\max_{K\in\mathcal K}
U_v(K,S_v(K))
]

并在匹配总体平均预算下求最优分配。

若 Oracle 动态预算相对最佳固定 (K) 的提升：

* 平均 mAP < 0.5；
* 或 mAP@0.7 < 0.3；
* 或 utility curve 的视频间方差不显著高于测量噪声；

则动态 (K) 没有足够 headroom，应停止作为主创新。

* 训练辅助 hard-label 成本单独列账；
* 不把 Oracle 视为方法。

### 首粒种子通过门

`DESIGN_PROPOSAL`

D0 必须同时满足：

1. 实际平均帧数与目标偏差 ≤1%；
2. 相对 F1 平均 mAP ≥+0.50；
3. mAP@0.7 ≥+0.30，或至少 95% 视频 bootstrap CI 下界 (>0)；
4. 宽双端支持不下降；
5. 最大空洞不恶化；
6. batch permutation 和 batch size 不改变每视频 (K_v)；
7. selector+solver p95 时延 ≤所节省 backbone 时延的 20%；
8. 相对 dense 具有真实端到端加速；
9. 相对 F1 的提升不能由更高平均帧数解释。

### 首粒种子失败分级

| 结果                      | 裁决                |
| ----------------------- | ----------------- |
| D0 比 F1 ≥0.5 且高 tIoU 改善 | 放行多种子             |
| 提升 0.2–0.5，机制指标正确       | 允许一次预注册修订         |
| 提升 <0.2                 | 动态 K 主 claim 失败   |
| 平均 mAP 提升但 mAP@0.7/双端恶化 | TAD 核心失败          |
| Oracle headroom <0.5    | 停止动态 K，不再调 scorer |
| 实际无加速                   | 删除效率 claim        |
| 依赖 test batch           | 主协议失败             |

## 阶段 D：放行后扩展

`DESIGN_PROPOSAL`

额外种子使用预注册的 5801、8123。放行条件：

* 3 个种子平均提升 ≥0.4；
* 至少 2/3 种子为正；
* pooled video bootstrap CI 下界 (>0)；
* 无种子出现显著高 tIoU 崩溃。

第二检测器只有在多种子通过后运行。推荐选择与 AdaTAD 时序头不同的 ActionFormer/TemporalMaxer 路径。ActionFormer 本身以逐时刻分类和边界回归为核心，因此是检验物理时间插件泛化的合理后端。 ([ECVA][7])

## 15.1 对 69–70 目标的科学判断

`PARTNER_CLAIM`

若干净 dense 确实约 69，而 uniform 50% 约 65，则平均 50% 帧预算下达到 69–70 意味着几乎完全消除 50% 观测损失，甚至超过 dense。只有 Oracle 动态预算和 Oracle 位置同时显示足够 headroom 时，这一目标才合理。

`DESIGN_PROPOSAL`

最低成功标准不应是绝对 69，而应是：

[
\text{在相同真实成本下稳定改善 accuracy–cost Pareto}
]

并且改善集中于高 tIoU、双端支持和长尾困难视频。

# 16. CVPR 论文标题、贡献、主图、主表和叙事

## 16.1 标题候选

1. **METER-TAD: Risk-Calibrated Marginal Evidence Transport for Dynamic-Budget Temporal Action Detection**
2. **Spend Frames Where Boundaries Need Them: Dynamic Physical Evidence Allocation for Temporal Action Detection**
3. **From Frame Budgets to Localization Risk: An Anytime Pre-Backbone Sampler for Temporal Action Detection**

## 16.2 一句话主张

`DESIGN_PROPOSAL`

> METER-TAD 在预注册的平均端到端成本下，通过硬反事实边际检测价值和成对边界风险构造嵌套物理帧阶梯，使固定预算、动态预算和严格免训练采样共享同一定位保持解码器。

## 16.3 三条且仅三条核心贡献

1. **问题与理论**：提出高 tIoU 定位风险下的边际物理证据分配，并给出 batch-independent 对偶预算、时间映射误差和预算单调性命题。
2. **方法**：提出嵌套 exact-(K) 的双边界风险传输，外层动态分配视频预算，内层保持物理时间和双端覆盖。
3. **证据**：建立多尺度硬反事实与严格 60 轮、真实成本匹配协议，区分软代理、直接梯度和真实离散收益。

## 16.4 摘要骨架

`DESIGN_PROPOSAL`

第一段：固定帧预算浪费简单视频的观测，同时使复杂视频边界证据不足。

第二段：指出 TAD 与识别/重建不同——帧价值由成对边界、物理时间扭曲和高 tIoU 风险决定。

第三段：介绍 METER-TAD 的 nested ladder、hard marginal utility、pair-risk 和 frozen dual price。

第四段：给出 batch-invariance、预算单调性和时间映射上界。

第五段：报告 matched budget、第二检测器、真实延迟和硬反事实证据；数字只能在实验后填写。

## 16.9 与 AdapTok 的准确表述

`DESIGN_PROPOSAL`

相关工作应写成：

> AdapTok learns reconstruction-quality curves for variable-length latent prefixes and jointly allocates latent tokens within each mini-batch. In contrast, we allocate raw physical observations for interval localization, where frame addition changes the temporal metric and where paired boundary risk, rather than reconstruction fidelity, determines high-tIoU success. We therefore use AdapTok-style quality prediction and batch ILP as a direct-transfer baseline, while our main protocol adopts hard detection counterfactuals, localization-risk constraints, and a pre-calibrated per-video dual policy.

不能写“受 AdapTok 启发所以提出 scorer+ILP”，然后把这两项列为贡献。

# 17. 三名苛刻审稿人的拒稿模拟和逐项防线

## 17.1 新颖性审稿人

### 最可能拒稿意见

# 20. 最终 Go / Major Redesign / Stop 裁决

## 最终裁决

[
\boxed{\textbf{MAJOR REDESIGN — 重大重构后继续}}
]

## 动态 (K) 的最终地位

`DESIGN_PROPOSAL`

**动态 (K) 应成为 DUCA 论文主模型不可缺少的结构性部分，但“动态 (K)”本身不是创新。**

唯一推荐是路线 C：

[
\boxed{
\text{外层：视频级风险校准动态预算}
+
\text{内层：定位保持的 exact-K 物理时间传输}
}
]

固定 (K) 是它的严格退化特例和公平对照，而不是另一套独立方法。

## 为什么值得继续

1. `DOCUMENTED_RESULT` 当前负结果揭示了一个真实、TAD 特有且尚未解决的矛盾：局部动作富集与全局双边界覆盖发生冲突。
2. `PAPER_FACT` AdapTok、AdaFrame、MGSampler 等已经占据普通动态预算、未来效用和累积分布采样，但尚未解决高 tIoU、成对边界和物理时间失真。
3. `DESIGN_PROPOSAL` 该缺口可以形成明确数学问题、可证明命题和有限实验内的停止门。
4. `UNRESOLVED` 当前没有证据保证它会提高 mAP；因此必须先做 Oracle 和 hard-utility 门，而不是直接进入大规模训练。

## 立即做

[
\boxed{
\text{基线恢复}
\rightarrow
\text{pre-NMS 物理映射}
\rightarrow
\text{动态 Oracle}
\rightarrow
\text{多尺度 hard swap}
\rightarrow
\text{fixed-K pair-risk transport}
}
]

## 通过门后做

[
\boxed{
\text{nested utility curve}
\rightarrow
\text{frozen dual dynamic K}
\rightarrow
\text{60轮首粒种子}
\rightarrow
\text{多种子与第二检测器}
}
]

## 暂不做

[
\boxed{
\text{test-batch ILP}
,\quad
\text{完整主动感知}
,\quad
\text{Shapley 主训练}
,\quad
\text{direct ST}
,\quad
\text{以 zero-shot 为主故事}
}
]

## 绝对停止条件

满足任一项即停止当前动态预算主路线：

1. dynamic budget Oracle 相对最佳 fixed-(K) headroom <0.5 mAP；
2. 多尺度 hard utility 无法被显著预测；
3. bounded inner transport 仍不能修复双端支持和最大空洞；
4. D0 在公平 60 轮下不能超过 F1；
5. 提升只出现在低 tIoU，mAP@0.7 下降；
6. 实际端到端成本无节省；
7. 方法必须依赖检测器专用时间模块才能工作；
8. 第二检测器完全失败。

在这些门通过之前，DUCA 不是一篇已经接近完成的 CVPR 方法，而是一项具有明确科学潜力、但必须重建中心命题和证据链的研究。动态 (K) 不应被保守地降级；它应被正面证明，或者被正面证伪。
