## 1. Executive verdict

# `NEW_PRIMARY_HYPOTHESIS_JUSTIFIED`

同时包含两个不可拆开的子裁决：

1. **关闭 Free NativeTokenSelect v1。**
2. **把 Hybrid 仅用于提出一个新的、独立预注册的 Structured Complementary Routing 假设，不得用它追认旧假设。**

最重要的研究判断是：

> **Hybrid 的信号首先说明“受约束的互补支持集合与较低方差的离散搜索空间”可能有效，而不是证明自由 token saliency、learned geometry 或 Geometry Zoom 有效。**

目前最合理的下一代模型不是“给 Free 增加更多 head 和 loss”，而是重新定义决策变量：

```text
从：64 个无角色的自由 learned slots
改为：global context / geometry support / complementary residual
     三种具有不同计算职责的 exact-K 联合决策
```

而且必须使用对**真实 hard set 概率**有效的优化方法，不能继续依赖当前 selected-only straight-through 幅度代理。

当前方向应定位为：

> **source-native pre-backbone token routing**

而不是：

> **Geometry Zoom**

只有真正引入 source-coordinate continuous crop、variable scale/aspect、局部 source-density 放大，并在 heavy backbone 之前执行，才有资格恢复 Zoom 叙事。

### 3.1 Hard top-K 的真实梯度

令：

[
S(z)=\operatorname{TopK}_K(z),\qquad
h_i(z)=\mathbb{1}[i\in S(z)].
]

当第 K 与 K+1 名不存在 tie 时，总存在一个足够小邻域，使排序和集合 (S) 不变。因此：

[
\frac{\partial h_i}{\partial z_j}=0
]

几乎处处成立；在排序交换的 tie 超平面上则不可导。

PyTorch 对由 integer indices 执行的 gather 不会自动产生“把 token (j) 换成 token (i)”的梯度。

### 3.2 当前 ST 实际优化什么

代码定义：

[
\tau=\operatorname{sg}\left(\operatorname{Kth}(z)\right),
\qquad
s_i=\sigma\left(\frac{z_i-\tau}{T}\right).
]

对 hard-selected set (S) 中的 token：

[
g_i=1+s_i-\operatorname{sg}(s_i).
]

forward 时：

[
g_i=1.
]

selected feature 为：

[
y_i=g_i f_i,\quad i\in S.
]

忽略共享网络导致的间接耦合，其直接梯度为：

[
\frac{\partial L}{\partial z_j}
===============================

\mathbb{1}[j\in S]
\left\langle
\frac{\partial L}{\partial y_j},f_j
\right\rangle
\frac{s_j(1-s_j)}{T}.
]

因此：

* 对 (j\notin S)，直接 membership gradient 为零。
* K/K+1 threshold 的梯度被 detach。
* 当前梯度并不近似：

[
\Delta_{i\rightarrow j}
=======================

L\left(S\setminus{i}\cup{j}\right)-L(S).
]

它近似的是：

> “已经被选中的 feature 若被连续缩放，detector loss 如何变化”。

这不是 hard membership 的交换信用。

现有代码实际上已实现对单一 Free/ROI family 的 Plackett–Luce score-function 候选，并能把真实 detector loss 绑定到 ordered log-probability。

### 3.3 为什么 64 个 Free slots 特别困难

在 uniform pooling 下，每个 selected token 的直接聚合系数是 (1/K=1/64)。虽然 VideoMAE 内部仍有 selected-token interactions，但 router 得到的 amplitude credit 被平均削弱。

同时 Free 面对的支持集合约为：

[
\binom{220}{64}.
]

它没有：

* mandatory global coverage；
* role decomposition；
* spatial diversity；
* temporal persistence；
* boundary-conditioned transition；
* hard-set replacement credit。

Hybrid 强制包含 8 个 deterministic context token，并把剩余决策拆成 28 ROI 和 28 residual。即使 learned geometry 没有任何真正语义，它也已经：

1. 缩小并重构搜索空间；
2. 固定最低 coverage；
3. 降低 residual slots 的竞争；
4. 给各 role 提供不同 score 分布；
5. 增大相邻 tubelet support overlap 的可能性。

这足以形成一个新的 primary hypothesis。

### 5.2 方向 A：Structured Complementary Routing

关键变化不是“加入 ROI head”，而是为计算分配赋予三个角色：

* **Context**：保证全局场景、人物—物体关系和背景覆盖。
* **Geometry**：选择 scout 认为属于连续动作相关区域的 source-native support。
* **Residual**：主动寻找 geometry 未覆盖但对 detector 有用的补充证据。

预算不再永久固定 `8/28/28`，而从小型可行集合中动态选择：

[
\mathcal B_K=
\left{
(k_c,k_g,k_r):
k_c+k_g+k_r=K,;
k_c\in{4,8,12},;
k_g,k_r\ge 8,;
k_g,k_r\in4\mathbb Z
\right}.
]

预算以一个 VideoMAE 16-frame chunk，即 8 个 tubelets 为粒度保持恒定，避免逐 tubelet 剧烈震荡。

### 5.3 方向 B：真正的 Geometry Zoom

真正的 Zoom 必须执行：

[
\theta_t=(c^x_t,c^y_t,\log s_t,\log a_t)
]

并在 raw source 上构建：

[
X^{\rm local}_t
===============

\operatorname{SampleGrid}(X_t,\theta_t).
]

固定大小的 local canvas 对应源图上可变面积，因此 local patch 在源坐标上的采样密度随 (s_t) 变化，这才是“放大”。

heavy backbone 的输入应是：

```text
small mandatory global context
+
one or more source-coordinate continuous local trajectories
```

而不是：

```text
先完整执行 dense heavy backbone
→ 再裁 feature ROI
```

AdaFocus 及 AdaFocus V2 已采用轻量全局网络定位 patch，再由高容量网络处理局部 patch；Uni-AdaFocus 进一步把 patch 的位置、大小及时间/样本预算纳入动态计算。因此，一个新 Geometry Zoom 方法必须靠 TAD-specific boundary trajectories、source-density allocation 和严谨 full-stack Pareto 区分，而不能只复用“scout + crop”。([Open Access CVF][1])

### 5.4 方向 C：Coverage-aware routing

定义 scout token 描述符 (u_{t,i})，目标：

[
F_t(S)=
\lambda_r\sum_{j\in S}r_{t,j}
+
\lambda_m\sum_{j\in S}m_{t,j}
+
\lambda_f\sum_{i=1}^{N}\max_{j\in S}\operatorname{sim}(u_{t,i},u_{t,j})
-----------------------------------------------------------------------

\lambda_o\sum_{j\ne k\in S}\operatorname{overlap}(j,k).
]

它与 Free 的区别是：

* Free 只优化独立 saliency score。
* Coverage routing 优化集合层面的代表性和互补性。
* 与 ToMe 的区别是它在 heavy backbone **之前**选 source-native support，而 ToMe 在 transformer 中逐层合并已有 token。ToMe、DynamicViT、ATS 和 TokenLearner 已经充分占据一般 token reduction 叙事。([ICLR][2])

## 6. Recommended model

# CER-TAD

## Complementary Evidence Routing for Temporal Action Detection

### 6.1 诚实的 claim 名称

**Boundary-Conditioned Complementary Pre-Backbone Routing**

不要使用：

```text
Spatial Zoom
Geometry Zoom
Adaptive resolution
Native-density magnification
```

### 6.2 一句话贡献

> CER-TAD 将离线 TAD 的空间计算分配建模为 context、geometry 与 residual 三类互补证据的 exact-K 离散联合决策，并通过真实 hard-route likelihood 与 detector risk 优化该决策，而不是训练一个无约束 saliency top-K。

### 6.3 数据流

```text
raw source RGB [B,3,768,H,W]
        │
        ├── low-cost 96×96 scout
        │       ├── scout state h_t             [B,384,D]
        │       ├── geometry θ_t                [B,384,4]
        │       ├── geometry/ROI logits z^g     [B,384,220]
        │       ├── residual logits z^r         [B,384,220]
        │       └── boundary probability p_t    [B,384]
        │
        ├── block-wise dynamic exact-K role budget
        │       b_q=(k_c,k_g,k_r)
        │
        ├── deterministic context anchors C_t
        ├── hard geometry support G_t
        ├── hard complementary residual R_t
        │
        └── S_t=C_t∪G_t∪R_t, |S_t|=K, duplicate=0
                │
                ├── gather native 2×16×16 tubelets
                ├── one packed VideoMAE forward
                ├── coordinate-lineage packed Adapter
                ├── absolute-coordinate-only aggregation
                ├── deterministic 384→768 restoration
                └── ActionFormer / TAD detector
```

### 6.4 Exact-K 角色预算

每个 16-frame block (q)：

[
b_q=(k^c_q,k^g_q,k^r_q)
\sim
\pi_b(\cdot\mid \bar h_q,\bar p_q),
]

满足：

[
k^c_q+k^g_q+k^r_q=K.
]

推理时：

[
b_q=\arg\max_{b\in\mathcal B_K}\pi_b(b\mid\bar h_q,\bar p_q).
]

### 6.5 Context role

从所有 valid native coordinates 中使用 deterministic farthest-point anchors：

[
C_t=\operatorname{FPS2D}(U,k^c_q).
]

它不依赖 label、teacher 或 prediction cache。

### 6.6 Geometry role

从排除 context 后的 support 中：

[
G_t\sim
\operatorname{PL-WOR}
\left(
z^g_t,;
k^g_q,;
U\setminus C_t
\right).
]

其中 `PL-WOR` 是 Plackett–Luce without replacement。

### 6.7 Residual role

定义互补 residual score：

[
\tilde z^r_{t,i}
================

z^r_{t,i}
-\alpha\sigma(z^g_{t,i})
-\beta\max_{j\in G_t}
\exp\left(
-\frac{|u_i-u_j|^2}{2\sigma^2}
\right).
]

再从剩余 support 中采样：

[
R_t\sim
\operatorname{PL-WOR}
\left(
\tilde z^r_t,;
k^r_q,;
U\setminus(C_t\cup G_t)
\right).
]

因此：

[
C_t\cap G_t=C_t\cap R_t=G_t\cap R_t=\varnothing.
]

### 6.8 Hard selection 的梯度

训练时使用 Gumbel-top-K 得到 exact without-replacement hard sample；其 ordered set 对应可计算的 Plackett–Luce likelihood。Gumbel-top-K 是从类别分布中精确无放回抽取 K 项的标准构造。([Proceedings of Machine Learning Research][3])

令完整 route 为：

[
a=(b_{1:Q},G_{1:T},R_{1:T}).
]

定义 detector risk：

[
\mathcal R(a)=
\mathcal L_{\rm det}(a)
+
\lambda_{\rm cov}\mathcal C(a)
+
\lambda_{\rm stab}\mathcal J(a).
]

使用 state-only critic (V_\psi(h))：

[
\mathcal L_{\rm policy}
=======================

\mathbb E_a
\left[
\left(
\operatorname{sg}[\mathcal R(a)]
--------------------------------

\operatorname{sg}[V_\psi(h)]
\right)
\log\pi_\theta(a\mid h)
\right].
]

因为这里优化的是 risk，梯度下降会降低高 risk route 的 log-probability。

critic：

[
\mathcal L_{\rm value}
======================

\left(
V_\psi(h)-\operatorname{sg}[\mathcal R(a)]
\right)^2.
]

与当前 ST 相比，PL denominator 包含仍可选的全部 token，因此未被选择的 token 也获得直接 score-function credit。

### 6.9 Coverage 与 collapse 防护

[
\mathcal C(S_t)
===============

\frac1N
\sum_{i=1}^{N}
\min_{j\in S_t}
|u_i-u_j|_2^2.
]

同时固定最小 role budget：

```text
k_context ≥ 4
k_geometry ≥ 8
k_residual ≥ 8
```

这些是可行域约束，不是事后 penalty 调参。

### 6.10 Temporal consistency

定义：

[
J_t=
1-
\frac{|S_t\cap S_{t-1}|}
{|S_t\cup S_{t-1}|}.
]

但不应在真实动作边界强行保持相同 support，因此：

[
\mathcal J
==========

\frac1{T-1}
\sum_{t=2}^{T}
\left(
1-\max(\hat p_{t-1},\hat p_t)
\right)J_t.
]

* 动作内部：鼓励稳定 support，保护 Adapter lineage。
* 预测边界附近：允许 route 快速变化。

### 6.11 Boundary-sensitive mechanism

训练期从标准 GT segment 构造边界带：

[
y^{\rm bdry}_t
==============

\mathbb 1
\left[
\min_m
\left{
|t-s_m|,\ |t-e_m|
\right}
\le r
\right].
]

训练：

[
\mathcal L_{\rm bdry}
=====================

\operatorname{BalancedBCE}
(\hat p_t,y^{\rm bdry}_t).
]

推理时 router 只使用自身预测 (\hat p_t)，不存在 GT、teacher 或 oracle 输入。

### 6.12 完整训练目标

[
\mathcal L=
\mathcal L_{\rm cls}
+
\mathcal L_{\rm reg}
+
\lambda_\pi\mathcal L_{\rm policy}
+
\lambda_v\mathcal L_{\rm value}
+
\lambda_b\mathcal L_{\rm bdry}
------------------------------

\lambda_H H(\pi_b).
]

coverage 和 temporal stability 放入 detached policy risk，而不是直接对 hard indices 求梯度。

### 6.13 Geometry/support 与 representation 解耦

推荐主模型中：

```text
geometry affects membership:       YES
geometry_projection into adapter:  NO
ROI-relative coordinate features:  NO
absolute source coordinates:       YES, all sparse arms matched
pooling:                            uniform_selected
```

只有在独立 ablation 中才重新打开：

```text
geometry_projection
ROI-relative coordinates
```

否则无法判断增益来自 support 还是 side-channel。

### 6.14 No-leak 证明

router forward 的允许输入：

```text
raw/scout video
valid native mask
source coordinates
learned parameters
```

禁止输入：

```text
validation/test GT
teacher output
oracle ROI
manual ROI
raw prediction cache
official-test result
```

GT 只在 training loss 构造 boundary target 时使用，不进入 router forward，也不保存为 inference dependency。

### 6.15 One-heavy-forward 证明

CER-TAD 只替换 `select_exact_k` 之前的 route policy。其后继续调用一次：

```python
self.model.backbone.forward_native_packed(...)
```

当前 packed implementation 已显式检查 invocation delta 必须等于 1。

VideoMAE 的 patch embed 只作用于 gathered native tubelets，12 个 block 的 attention/MLP/Adapter 均使用 selected mask。

### 6.16 复杂度

设每个 VideoMAE chunk 有 (m=8) 个 tubelets，空间 token 数 (N=220)，选择 K 个。

Router：

[
O(BTNK)
]

最坏来自 residual 对 geometry support 的 complement distance；N 和 K 都很小。

Heavy backbone：

[
O\left(
LBQ
\left[
(mK)^2C + mKC^2
\right]
\right),
\qquad Q=T/m.
]

Adapter：

[
O(LBTKC).
]

必须额外实测当前 dense positional carrier、clone/scatter、decode 和 postprocess 成本，不能只报告上述理想算子复杂度。

### 6.17 失败回退

* dynamic budget collapse，但 fixed-role union 有效：冻结预注册 fixed budget，论文降级为 fixed complementary routing。
* geometry+context 不优于 context-only：删除 geometry role 和 geometry claim。
* residual 不提供增量：删除 residual role。
* boundary head无增量：移除 boundary-sensitive claim。
* P2 无 full-stack Pareto：**终止整个效率论文方向**。
* 仅 accuracy 改善而无真实成本改善：不能包装为高效方法。

### 6.18 为什么不是 Free v1 加 head/loss

CER-TAD 改变了四个根本对象：

1. **动作空间**：无角色集合 → 互补角色 exact-K 集合。
2. **估计器**：selected-only ST → hard route likelihood。
3. **因果边界**：support 与 geometry representation 解耦。
4. **时间结构**：无稳定性 → boundary-conditioned persistence。

这不是 loss weight 调整。

### 7.1 Hard PL without replacement

```python
def plackett_luce_without_replacement(
    logits: Tensor,       # [N]
    available: Tensor,    # [N] bool
    count: int,
    *,
    temperature: float,
    stochastic: bool,
) -> tuple[Tensor, Tensor]:
    if logits.ndim != 1 or available.shape != logits.shape:
        raise ValueError("PL inputs must be matching [N] tensors")
    if available.dtype != torch.bool:
        raise TypeError("available must be bool")
    if not 0 <= count <= int(available.sum().item()):
        raise ValueError("count exceeds valid support")

    scaled = logits / temperature
    ranking = scaled.masked_fill(~available, float("-inf"))

    if stochastic:
        u = torch.rand_like(ranking).clamp_(1e-6, 1.0 - 1e-6)
        ranking = ranking - torch.log(-torch.log(u))

    ordered = torch.topk(
        ranking, k=count, dim=-1, sorted=True
    ).indices

    remaining = available.clone()
    log_prob = logits.new_zeros(())
    for slot in range(count):
        choice = ordered[slot]
        candidate = scaled.masked_fill(
            ~remaining, float("-inf")
        )
        log_prob = (
            log_prob
            + F.log_softmax(candidate, dim=-1)[choice]
        )
        remaining[choice] = False

    return ordered, log_prob
```

### 7.2 Dynamic exact-K role budget

```python
def enumerate_exact_budgets(
    total_k: int,
    context_options=(4, 8, 12),
    min_geometry: int = 8,
    min_residual: int = 8,
    role_step: int = 4,
) -> Tensor:
    triples = []
    for kc in context_options:
        for kg in range(min_geometry, total_k + 1, role_step):
            kr = total_k - kc - kg
            if kr < min_residual or kr % role_step:
                continue
            triples.append((kc, kg, kr))

    if not triples:
        raise ValueError("no feasible exact-K role budget")

    return torch.tensor(
        sorted(set(triples)),
        dtype=torch.long,
    )  # [M,3]
```

### 7.3 Detector-bound policy loss

```python
def detector_bound_policy_losses(
    *,
    detector_losses: dict[str, Tensor],
    route: ComplementaryRoute,
    policy_weight: float,
    critic_weight: float,
    budget_entropy_weight: float,
) -> dict[str, Tensor]:
    detector_risk = sum(
        value
        for value in detector_losses.values()
        if torch.is_tensor(value)
    )
    if detector_risk.ndim != 0:
        raise ValueError("detector risk must be scalar")

    risk = (
        detector_risk.detach().expand_as(
            route.value_baseline
        )
        + route.route_penalty.detach()
    )
    advantage = risk - route.value_baseline.detach()

    return {
        "cer_policy_loss":
            policy_weight
            * (advantage * route.mean_log_prob).mean(),

        "cer_value_loss":
            critic_weight
            * F.mse_loss(route.value_baseline, risk),

        "cer_budget_entropy_loss":
            -budget_entropy_weight
            * route.budget_entropy.mean(),
    }
```

## 9. Paper plan

### 9.1 足以成为主方法的贡献

唯一足够强的候选贡献是：

> **将 TAD 的 pre-backbone spatial allocation 从独立 token saliency ranking 重新定义为具有 context/geometry/residual 角色的 complementary exact-K structured decision，并使用真实 hard-route likelihood 与 boundary-conditioned detector risk 训练。**

单独的以下贡献不够：

```text
增加 geometry head
增加 context tokens
增加 diversity loss
把 8/28/28 改成动态比例
加入 boundary BCE
使用 Gumbel-top-K
```

论文价值来自它们共同支撑一个新的问题定义和可证伪机制，而不是模块数量。

### 9.2 与相关方向的本质区别

#### DynamicViT / ATS / A-ViT / ToMe

这些方法主要在 transformer 内部依据已经产生的 feature token 进行 pruning、halting、sampling 或 merging；DynamicViT 通过中间层预测模块和 attention masking 逐层裁剪，ATS 是插入 block 内的自适应采样，ToMe 在 block 内合并相似 token。([arXiv][4])

CER-TAD 的差异必须是：

```text
before heavy backbone
source-native support
exact-K
offline TAD detector utility
boundary-sensitive temporal role allocation
```

#### TokenLearner

TokenLearner 生成少量自适应聚合 token，而 CER-TAD 保留真实 source-coordinate native support，不是软聚合的 latent token。([arXiv][5])

#### AdaFocus / Uni-AdaFocus

它们是 Geometry Zoom 路线最接近的先验：低成本全局网络选局部 patch，再由高容量网络处理。因此当前方法若没有 continuous crop/source-density 放大，不能把 token gather 描述为 Zoom。([Open Access CVF][1])

#### EVAD

EVAD 在 spatio-temporal action detection 中保留 keyframe tokens、选择其他帧中的 motion-relevant tokens，并用 context refinement 恢复检测信息。它会成为“动作检测中 token dropout 与 context”的直接审稿先验。CER-TAD 必须强调任务是 offline temporal action detection、决策在 heavy backbone 前、exact source-native support，以及边界/短动作效用。([Open Access CVF][6])

#### TAD sampling / AdaTAD

SCSampler 主要选择 salient temporal clips；AdaTAD/TIA 主要解决长输入、巨型 backbone 的端到端训练和 temporal adapter，而不是动态 spatial support。([Open Access CVF][7])

#### 2026 动态 token allocation

AdapTok 已研究内容自适应的时序 token allocation，MeToM 已使用视频元数据执行动态 budget 和 token merging，尽管它们分别面向生成式 tokenizer 与 Video-LLM。因而“动态分配 token budget”本身已不足以成为新颖性；必须建立 TAD-specific complementary roles、hard credit 与 boundary mechanism。([Open Access CVF][8])

### 9.3 当前结果最多支持什么

> 在 K=64 的单 seed development-only screen 中，无约束 Free NativeTokenSelect 明显弱于 fixed/random，而一个同时引入 deterministic context、learned geometry support、role quota 和 geometry-conditioned representation 的 Hybrid 恢复至接近 dense。该结果否定 Free v1，并提出结构化互补路由假设，但由于多重干预、单 seed、ROI decode failure 和 selector 缺失，不能建立因果或论文性能结论。

### 9.6 最可能的三条拒稿意见

#### Attack 1：Hybrid 是多重干预，作者无法证明 geometry 或 complementarity

* 主模型关闭 geometry representation。
* context/residual/geometry/full 四臂完整分解。
* geometry-shuffled control。
* 同架构、同参数、同 K。

#### Attack 2：hard top-K 训练是错误 surrogate，结果可能只是偶然搜索偏差

模型层解决：

* PL hard likelihood。
* unselected-gradient KAT。
* detector-bound score-function。
* state-only critic。
* 三 seed、paired uncertainty。

#### Attack 3：这不是 Zoom，而且系统成本不可信

模型层解决：

* 改名为 CER-TAD。
* 明确 `uses_grid_sample=False`、`uses_resized_local_crop=False`。
* 完整 decode-to-NMS/energy ledger。
* 若未来做 Zoom，单独实现 TrajectoryZoom，不追溯改名。
