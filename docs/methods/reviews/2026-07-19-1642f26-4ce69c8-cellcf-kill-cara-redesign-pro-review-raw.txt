[MATHEMATICAL_CONSEQUENCE] 当前 CellCF **不能实现 boundary-adaptive budget allocation**。它只能在每个 exact-uniform Voronoi cell 内替换均匀 anchor 所对应的视觉帧，不允许任何 cell 放弃名额，也不允许高 transition cell 获得第二个名额。

[MATHEMATICAL_CONSEQUENCE] 在 `T=768,K=384` 下，它不是“从背景抽走大量预算并在边界增加密度”的方法，而是一个严格受限的 **uniform phase/content correction**。

[CODE_FACT] counterfactual teacher 在 `torch.no_grad()` 中评估 hard alternatives，将 utility `detach()` 后交给 selector；配置同时把 direct detector-gradient bridge 设为零。

[EXPERIMENT_FACT] 用户给定的同协议单种子事实中，CellCF 为 `64.0610`，低于 transition-beta0 的 `64.2755`；因此当前证据既不支持 CellCF 优于 transition-only，也不支持 detached counterfactual utility 带来总体增益。

[EXPERIMENT_FACT] CellCF 的 `@0.7=43.8241` 虽高于 transition-beta0 的 `43.1336`，但只有一个种子，且同时存在采集时间与 detector 时间不一致的混杂，不能解释为边界机制成立。

[INFERENCE] DUCA 的研究目标仍有价值，但当前 CellCF 这个可行集合必须终止。下一条主线应改为 **coverage skeleton + adaptive residual allocation + actual-position physical-grid detector**。

# 3. `CODE_AUDIT_FINDINGS`

## P0：足以终止当前 CellCF 主方法的事实

### P0-1：可行集合没有跨区域预算转移能力

[CODE_FACT] exact-uniform anchor 为

[
a_j=\operatorname{round}!\left(\frac{j(T-1)}{K-1}\right),\qquad j=0,\dots,K-1.
]

Cell 边界使用相邻 anchor 中点，并把正好处于中点的帧归给更早的 cell。

[MATHEMATICAL_CONSEQUENCE] 对 `T=768,K=384`：

* anchor 相邻间隔有 382 个为 2，只有 `382→385` 的一个间隔为 3；
* 382 个 cell 长度为 2；
* 1 个中央 cell 长度为 3；
* 最后 1 个 cell 长度为 1；
* 任意选中位置相对本 cell anchor 的最大位移是 1 帧；
* 绝大多数二帧 cell 的 anchor 位于 cell 左端，因此实际只能保持 anchor 或向右移动 1 帧；只有中央三帧 cell 能左右各移动 1 帧。

[MATHEMATICAL_CONSEQUENCE] 当前可行集合可写为

[
\mathcal F_{\text{cell}}
========================

\left{
S:\ |S\cap C_j|=1,\ \forall j=0,\dots,K-1
\right}.
]

对任何由完整 cells 构成的区域 (R=\bigcup_{j\in J}C_j)，恒有

[
|S\cap R|=|J|,
]

与 selector score 完全无关。因此稳定背景中的完整 cell **永远不能释放预算**，边界区域中的完整 cell **永远不能获得第二个名额**。

[MATHEMATICAL_CONSEQUENCE] 以整数边界 (b) 的局部窗口 (W_r(b)=[b-r,b+r]) 计，当前 CellCF 可实现的最大局部样本数为：

|   半径 | 窗口宽度 | exact-uniform 最大数 | CellCF 最大数 | 新 residual family 可达数 |
| ---: | ---: | ----------------: | ---------: | --------------------: |
| `r0` |    1 |        1，但某些位置为 0 |          1 |                     1 |
| `r1` |    3 |                 2 |          2 |                     3 |
| `r2` |    5 |                 3 |          3 |                     5 |
| `r4` |    9 |                 5 |          5 |                     9 |

[MATHEMATICAL_CONSEQUENCE] CellCF 可以改变“边界附近哪一帧被看见”，但不能提高局部采样率的上限；在 `r4` 内仍最多 5 帧，与 stride≈2 的 uniform 最大密度相同。

[CODE_FACT] 当前 family 的理论最大未选洞为 3；对应测试明确检查 `T=768,K=384` 下该上限可达到。

[MATHEMATICAL_CONSEQUENCE] exact-uniform 本身最大未选洞为 2，而 CellCF 为获得一帧局部位移，反而允许最大洞扩大到 3。

### P0-2：实际采集时间和 detector 时间不是同一坐标

[CODE_FACT] selector 实际从 `positions` 采集原始帧，但 local-cell 模式另行生成 `detector_grid_positions=anchor_positions`。在 counterfactual teacher 中：

* `selected_inputs` 由实际候选 `positions` gather；
* `selected_axis_to_true_time_dense_index` 写入的是 `detector_positions`；
* GT remap 也使用该 `detector_positions`；
* 候选 flip 改变实际帧，却保持 detector anchor grid 不变。

[CODE_FACT] 推理后处理若 detector 输出为 selected-axis，会再次使用 `selected_axis_to_true_time_dense_index` 进行逆映射。

[MATHEMATICAL_CONSEQUENCE] 当前实际执行的是：

[
\text{visual content at }p_j
\quad\longrightarrow\quad
\text{detector label/time at }a_j,
]

其中 (|p_j-a_j|\le1)。

[SEVERE_VERDICT] 这不是随机实现错误，而是被测试固定的设计合同；但它意味着 CellCF 的科学语义是 **在固定 uniform 时间网格上替换视觉内容**，不是在真实 observation time 上重新分配时序采样。

[INFERENCE] 因此当前 @0.7 略高可能来自四种互相混杂的来源：

| 来源                                     | 能否由当前结果区分               |
| -------------------------------------- | ----------------------- |
| 实际选择了更有边界信息的相邻帧                        | 不能；缺当前 checkpoint 的选帧审计 |
| 将相邻视觉帧标成 uniform anchor 的坐标替换效应        | 不能；这是现行合同               |
| 视觉内容变化导致分类排序、proposal score 或 NMS 顺序变化 | 不能                      |
| 单种子随机波动                                | 不能                      |

[PROPOSAL] 决定性检查必须使用同一 one-per-cell selector，分别在 `anchor-grid` 和 `actual-position physical-grid` 下运行；正式新方法不得再把 actual acquisition position 替换成 anchor time。

### P0-3：CellCF 没有 direct detector gradient

[CODE_FACT] 配置明确为：

```text
detector_gradient_mode="none"
detector_gradient_final_weight=0
detector_utility_is_direct_gradient=False
```

并将 detector utility 描述为 detached local hard flip。

[CODE_FACT] teacher 先恢复模型 buffer/RNG，在 `torch.no_grad()` 中计算 baseline 与 candidate 的 ActionFormer cls+reg loss，再把 utility detach 后送入 signed logistic selector loss。

[MATHEMATICAL_CONSEQUENCE] detector loss 不可能通过 hard frame gather 直接改变选择位置；它只产生一个训练期排序标签。

[SEVERE_VERDICT] “detector loss 直接穿过 hard selection 改善 selector”这一论文口径在当前代码上是错误的。

### P0-4：当前结果不支持 CellCF

[EXPERIMENT_FACT] 单种子差值：

[
\Delta_{\text{transition-uniform}}=+0.4161,
]

[
\Delta_{\text{CellCF-transition}}=-0.2145.
]

[EXPERIMENT_FACT] CellCF 仅在 `@0.7` 单点高于 transition-beta0，`@0.4` 也略高，但 `Avg-mAP`、`@0.5`、`@0.6` 均不支持其整体优越性。

[SEVERE_VERDICT] 当前 CellCF 不得称为“优于 transition-only”，也不得将 @0.7 单点事后解释成 boundary benefit。

[EXPERIMENT_FACT] 132 epochs / 13,200 successful updates 是专门延长的暴露协议；官方基线配置的正式 workflow 为 60 epochs。仓库现有 physical-grid full-train 配置同样固定为 60 epochs。

### P0-5：现有 ceiling 工具不能直接回答可行集合上限

[CODE_FACT] 现有 feasible-set 工具只验证 supplied candidates 是否满足 exact-K/max-hole，再从其中取最小 detector loss；测试明确要求输出角色为“best of supplied candidates, not upper bound”。

[CODE_FACT] 现有 GT-informed selection 是“先选 GT boundary，再用 uniform 补足”的 heuristic，测试明确断言 `is_optimized_oracle=False`。

[SEVERE_VERDICT] 在没有新增 family-constrained optimizer 前，任何把这些脚本输出称为 “CellCF oracle ceiling” 的口径都必须拒绝。

## P1：必须在重构中修正的问题

### P1-1：selector 确实读取真实 ASFormer temporal hidden，但不是 absolute hidden

[CODE_FACT] 配置要求 `coarse_hidden_kind="official_asformer_encoder_hidden"`、hidden dim 96，并要求 hidden 必须返回。

[CODE_FACT] transition descriptor 为：

[
[
\Delta \ell_t,\ |\Delta \ell_t|,
\Delta H(p_t),\ |\Delta H(p_t)|,
\Delta h_t,\ |\Delta h_t|,
1-\cos(h_t,h_{t-1})
],
]

维度为 (2D+5=197)。它使用 ASFormer encoder hidden 的差分和相邻 cosine change，但不暴露 absolute hidden。

[CODE_FACT] 现行梯度所有权是：

* actionness logits 在构造 descriptor 前 detach；
* policy scorer 使用 `descriptors.detach()`，因此 policy/CF 只更新 scorer；
* auxiliary transition scorer 使用未 detach descriptor，因此 transition auxiliary 可以更新 ASFormer hidden。

[INFERENCE] 当前模型不是“只看 `p_action` 和差分曲线”；它看到了真正的 ASFormer temporal hidden 关系特征。但 detector utility 并不会更新这些 hidden。

### P1-2：当前 detector 不是未经修改的官方 AdaTAD

[CODE_FACT] 被复用的主体包括 VideoMAE-S adapter backbone、projection、neck、ActionFormer cls/reg loss 与 NMS 配置；CellCF 配置也声明 detector loss/head/NMS 本身未换成另一套算法。

[CODE_FACT] 实际源码层面有以下 wrapper/extension：

1. `ActionFormer` 在 backbone 前调用 frame selector；
2. 集成 no-grad counterfactual teacher；
3. 训练时允许 selector remap GT；
4. 推理时执行 selected-axis inverse map；
5. `AnchorFreeHead` 增加 physical-grid 分支；
6. 当前 CellCF 关闭 physical-grid，仍走 selected-axis anchor map。

[SEVERE_VERDICT] 正确论文表述应是“复用官方 AdaTAD/ActionFormer 组件和 loss/NMS，外加 DUCA pre-backbone wrapper 与时序坐标扩展”，不能写成“源码完全等同官方 AdaTAD”。

### P1-3：仓库已有 physical-grid 路径，应直接复用

[CODE_FACT] physical-grid head：

* 读取实际 `irregular_selected_positions`；
* 拒绝 selected-axis GT remap；
* 将 FPN prior center 映射到真实 dense time；
* 使用相邻 physical positions 计算 physical stride；
* 按 stride 重缩放 regression range。

[CODE_FACT] 仓库甚至已有 fixed384/dense768、max-gap=3、uniform scaffold + actionness/uncertainty 的 physical-grid 配置。

[PROPOSAL] 新 DUCA 只应复用其 physical-time detector contract 和相关测试，不应复用其中的固定 actionness quota 或 straight-through detector bridge。

### P1-4：当前成本协议尚不足以满足最终论文表格

[CODE_FACT] 当前 `input_pipeline_serial_ms` 把 dataset read、decode、transforms 和 collate 合并，无法分别回答 decode 与 resize/preprocess 的成本。

[SEVERE_VERDICT] 本次读取到的指定文件不能证明 CellCF 或新 DUCA 已通过真实成本 gate；在正式 profile 完成前只能说成本协议存在，不能说 Pareto 已成立。

# 4. `FEASIBLE_SET_CEILING_EXPERIMENT`

## 4.1 统一记号

[PROPOSAL] 对每个有效窗口定义：

[
V_L={0,\dots,L-1},\qquad K_L=\min(384,L).
]

对升序选择 (S={s_1<\cdots<s_m})，定义最大未选洞：

[
g(S)=
\max
\left(
s_1,,
L-1-s_m,,
\max_i(s_{i+1}-s_i-1)
\right).
]

[PROPOSAL] A–D 的统一 hard coverage 合同使用 (G=3)，因为这是当前 CellCF 的理论最大洞；E 作为 unrestricted privileged reference 不要求 (G)。

## 4.2 五个可行集合

### A. Exact-uniform

[
\mathcal F_A={U_L},
\quad
U_L=
\left{
\operatorname{round}\frac{j(L-1)}{K_L-1}
\right}_{j=0}^{K_L-1}.
]

[MATHEMATICAL_CONSEQUENCE] `L=768` 时 exact-K=384，最大未选洞为 2，没有自适应自由度。

### B. 当前 one-per-cell CellCF oracle

[
\mathcal F_B=
\left{
S:\ |S\cap C_j|=1,\ \forall j
\right}.
]

[MATHEMATICAL_CONSEQUENCE] exact-K=384，最大未选洞≤3，单 cell 最大 quota=1，最大 anchor 位移=1。

[MATHEMATICAL_CONSEQUENCE] 它能够优化 r0 phase hit，但不能在 `r4` 窗口中超过 5 帧，也不能从完整背景 cell 释放预算。

### C. Coverage skeleton + adaptive residual budget

[PROPOSAL] 先构造满足 (g(C_G)\le G) 的最小 deterministic skeleton。最小数量为

[
M_G(L)=
\max\left(
1,,
\left\lceil\frac{L-G}{G+1}\right\rceil
\right).
]

对 `L=768,G=3`：

[
M_G=192,\qquad R=K-M_G=192.
]

可行集合为

[
\mathcal F_C=
\left{
C_G\cup A:
A\subseteq V_L\setminus C_G,\ |A|=R
\right}.
]

[MATHEMATICAL_CONSEQUENCE] skeleton 单独保证 (g(S)\le3)，因此任意 residual 替换都不会破坏 coverage。

[MATHEMATICAL_CONSEQUENCE] `r4` 的九帧窗口可以被完整选中；稳定背景理论上最多可释放 192 个 residual 名额。

### D. Variable-quota / exact-K max-gap allocation

[PROPOSAL] 以宽约 4 的 macro cells (D_j) 定义整数 quota

[
q_j=\sum_{t\in D_j}x_t,
\quad
0\le q_j\le |D_j|,
\quad
\sum_jq_j=K_L,
]

并强制

[
\sum_{t=i}^{i+G}x_t\ge1,
\qquad
i=0,\dots,L-G-1.
]

等价全局可行集合为

[
\mathcal F_D=
\left{
S:\ |S|=K_L,\ g(S)\le3
\right}.
]

[CODE_FACT] 仓库已有 `global_structured_topk` 的 exact-K/max-gap hard Viterbi 和 soft forward-backward，可直接作为 D 的 decoder 基础。

[MATHEMATICAL_CONSEQUENCE] D 是 C 的超集：coverage 位置本身也能随 evidence 移动，但 candidate swap 和训练归因更困难。

### E. Unrestricted GT oracle

[
\mathcal F_E=
\left{
S:\ |S|=K_L
\right}.
]

[PROPOSAL] E 只作为 privileged reference，同时额外报告一个 `E-G3`，用于区分“去掉 max-gap 约束”与“仅扩大配额自由度”的收益。

[SEVERE_VERDICT] 历史 76.67 不能直接填入本表；应在同一 physical-time detector、同一 evaluator、同一 dense coordinate 下重新生成，或者仅列为“历史不可比参考”。

## 4.3 精确几何 oracle

[PROPOSAL] 新增 `tools/bata/diagnose_duca_allocation_ceiling.py`，使用二进制变量 (x_t) 和 endpoint coverage 变量：

[
y_{b,r}
=======

\mathbf 1
\left[
\sum_{|t-b|\le r}x_t\ge1
\right],
]

[
z_{a,r}=y_{s_a,r}\land y_{e_a,r}.
]

[PROPOSAL] 每个 family 应产生两类结果：

1. **Metric-wise capacity envelope**：分别最大化 boundary recall@r0/r1/r2/r4、both-endpoint recall、short-action coverage 和局部样本数；
2. **Canonical oracle selection**：按冻结的 lexicographic 顺序求一个唯一选择，用于 detector 诊断。

[PROPOSAL] canonical 顺序预注册为：

1. 最大化 short-action both-endpoint recall@r1；
2. 最大化全部 action both-endpoint recall@r1；
3. 最大化 boundary recall@r0；
4. 依次最大化 recall@r1、r2、r4；
5. 最大化每个 boundary 的 `r4` 实际样本数；
6. 最小化 selected-to-boundary distance；
7. 最后以较早时间位置作确定性 tie-break。

[PROPOSAL] 可使用诊断专用 CP-SAT；只有 solver 返回 `OPTIMAL` 且 optimality gap 为 0 时，输出才允许标记为 `geometry_oracle=true`。没有 exact solver 时必须 fail closed，不得退化成 greedy 后继续叫 ceiling。

## 4.4 Frozen-detector secondary diagnostic

[PROPOSAL] 对每个 canonical GT oracle selection：

* gather 实际选中帧；
* 将实际位置写入 `irregular_selected_positions`；
* 使用 physical-grid ActionFormer；
* GT 保持 dense physical axis；
* 固定同一个 matched detector checkpoint；
* 运行 cls+reg loss 和完整 mAP evaluator。

[INFERENCE] 这仍不是“可学习 selector 的性能上限”，因为 detector 没有针对每个 oracle family 重训；它是一个成本很低的 necessary-condition diagnostic。

[PROPOSAL] 现有 `diagnose_duca_feasible_set_ceiling.py` 只保留为 candidate detector-loss validator；新脚本负责生成 family、证明约束和求解 oracle。

## 4.5 必须输出的指标

[PROPOSAL] 每个 family、每个原始视频输出：

* boundary recall@r0/r1/r2/r4；
* both-endpoint recall@r0/r1/r2/r4；
* short/medium/long action 的 any-frame 与 both-endpoint coverage；
* selected-to-boundary mean/median/p95 distance；
* boundary-local sampling enrichment；
* 每个 boundary 的 `r0/r1/r2/r4` 选帧数；
* stable-background budget release；
* max-gap p50/p95/max；
* unique selected K；
* heavy executed slots；
* clustering coefficient；
* privileged detector cls/reg loss；
* privileged Avg-mAP 与各 tIoU；
* 相对 exact-uniform 的 paired delta。

[PROPOSAL] `stable background` 固定定义为距任意 GT segment 及其端点超过 8 个 dense frames 的位置；不得事后调整半径。

[PROPOSAL] 重叠窗口先按原始视频合并，同一个原始 endpoint 在一个视频内只计一次；bootstrap 单位必须是原始 video。

## 4.6 伪代码

```python
for video in videos:
    L = video.valid_len
    K = min(384, L)

    families = {
        "uniform": build_uniform_family(L, K),
        "cellcf": build_one_per_cell_family(L, K),
        "cover_residual": build_skeleton_residual_family(L, K, max_gap=3),
        "variable_quota": build_exact_k_max_gap_family(L, K, max_gap=3),
        "unrestricted": build_exact_k_family(L, K),
    }

    for name, family in families.items():
        envelope = {}
        for metric in PRE_REGISTERED_CAPACITY_METRICS:
            solution = solve_binary_program(
                family=family,
                gt_segments=video.gt_segments,
                objective=metric,
            )
            assert solution.status == "OPTIMAL"
            envelope[metric] = evaluate_selection(solution.positions)

        canonical = solve_lexicographic_oracle(
            family=family,
            gt_segments=video.gt_segments,
            objective_order=FROZEN_OBJECTIVE_ORDER,
        )
        assert canonical.status == "OPTIMAL"
        assert len(canonical.positions) == K
        assert max_unselected_hole(L, canonical.positions) <= family.max_gap

        write_geometry_and_detector_record(
            family=name,
            envelope=envelope,
            canonical=canonical,
            provenance=hash_bound_provenance,
        )
```

## 4.7 停止规则

[PROPOSAL] **当前 CellCF 不再获得长训练预算。** 即使 B 的 r0 oracle 有改善，它也只能保留为 phase-correction control，不能恢复为 adaptive-allocation 主方法。

[PROPOSAL] 若 B 相对 A 的 privileged detector oracle同时满足：

[
\Delta\text{Avg-mAP}<0.5,\qquad
\Delta @0.7<1.0,
]

则 CellCF 连 phase-correction 支线也停止，只保留历史结果。

[PROPOSAL] C 或 D 只有同时满足以下条件才进入 60-epoch 训练：

1. exact-K 和 max-gap 合规率 100%；
2. boundary recall@r0 相对 A 至少提高 10 个百分点；
3. `r4` 每边界平均多分配至少 1.5 帧；
4. stable-background 释放预算平均至少 `0.10K`；
5. short-action any-frame coverage 不低于 A；
6. privileged detector oracle 的 `ΔAvg-mAP≥0.75` 或 `Δ@0.7≥1.0`；
7. 上述 detector delta 的 video-cluster 95% CI 下界大于 0。

[PROPOSAL] 若 D 相对 C 的 oracle 优势小于 `+0.5 Avg-mAP` 且小于 `+1.0 @0.7`，固定选择 C；复杂度更高的 D 不进入主线。

# 6. `FINAL_METHOD_SPECIFICATION`

## 6.1 方法名称与核心合同

```text
Method: DUCA-CARA
Expansion: Coverage-Anchored Residual Allocation
Task: Offline TAD
Dense window: T=768
Heavy budget: K=384
Coverage max hole: G=3
Skeleton count at L=768: M=192
Adaptive residual count: R=192
Detector coordinate: true_time_dense_index
Detector bridge: hard counterfactual distillation, no direct gradient
Dynamic budget: disabled
```

## 6.2 网络与张量流

[PROPOSAL] 输入 dense offline window：

[
X\in\mathbb R^{B\times3\times T\times H\times W},
\qquad
m\in{0,1}^{B\times T}.
]

[PROPOSAL] 所有 T 帧先缩放到 64×64，送入现有 binary actionness probe：

[
\ell,\ h
========

f_{\text{coarse}}(X_{64}),
]

其中

[
\ell\in\mathbb R^{B\times T},\qquad
h\in\mathbb R^{B\times T\times96}.
]

[PROPOSAL] action probability 和 uncertainty：

[
p_t=\sigma(\ell_t),
]

[
H_t=-p_t\log p_t-(1-p_t)\log(1-p_t),
]

[
u^{\text{unc}}_t=1-|2p_t-1|.
]

[PROPOSAL] transition descriptor 直接复用现有形式：

[
d_t=
[
\Delta\ell_t,,
|\Delta\ell_t|,,
\Delta H_t,,
|\Delta H_t|,,
\Delta h_t,,
|\Delta h_t|,,
1-\cos(h_t,h_{t-1})
]
\in\mathbb R^{197}.
]

[PROPOSAL] scorer：

[
s_t=f_{\text{transition}}(\operatorname{stopgrad}(d_t)).
]

[SEVERE_VERDICT] 新主方案中，所有 selector loss 都不得更新 coarse stem、ASFormer 或 binary action head；粗模型参数只归 binary action/background BCE 所有。这样边界监督只能训练 transition-derived scorer，不会把 coarse model 偷换成 start/end predictor。

## 6.3 Coarse action/background BCE

[PROPOSAL] 对训练 GT segment ([s_n,e_n))：

[
y_t=
\mathbf1
\left[
\exists n:\ s_n\le t<e_n
\right].
]

使用 proper unweighted BCE：

[
L_{\text{act}}
==============

\frac{
\sum_{b,t}m_{b,t},
\operatorname{BCEWithLogits}(\ell_{b,t},y_{b,t})
}{
\sum_{b,t}m_{b,t}
}.
]

[PROPOSAL] 不使用 batch-dependent `pos_weight`，避免把输出概率变成不可解释的重加权 posterior；类不平衡通过 AUPRC 和 train-only calibration audit处理。

[PROPOSAL] 若进行 temperature calibration，只能在冻结的 train-video calibration split 上拟合一个 scalar temperature/bias，并在 validation/test 前冻结；不得读取 validation/test GT 调整。

## 6.4 Hard coverage 与 exact budget

[PROPOSAL] 对每个有效长度 L：

1. (K_L=\min(384,L))；
2. 构造最小 (G=3) scaffold，大小 (M_G(L))；
3. 在非 scaffold 的有效位置上按 (s_t) 取 top (R=K_L-M_G(L))；
4. 合并并排序；
5. 断言 exact-K 与 max-gap；
6. 将实际 positions 原样写入 physical-grid metadata。

[MATHEMATICAL_CONSEQUENCE] coverage、diversity 和 budget 不再作为可被权重抵消的 soft loss：

* exact-K 是 hard constraint；
* max-gap 是 hard constraint；
* scaffold 提供全局 diversity；
* residual 被允许有意聚集，不添加会抵消边界聚集的 redundancy penalty。

## 6.5 Transition-derived boundary supervision

[PROPOSAL] 仅训练 transition scorer 的 train-only target：

[
q_t
\propto
\sum_n
\left[
\exp\left(-\frac{(t-s_n)^2}{2\sigma^2}\right)
+
\exp\left(-\frac{(t-e_n)^2}{2\sigma^2}\right)
\right],
]

其中 (\sigma=2)，截断半径 4。

[PROPOSAL] listwise loss：

[
L_{\text{transition}}
=====================

-\sum_t q_t
\log
\frac{\exp(s_t/\tau)}
{\sum_{j:m_j=1}\exp(s_j/\tau)},
\qquad \tau=0.7.
]

[MATHEMATICAL_CONSEQUENCE] 该目标直接训练 hard top-R 所需的全局排序，但不会把 soft occupancy 喂给 detector，因此没有 soft-forward/hard-inference detector mismatch。

## 6.6 Detector-aware hard counterfactual distillation

[PROPOSAL] 主 hard selection 为

[
S=C_G\cup A.
]

只允许从 adaptive residual (A) 中移除位置 (r)，再从未选位置加入 (a)：

[
S'=S\setminus{r}\cup{a}.
]

[MATHEMATICAL_CONSEQUENCE] 因为 skeleton 不动，任何 swap 自动保持 exact-K 和 max-gap≤3；不需要事后 repair。

[PROPOSAL] 使用当前 detector 参数，在 `no_grad` 下计算：

[
U_{a,r}
=======

## L_{\text{det}}(S)

L_{\text{det}}(S').
]

正值表示加入 (a)、移除 (r) 改善 detector。

[PROPOSAL] selector pairwise loss：

[
\Delta s=s_a-s_r,
]

[
L_{\text{CF}}
=============

\frac1N
\sum
w(U)
\operatorname{softplus}
\left(
-\operatorname{sign}(U)
\frac{\Delta s}{\tau_{\text{CF}}}
\right).
]

[PROPOSAL] `U` 必须 detach；`L_CF` 只更新 transition scorer。

[MATHEMATICAL_CONSEQUENCE] 该梯度方向与真实 hard inference utility 对齐：若某次 hard swap 降低 detector loss，则训练要求加入位置得分高于被移除位置；它不是“nonzero gradient 即正确”，而是显式有符号排序。

[PROPOSAL] 每 8 个 successful updates 执行一次 counterfactual step，每次最多 4 个候选；前 600 successful updates 不启用 CF。平均额外 detector forward-equivalent 约为：

[
\frac{1+4}{8}=0.625
]

次/更新，外加正常主 forward。

## 6.7 总损失与梯度所有权

[
L
=

L_{\text{det}}
+
\lambda_aL_{\text{act}}
+
\lambda_tL_{\text{transition}}
+
\lambda_{\text{CF}}L_{\text{CF}}.
]

[PROPOSAL] 初始固定权重：

[
\lambda_a=1,\qquad
\lambda_t=0.5,\qquad
\lambda_{\text{CF}}=0.25.
]

| Loss                    | 更新对象                                                          | 禁止更新对象                                          |
| ----------------------- | ------------------------------------------------------------- | ----------------------------------------------- |
| (L_{\text{act}})        | [PROPOSAL] low-res stem、ASFormer、binary head                  | transition scorer、heavy detector                |
| (L_{\text{transition}}) | [PROPOSAL] transition scorer                                  | coarse stem/ASFormer/action head、heavy detector |
| (L_{\text{CF}})         | [PROPOSAL] transition scorer                                  | coarse model、heavy detector                     |
| (L_{\text{det}})        | [PROPOSAL] VideoMAE adapter、projection、neck、ActionFormer head | coarse model、transition scorer                  |

[SEVERE_VERDICT] 不使用 direct ST pixel bridge，不使用 soft frame mixture，不让 detector loss 破坏 actionness calibration。

## 6.8 Physical-time detector

[PROPOSAL] 对实际选择

[
P=(p_1<\cdots<p_K)
]

写入：

```text
irregular_selected_positions=P
selected_dense_indices=P
detector_output_coordinate_space=true_time_dense_index
irregular_native_axis=true
remap_gt_to_selected_axis=false
```

[PROPOSAL] GT segments 始终保留 dense physical time，不再做 selected-axis remap。

[CODE_FACT] 已有 physical-grid head会根据实际 positions 将 nominal center 映射到 physical center，并以相邻 physical positions 推导 physical stride 和 regression range。

[MATHEMATICAL_CONSEQUENCE] acquisition time、GT time、head prior time 和 prediction time成为同一个坐标系，消除当前 CellCF 的 observation-time substitution。

## 6.9 AMP、successful update 与 EMA

[PROPOSAL] 延续现有 fail-closed 语义：

* counterfactual teacher 在主 detector graph 建立前运行；
* no-grad autocast 禁止复用 detached FP16 parameter cache；
* 每个候选前恢复 detector buffers、PyTorch/CUDA/Python/NumPy RNG；
* AMP overflow 时重放同一 batch/RNG；
* optimizer、LR schedule、CF schedule、EMA 和 `after_optimizer_step` 仅在 successful update 后前进；
* terminal checkpoint 只评估 `state_dict_ema`。

[CODE_FACT] 现有 teacher 已实现 buffer/RNG 保存恢复、frozen loss normalizer 和 no-grad utility detach，可直接修改候选集合与坐标，而无需重写整个 teacher。

## 6.10 短窗口

[PROPOSAL] 选择语义使用：

[
K_{\text{eff}}=\min(384,L).
]

若 (L\le384)，选择全部有效帧。

[PROPOSAL] 第一版保持当前固定 VideoMAE wrapper 时，必须同时报告：

```text
unique_selected_K=K_eff
heavy_executed_slots=384
```

[SEVERE_VERDICT] 只要 heavy backbone 仍计算 padded 384 slots，就不得把 `K_eff` 作为成本节省。Dynamic MUST 仍然冻结。

## 6.11 训练和推理同构

[PROPOSAL] 训练 detector forward 和正式推理都只使用 hard set `S`。

[PROPOSAL] 推理路径严格为：

```text
dense decoded window
→ low-res binary action-state model
→ transition descriptors
→ transition scorer
→ fixed scaffold + hard residual top-R
→ gather actual K frames
→ heavy VideoMAE/AdaTAD detector on physical grid
→ NMS/postprocess
```

[SEVERE_VERDICT] 推理时不得读取 GT、teacher、oracle selection、JSONL、ledger、detector cache 或 train-time utility。

## 6.12 成本语义与 break-even

[MATHEMATICAL_CONSEQUENCE] 相对 bare exact-uniform384，新方法具有相同 heavy K，却多出 dense coarse probe 和 selector，因此通常不会更便宜；它必须用更高定位精度证明自己是新的 Pareto 点。

[MATHEMATICAL_CONSEQUENCE] 相对 dense AdaTAD768，新方法可能通过减少 heavy backbone 帧数节省成本，但必须计入 dense decode、resize、coarse probe、selector 和 physical-grid overhead。

[PROPOSAL] 训练能耗 break-even 相对 dense 定义为：

[
N_{\text{BE}}
=============

\frac{
E_{\text{train,new}}-E_{\text{train,uniform}}
}{
E_{\text{infer,dense}}-E_{\text{infer,new}}
}.
]

只有分母为正时才报告有限 break-even。

[SEVERE_VERDICT] 相对 bare uniform384，若 (E_{\text{infer,new}}>E_{\text{infer,uniform}})，不存在成本 break-even；不得伪造一个正数。

## 8.4 核心 decoder 补丁

```python
from __future__ import annotations

import math
from dataclasses import dataclass

import torch


@dataclass
class CoverageResidualSelection:
    hard_occupancy: torch.Tensor          # [B, T]
    selected_positions: torch.Tensor      # [B, K_max], padded with -1
    selected_valid: torch.Tensor          # [B, K_max]
    scaffold_occupancy: torch.Tensor      # [B, T]
    residual_occupancy: torch.Tensor      # [B, T]
    effective_k: torch.Tensor             # [B]
    scaffold_count: torch.Tensor          # [B]
    max_unselected_hole: int


def minimal_balanced_scaffold(
    valid_len: int,
    max_unselected_hole: int,
    *,
    device: torch.device,
) -> torch.Tensor:
    """Minimum-cardinality deterministic set with max hole <= G."""

    L = int(valid_len)
    G = int(max_unselected_hole)
    if L <= 0:
        return torch.empty(0, dtype=torch.long, device=device)
    if G < 0:
        raise ValueError("max_unselected_hole must be non-negative")

    count = max(1, math.ceil((L - G) / (G + 1)))
    count = min(count, L)

    # Distribute L-count unselected frames over count+1 holes.
    unselected = L - count
    base, extra = divmod(unselected, count + 1)
    holes = [base + 1] * extra + [base] * (count + 1 - extra)

    if max(holes, default=0) > G:
        raise RuntimeError("balanced scaffold construction violated max hole")

    positions: list[int] = []
    cursor = holes[0]
    for index in range(count):
        positions.append(cursor)
        cursor += 1 + holes[index + 1]

    result = torch.tensor(positions, dtype=torch.long, device=device)
    if result.numel() != count:
        raise RuntimeError("scaffold count mismatch")
    return result


def coverage_residual_topk(
    policy_scores: torch.Tensor,
    valid_mask: torch.Tensor,
    *,
    k: int,
    max_unselected_hole: int,
) -> CoverageResidualSelection:
    """Hard-identical training/inference selection.

    Coverage is guaranteed by a fixed minimum scaffold. All remaining budget
    is allocated globally by learned or hand-written transition evidence.
    """

    if policy_scores.ndim != 2:
        raise ValueError("policy_scores must be [B,T]")
    valid = valid_mask.to(device=policy_scores.device, dtype=torch.bool)
    if valid.shape != policy_scores.shape:
        raise ValueError("valid_mask must align with policy_scores")

    batch, temporal_len = policy_scores.shape
    hard = torch.zeros_like(policy_scores)
    scaffold_mask = torch.zeros_like(policy_scores)
    residual_mask = torch.zeros_like(policy_scores)

    rows: list[torch.Tensor] = []
    effective_k: list[int] = []
    scaffold_counts: list[int] = []

    for batch_idx in range(batch):
        valid_positions = torch.nonzero(
            valid[batch_idx], as_tuple=False
        ).flatten()
        L = int(valid_positions.numel())
        K = min(int(k), L)
        effective_k.append(K)

        if K == 0:
            rows.append(torch.empty(0, dtype=torch.long,
                                    device=policy_scores.device))
            scaffold_counts.append(0)
            continue

        local_scaffold = minimal_balanced_scaffold(
            L,
            max_unselected_hole,
            device=policy_scores.device,
        )
        if local_scaffold.numel() > K:
            raise ValueError(
                f"coverage scaffold requires {local_scaffold.numel()} "
                f"positions but budget is {K}"
            )

        scaffold = valid_positions[local_scaffold]
        scaffold_mask[batch_idx, scaffold] = 1.0
        scaffold_counts.append(int(scaffold.numel()))

        residual_count = K - int(scaffold.numel())
        allowed = valid[batch_idx].clone()
        allowed[scaffold] = False

        if residual_count > 0:
            candidate_positions = torch.nonzero(
                allowed, as_tuple=False
            ).flatten()

            # Stable sort makes equal-score ties deterministic by time index.
            candidate_scores = policy_scores[
                batch_idx, candidate_positions
            ].detach()
            order = torch.argsort(
                candidate_scores,
                descending=True,
                stable=True,
            )
            residual = candidate_positions[order[:residual_count]]
            residual_mask[batch_idx, residual] = 1.0
            selected = torch.cat((scaffold, residual)).sort().values
        else:
            selected = scaffold.sort().values

        if selected.numel() != K:
            raise RuntimeError("coverage-residual decoder violated exact K")

        hard[batch_idx, selected] = 1.0
        rows.append(selected)

    max_k = max(effective_k, default=0)
    padded = torch.full(
        (batch, max_k),
        -1,
        dtype=torch.long,
        device=policy_scores.device,
    )
    selected_valid = torch.zeros(
        (batch, max_k),
        dtype=torch.bool,
        device=policy_scores.device,
    )
    for batch_idx, row in enumerate(rows):
        padded[batch_idx, : row.numel()] = row
        selected_valid[batch_idx, : row.numel()] = True

    return CoverageResidualSelection(
        hard_occupancy=hard,
        selected_positions=padded,
        selected_valid=selected_valid,
        scaffold_occupancy=scaffold_mask,
        residual_occupancy=residual_mask,
        effective_k=torch.tensor(
            effective_k, device=policy_scores.device
        ),
        scaffold_count=torch.tensor(
            scaffold_counts, device=policy_scores.device
        ),
        max_unselected_hole=int(max_unselected_hole),
    )
```

## 8.5 Hard utility 排序损失

```python
import torch
import torch.nn.functional as F


def hard_swap_utility_ranking_loss(
    policy_scores: torch.Tensor,       # [B,T]
    add_positions: torch.Tensor,       # [B,M]
    remove_positions: torch.Tensor,    # [B,M]
    detector_utility: torch.Tensor,    # [B,M], detached
    candidate_valid: torch.Tensor,     # [B,M]
    *,
    temperature: float = 0.7,
    utility_epsilon: float = 1.0e-6,
    max_weight: float = 4.0,
) -> torch.Tensor:
    valid = (
        candidate_valid.bool()
        & torch.isfinite(detector_utility)
        & (detector_utility.abs() > utility_epsilon)
    )
    if not valid.any():
        return policy_scores.sum() * 0.0

    add_score = policy_scores.gather(
        1, add_positions.clamp_min(0)
    )
    remove_score = policy_scores.gather(
        1, remove_positions.clamp_min(0)
    )
    score_delta = (add_score - remove_score) / temperature

    utility = detector_utility.detach()
    direction = utility.sign()

    scale = utility.abs()[valid].median().clamp_min(
        utility_epsilon
    )
    weight = (utility.abs() / scale).clamp(max=max_weight)

    per_pair = weight * F.softplus(-direction * score_delta)
    return per_pair[valid].mean()
```

# 10. `FINAL_RECOMMENDATION`

1. [SEVERE_VERDICT] 立即 KILL 当前 one-per-cell CellCF 作为论文主方法，因为它在数学上只能做 uniform phase/content correction，不能做边界自适应预算分配。

3. [PROPOSAL] 唯一应进入实现的主方案是 `G=3` 的 192-frame coverage skeleton 加 192-frame global residual allocation。
4. [PROPOSAL] 所有实际选择位置必须直接送入仓库已有 physical-grid ActionFormer，GT 不再 remap 到 selected-axis。
5. [PROPOSAL] coarse stem、ASFormer 和 binary head只由 action/background BCE训练，transition 与 detector utility只训练 scorer。
6. [PROPOSAL] detector feedback 使用 residual-only hard counterfactual signed ranking，不使用 straight-through soft detector bridge。
7. [PROPOSAL] ceiling 通过后只运行六臂、三种子、官方 60-epoch、terminal-EMA 的决定性矩阵。
8. [PROPOSAL] 成本 profiler 必须先拆分 decode、resize/preprocess 与 NMS，并同时比较 bare uniform384 和 dense768。
9. [SEVERE_VERDICT] 若 `CAR-CF` 不能稳定超过 matched uniform，或 full-stack savings 不成立，DUCA 应从论文主线终止，Dynamic MUST 继续冻结。
