## **大修后重审**

研究问题值得继续，“严格帧预算下的任务感知前置选帧”具备方法论文潜力；但当前规范尚未完整定义密度可行域、连续代理、整数 exact-K 解码、坐标契约和贡献目标，A0–A4 也不能完成所声称的独立归因。逆 CDF 固定分位本身缺乏新颖性，干净均匀、硬收益对齐和真实成本均未闭环。应先形式化并执行最小门禁，不能批准现规范直接进入完整长训练。

## 4.2 主要问题

1. **“低成本证据”没有计算合同。**
   科学问题是：节省来自少处理重型 backbone，还是被低分辨率 probe、解码和 selector 抵消？应固定证据输入分辨率、访问帧数和部署路径，并要求 probe+selector 不超过被节省 backbone 成本的 15%。失败后保留方法正确性研究，但删除效率主张。

2. **P1/P2 全通过后才允许实施 P3，过度串行。**
   P1 的 wrapper parity 与 exact-K/坐标测试确实是长训练依赖；但 P2 的直接梯度准入只应阻塞 A4，不应阻塞有界解码器、A1/A2 或排名教师的独立实现。当前顺序会把科学依赖误写成项目管理依赖。

3. **“第一粒种子提高 0.5 后才继续”会产生赢家偏差。**
   单一随机种子既用于选路线又进入最终均值，会高估结果。应把该运行定义为 development screening seed，明确排除出论文最终统计；冻结方法后使用三枚预登记新种子。

4. **A4 门既可能过松，也可能过严。**
   “置信区间下界大于 0”允许极小而无意义的相关；同时五个条件全部并列，可能因一个低功效子指标误杀。需要一个预登记主终点和若干安全终点。

5. **64 个视频、128 个窗口不是天然充分。**
   同一窗口产生几十个 perturbation，它们不是独立样本。统计单位应是视频；先做 cluster-level power simulation，再确定样本量。候选数增加不能替代独立视频数。

6. **A0–A4 当前不能独立回答四个问题。**
   A1/A2 的 selector 基础学习目标未定义；A2→A3 同时改变监督和可能的尺度归一化；A3 第一粒种子为正后才补 cls/reg 单独臂会造成选择性归因。

7. **checkpoint 规则仍有选择成本不一致风险。**
   相同评估频率并不意味着相同过拟合机会，尤其 learned selector 的方差更高。最终主表最好统一使用“正好 6000 次成功更新后的 EMA”，而不是各臂挑最佳中间点。官方配置本身也以 EMA 和固定 60 轮终点为核心。

8. **“不改后端”的边界不够精确。**
   允许：插件在进入 detector 前把 GT 从原时间映到 warped time，输出后再逆映射；标签分配器、检测头和损失代码本身保持不变。
   不允许：改变标签匹配规则、回归参数化、时域位置编码或 NMS。
   长度相关的张量尺寸从 768 改为 K 是接口适配，不是方法贡献，但必须让 A0–A4 完全一致。

9. **决定性诊断尚缺。**
   必须包括：mAP@0.7、短动作、起止边界误差、选帧密度熵、最大洞、CDF 偏移、动作内/边界/背景采样比例、不同种子选帧 Jaccard、round-trip 坐标误差。TAD 对缺帧和时序扰动的定位误差具有明显敏感性，因此只看平均 mAP 不足。([[CVF Open Access](https://openaccess.thecvf.com/content/CVPR2024/html/Zeng_Benchmarking_the_Robustness_of_Temporal_Action_Detection_Models_Against_Temporal_CVPR_2024_paper.html)][3])

10. **PR 不是可审阅的纯文档 PR。**
    133 文件的 aggregate diff 会掩盖规范修改。失败后不是否决方法，而是拒绝对该 PR 给出“通过书面规范”的工程结论。

## 4.3 次要问题

* “轮”与“成功 optimizer update”混用；所有课程、门和预算应以 6000 次成功更新定义。
* 未定义首尾未覆盖区间是否计入最大间隔。
* 未定义多个整数解等价时的确定性 tie-break。
* “累计坐标偏移”应直接写为相对 canonical uniform anchor 的前缀偏移，而不是仅用自然语言。
* “分类与回归至少一项分别显示正对齐”语义矛盾，应改为两者各自达到安全门，或明确哪一个是主任务。
* 0.1/0.25/0.5 三个梯度比例仍有开发自由度；建议只保留一个基于梯度范数自动归一的固定目标比例。
* “质量传输”没有数学定义；应删除该模糊术语，改为 rank-normalized distribution distillation。
* 69% 应从成功门改为 stretch goal。

### 5. 推荐的唯一主模型

## 5.1 模型名称与核心

推荐唯一主模型为：

> **有界效用校准单调时间扭曲**：用低成本证据预测一个受局部伸缩和累计偏移双重约束的时间密度，以固定分位生成连续采样位置，再由确定性动态规划解码严格 K 个整数帧；selector 主要通过经硬换帧验证的分类/回归效用排名学习。

主模型不包含直接检测梯度。直接梯度只作为一个通过额外门禁后的增强臂。

这使论文只有一个核心因果链：

[
\text{经验证的任务效用排序}
\rightarrow
\text{受约束时间密度}
\rightarrow
\text{有界单调时间扭曲}
\rightarrow
\text{exact-K 硬选帧}
\rightarrow
\text{不变的 TAD detector}.
]

## 5.2 正密度与可行域

候选时间格点为 (i=0,\ldots,T-1)，对应单元

[
I_i=[i/T,(i+1)/T).
]

低成本证据为 (e_{1:T})，selector 输出 logits：

[
a_i=h_\theta(e_{1:T})_i,\qquad
\bar p_i=\operatorname{softmax}(a)_i.
]

将 (\bar p) 投影到预登记的凸可行域：

[
p_\theta
========

\arg\min_{p\in\mathcal P_{T,K}}
\operatorname{KL}(p|\bar p),
]

其中

[
\mathcal P_{T,K}=
\left{
p:
\sum_i p_i=1,\quad
\frac{1}{2T}\le p_i\le\frac{2}{T},\quad
\left|
\sum_{r=0}^{i-1}p_r-\frac{i}{T}
\right|
\le \delta_K
\right},
]

固定

[
\delta_K=\frac{4}{K}.
]

定义分段常数正密度：

[
\rho_\theta(t)=T p_i,\qquad t\in I_i.
]

因此

[
\frac12\le\rho_\theta(t)\le2.
]

该定义具有三个优点：

1. 正性由构造保证；
2. 局部采样密度最多是均匀的 2 倍、最少是 1/2；
3. CDF 与恒等时间的累计偏离显式受限，而不是依赖损失惩罚“希望它别塌缩”。

这些常数必须在规范中固定。允许以后通过训练侧开发集做一次替换，但不得在主结果后回调。

## 5.3 累积分布和连续位置

[
F_\theta(t)=\int_0^t\rho_\theta(u),du,
\qquad
q_j=\frac{j+1/2}{K},
\qquad
y_j=F_\theta^{-1}(q_j).
]

连续代理使用线性插值：

[
\tilde x_j=\operatorname{Interp}(x_{1:T},y_j).
]

若启用硬前向、软反向诊断：

[
x_j^{ST}
========

x_{s_j}
+
\tilde x_j
----------

\operatorname{sg}(\tilde x_j).
]

其前向严格等于真实离散帧 (x_{s_j})，软项只提供代理梯度。

## 5.4 整数 exact-K 解码

令格点中心

[
c_i=\frac{i+1/2}{T}.
]

使用确定性动态规划：

[
S^\star
=======

\arg\min_{0\le s_0<\cdots<s_{K-1}<T}
\sum_{j=0}^{K-1}
\left(c_{s_j}-y_j\right)^2,
]

约束：

[
1\le s_{j+1}-s_j\le G_K,
]

[
s_0\le G_K-1,\qquad
T-1-s_{K-1}\le G_K-1,
]

[
|s_j-u_j|\le D_K,
]

其中

[
G_K=\left\lceil\frac{2T}{K}\right\rceil,\qquad
D_K=\left\lceil\frac{4T}{K}\right\rceil,
]

(u_j) 是同一解码器在常数密度下产生的 canonical uniform 序列。所有代价相同时采用字典序最小解。

由此得到：

* 严格 K；
* 唯一、递增；
* 首尾及内部最大未覆盖洞受限；
* 每个位置相对均匀 anchor 的累计偏移受限；
* 同一输入必得同一输出；
* 常数 logits 严格退化为 A0 使用的 exact-uniform。

不要再在解码后增加 hard repair。任何 repair 都说明可行域或解码器定义失败。

## 5.5 插件侧最小时间修正

非均匀采样后，检测器的 K 个槽应解释为均匀的 **warped time** (q)，而不是原始物理时间 (t)。

训练时：

[
q_{\text{gt,start}}=F_\theta(t_{\text{gt,start}}),\qquad
q_{\text{gt,end}}=F_\theta(t_{\text{gt,end}}).
]

将这两个值作为插件输出交给原封不动的标签分配器和检测损失。该 GT 映射使用 hard/de­tached (F_\theta)，不得让 selector 从 GT 坐标变换中获得隐蔽梯度。

推理时：

[
\hat t_{\text{start}}=F_\theta^{-1}(\hat q_{\text{start}}),\qquad
\hat t_{\text{end}}=F_\theta^{-1}(\hat q_{\text{end}}).
]

这属于插件 I/O 坐标适配，不属于 detector 内部真实时间注入。检测头、标签分配规则、损失和 NMS 全部不改。

**只有“限制扭曲”而没有这套 (t\leftrightarrow q) 对称映射是不够的。**

## 5.6 可证明命题

可以提出真实但克制的几何命题，不能声称它保证 mAP。

**命题：有界时间扭曲。**
设

[
0<m\le\rho(t)\le M,\qquad
|F-I|_\infty\le\delta,\qquad
G=F^{-1}.
]

则对任意 (q,q_1,q_2\in[0,1])：

[
|G(q)-q|\le\delta,
]

[
\frac{|q_2-q_1|}{M}
\le
|G(q_2)-G(q_1)|
\le
\frac{|q_2-q_1|}{m},
]

并且

[
\left|
\big(G(q_2)-G(q_1)\big)-(q_2-q_1)
\right|
\le2\delta.
]

若整数解码中心相对连续分位的最大误差为

[
r=\max_j|c_{s_j}-y_j|,
]

则

[
|c_{s_j}-q_j|\le\delta+r,
]

[
c_{s_{j+1}}-c_{s_j}
\le
\frac{1}{Km}+2r.
]

若 detector 在 warped time 上的边界误差为
(|\hat q-q|)，则映回原时间后的误差满足

[
|\hat t-t|
\le
\frac{|\hat q-q|}{m}+r_{\text{map}}.
]

这证明的是：

* 局部伸缩上界；
* 累计时间偏移上界；
* 区间长度扭曲上界；
* warped-time 边界误差映回原时间时不会无限放大。

它**不证明**检测性能提高，也不证明相同语义在 warp 后完全不变。后者仍需实验。

## 5.7 贡献监督选择

| 目标               | 优点         | 致命缺点                                             | 裁决                           |
| ---------------- | ---------- | ------------------------------------------------ | ---------------------------- |
| 原始幅值拟合           | 简单         | cls/reg 尺度不同，重尾、随 checkpoint 变化；5–6 对 0.2 没有直接含义 | 删除主路线                        |
| Listwise ranking | 抗尺度，直接关心排序 | 不能直接规定应分配多少密度质量                                  | 可作中间表示                       |
| 分布蒸馏             | 与密度输出天然一致  | 温度和绝对幅值可能成为调参自由度                                 | 适合，但需 rank-normalized target |
| 最优传输             | 可表达质量移动和距离 | 解码器本身已经是 1D 单调传输；再加 OT 会重复机制并引入正则系数              | 不推荐为主目标                      |

推荐唯一主要目标为 **rank-normalized distribution distillation**。

连续代理分别产生分类和回归的边际效用：

[
g_i^{h}
=======

-\frac{\partial L_h}{\partial a_i},
\qquad
h\in{\mathrm{cls},\mathrm{reg}}.
]

对每个窗口内部排序，高效用 rank 为 (T)，最低为 1：

[
q_i^h
=====

\frac{2,\operatorname{rank}(g_i^h)}
{T(T+1)}.
]

主 selector 损失：

[
L_{\mathrm{RDD}}
================

\frac12\operatorname{KL}(q^{\mathrm{cls}}|p_\theta)
+
\frac12\operatorname{KL}(q^{\mathrm{reg}}|p_\theta).
]

教师 rank 完全 stop-gradient，不求二阶梯度。其合法性由硬换帧的 `G_rank` 验证。

这同时保留：

* listwise 的尺度稳健性；
* distribution target 与密度输出的匹配；
* cls/reg 分开审计；
* 无温度、无原始幅值拟合；
* 无第二个 OT 模块。

## 5.8 训练课程

推荐一个主课程和一个必要对照：

### 主课程

总计 6000 次成功 optimizer update：

[
p^{(\alpha)}
============

(1-\alpha)\frac{\mathbf1}{T}
+
\alpha p_\theta.
]

* update 0–999：(\alpha=0)，严格均匀硬前向；selector 可学习 RDD，但不改变选帧；
* update 1000–1499：(\alpha) 从 0 线性升到 1；
* update 1500–5999：(\alpha=1)。

这是一个单次联合训练，不是 30+60 两阶段训练。

### 必要对照

从 update 0 起 (\alpha=1)，其余完全相同。

因此能回答：均匀稳定期是否是必要优化机制，而不是比较两套不同训练预算。

### 参数梯度

* detector 参数只接受原官方 (L_{\mathrm{cls}}+L_{\mathrm{reg}})；
* selector 主模型只接受 (L_{\mathrm{RDD}})；
* 不因关闭 selector 梯度而关闭 detector 学习；
* 最终 checkpoint 统一为第 6000 次成功更新后的 EMA。

### 唯一允许的增强版

只有 `G_direct` 通过时，增加：

[
L_{\mathrm{sel}}
================

L_{\mathrm{RDD}}
+
\lambda_{\mathrm{dir}}L_{\mathrm{det}}^{ST}.
]

固定梯度范数目标比例为 0.25：

[
\lambda_{\mathrm{dir}}
======================

\operatorname{clip}
\left(
0.25
\frac{|\nabla_\theta L_{\mathrm{RDD}}|}
{|\nabla_\theta L_{\mathrm{det}}^{ST}|+\epsilon},
\lambda_{\min},
\lambda_{\max}
\right).
]

不再枚举 0.1/0.25/0.5 后按性能选一个。

## 5.9 真正的新意边界

逆 CDF、累计质量和固定系统点并不是新理论；系统 PPS 抽样和已有视频采样方法已包含相近思想。([[Taylor & Francis Online](https://www.tandfonline.com/doi/abs/10.1080/01621459.1966.10480902)][4])

允许声称的新意只能是：

1. **带统一恒等路径、局部伸缩和累计偏移证书的 exact-K TAD 时间扭曲；**
2. **用真实硬换帧验证后才允许进入模型的任务效用 rank-to-density 学习；**
3. **不修改 detector 内部结构的 warped-time I/O 契约，以及高 IoU、短动作和真实系统成本证据。**

若这三点没有同时成立，不应使用“理论传输模型”作为主要叙事。

#### 6.1 可直接写回规范的模型定义

> 主 selector 输出候选时间质量 (p)，并通过 KL 投影落入固定可行域 (\mathcal P_{T,K})。该可行域同时约束单格密度、CDF 相对恒等映射的累计偏移以及总质量。连续位置由固定分位 (F^{-1}((j+1/2)/K)) 得到，整数位置由带最大间隔、首尾覆盖和 canonical-uniform 偏移约束的确定性动态规划解码。任何解码后 repair 均视为实现失败。

#### 6.2 可直接写回规范的双门定义

> `G_rank` 判断 detached 分类/回归贡献排名是否能预测真实硬换帧收益；只有 `G_rank` 通过，贡献 rank-distillation 才可进入主模型。
> `G_direct` 在 `G_rank` 之上进一步判断连续梯度的多尺度可组合性、共享参数梯度稳定性以及短程配对训练收益；只有 `G_direct` 通过，直接检测梯度才可进入增强臂。
> `G_rank` 失败时，不得保留贡献教师；`G_direct` 失败但 `G_rank` 通过时，删除直接梯度，保留 detached ranking。

#### 6.3 推荐主实验臂

| 臂  | 定义                                   | 唯一问题             |
| -- | ------------------------------------ | ---------------- |
| A0 | clean exact-uniform                  | 公平基线             |
| A1 | 无累计/局部界的 monotone density + RDD，从零释放 | 学习密度本身是否有价值      |
| A2 | 有界 density + RDD，从零释放                | 几何约束是否有价值        |
| A3 | A2 + 1000-update uniform warmup      | **推荐主模型；课程是否必要** |
| A4 | A3 + 通过 G_direct 的直接检测梯度             | 直接梯度是否有额外价值      |

贡献监督是否必要，不应通过条件性长训练补臂，而应增加固定的机制控制：

* `A3-shuffled-RDD`：视频内打乱教师 rank；
* `A3-motion-prior`：使用简单部署可见运动先验替代任务贡献；
* 或在短程开发实验中使用 `A3-no-RDD`。

如果真实 RDD 不优于 shuffled/motion control，则删除贡献故事。

#### 6.4 可直接写回规范的依赖规则

> P1 基线恢复、P2 统计门和有界解码器实现可以并行。任何 learned-selector 长训练前只强制要求：clean/wrapper parity 通过、exact-K/坐标契约测试通过、A0 配置冻结。`G_rank` 仅阻塞 RDD 臂；`G_direct` 仅阻塞直接梯度臂。不得用“P2 尚未全部完成”阻塞与其无关的 A1/A2 实现。

#### 6.5 可直接写回规范的种子规则

> 第一枚运行固定为 development screening seed，仅用于决定是否冻结当前结构，不能进入论文均值、标准差或置信区间。设计冻结后，使用三枚事先登记且未用于开发的种子运行最终 A0 与主模型；不得按第一枚最终种子表现决定是否补齐其余种子。

#### 6.6 可直接写回规范的 checkpoint 规则

> 最终主表中所有训练臂统一使用正好 6000 次成功 optimizer update 后的 EMA checkpoint。训练侧留出集合用于冻结结构、门槛和超参数，不用于为每个最终臂单独挑最佳 epoch。官方测试只在模型和 checkpoint 规则冻结后评估一次。中间最佳 checkpoint 仅进入训练诊断图。

## 7.3 延期

1. **真正免训练模式。**
   主模型通过后，再用同一可行域、解码器和坐标适配器，将 (h_\theta) 替换为冻结通用证据源。科学问题是跨任务零适配能力，不应与任务适配主模型争夺主叙事。

2. **detector 内部真实时间注入。**
   只作为 same-selected-frames 上限诊断，用于估计纯插件因忽略真实时间产生的剩余差距。即使有效，也不得进入纯前置主声明。

3. **更多预算、动态 K、更多数据集。**
   K384/K192 和第二检测器尚未通过前，增加预算矩阵只会扩大未解释结果。

4. **整视频 1/2、1/4 降帧率的完整多种子。**
   先做一遍确认语义和历史结果；除非它成为强竞争基线，否则不需要优先补完整矩阵。

## 7.4 删除

* 原始贡献幅值拟合主臂；
* 第二套 OT 损失；
* 解码后 gap repair、uniform scaffold 或膨胀；
* A3 第一种子为正后才决定是否报告 cls/reg 分臂；
* 未通过 `G_direct` 后降低阈值继续运行 A4；
* 把 30+60、约 80 轮或 K192 中间 checkpoint 放入公平主表；
* 用官方测试选择梯度比例、课程长度、密度界限或 checkpoint；
* 新通用调度平台、复杂日志系统和版本治理型“贡献”。

### 10. CVPR 论文判断

## 10.1 一句话论文命题

> 在不修改时域动作检测器内部结构的条件下，一个由真实硬选帧效用校准、具有 exact-K 与可证明时间扭曲上界的前置单调采样插件，能够以显著降低的真实视频主干计算稳定保护高 IoU 和短动作定位性能。

## 10.2 允许的三个核心贡献

1. **有界 exact-K 时间扭曲模型**
   常数密度为均匀恒等路径，具有局部伸缩、累计偏移、最大洞和整数解码证书。

2. **硬策略验证的效用学习**
   分类和回归的连续边际贡献必须先通过真实硬换帧 rank gate，再以 scale-free rank distribution 训练 selector。

3. **严格纯插件证据**
   warped-time I/O adapter、clean uniform parity、第二检测器、高 IoU/短动作和完整端到端成本共同证明收益不是 wrapper、后端修改或 FLOPs 幻觉。

不要再增加第四、第五个“贡献”。课程训练、DP 实现、日志、Slurm 和 checkpoint 治理都不是论文贡献。

## 10.3 五个最可能的审稿攻击点及所需证据

| 攻击                                    | 审稿人会如何质疑                             | 必须给出的证据                                                              |
| ------------------------------------- | ------------------------------------ | -------------------------------------------------------------------- |
| 1. 只是 inverse-CDF/systematic sampling | “这是经典概率比例抽样加网络打分”                    | 与系统抽样、MGSampler-like baseline 的明确关系；真正的有界命题和消融                       |
| 2. 并非纯前置插件                            | “你改了标签、时间坐标和后端”                      | clean/wrapper parity；清晰的 (t\leftrightarrow q) I/O 合同；detector 源码差异清单 |
| 3. 软梯度不代表硬收益                          | “ST 只是伪梯度”                           | 多尺度硬 swap、matched random、视频级 CI、G_rank/G_direct                      |
| 4. 增益来自不公平训练                          | “uniform 少训练、checkpoint 不同或测试调参”     | 全部 6000 updates、final EMA、同测试次数、超预算结果单列                              |
| 5. 只对 AdaTAD 有效且成本不真实                 | “这是 AdaTAD wrapper trick，probe 吞掉节省” | 第二检测器、trained full-stack p50/p95、能耗、峰值显存和 overhead                   |

## 10.4 达到什么结果可以投稿

69–70% 不是必须门槛，也没有当前证据支持它是合理信息上界。建议投稿门槛为：

1. K=384 主模型相对 clean uniform：

   * 三种子平均至少 **+1.0 pp**；
   * 视频级配对 95% CI 下界大于 0；
   * 恢复至少 **40% 的 uniform→dense 性能差距**，或距离本地严格复现 dense 不超过约 2 pp；
   * mAP@0.7 不系统下降；
   * 短动作不系统下降。

2. K=192：

   * 相对 clean uniform 至少 +1.0 pp；
   * 高 IoU 和短动作方向一致。

3. 第二检测器：

   * 至少 +0.5 pp，且不依赖修改 detector 内部时间表示。

4. 效率：

   * 完整端到端 latency 或能耗至少降低 30%；
   * probe+selector 开销小于被节省 backbone 成本的 15%。

若最终达到 69% 左右，那将是很强的结果；但在 clean K384 uniform 未知时，不应以此反向设计实验。

## 10.5 什么结果意味着停止或重新定义路线

出现任一情况，应停止当前论文主张：

* clean/wrapper parity 长期无法达到近似等价；
* `G_rank` 失败，即贡献排序不能预测硬收益；
* K384 主模型相对 clean uniform 小于 +0.5 pp；
* 增益只在 detector 内部真实时间注入后存在；
* mAP@0.7 或短动作持续下降；
* 第二检测器上增益消失或反向；
* selector/probe 吞掉大部分 backbone 节省；
* 主要提升依赖超预算训练、最佳测试 checkpoint 或事后放宽门槛。

对应的重定义方式应是：

* 若效用 rank 失败：删除贡献蒸馏和 direct gradient，降级为有界采样基线；
* 若 warp 几何失败：放弃“纯前置且后端无感”，转为明确的 time-aware detector 方法；
* 若跨 detector 失败：诚实收缩为 AdaTAD-specific 方法；
* 若性能提升不足但成本极强：改写为系统效率论文，而不是 CVPR 方法论文；
* 若性能与成本都不足：停止 DUCA 主路线，不再通过增加损失和模块维持。

## 10.6 真正免训练模式的统一方式

免训练模式不应成为第二套方法。它应与任务适配主模型共用：

[
\mathcal P_{T,K},
\quad F,
\quad F^{-1},
\quad \text{exact-K DP},
\quad t\leftrightarrow q\text{ adapter}.
]

唯一变化是证据映射：

* 任务适配模式：(a=h_\theta(e))，在目标 TAD 训练集上学习；
* 免训练模式：(a=h_\phi(e))，(\phi) 完全冻结，且不使用目标域优化、教师、缓存或 GT。

这样它们共享同一理论和解码器，但承担不同声明：

* task-adapted 模式证明最佳任务效用；
* train-free 模式证明迁移和部署便利性；
* 二者不能混在同一主结果中，也不能用 train-free 弱结果反过来否定 task-adapted 模型。
