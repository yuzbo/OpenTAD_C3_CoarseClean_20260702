# 0. Executive verdict

## **HOLD_FOR_CORRECTNESS_FIX**

当前精确提交**不能直接进入 replacement P1**，但也**没有证据支持停止 GeoRoute**：

1. P1 Jobs `1196071–1196077` 是共同的 checkpoint 存储失败，没有产生任何可用 mAP、成本、selection 或 A-MoD 结果；Job `1196078` 也没有作出选择。因此不能把失败 namespace 当作模型负结果。
2. 当前代码存在六个足以污染 P1 科学解释的阻塞项：

   * 180×320 被复制补成 192×320，却没有 validity mask；
   * 每个 ViT block 的 attention/MLP 是 packed 的，但原 Adapter 仍在完整 padded lattice 上运行；
   * `free` 对照并不真正 ROI-free，它仍接收 learned geometry；
   * learned routes 还额外使用 route logits 做 softmax pooling，而 fixed/random 使用均匀 pooling；
   * hybrid 的硬策略与 ST surrogate 不一致，deterministic context 也错误获得 route gradient；
   * checkpoint 无界保存且 dispatcher 没有 aggregate storage headroom preflight。
3. 当前最值得优先验证的是 **Route B：真正 ROI-free 的 NativeTokenSelect-AdaTAD + validity-aware coordinate-lineage packed Adapter**。
4. **Route A 只能在修正后的 hybrid 于 P1 同时击败 free、random 和 geometry-only control 后进入 P2。**
5. A-MoD 与 FlashVID-inspired residual 均不得加入 P1R。

## 2.2 当前真正节省的成本

对于当前 180×320 的 `N=240`、P1 的 `K=64`：

[
\frac{K}{N}=0.2667,\qquad
\left(\frac{K}{N}\right)^2=0.0711.
]

因此：

* attention pairwise 项理论 token 比例约为 **7.1%**；
* QKV、projection、MLP 等线性 token 项理论比例约为 **26.7%**；
* 原 VideoMAE Adapter 当前仍为 **100% dense lattice 成本**；
* detector、decode、scout、H2D、NMS 均不因 K 自动按比例缩小。

所以当前路径只能声称“**packed attention/MLP execution**”，不能声称“完整 backbone 按 (K/N) 缩放”，更不能把固定 K 直接称为端到端加速。源码本身也把 dense Adapter 与 packed attention/MLP 分开计数。

## 3.1 Native remainder 的裁决

我不建议保留当前复制 padding 再仅加 mask，而建议：

[
H_v = 16\left\lfloor H/16\right\rfloor,\qquad
W_v = 16\left\lfloor W/16\right\rfloor.
]

对 180×320：

[
H_v=176,\quad W_v=320,\quad N=11\times 20=220.
]

理由是原 `PatchEmbed` 使用 kernel/stride `2×16×16`、zero padding，本来就会忽略不能组成完整 patch 的 remainder。

因此：

* 忽略底部 4 行与原 dense Conv3d support 一致；
* 不产生合成 spatial token；
* absolute position 使用 11×20 grid，不再按错误的 12×20 归一化；
* 仍显式生成 `[B,384,220]` 的 bool `valid_patch_mask`，供将来的变分辨率或 batch padding；
* 任一 tubelet 的 valid count 小于 K 时，在 scout/VideoMAE 之前 fail closed。

## 3.2 `free` 对照的两个隐藏混杂

当前 experiment contract 把 `free` 命名为“free residual TokenSelect-only control”。

真实代码却同时给它：

1. learned geometry；
2. geometry-relative coordinates；
3. learned geometry projection；
4. residual logits softmax pooling。

因此当前 `free` 不只是“选择自由 token”。P1R 必须改为：

* `free` 的 geometry 固定为全图 `(0.5,0.5,1,1)`；
* geometry head 对 `free` 冻结；
* 所有 P1 variants 使用相同的 uniform-selected pooling；
* learned route logits 只决定 membership/gradient estimator，不额外改变 pooling；
* `fixed_lattice_geometry` 继续作为唯一 learned-geometry-without-learned-selection control。

* 其 claim 可以严格写成“detector-supervised native token selection”，不需要把 geometry 包装成贡献；

# 5. Recommended architecture

## 5.1 主推荐：Validity-Aware NativeTokenSelect-AdaTAD

给定完整视频窗口：

[
X\in\mathbb{R}^{B\times 3\times 768\times H\times W}.
]

使用原生 VideoMAE support：

[
T=768/2=384,\qquad
H_g=\lfloor H/16\rfloor,\quad
W_g=\lfloor W/16\rfloor,\quad
N=H_gW_g.
]

原生 tubelet：

[
x_{t,i}\in\mathbb{R}^{3\times2\times16\times16},
\qquad
v_{t,i}\in{0,1}.
]

当前 180×320 修正后：

[
H_g=11,\quad W_g=20,\quad N=220.
]

Scout 输出：

[
z_{t,i}\in\mathbb{R}^{C_s},\qquad
\ell^{free}*{t,i}=h*{\mathrm{free}}(z_{t,i}).
]

Route B 使用：

[
S_t=\operatorname{ExactTopK}
\left(
{\ell^{free}*{t,i}:v*{t,i}=1},K
\right),
\qquad |S_t|=K.
]

无 spatial GT、teacher、oracle、validation/test GT 或 cached prediction。

## 5.2 修正后的 hybrid

定义：

* (U_t)：deterministic valid uniform context；
* (R_t)：ROI family；
* (Q_t)：residual family。

满足：

[
U_t\subset V_t,
]

[
R_t=
\operatorname{TopK}*{K*{\mathrm{roi}}}
\left(\ell^{roi}_t;\ V_t\setminus U_t\right),
]

[
Q_t=
\operatorname{TopK}*{K*{\mathrm{res}}}
\left(\ell^{res}_t;\ V_t\setminus(U_t\cup R_t)\right),
]

[
S_t=U_t\cup R_t\cup Q_t,\qquad
|S_t|=K_{\mathrm{ctx}}+K_{\mathrm{roi}}+K_{\mathrm{res}}=K.
]

## 5.3 Branch-aligned ST

对 deterministic context：

[
g_{t,i}=1,\quad i\in U_t,
]

且 route gradient 为零。

对 ROI 与 residual 分别构造：

[
\tilde g^{roi}_{t,i}
====================

\sigma\left(
\frac{\ell^{roi}_{t,i}-\theta^{roi}_t}{\tau}
\right),
\quad i\in V_t\setminus U_t,
]

[
\tilde g^{res}_{t,i}
====================

\sigma\left(
\frac{\ell^{res}_{t,i}-\theta^{res}_t}{\tau}
\right),
\quad i\in V_t\setminus(U_t\cup R_t).
]

硬前向、软反向：

[
g_{t,i}=1+
\tilde g_{t,i}
-\operatorname{sg}(\tilde g_{t,i}).
]

不能再用一个 `roi_logits + residual_logits` 的全局 soft top-k 代替 staged hard policy。

## 5.4 真实 staged hybrid score-function

若使用 score-function，联合 likelihood 必须是：

[
\log p(S\mid X)
===============

\sum_t
\left[
\log p_{\mathrm{PL}}
(R_t\mid V_t\setminus U_t)
+
\log p_{\mathrm{PL}}
(Q_t\mid V_t\setminus(U_t\cup R_t))
\right].
]

策略损失：

[
\mathcal L_{\pi}
================

\lambda_\pi
\frac1B\sum_b
\left(
\operatorname{sg}(L_{\mathrm{det},b})
-b
\right)
\sum_t\log p(S_{b,t}\mid X_b).
]

当前 `mean(B,T)` 应改为 `sum(T).mean(B)`。旧实现只差固定 (1/T) 缩放，但旧 `score_function_weight` 不能直接沿用，必须重新校准。

## 5.5 Packed coordinate-lineage Adapter

每个 block 的 selected representation：

[
h_{t,k}\in\mathbb{R}^{C},\qquad
i_{t,k}\in{0,\ldots,N-1}.
]

仅当相邻 tubelet 也选择同一 spatial index 时建立 temporal neighbor：

[
h^-*{t,k}=
\begin{cases}
h*{t-1,k'},&i_{t-1,k'}=i_{t,k}\
0,&\text{otherwise}
\end{cases}
]

[
h^+*{t,k}=
\begin{cases}
h*{t+1,k'},&i_{t+1,k'}=i_{t,k}\
0,&\text{otherwise}.
\end{cases}
]

复用原 Adapter 参数：

[
z_{t,k}=\phi(W_dh_{t,k}),
]

[
a_{t,k}
=======

W_p\left(
D_{-1}z^-*{t,k}
+D_0z*{t,k}
+D_{+1}z^+_{t,k}
+b_D
\right)+b_P,
]

[
h'_{t,k}
========

h_{t,k}
+
\gamma W_u(z_{t,k}+a_{t,k}).
]

性质：

* 不创建新的 Adapter 参数；
* full-K 时退化为原 dense Adapter；
* 稀疏时未选位置严格 identity bypass；
* 同一 spatial lineage 才进行 temporal convolution；
* detector-facing `[B,384,768]` 不变。

## 5.6 公平 pooling

P1R 所有 variants 统一使用：

[
f_t=\frac1K\sum_{i\in S_t}\hat h_{t,i}.
]

route logits 只决定 selection，不再额外决定 pooling 权重。

`fixed_lattice_geometry` 和 hybrid/ROI 可以通过单独的 geometry projection 比较 geometry side-channel；`free` 使用固定全图 geometry。

## 5.7 Soft-to-hard curriculum

当前代码没有实现 curriculum。若 P1 winner 进入后续优化，应按 successful optimizer update (u) 推进：

### Phase 1：dense relaxed support

[
u<U_d.
]

* heavy backbone 运行全部 valid tokens；
* scout soft support 调制 token；
* 明确记录 `sparse_cost_claim_allowed=False`。

### Phase 2：soft/hard transition

[
U_d\le u<U_d+U_h.
]

定义：

[
\alpha(u)=
\frac{u-U_d}{U_h},
]

[
p_{\mathrm{hard}}(u)
====================

\frac12-\frac12\cos(\pi\alpha),
]

[
\tau(u)
=======

\exp\big[
(1-\alpha)\log\tau_{\mathrm{start}}
+\alpha\log\tau_{\mathrm{end}}
\big].
]

每个 successful update 用 stateless draw 选择 dense-relaxed 或 hard-exact-K，**每步仍只有一次 heavy forward**。其期望目标为：

[
(1-p_{\mathrm{hard}})\mathbb E[L_{\mathrm{dense}}]
+
p_{\mathrm{hard}}\mathbb E[L_{\mathrm{hard}}].
]

### Phase 3：hard exact-K

[
u\ge U_d+U_h.
]

`U_d`、`U_h`、`\tau_start`、`\tau_end` 必须由 P0R calibration manifest 绑定；不能按 raw forward 次数、epoch 或 validation mAP 自适应改变。

## 5.8 FlashVID-inspired residual：仅 Route A 的 P2 comparator

Scout-only residual：

[
r_{t,i}=h_r(z_{t,i}),
]

运动新颖性：

[
m_{t,i}
=======

1-\max_{j\in\mathcal N_{3\times3}(i)}
\cos(z_{t,i},z_{t-1,j}),
]

顺序 diversity：

[
d^{(q)}_{t,i}
=============

1-\max_{j\in Q_t^{(<q)}}
\cos(z_{t,i},z_{t,j}),
]

综合：

[
s^{(q)}_{t,i}
=============

\alpha r_{t,i}
+\beta m_{t,i}
+\gamma d^{(q)}_{t,i}.
]

每次从 remaining valid set 中选择一个 token，严格无放回，直到 (K_{\mathrm{res}})。它不得使用 full vision encoder，也不得产生第二次 heavy forward。free TokenSelect 必须保留为主对照。

## 5.9 Cost objective

固定 K 的 P1：

[
\mathcal L =
\mathcal L_{\mathrm{cls}}
+\mathcal L_{\mathrm{reg}}
+\mathcal L_{\mathrm{geom}}
+\mathcal L_\pi.
]

不加入 cost loss。

动态 K/depth 阶段才允许：

[
\mathcal L =
\mathcal L_{\mathrm{det}}
+
\lambda\big(c(a)-B\big),
]

其中 (c(a)) 是预先实测并冻结的 cost lookup。wall-clock latency 可以作为不可微 reward 或 lookup 值，但不能伪装成 pathwise differentiable loss。

```python
from typing import Any

import torch
import torch.nn.functional as F


def _mask_from_indices(indices: torch.Tensor, item_count: int) -> torch.Tensor:
    if indices.ndim != 3:
        raise ValueError("indices must be [B,T,K]")
    mask = torch.zeros(
        (*indices.shape[:2], int(item_count)),
        device=indices.device,
        dtype=torch.bool,
    )
    return mask.scatter(-1, indices, True)


def _normalize_valid_mask(
    logits: torch.Tensor,
    valid_mask: torch.Tensor | None,
) -> torch.Tensor:
    if valid_mask is None:
        valid_mask = torch.ones_like(logits, dtype=torch.bool)
    if valid_mask.dtype != torch.bool or valid_mask.shape != logits.shape:
        raise ValueError("valid_mask must be bool [B,T,N] matching routing logits")
    if not bool(valid_mask.any(dim=-1).all().item()):
        raise ValueError("every temporal tubelet must contain at least one valid patch")
    return valid_mask


def _uniform_indices_from_valid_mask(
    valid_mask: torch.Tensor,
    *,
    count: int,
) -> torch.Tensor:
    if valid_mask.ndim != 3 or valid_mask.dtype != torch.bool:
        raise ValueError("valid_mask must be bool [B,T,N]")
    batch, tubelets, item_count = map(int, valid_mask.shape)
    count = int(count)
    if count <= 0:
        return torch.empty(
            (batch, tubelets, 0),
            device=valid_mask.device,
            dtype=torch.long,
        )

    valid_counts = valid_mask.sum(dim=-1)
    if bool((valid_counts < count).any().item()):
        raise ValueError("not enough valid patches for deterministic exact-K context")

    candidates = torch.arange(
        item_count,
        device=valid_mask.device,
        dtype=torch.long,
    ).view(1, 1, item_count).expand(batch, tubelets, item_count)

    compact = torch.sort(
        candidates.masked_fill(~valid_mask, item_count),
        dim=-1,
    ).values

    if count == 1:
        slots = torch.div(valid_counts, 2, rounding_mode="floor").unsqueeze(-1)
    else:
        rank = torch.arange(
            count,
            device=valid_mask.device,
            dtype=torch.long,
        ).view(1, 1, count)
        slots = torch.div(
            rank * (valid_counts - 1).unsqueeze(-1),
            count - 1,
            rounding_mode="floor",
        )
    return compact.gather(-1, slots)


def _topk_excluding(
    scores: torch.Tensor,
    *,
    count: int,
    excluded: torch.Tensor,
    valid_mask: torch.Tensor,
) -> torch.Tensor:
    count = int(count)
    if count == 0:
        return torch.empty(
            (*scores.shape[:2], 0),
            device=scores.device,
            dtype=torch.long,
        )

    available = valid_mask & ~excluded
    if bool((available.sum(dim=-1) < count).any().item()):
        raise ValueError("not enough valid unselected tokens for exact-K route")

    masked = scores.masked_fill(~available, float("-inf"))
    return _stable_argsort_descending(masked)[..., :count]


def _sample_plackett_luce_order(
    logits: torch.Tensor,
    *,
    count: int,
    temperature: float,
    available_mask: torch.Tensor,
) -> torch.Tensor:
    count = int(count)
    if count == 0:
        return torch.empty(
            (*logits.shape[:2], 0),
            device=logits.device,
            dtype=torch.long,
        )
    if float(temperature) <= 0.0:
        raise ValueError("score-function temperature must be positive")
    if bool((available_mask.sum(dim=-1) < count).any().item()):
        raise ValueError("not enough available tokens for Plackett-Luce sample")

    uniform = torch.rand_like(logits).clamp_(1e-6, 1.0 - 1e-6)
    gumbel = -torch.log(-torch.log(uniform))
    perturbed = (logits / float(temperature) + gumbel).masked_fill(
        ~available_mask,
        float("-inf"),
    )
    return _stable_argsort_descending(perturbed)[..., :count]


def ordered_plackett_luce_log_prob(
    logits: torch.Tensor,
    ordered_indices: torch.Tensor,
    *,
    temperature: float,
    available_mask: torch.Tensor | None = None,
) -> torch.Tensor:
    if logits.ndim != 3 or ordered_indices.ndim != 3:
        raise ValueError("logits and ordered_indices must be [B,T,*]")
    if logits.shape[:2] != ordered_indices.shape[:2]:
        raise ValueError("logits and ordered_indices must share [B,T]")
    if float(temperature) <= 0.0:
        raise ValueError("score-function temperature must be positive")

    available = _normalize_valid_mask(logits, available_mask).clone()
    scaled = logits / float(temperature)
    result = torch.zeros(
        logits.shape[:2],
        device=logits.device,
        dtype=logits.dtype,
    )

    for slot in range(int(ordered_indices.shape[-1])):
        choice = ordered_indices[..., slot : slot + 1]
        if bool((~available.gather(-1, choice)).any().item()):
            raise ValueError(
                "ordered Plackett-Luce route selected an invalid or duplicate token"
            )
        candidate_logits = scaled.masked_fill(~available, float("-inf"))
        result = result + F.log_softmax(
            candidate_logits,
            dim=-1,
        ).gather(-1, choice).squeeze(-1)
        available = available.scatter(-1, choice, False)

    return result


def _soft_topk_gate(
    scores: torch.Tensor,
    *,
    count: int,
    temperature: float,
    available_mask: torch.Tensor,
) -> torch.Tensor:
    count = int(count)
    if count == 0:
        return torch.zeros_like(scores)
    if float(temperature) <= 0.0:
        raise ValueError("straight-through temperature must be positive")

    available_counts = available_mask.sum(dim=-1)
    if bool((available_counts < count).any().item()):
        raise ValueError("soft top-k has fewer available tokens than requested")

    masked = scores.masked_fill(~available_mask, float("-inf"))
    threshold = torch.topk(
        masked,
        k=count,
        dim=-1,
    ).values[..., -1:].detach()

    gate = torch.sigmoid((scores - threshold) / float(temperature))
    gate = gate * available_mask.to(dtype=gate.dtype)

    # When every available item must be selected, the relaxed support is exactly
    # the available mask instead of an arbitrary sigmoid value.
    full_capacity = available_counts.eq(count).unsqueeze(-1)
    return torch.where(
        full_capacity,
        available_mask.to(dtype=gate.dtype),
        gate,
    )


def select_exact_k(
    *,
    roi_logits: torch.Tensor,
    residual_logits: torch.Tensor,
    mode: str,
    tokens_per_tubelet: int,
    context_tokens: int,
    roi_fraction: float,
    training: bool,
    estimator: str,
    temperature: float,
    random_seed: int = 0,
    valid_mask: torch.Tensor | None = None,
) -> dict[str, Any]:
    """Return a validity-aware, no-duplicate exact-K native route.

    Shapes:
        roi_logits:      [B,T,N], floating point
        residual_logits: [B,T,N], same shape/dtype/device
        valid_mask:      [B,T,N], bool
        indices:         [B,T,K], long
        st_gate:         [B,T,K], logits dtype

    Hybrid likelihood is staged:
        deterministic context
        -> ROI conditioned on excluding context
        -> residual conditioned on excluding context and sampled ROI.
    """

    if mode not in ROUTE_MODES:
        raise ValueError(f"unsupported GeoRoute mode {mode!r}")
    if estimator not in POLICY_ESTIMATORS:
        raise ValueError(f"unsupported GeoRoute estimator {estimator!r}")
    if roi_logits.shape != residual_logits.shape or roi_logits.ndim != 3:
        raise ValueError("ROI and residual logits must match [B,T,N]")
    if not bool(torch.isfinite(roi_logits).all().item()):
        raise ValueError("ROI logits must be finite")
    if not bool(torch.isfinite(residual_logits).all().item()):
        raise ValueError("residual logits must be finite")

    batch, tubelets, item_count = map(int, roi_logits.shape)
    valid = _normalize_valid_mask(roi_logits, valid_mask)
    valid_counts = valid.sum(dim=-1)

    if mode == "dense":
        first_count = valid_counts.reshape(-1)[0]
        if not torch.equal(
            valid_counts,
            first_count.expand_as(valid_counts),
        ):
            raise ValueError(
                "dense native route requires equal valid patch capacity for every tubelet"
            )
        target_k = int(first_count.item())
    else:
        target_k = int(tokens_per_tubelet)

    if target_k <= 0:
        raise ValueError("target K must be positive")
    if bool((valid_counts < target_k).any().item()):
        raise ValueError(
            "valid native patch count is smaller than requested exact-K budget"
        )
    if mode == "dense" and int(context_tokens) != 0:
        raise ValueError("dense route requires context_tokens=0")
    if mode != "dense" and not (0 <= int(context_tokens) < target_k):
        raise ValueError("context_tokens must lie in [0,K)")
    if not (0.0 <= float(roi_fraction) <= 1.0):
        raise ValueError("roi_fraction must lie in [0,1]")
    if mode in {"roi", "free", "hybrid"} and float(temperature) <= 0.0:
        raise ValueError("learned routing requires a positive temperature")
    if estimator == "score_function" and mode not in {"roi", "free", "hybrid"}:
        raise ValueError(
            "score_function is valid only for ROI, free, or staged hybrid routes"
        )
    if estimator == "none" and mode in {"roi", "free", "hybrid"} and training:
        raise ValueError(
            "learned training route requires straight_through or score_function"
        )

    role_counts = {
        "context": 0,
        "roi": 0,
        "residual": 0,
        "free": 0,
        "dense": 0,
        "uniform": 0,
        "random": 0,
    }
    ordered_log_prob: torch.Tensor | None = None

    if mode == "dense":
        ordered = _uniform_indices_from_valid_mask(valid, count=target_k)
        ordered_surrogate = torch.ones_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        ordered_aggregation_logits = torch.zeros_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        role_counts["dense"] = target_k

    elif mode == "uniform":
        ordered = _uniform_indices_from_valid_mask(valid, count=target_k)
        ordered_surrogate = torch.zeros_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        ordered_aggregation_logits = torch.zeros_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        role_counts["uniform"] = target_k

    elif mode == "random":
        random_scores = _stateless_random_scores(
            roi_logits,
            seed=int(random_seed),
        ).masked_fill(~valid, float("-inf"))
        ordered = _stable_argsort_descending(random_scores)[..., :target_k]
        ordered_surrogate = torch.zeros_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        ordered_aggregation_logits = torch.zeros_like(
            ordered,
            dtype=roi_logits.dtype,
        )
        role_counts["random"] = target_k

    elif mode in {"roi", "free"}:
        logits = roi_logits if mode == "roi" else residual_logits
        empty_exclusion = torch.zeros_like(valid)

        if training and estimator == "score_function":
            ordered = _sample_plackett_luce_order(
                logits,
                count=target_k,
                temperature=temperature,
                available_mask=valid,
            )
            ordered_log_prob = ordered_plackett_luce_log_prob(
                logits,
                ordered,
                temperature=temperature,
                available_mask=valid,
            )
        else:
            ordered = _topk_excluding(
                logits,
                count=target_k,
                excluded=empty_exclusion,
                valid_mask=valid,
            )

        soft = _soft_topk_gate(
            logits,
            count=target_k,
            temperature=temperature,
            available_mask=valid,
        )
        ordered_surrogate = soft.gather(-1, ordered)
        ordered_aggregation_logits = logits.gather(-1, ordered)
        role_counts[mode] = target_k

    else:
        context_count = min(int(context_tokens), target_k)
        remainder = target_k - context_count
        roi_count = int(round(float(roi_fraction) * remainder))
        roi_count = min(max(roi_count, 0), remainder)
        residual_count = remainder - roi_count

        index_parts: list[torch.Tensor] = []
        surrogate_parts: list[torch.Tensor] = []
        aggregation_parts: list[torch.Tensor] = []
        excluded = torch.zeros_like(valid)

        if context_count:
            context = _uniform_indices_from_valid_mask(
                valid,
                count=context_count,
            )
            index_parts.append(context)
            # Deterministic context has no route gradient.
            surrogate_parts.append(
                torch.zeros_like(context, dtype=roi_logits.dtype)
            )
            aggregation_parts.append(
                torch.zeros_like(context, dtype=roi_logits.dtype)
            )
            excluded = excluded | _mask_from_indices(context, item_count)

        roi_available = valid & ~excluded
        if roi_count:
            if training and estimator == "score_function":
                roi_indices = _sample_plackett_luce_order(
                    roi_logits,
                    count=roi_count,
                    temperature=temperature,
                    available_mask=roi_available,
                )
                ordered_log_prob = ordered_plackett_luce_log_prob(
                    roi_logits,
                    roi_indices,
                    temperature=temperature,
                    available_mask=roi_available,
                )
            else:
                roi_indices = _topk_excluding(
                    roi_logits,
                    count=roi_count,
                    excluded=excluded,
                    valid_mask=valid,
                )

            roi_soft = _soft_topk_gate(
                roi_logits,
                count=roi_count,
                temperature=temperature,
                available_mask=roi_available,
            )
            index_parts.append(roi_indices)
            surrogate_parts.append(roi_soft.gather(-1, roi_indices))
            aggregation_parts.append(
                roi_logits.gather(-1, roi_indices)
            )
            excluded = excluded | _mask_from_indices(
                roi_indices,
                item_count,
            )

        residual_available = valid & ~excluded
        if residual_count:
            if training and estimator == "score_function":
                residual_indices = _sample_plackett_luce_order(
                    residual_logits,
                    count=residual_count,
                    temperature=temperature,
                    available_mask=residual_available,
                )
                residual_log_prob = ordered_plackett_luce_log_prob(
                    residual_logits,
                    residual_indices,
                    temperature=temperature,
                    available_mask=residual_available,
                )
                ordered_log_prob = (
                    residual_log_prob
                    if ordered_log_prob is None
                    else ordered_log_prob + residual_log_prob
                )
            else:
                residual_indices = _topk_excluding(
                    residual_logits,
                    count=residual_count,
                    excluded=excluded,
                    valid_mask=valid,
                )

            residual_soft = _soft_topk_gate(
                residual_logits,
                count=residual_count,
                temperature=temperature,
                available_mask=residual_available,
            )
            index_parts.append(residual_indices)
            surrogate_parts.append(
                residual_soft.gather(-1, residual_indices)
            )
            aggregation_parts.append(
                residual_logits.gather(-1, residual_indices)
            )

        ordered = torch.cat(index_parts, dim=-1)
        ordered_surrogate = torch.cat(surrogate_parts, dim=-1)
        ordered_aggregation_logits = torch.cat(
            aggregation_parts,
            dim=-1,
        )
        role_counts.update(
            context=context_count,
            roi=roi_count,
            residual=residual_count,
        )

    if ordered.shape != (batch, tubelets, target_k):
        raise RuntimeError("exact-K route produced an invalid index shape")

    selected_mask = _mask_from_indices(ordered, item_count)
    if not bool((selected_mask.sum(dim=-1) == target_k).all().item()):
        raise RuntimeError("exact-K route contains duplicate indices")
    if not bool(valid.gather(-1, ordered).all().item()):
        raise RuntimeError("exact-K route selected an invalid native patch")

    # Packed execution expects row-major spatial order, not policy order.
    indices, sort_permutation = torch.sort(ordered, dim=-1)
    selected_surrogate = ordered_surrogate.gather(
        -1,
        sort_permutation,
    )
    selected_aggregation_logits = ordered_aggregation_logits.gather(
        -1,
        sort_permutation,
    )

    if (
        training
        and estimator == "straight_through"
        and mode in {"roi", "free", "hybrid"}
    ):
        st_gate = torch.ones_like(selected_surrogate) + (
            selected_surrogate - selected_surrogate.detach()
        )
    else:
        st_gate = torch.ones_like(selected_surrogate)

    return {
        "schema_version": GEOROUTE_ROUTING_SCHEMA,
        "mode": mode,
        "indices": indices,
        "ordered_indices": ordered,
        "selected_mask": selected_mask,
        "selected_surrogate": selected_surrogate,
        "selected_aggregation_logits": selected_aggregation_logits,
        "st_gate": st_gate,
        "ordered_log_prob": ordered_log_prob,
        "target_k": target_k,
        "item_count": item_count,
        "valid_count_min": int(valid_counts.min().item()),
        "valid_count_max": int(valid_counts.max().item()),
        "role_counts": role_counts,
    }


def score_function_policy_loss(
    *,
    detector_cost: torch.Tensor,
    ordered_log_prob: torch.Tensor,
    baseline: torch.Tensor,
    weight: float,
) -> torch.Tensor:
    if detector_cost.ndim != 0 or not bool(
        torch.isfinite(detector_cost).item()
    ):
        raise ValueError("detector_cost must be one finite scalar")
    if ordered_log_prob.ndim != 2 or not bool(
        torch.isfinite(ordered_log_prob).all().item()
    ):
        raise ValueError("ordered_log_prob must be finite [B,T]")
    if baseline.ndim != 0 or not bool(torch.isfinite(baseline).item()):
        raise ValueError("baseline must be one finite scalar")
    if float(weight) < 0.0:
        raise ValueError("score-function weight must be non-negative")

    advantage = detector_cost.detach() - baseline.detach()
    joint_log_probability = ordered_log_prob.sum(dim=-1)
    return (
        float(weight)
        * advantage
        * joint_log_probability.mean(dim=0)
    )
```

## 6.2 P1R 必须：忽略 spatial remainder 并输出 valid mask

```python
def extract_native_tubelets(
    source: torch.Tensor,
    *,
    patch_size: int,
    tubelet_size: int,
) -> tuple[
    torch.Tensor,
    tuple[int, int],
    tuple[int, int],
    torch.Tensor,
]:
    """Extract only complete native VideoMAE tubelets.

    Returns:
        native:
            uint8 [B,T_tubelet,N,3,tubelet_size,patch_size,patch_size]
        grid_hw:
            complete spatial patch grid
        ignored_remainder_bottom_right:
            source pixels ignored because they cannot form a complete patch
        valid_patch_mask:
            bool [B,T_tubelet,N]
    """

    if source.ndim != 5 or source.shape[1] != 3:
        raise ValueError("source must be uint8 [B,3,T,H,W]")
    if source.dtype != torch.uint8:
        raise TypeError("native source must remain uint8")

    batch, channels, frames, height, width = map(int, source.shape)
    patch_size = int(patch_size)
    tubelet_size = int(tubelet_size)

    if frames % tubelet_size:
        raise ValueError(
            "source frame count must be divisible by VideoMAE tubelet size"
        )

    valid_height = (height // patch_size) * patch_size
    valid_width = (width // patch_size) * patch_size
    if valid_height <= 0 or valid_width <= 0:
        raise ValueError(
            "source is smaller than one complete native spatial patch"
        )

    ignored_bottom = height - valid_height
    ignored_right = width - valid_width
    source = source[..., :valid_height, :valid_width].contiguous()

    grid_height = valid_height // patch_size
    grid_width = valid_width // patch_size
    tubelets = frames // tubelet_size
    item_count = grid_height * grid_width

    native = (
        source.reshape(
            batch,
            channels,
            tubelets,
            tubelet_size,
            grid_height,
            patch_size,
            grid_width,
            patch_size,
        )
        .permute(0, 2, 4, 6, 1, 3, 5, 7)
        .reshape(
            batch,
            tubelets,
            item_count,
            channels,
            tubelet_size,
            patch_size,
            patch_size,
        )
        .contiguous()
    )

    valid_patch_mask = torch.ones(
        (batch, tubelets, item_count),
        device=source.device,
        dtype=torch.bool,
    )
    return (
        native,
        (grid_height, grid_width),
        (ignored_bottom, ignored_right),
        valid_patch_mask,
    )
```

```python
@staticmethod
def _lookup_selected_neighbor(
    source_values: Tensor,
    source_indices: Tensor,
    query_indices: Tensor,
) -> Tensor:
    """Match exact spatial lineage between adjacent temporal tubelets.

    Args:
        source_values:  [B,T,K,C_hidden]
        source_indices: [B,T,K], sorted long
        query_indices:  [B,T,K], sorted long

    Returns:
        [B,T,K,C_hidden], zero where no exact spatial match exists.
    """

    if source_values.ndim != 4:
        raise ValueError("source_values must be [B,T,K,C]")
    if source_indices.shape != source_values.shape[:3]:
        raise ValueError("source_indices must match source_values [B,T,K]")
    if query_indices.shape != source_indices.shape:
        raise ValueError("query_indices must match source_indices")
    if source_indices.dtype != torch.long:
        raise TypeError("packed spatial indices must be torch.long")

    select_count = int(source_indices.shape[-1])
    positions = torch.searchsorted(
        source_indices.contiguous(),
        query_indices.contiguous(),
    )
    bounded = positions.clamp(max=select_count - 1)
    hit = (
        positions < select_count
    ) & (
        source_indices.gather(-1, bounded) == query_indices
    )

    gathered = source_values.gather(
        2,
        bounded.unsqueeze(-1).expand(
            *bounded.shape,
            int(source_values.shape[-1]),
        ),
    )
    return gathered * hit.unsqueeze(-1).to(
        dtype=source_values.dtype
    )


def forward_native_packed(
    self,
    inputs: Tensor,
    dense_mask: Tensor,
    spatial_indices: Tensor,
    *,
    grid_height: int,
    grid_width: int,
) -> Tensor:
    """Apply the original Adapter parameters only to selected lineages.

    Args:
        inputs:
            dense carrier [B*chunks,tubelets_per_chunk*N,C]
        dense_mask:
            bool carrier mask [B*chunks,tubelets_per_chunk*N]
        spatial_indices:
            sorted selected native indices [B,total_tubelets,K]

    Unselected carrier positions are exact identity bypasses.
    Full-K selection is numerically equivalent to ``forward(inputs,h,w)``.
    """

    if inputs.ndim != 3:
        raise ValueError("packed Adapter inputs must be [Bchunk,L,C]")
    if dense_mask.dtype != torch.bool:
        raise TypeError("packed Adapter dense_mask must be bool")
    if dense_mask.shape != inputs.shape[:2]:
        raise ValueError("packed Adapter dense_mask must match inputs")
    if spatial_indices.ndim != 3:
        raise ValueError("spatial_indices must be [B,T,K]")
    if spatial_indices.dtype != torch.long:
        raise TypeError("spatial_indices must be torch.long")

    batch_size, total_tubelets, select_count = map(
        int,
        spatial_indices.shape,
    )
    channels = int(inputs.shape[-1])
    spatial_tokens = int(grid_height) * int(grid_width)

    if select_count <= 0:
        raise ValueError("packed Adapter requires K>0")
    if int(inputs.shape[1]) % spatial_tokens:
        raise ValueError(
            "packed carrier token count is not divisible by spatial grid"
        )

    tubelets_per_chunk = int(inputs.shape[1]) // spatial_tokens
    if total_tubelets % tubelets_per_chunk:
        raise ValueError(
            "total tubelets must be divisible by tubelets per chunk"
        )
    chunk_count = total_tubelets // tubelets_per_chunk
    if int(inputs.shape[0]) != batch_size * chunk_count:
        raise ValueError(
            "packed carrier batch/chunk layout is inconsistent"
        )
    if total_tubelets != int(self.temporal_size):
        raise ValueError(
            "packed Adapter temporal axis differs from pretrained Adapter"
        )
    if int(dense_mask.sum().item()) != (
        batch_size * total_tubelets * select_count
    ):
        raise ValueError(
            "packed Adapter mask does not contain exact B*T*K selections"
        )
    if select_count > 1 and not bool(
        (
            spatial_indices[..., 1:]
            > spatial_indices[..., :-1]
        ).all().item()
    ):
        raise ValueError(
            "packed Adapter indices must be strictly increasing"
        )

    selected_inputs = inputs[dense_mask].reshape(
        batch_size,
        total_tubelets,
        select_count,
        channels,
    )
    hidden = self.act(self.down_proj(selected_inputs))

    previous = torch.zeros_like(hidden)
    following = torch.zeros_like(hidden)

    if total_tubelets > 1:
        previous[:, 1:] = self._lookup_selected_neighbor(
            hidden[:, :-1],
            spatial_indices[:, :-1],
            spatial_indices[:, 1:],
        )
        following[:, :-1] = self._lookup_selected_neighbor(
            hidden[:, 1:],
            spatial_indices[:, 1:],
            spatial_indices[:, :-1],
        )

    if (
        self.dwconv.kernel_size != (3,)
        or self.dwconv.dilation != (1,)
        or self.dwconv.stride != (1,)
        or self.dwconv.padding != (1,)
    ):
        raise RuntimeError(
            "coordinate-lineage Adapter requires the original "
            "kernel_size=3,dilation=1,stride=1,padding=1"
        )
    if self.conv.kernel_size != (1,):
        raise RuntimeError(
            "coordinate-lineage Adapter requires pointwise Conv1d"
        )

    # Depthwise temporal Conv1d re-expressed over matched spatial lineages.
    kernel = self.dwconv.weight[:, 0, :]
    temporal = (
        previous * kernel[:, 0].view(1, 1, 1, -1)
        + hidden * kernel[:, 1].view(1, 1, 1, -1)
        + following * kernel[:, 2].view(1, 1, 1, -1)
    )
    if self.dwconv.bias is not None:
        temporal = temporal + self.dwconv.bias.view(
            1,
            1,
            1,
            -1,
        )

    temporal = F.linear(
        temporal,
        self.conv.weight[:, :, 0],
        self.conv.bias,
    )
    selected_output = (
        self.up_proj(hidden + temporal) * self.gamma
        + selected_inputs
    )

    output = inputs.clone()
    output[dense_mask] = selected_output.reshape(-1, channels)
    return output
```

```python
def _nearest_existing_parent(path: Path) -> Path:
    candidate = path.resolve()
    while not candidate.exists():
        parent = candidate.parent
        if parent == candidate:
            raise FileNotFoundError(
                f"no existing filesystem parent for {path}"
            )
        candidate = parent
    return candidate

        "cell_count": int(cell_count),
        "per_cell_peak_bytes": per_cell_peak,
        "required_bytes": required_bytes,
        "safety_bytes": safety_bytes,
        "required_with_safety_bytes": required_with_safety,
        "free_bytes": free_bytes,
        "checkpoint_policy": "final_only",
        "passed": free_bytes >= required_with_safety,
        "official_test_opened": False,
    }
    receipt["receipt_sha256"] = canonical_sha256(receipt)

    if not receipt["passed"]:
        raise RuntimeError(
            "GeoRoute storage preflight failed closed: "
            f"free={free_bytes}, "
            f"required_with_safety={required_with_safety}, "
            f"cells={cell_count}"
        )
    return receipt
```

```python
def select_p1_roi_candidate(
    records: Mapping[str, Mapping[str, Any]],
) -> dict[str, Any]:
    required = set(P1_VARIANTS)
    if set(records) != required:
        raise ValueError(
            f"P1 record set must equal {sorted(required)}"
        )

    for name, record in records.items():
        if (
            record.get("stage") != "p1"
            or record.get("variant") != name
        ):
            raise ValueError(f"invalid P1 record for {name}")
        if record.get("official_test_opened") is not False:
            raise ValueError("P1 record opened official test")
        high_iou_score(record["metrics"])
        profile = record.get("profile", {})
        if not isinstance(
            profile.get("development_window_wall_p50_ms"),
            (int, float),
        ):
            raise ValueError(
                f"P1 record lacks measured development cost: {name}"
            )

    scores = {
        name: high_iou_score(record["metrics"])
        for name, record in records.items()
    }
    costs = {
        name: float(
            record["profile"][
                "development_window_wall_p50_ms"
            ]
        )
        for name, record in records.items()
    }

    hybrid_accuracy_gate = scores["hybrid"] > max(
        scores["free"],
        scores["random"],
        scores["fixed_lattice_geometry"],
    )
    hybrid_cost_gate = costs["hybrid"] <= min(
        costs["free"],
        costs["random"],
        costs["fixed_lattice_geometry"],
    )

    free_accuracy_gate = scores["free"] > max(
        scores["roi"],
        scores["hybrid"],
    )
    free_cost_gate = costs["free"] <= min(
        costs["roi"],
        costs["hybrid"],
    )

    best_learned = max(
        scores["free"],
        scores["roi"],
        scores["hybrid"],
    )
    best_nonlearned = max(
        scores["fixed_lattice"],
        scores["random"],
    )

    if hybrid_accuracy_gate and hybrid_cost_gate:
        status = "ADVANCE_HYBRID_TO_P2"
        winner = "hybrid"
        route = "A"
    elif free_accuracy_gate and free_cost_gate:
        status = "ADVANCE_FREE_TO_P2"
        winner = "free"
        route = "B"
    elif best_learned <= best_nonlearned:
        status = "STOP_LEARNED_ROUTING"
        winner = None
        route = "C"
    else:
        # No post-hoc tuning is allowed for a mixed/ambiguous result.
        status = "STOP_AMBIGUOUS_NO_PREDECLARED_WINNER"
        winner = None
        route = "C"

    decision = {
        "schema_version": GEOROUTE_EXPERIMENT_SCHEMA,
        "stage": "p1_selection",
        "selection_metric": "mean(mAP@0.6,mAP@0.7)",
        "scores": scores,
        "development_window_wall_p50_ms": costs,
        "hybrid_accuracy_gate": hybrid_accuracy_gate,
        "hybrid_cost_gate": hybrid_cost_gate,
        "free_accuracy_gate": free_accuracy_gate,
        "free_cost_gate": free_cost_gate,
        "selected_route": route,
        "selected_variant": winner,
        "status": status,
        "paper_claim_allowed": False,
        "official_test_opened": False,
    }
    decision["selection_sha256"] = canonical_sha256(
        decision
    )
    return decision
```

## 6.9 P1 positive 后才允许：A-MoD interface

当前 PyTorch `scaled_dot_product_attention()` 的公开签名返回一个 output `Tensor`，不返回 attention weights；`MultiheadAttention` 只有在 `need_weights=True` 时返回权重，而官方文档明确说明 `need_weights=False` 才使用优化 SDPA 路径。([PyTorch Documentation][1]) ([PyTorch Documentation][2])

因此当前框架下，我**拒绝提供伪 production A-MoD block**。

Tiny KAT 可使用：

```python
def explicit_attention_column_mean(
    query: torch.Tensor,
    key: torch.Tensor,
) -> torch.Tensor:
    """Tiny-test-only statistic.

    query/key: [B,H,N,D]
    returns:   [B,N]
    """
    scale = query.shape[-1] ** -0.5
    attention = torch.softmax(
        torch.matmul(
            query,
            key.transpose(-2, -1),
        ) * scale,
        dim=-1,
    )
    return attention.mean(dim=(1, 2))
```

Production 必须先提供真实 kernel/interface：

```python
def fused_sdpa_with_column_sum(
    query: torch.Tensor,
    key: torch.Tensor,
    value: torch.Tensor,
    *,
    dropout_p: float,
    is_causal: bool,
) -> tuple[torch.Tensor, torch.Tensor]:
    """Required custom Triton/CUDA contract.

    Returns:
        output:     [B,H,N,Dv]
        column_sum: [B,H,N], accumulated without materializing [N,N]
    """
    raise NotImplementedError(
        "Requires an audited Triton/CUDA fused attention kernel"
    )
```

只有该 kernel 在以下条件全部通过后，才允许实现 A-MoD：

* capacity ratio 1.0 与 dense block parity；
* exact capacity；
* 每 tubelet 最低保留量；
* 未选 token identity bypass；
* score 不乘回 output；
* random exact-K、linear MoD、A-MoD 三对照；
* fused kernel 不 materialize (N\times N) attention；
* backward、AMP、DDP、checkpoint KAT；
* 独立 component latency 与 energy trace。

候选 one-based 层序可以是：

```text
Dense 4 -> MoD 5
Dense 6 -> MoD 7
Dense 8 -> MoD 9
Dense 10 -> MoD 11
Dense 12
```

即 zero-based MoD indices `{4,6,8,10}`。但它只是 P2 条件候选，不是当前推荐补丁。
