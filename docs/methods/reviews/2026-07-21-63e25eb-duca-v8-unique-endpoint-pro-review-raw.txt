# 2. 最终裁决

## **HOLD**

更精确地说：

> **HOLD 当前 V8 learned official-60 执行许可；不 KILL 全局 exact-(K) 路线，但禁止用当前 P0 winner 直接解锁 G0/G1/G2。**

裁决边界如下。

[CODE_FACT] hard Viterbi、soft forward-backward 和 ordered slot marginals 使用同一个 exact-(K)、max-hole 状态机；当前没有 post-hoc repair 掩盖可行集不一致。因此，**结构化解码器本身不是主要失败点**。

[CODE_FACT] 当前最严重问题是：V8 把一个半径 4 的 Gaussian transition target 同时当作 transition 分布目标和 boundary target，再用“邻域期望 occupancy mass”而不是“至少命中一次的事件概率”训练。这个目标会继续奖励同一边界附近的第二、第三个 slot，且有效奖励带可扩展到真实端点约 ±8。

[INFERENCE] 该代码事实与“相邻选择从约 4.4% 上升至约 35%、但 radius-1 端点召回下降 9–10 点”的现象方向完全一致。V8 目前学到的是“往宽边界带堆 occupancy mass”，不是“每个真实端点至少分配一个有用观测”。

[CODE_FACT] G1/G2 的 detector feedback 是 hard-forward、soft-backward 的局部 Taylor transport surrogate；源码自己明确称其仍是 surrogate，并要求在 full training 前通过 hard-swap alignment gate。当前串行 gate 没有生成该真实 alignment 证据，却把 `formal_training_unlocked=True` 写入 gate suite。

[PROPOSAL] 当前 P0 作业可以跑完，结果只能作为 V8 负面诊断；不得把其 winner 当作 G0/G1/G2 的科学解锁。U 臂可以先完成，用于复现当前 matched baseline。之后只允许一次有界修订：**Unique-Endpoint Event Objective**，见第 8 节。

[PROPOSAL] 若该修订后的 G0 仍不能超过 U，且 scorer 仍不能至少追平 `abs(delta p)`，则应 **KILL 在 (T=768,K=384,G=2) 下的全局 learned selection 主线**，停止继续调 scorer、bridge 或 curriculum。

# 3. 当前真实模型图

## 3.1 前向张量图

```text
dense raw video
X: [B,C,T=768,H,W] 或 [B,N,C,T=768,H,W]
│
├── C3 coarse probe，输入降到 64×64
│   ├── spatial stem: Conv3→96, stride 2
│   ├── spatial stem: Conv96→96, stride 2
│   ├── official ASFormer temporal trunk, 2 layers
│   ├── action logits z: [B,768]
│   └── encoder hidden h: [B,768,96]
│
├── actionness BCE
│   └── P0: 更新 spatial stem + ASFormer + action heads
│
└── transition descriptors
    d_t = [
      Δz_t, |Δz_t|,
      Δentropy_t, |Δentropy_t|,
      Δh_t[96], |Δh_t|[96],
      1-cos(h_t,h_{t-1})
    ]
    d: [B,768,197]
    │
    └── scorer:
        LayerNorm(197)
        Linear(197→64)
        GELU
        Linear(64→1)
        scores s: [B,768]
```

[CODE_FACT] scorer 不是“六个标量参数”，而是六个 parameter tensors、共 **13,131 个标量**：LayerNorm weight/bias、两层 Linear weight/bias。它真正使用 hidden delta、hidden absolute delta、logit delta、entropy delta 和 cosine change；没有使用 absolute hidden，也不是 actionness top-k。

[CODE_FACT] actionness logits 在 transition 路径中无条件 `detach()`；hidden 路径则由 `policy_hidden_gradient_scale` 和 `auxiliary_hidden_gradient_scale` 控制。当前 P0 两者均使 transition/boundary 梯度不能进入 coarse，只有 actionness BCE 更新 coarse。

## 3.2 结构化 hard/soft 路径

```text
learned scorer scores s[B,T]
       │
       ├── normalize learned scores
       ├── normalize exact-uniform reference
       └── l(alpha) = (1-alpha)*uniform_reference + alpha*learned
                         │
                         ├── hard Viterbi exact K=384, G=2
                         │     hard positions: [B,384]
                         │     hard occupancy: [B,768]
                         │
                         └── soft forward-backward, same K/G family
                               soft occupancy: [B,768]
                               ordered slot assignment: [B,384,768]
```

[CODE_FACT] hard path 和 surrogate path 都调用 `continuous_policy_logits`，然后以相同 `effective_k`、`max_hole`、temperature 进入 `global_structured_topk`。hard path用于真实 gather，soft path只用于训练梯度。`max_gap_repair.enabled=False`。

```text
hard positions [B,384]
      │
      └── gather dense raw video along temporal axis
          X_sparse: temporal length 384
                  │
                  ├── VideoMAE-S backbone
                  ├── projection / neck
                  └── official ActionFormerHead
                      cls loss + reg loss
```

## 3.3 detector bridge

G1/G2 的实际桥为：

[
\tilde x_k =
x_{t_k}^{\text{hard}}
+
\lambda,
\operatorname{stopgrad}!\left(
\frac{x_{t_k+1}-x_{t_k-1}}{2}
\right)
\left(
\mathbb E_q[t_k]-\operatorname{stopgrad}(\mathbb E_q[t_k])
\right).
]

[CODE_FACT] 前向值严格等于 hard gather；反向把 detector loss 对 raw input 的梯度乘局部时间斜率，再传到 ordered slot 的期望位置和 scorer。它不是 hard index 的直接导数。

## 3.4 U/G0/G1/G2 实际解析结果

| 臂  |       P0 初始化 | alpha | coarse | transition auxiliary |        detector→scorer |             companion |
| -- | -----------: | ----: | ------ | -------------------: | ---------------------: | --------------------: |
| U  |            无 |  始终 0 | 不用于训练  |                    0 |                      0 |                     无 |
| G0 | EMA selector |   0→1 | 冻结     |          `.02 / 2.0` |                      0 |                     无 |
| G1 |         同 G0 |   0→1 | 冻结     |          `.02 / 2.0` |        0→.25 surrogate |                     无 |
| G2 |         同 G1 |   0→1 | 冻结     |          `.02 / 2.0` | learned rows，乘 (B/n_L) | 50% hard uniform rows |

[CODE_FACT] U 是同一 DUCA wrapper、同一 K=384、同一 selected-axis/remap 路径中的 exact-uniform control，不是“不带 selector 的原生官方 AdaTAD”。它适合作为 learned-policy matched baseline，但不能证明与历史 65.696 的协议等价。

[CODE_FACT] G2 的 companion 是**替换 batch 中约一半行的 hard positions 和 ordered slot assignment**，只进行一次 detector forward；不是再跑一份 companion detector。

[CODE_FACT] G2 没有替换 `soft_coverage` 或 transition auxiliary scores。因此 uniform companion 行仍用 learned policy 接收全部 GT transition/boundary 辅助梯度；只有 detector-bridge 梯度被置零，learned 行乘 (B/n_L)。这意味着 G2 的精确语义是：

> detector 输入 companion + scorer detector-gradient subsampling，**不是**完整 selector-training companion。

# 6. 实验与数值解释

## 6.1 已有 terminal 结果

[EXPERIMENT_FACT，用户提供]

| V5 臂                 | epoch-59 EMA |
| -------------------- | -----------: |
| U                    |  **64.4580** |
| direct-0.25          |      63.7102 |
| homotopy-0.25        |      63.0601 |
| homotopy + companion |      63.6931 |

[EXPERIMENT_FACT] companion 相对 homotopy 恢复 `+0.6330`，但仍低于 U `-0.7649`。

[INFERENCE] 这说明 companion 对 detector 输入分布稳定性确有帮助，但不足以克服 policy 本身选错位置。它不支持“只需更多 companion 即可成功”。

## 6.2 当前 P0 loss 不能按表面大小解释

[EXPERIMENT_FACT，用户提供] 当前日志：

```text
weighted actionness                = 0.6855
weighted transition               = 0.6396
weighted transition-boundary      = 0.1415
total                              ≈ 1.4665
```

按配置权重还原：

[
L_{\text{action,raw}}=0.6855,
]

[
L_{\text{transition,raw}}
=\frac{0.6396}{0.10}=6.396,
]

[
L_{\text{boundary,raw}}
=\frac{0.1415}{16}=0.00884375.
]

### Actionness BCE

[CODE_FACT] 当前是 `class_balanced_mean`：正、负样本 BCE 分别求均值，再按固定 prior 0.5 合并。因此零 logit 基线约为：

[
-\log(0.5)=0.6931,
]

不受动作帧实际 prevalence 直接控制。

[INFERENCE] `0.6855` 仅比随机零 logit 好约 `0.0076`，说明 logit margin/calibration 仍弱；但不能单凭该值断言标签错。用户提供的 AUROC `0.6161` 说明已有弱排序信号。

必须补的诊断是：

* 正、负样本 mean/std logit；
* 分别的 positive BCE、negative BCE；
* Brier score、ECE；
* train/holdout AUROC 曲线；
* spatial stem、ASFormer、action head 的独立 gradient norm；
* mask 内外 target 数量与非零率。

若 shuffled-label 与真实标签得到近似 AUROC，才支持标签或 mask bug；目前静态代码没有该证据。

### Transition loss

对于满长 (T=768) 的均匀 categorical 分布：

[
\log 768=6.6438.
]

[INFERENCE] 当前 raw transition CE `6.396` 只比均匀好约 `0.248` nats。结合 scorer AUROC `0.527–0.530 < abs(delta p) 0.611–0.618`，说明 scorer 并未有效利用 197 维描述符。

但根因更可能是**训练 target 与评测 target 不一致**：训练 target 是 sigma=2、radius=4 的宽 Gaussian，诊断却关心精确端点/radius-0 或 radius-1。

### Boundary loss

[INFERENCE] raw boundary mass loss `0.00884` 很小不代表“真实端点覆盖已好”。它只说明宽邻域中的 expected occupancy mass 已经很高。由于损失是 `exp(-mass)`，mass 从 1 增至 2 仍会使损失从 `0.368` 降至 `0.135`，继续鼓励重复 slot。

## 6.3 为什么 learned < uniform

按证据强度排序：

1. [CODE_FACT] **监督语义错误**：Gaussian support radius 4 再加 coverage radius 4，形成约 ±8 的奖励带；同一事件重复计数并持续奖励多 slot。
2. [EXPERIMENT_FACT] **scorer 确实学错**：AUROC 明显低于无参数的 `abs(delta p)`。
3. [EXPERIMENT_FACT] **错误行为已显现**：相邻选择约 35%，同时 radius-1 recall 下降。
4. [EXPERIMENT_FACT] **uniform 对 radius-1 已饱和**：约 0.9998，边界覆盖代理几乎没有正 headroom，只能防止退化。
5. [INFERENCE] **selected-axis 几何更偏爱 uniform**：U 的 true↔selected map 接近 affine；learned irregular map 让一个 selected-axis offset 对应可变真实时长。
6. [CODE_FACT] **detector surrogate 尚未验证**：能够反传不等于与 hard swap loss reduction 同向。
7. [INFERENCE] **hard-set curriculum 不连续**：alpha 连续不保证 Viterbi argmax 集合连续。
8. [EXPERIMENT_FACT] V5 已表明 detector feedback 和 companion 均未恢复到 U，不能再把负结果解释成“仅训练不够”。

## 6.4 selected-axis 审计

[CODE_FACT] 训练时 GT 从 true dense axis 通过同一个 `TrueTimeMap.true_to_selected` 映射到 selected axis；推理时 proposals 在 NMS/秒转换前通过 `selected_to_true` 逆映射。映射为严格单调的 piecewise-linear 插值。

[CODE_FACT] 未发现以下直接错误：

* 训练 remap 后忘记 inverse-map；
* inference 在 selected coordinate 直接转秒；
* selected positions 非严格递增；
* missing inverse metadata 静默通过。

[INFERENCE] 但该合同仍有方法风险：ActionFormer 的 regression range、center sampling 和 offset loss 都在 selected ordinal axis 上定义。对 learned irregular sampling：

[
1\text{ selected-axis unit}
\neq
1\text{ fixed true-time unit}.
]

因此同样的真实边界误差，在不同局部采样密度下会对应不同训练损失。这个风险应通过 synthetic parity test 和 matched U 复现证伪，而不能仅凭“inverse-map 存在”宣称无影响。

## 6.5 64.458 与历史 65.696

[EXPERIMENT_FACT] `65.696` 是用户明确标记的协议不匹配背景锚点。

[INFERENCE] 差异最可能来自以下组合，而不是 learned selector：

* K=384 sparse backbone 路径与历史协议不同；

* pretrained checkpoint、optimizer、scheduler、seed 或 data order；

* 训练窗口或正式 protocol 差异。

### headroom 裁决

[INFERENCE] 在 (T=768,K=384,G=2) 下，全局可行集并非退化为每 cell 一帧。令 (g_j\in{0,1,2}) 表示相邻选择之间或边缘的未选择数量，则：

[
\sum_j g_j=T-K=384.
]

每增加一个 `g=2` 的较大空洞，必须由额外的 `g=0` 邻接选择补偿。因此该 family 确实能大规模聚集和跨区域转移预算。

但已有事实说明：

* 几何自由度存在；
* **可靠 detector-utility headroom 尚未建立**；
* radius-1 coverage 本身几乎无 headroom；
* 当前自由度被 objective 用来制造错误聚集。

因此目前是 **有可行集自由度、无已证实任务效用 headroom**，只值得一次 objective 修复，不值得继续无界调参。

# 8. 首选优化方案

## **Unique-Endpoint Event Objective，唯一首选**

该方案不更换 coarse probe、scorer、DP、detector wrapper、K、G、预算、selected-axis 或 VideoMAE。只修正 scorer 学习目标和两个确定性合同错误。

## 8.1 数学定义

对每个训练窗口的每个 GT start/end (b_i)，先定义确定性中心：

[
c_i=
\operatorname{clamp}
\left(
\left\lfloor b_i+0.5\right\rfloor,
0,V-1
\right),
]

其中 (V) 为 valid dense length。

定义唯一端点事件：

[
E_i={t: |t-c_i|\le1,;t<V}.
]

完全相同的 event mask 去重；start/end 过近时允许一个观测同时覆盖两者，这与 radius-1 endpoint metric 一致。

### Scorer event-distribution loss

[
p_\theta(t)=
\operatorname{softmax}\left(s_t/0.7\right),
]

[
L_{\text{event}}
================

-\frac1N\sum_i
\log\left(
\sum_{t\in E_i}p_\theta(t)+10^{-8}
\right).
]

这取代 Gaussian `transition_distribution_loss`。

### Exact structured coverage loss

令：

[
P_\theta(S)
\propto
\exp\left(
\sum_{t\in S}\ell_t/\tau
\right)
\mathbf 1[
|S|=384,;\operatorname{maxhole}(S)\le2
].
]

对每个端点：

[
q_i=P_\theta(S\cap E_i\neq\varnothing),
]

[
L_{\text{exact-cover}}
======================

-\frac1N\sum_i\log(q_i+10^{-12}).
]

该概率由同一个 exact-(K)/G partition 计算，而不是 occupancy mass 近似。

总 P0 loss 冻结为：

[
L_{\text{P0}}=
1.0L_{\text{action}}
+0.10L_{\text{event}}
+16.0L_{\text{exact-cover}}.
]

[PROPOSAL] 首轮保持原权重，确保唯一科学变量是 target/objective 语义。不得同时搜索权重。

```python
def transition_event_distribution_loss(
    transition_scores,
    event_masks,
    event_valid,
    valid_mask,
    *,
    temperature=0.7,
):
    logits = transition_scores.float() / float(temperature)
    logits = logits.masked_fill(~valid_mask, -1.0e4)
    log_p = logits.log_softmax(dim=-1)

    event_log_mass = torch.logsumexp(
        log_p[:, None, :].masked_fill(~event_masks, -1.0e4),
        dim=-1,
    )
    return -event_log_mass[event_valid].mean()
```

## 8.4 日程确定性修复

当前公式必须改成以“当前 forward 是第几个成功 update”定义：

```python
def progress_for_next_successful_update(
    completed_updates: int,
    *,
    warmup: int,
    transition: int,
) -> float:
    if completed_updates < warmup:
        return 0.0
    if transition <= 0:
        return 1.0
    return min(
        1.0,
        float(completed_updates - warmup + 1) / float(transition),
    )
```

由此：

* updates 1–1000：alpha=0；
* updates 1001–2500：alpha 从 (1/1500) 到 1；
* updates 1–2500：bridge=0；
* updates 2501–4000：bridge 从 (0.25/1500) 到 0.25；

# 9. 两个备选及拒绝理由

## 备选一：`abs(delta p)` anchored residual scorer

数学形式：

[
s_t =
\operatorname{zscore}(|p_t-p_{t-1}|)
+0.25,r_\theta(d_t),
]

其中 residual output layer 零初始化。

修改：

* `transition_only.py::DucaTransitionUtilityScorer`
* `acquisition.py` scorer output
* config 增加固定 `delta_anchor_weight=1.0`、`residual_scale=0.25`

梯度：

* anchor 无参数；
* residual 只更新 scorer；
* coarse 仍由 action BCE 更新；
* inference 只增加逐点 delta 和加法，成本可忽略。

测试：

* 初始化时 policy scores 精确等于 normalized `abs(delta p)`；
* residual zero-init；
* hard K/G 不变；
* residual 梯度仅到 scorer。

唯一实验：

* 在 unique-event objective 已通过但 scorer 仍低于 delta 时，跑一个 anchored G0。

KILL：

* residual policy AUROC 不超过纯 delta；
* adjacency 或 endpoint distance恶化；
* terminal EMA 不超过 corrected unanchored G0。

**不作为首选的理由：**

[INFERENCE] 当前 target 本身错误。先加 anchor 会掩盖 target bug，可能只是把错误 objective 的破坏限制住，而不是证明 learned scorer 有增量价值。

## 备选二：detached hard one-swap detector utility distillation

使用仓库已有 legal hard-swap candidate 和 signed proximal machinery。

对每个 learned selection 生成最多 4 个满足 K/G 的 hard swaps：

[
u_j =
L_{\text{det}}(S)
-----------------

L_{\text{det}}(S_j).
]

`u_j` 全部 detach，训练 scorer 预测 swap 排序/符号；禁止直接从 candidate detector graph 回传到 scorer。

配置：

```text
candidates/window = 4
utility temperature = 1.0
teacher phase = update 2501–4000
coarse frozen
direct surrogate bridge = 0
```

梯度：

* baseline/candidate detector 只产生 detached utility；
* distillation loss 只更新 scorer；
* detector 主 forward 正常更新 detector 参数。

成本：

* 最坏约 baseline + 4 candidate detector evaluations；
* inference 无额外成本；
* 训练成本明显高于 G1/G2。

KILL：

```text
informative nonzero swaps < 24
distinct real batches < 4
sign agreement < 0.70
cluster-bootstrap lower <= 0.50
Spearman < 0.20
Spearman bootstrap lower <= 0
utility variance近零
terminal EMA不超过G0
```

**不作为首选的理由：**

当前 scorer target 尚未修正，而且 V5 detector feedback 已是负结果。先支付 4 倍级 teacher 成本不符合最小有界改进原则。

# 11. 论文主张边界

[CODE_FACT]

* 这是 offline、full-window、pre-backbone、exact-(K=384) 的结构化采样路线。
* hard 和 soft 路径共享 exact-K/max-hole feasible family。

* 当前 scorer 的 transition discrimination 低于 `abs(delta p)`，并产生错误聚集。

[CODE_FACT/EXPERIMENT_FACT]

* 不能说 detector loss“直接穿过 hard index”。
* 不能说 protected transport 已与 hard detector utility 对齐。

* 不能把 tests passing、hard K、max-hole 或梯度存在性写成科学效果证据。

## paper-ready 的必要证据
