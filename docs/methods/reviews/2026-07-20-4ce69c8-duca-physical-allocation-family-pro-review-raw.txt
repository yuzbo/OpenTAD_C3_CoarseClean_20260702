# 2. `EXECUTIVE_VERDICT`

## **`HOLD_AND_REVISE_FAMILY`**

当前不应开始 DUCA-CARA full training，也不应把 `G=3, 192 scaffold + 192 residual` 固化进模型。

决定性理由是：

1. `[MATHEMATICAL_CONSEQUENCE]` 当前 CellCF 的 regional quota vector 永远是
   [
   q_j=1,\qquad j=1,\ldots,K.
   ]
   它可以在 cell 内纠正采样 phase/content，但不能把一个背景 cell 的 quota 转移到边界 cell。它不是 adaptive allocation family。

2. `[CODE_FACT]` 当前 CellCF 对实际输入内容使用 acquisition positions gather，但 detector 的几何 prior、GT remap 和 prediction inverse map使用 uniform anchors。它测量的是：

   > **nonuniform content substitution under uniform detector geometry**

   而不是 physical-time boundary-adaptive sampling。

3. `[MATHEMATICAL_CONSEQUENCE]` “原始帧最大间隔≤10”与“exact uniform 必须可行”矛盾。Canonical uniform 本身存在一次 3-dense-index 间隔，即 12 原始帧。

4. `[MATHEMATICAL_CONSEQUENCE]` 若物理约束是“相邻选中中心及端点距离≤15 原始帧”，由于合法位置每 4 帧一个，实际有效上限是 12 帧。此时：

   * 任意位置上的最小固定 scaffold 需要 **255** 点；
   * 若还要求 scaffold 是 exact-uniform anchor 子集，以便 exact uniform 可复现，则最少需要 **382** 点；
   * 只剩 **2** 个 residual，不再是有意义的 192+192 adaptive allocation。

5. `[INFERENCE]` 因此固定 mandatory scaffold 的 C family 不是本轮最干净的 ceiling。应以 **D：global exact-K + physical max-interval** 为真正的 allocation-family ceiling，并把“scaffold + residual”仅作为一个对 D 解的 canonical decomposition，而不是固定可行集约束。

当前也不应直接 `KILL_DUCA_SELECTOR_ROUTE`：仓库已经有可复用的 physical-grid ActionFormer，而且尚未运行真正的 D/E exact ceiling。现有负面证据足以杀死 **current CellCF interpretation**，不足以杀死所有 literal pre-backbone selectors。

# 5. `CELL_FAMILY_MATHEMATICAL_AUDIT`

设：

[
L=768,\quad K=384,\quad
u_j=\operatorname{round_even}!\left(\frac{j(L-1)}{K-1}\right).
]

由代码的 midpoint rule 得到 cell：

[
C_j=[s_j,e_j),\qquad
s_j=\left\lfloor\frac{u_{j-1}+u_j}{2}\right\rfloor+1.
]

精确重建结果：

[
{|C_j|}=
\underbrace{2,\ldots,2}_{382\text{ cells}},
3,1.
]

唯一长度 3 的 cell 是 anchor index 192 对应的 `[384,387)`，最后一个 cell `[767,768)` 长度 1。

## 5.1 Current CellCF 的自由度

[
\mathcal B=
\left{
X\subseteq{0,\ldots,L-1}:
|X\cap C_j|=1,\ \forall j
\right}.
]

其集合大小：

[
|\mathcal B|
=\prod_j|C_j|
=3\cdot 2^{382}.
]

这看似很大，但它的 **regional allocation vector** 是固定的：

[
(|X\cap C_1|,\ldots,|X\cap C_K|)
=(1,\ldots,1).
]

`[MATHEMATICAL_CONSEQUENCE]` 因此 CellCF 有大量“cell 内内容自由度”，但没有“跨 region 的预算自由度”。它只能做：

* local phase correction；
* local content substitution；
* local within-cell utility choice。

它不能做：

* 背景 cell 释放 quota；
* 一个边界邻域获得多个额外 quota；
* short action 周围聚集多个 residual；
* global boundary-adaptive allocation。

## 5.2 `G=3,192+192` 的严格审计

若 `G` 指代码语义：最大连续未选 dense indices 数，则最小 scaffold cardinality 满足：

[
L-q \le (q+1)G,
]

因此

[
q_{\min}
=\left\lceil\frac{L-G}{G+1}\right\rceil.
]

对 `L=768,G=3`：

[
q_{\min}
=\left\lceil\frac{765}{4}\right\rceil
=192.
]

所以：

* `[MATHEMATICAL_CONSEQUENCE]` **在 dense-hole `G=3` 已经冻结的前提下，192 不是任意值，而是最小值。**
* `[MATHEMATICAL_CONSEQUENCE]` 但 `G=3` 本身若只是为了匹配 CellCF worst-hole，则是任意的研究选择，不是物理成本/覆盖要求推导出的值。

一个常见错误是直接取 every-other uniform anchor。由于 canonical uniform 有唯一一次 anchor gap 3，简单奇偶子集会跨越一个 5-index gap，导致 hole 4，违反 `G=3`。

存在一个满足 `G=3` 的 192-anchor 子集，但必须在特殊 gap 处切换 parity：

[
S=
{u_1,u_3,\ldots,u_{191},u_{192},u_{194},\ldots,u_{382}}.
]

它的最大 dense hole 是 3，且 `S⊂U`，因此 `U=S∪(U\setminus S)` 可以精确复现。

## 5.3 为什么该 192 scaffold 不满足“15 原始帧”

正式数据配置中：

[
\texttt{snippet_stride}
=\texttt{feature_stride}\times\texttt{sample_stride}
=4\times1=4.
]

所以 dense hole `G=3` 允许相邻 selected indices 相差 4：

[
4\text{ dense steps}\times4
=16\text{ original frames}.
]

它不是 15 帧约束。

## 5.4 物理 15 帧约束下的固定 scaffold 反例

冻结以下物理语义：

* 第一选择与窗口首个合法 frame 的距离 ≤15；
* 任意相邻选择中心的 original-frame distance ≤15；
* 最后选择与窗口最后合法 frame 的距离 ≤15。

合法 frame 坐标是 `0,4,8,...`，所以 ≤15 实际等价于 ≤12，允许最多 3 个 dense steps。

此时：

* 任意位置可用的最小 scaffold cardinality：**255**；
* 若 scaffold 必须是 canonical uniform 的子集：**382**。

后者的证明很直接：

* 相邻 uniform anchors 的 dense gap 是 2，只有一次是 3；
* 删除任意内部 anchor 后，两侧 retained-anchor gap 至少 `2+2=4` dense steps；
* 即至少 16 原始帧，违反 ≤15；
* 只能删除首尾两个 anchor，因此最小是 `384-2=382`。

`[MATHEMATICAL_CONSEQUENCE]` 固定 scaffold 同时满足：

1. scaffold 本身保证物理 ≤15；
2. scaffold 是 uniform 子集；
3. 留出大量 residual；

这三者在当前离散网格下不可兼得。

## 5.5 最小替代 family

`[PROPOSAL]` 不再把某个固定 `S` 设为 mandatory。采用：

[
\mathcal D_\Delta=
\left{
X:\ |X|=K_{\rm eff},
\ H_{\rm physical}(X)\le\Delta
\right}.
]

然后对每个已选 `X`，通过 canonical minimum-path decomposition 得到：

[
X=S(X)\cup R(X),
]

其中 `S(X)` 是从 `X` 内抽出的最小 coverage scaffold，`R(X)=X\setminus S(X)`。

这样：

* 可行集仍是 global exact-K/max-gap；
* “scaffold + residual”语义仍可报告；
* scaffold 不是预先固定的；
* exact uniform 只要满足物理 cap 就天然包含；
* 不会为了形式上的 scaffold 消耗 382 个 mandatory slots。

## 6.2 三种不能混写的 gap

必须同时记录：

1. **Dense hole**
   [
   H_{\rm index}
   =\max{x_1,\ x_{j+1}-x_j-1,\ L-1-x_K}.
   ]

2. **Original-frame interval**
   [
   H_{\rm frame}
   =\max{
   f(x_1)-f(0),
   f(x_{j+1})-f(x_j),
   f(L-1)-f(x_K)
   }.
   ]

3. **Seconds interval**
   [
   H_{\rm sec}
   =\max{
   \tau(x_1)-\tau(0),
   \tau(x_{j+1})-\tau(x_j),
   \tau(L-1)-\tau(x_K)
   }.
   ]

代码中的 `max_unselected_hole=G` 只对应第 1 个。

## 6.3 必须冻结的硬合同

`[PROPOSAL]`

* 硬约束主坐标：`original_frame_number`。
* 请求 cap：`max_original_frame_interval=15`。
* 实际离散可达 cap：12 帧，由 artifact 自动报告，不手写为另一超参。
* 同时报告 dense hole 和 seconds interval。
* `10` 帧 cap 判为与 uniform inclusion 不相容，直接 `INFEASIBLE_CONTRACT`。
* `K_eff=min(384,L)`。
* solver 只接收 valid prefix 的前 `L` 个物理坐标；padding 不得进入合法集合。

## 6.4 当前缺失的最小 metadata 修复

`[UNKNOWN]` 当前可从 `window_start_frame/snippet_stride/fps` 重建 intended frame/time 坐标，但 ceiling artifact 没有绑定实际 decode 后的每个合法 frame index。

```text
decoder_total_frames

decoder_avg_fps

```

# 8. `SET_INCLUSION_AND_FREEDOM_PROOFS`

## 8.1 Dense-hole `G=3` 语义下

[
\mathcal A \subsetneq \mathcal B \subsetneq \mathcal D_{\text{index},3}
\subsetneq \mathcal E.
]

* `A⊂B`：每个 uniform anchor 位于自己的 cell。
* `B⊂D_index,3`：one-per-cell 的理论 max hole 是3。
* 严格性反例：从 uniform 中删除某 cell 的 anchor，把该 quota 放到相邻 cell 的未选位置；可保持 hole≤3，但违反 one-per-cell。
* `D⊂E`：E 没有 gap 约束。

若 `S` 满足 cap：

[
\mathcal C(S)\subsetneq\mathcal D.
]

D 中存在不含某个 `s∈S` 的可行解，因此严格包含。

## 8.2 Physical-15 语义下

[
\mathcal A\subsetneq\mathcal D_{\rm frame,15}
\subsetneq\mathcal E.
]

但：

[
\mathcal B\nsubseteq\mathcal D_{\rm frame,15}.
]

原因是 B 的 worst case 有 4-dense-step interval，即16原始帧。

## 8.3 B 与 C 一般不可比较

* B 可选择不包含 mandatory scaffold `S` 的解，所以 `B⊄C`。
* C 可在一个 cell 放多个 residual、另一个 non-scaffold cell 为0，所以 `C⊄B`。

## 8.4 Family freedom

* A：
  [
  |\mathcal A|=1.
  ]

* B：
  [
  |\mathcal B|=3\cdot2^{382},
  \quad
  \log_2|\mathcal B|\approx383.585.
  ]
  但 quota-vector freedom 是0。

* 固定 C：
  [
  |\mathcal C(S)|
  ={L-|S|\choose K-|S|}.
  ]
  对 physical-15、`|S|=382`：
  [
  |\mathcal C|={386\choose2},
  ]
  residual freedom 很小。

* D：由 path-count DP 精确计算，不应只报组合近似。

* E：
  [
  |\mathcal E|={L\choose K}.
  ]

`[PROPOSAL]` artifact 同时报告：

```text
log2_selection_count
regional_quota_entropy
max_quota_per_uniform_cell
zero_quota_cell_count
multi_quota_cell_count
```

避免用巨大集合 cardinality 掩盖 B 的零 allocation freedom。

# 9. `EXACT_OPTIMIZATION_DESIGN`

## 9.1 哪些可以精确优化

### 几何/additive score

以下可由 DAG/DP 精确解：

* exact-K；
* original-frame max interval；
* additive coarse/transition score；
* background additive penalty；
* reference overlap；
* deterministic tie-break。

对当前 `L≤768,K≤384`，不需要 CP-SAT。

### GT 多指标 ceiling

以下更适合 CP-SAT：

* endpoint hit indicator；
* both-endpoint AND；
* overlapping GT；
* short-action minimum support；
* background count；
* 多级 lexicographic objective；
* mandatory scaffold/one-per-cell 等组合约束。

### 不可宣称精确优化的内容

`[MATHEMATICAL_CONSEQUENCE]` detector mAP 依赖：

* backbone nonlinear features；
* detector classification/regression；
* NMS；
* overlapping windows；
* video-level aggregation。

因此不能把 sample-wise position solver 称为“全局 detector-mAP oracle”。

## 9.2 四种必须分开的输出

1. **Metric-wise upper envelope**
   每个 metric 单独求一个 `OPTIMAL` 解。不同 metric 的解可以不同。

2. **Canonical lexicographic oracle**
   一套预注册优先级，只输出一个可复现 selection。

3. **Frozen-detector finite-candidate diagnostic**
   把预先列明的少量 exact solutions 输入 frozen physical-grid detector。

4. **Detector mAP**
   只称 secondary empirical diagnostic，不称 exact upper bound。

## 9.3 Canonical oracle 词典序

`[PROPOSAL]` 对每样本依次求解并锁定最优值：

1. maximize both-endpoint coverage at `r=0,1,2,4`；
2. maximize distinct endpoint hit at `r=0,1,2,4`；
3. minimize GT endpoint → nearest selected position total physical distance；
4. maximize short-action minimum support；
5. minimize background selected count；
6. maximize overlap with exact uniform；
7. lexicographically smallest selected-position tuple。

为什么 uniform overlap 放在最后：

* 不干扰 GT ceiling；
* empty-GT 样本会 canonical 地返回 exact uniform；
* 避免 equal-objective 时产生无意义的极端 clustering。

## 9.4 Radius 定义

为与现有 diagnostics 对齐，保留 dense radii `0/1/2/4`：

[
N_r(b)={t:|t-b|\le r}.
]

同时报告：

[
r_{\rm frame}=4r,\qquad
r_{\rm sec}=\frac{4r}{fps}.
]

对 fractional GT boundary，`r=0` 可能没有合法 grid point；artifact 必须另报 `boundary_on_grid_fraction`。

## 9.5 Solver status

| 状态           |         exact ceiling 可否使用 |
| ------------ | -------------------------: |
| `OPTIMAL`    |                          是 |
| `FEASIBLE`   | 否，只是 lower-bound candidate |
| `TIMEOUT`    |                          否 |
| `INFEASIBLE` |                  可作为合法合同结论 |
| `UNKNOWN`    |                fail closed |

CP-SAT 固定：

```text
num_search_workers=1
random_seed=0
solver_version=<hash-bound>
all objective coefficients integer-scaled
```

## 9.6 Split 与冻结

* `[CODE_FACT]` 本仓库的 `val` 和 `test` 都使用 THUMOS `validation` subset，只是 overlap protocol 不同。[`e2e_train_trunc...py:L43-L92`](https://github.com/yuzbo/OpenTAD_C3_CoarseClean_20260702/blob/4ce69c852bdbd902046b47bc6019ae11e850dbe4/configs/_base_/datasets/thumos-14/e2e_train_trunc_test_sw_256x224x224.py#L43-L92)
* `[PROPOSAL]` family、physical cap、objective order 和 gates 只用 training subset 冻结。
* 然后创建 preregistration hash。
* validation subset 只运行一次 sealed ceiling。
* 若未来另有真正 test GT，只有在 prereg hash 已冻结、`tuning=false` 时允许读取。

## 10.2 统计单位

* primary bootstrap unit：**video cluster**；

现有 analyzer 已使用 validation video cluster bootstrap，而不是 window bootstrap。[`analyze_duca_selection_quality.py:L618-L640`](https://github.com/yuzbo/OpenTAD_C3_CoarseClean_20260702/blob/4ce69c852bdbd902046b47bc6019ae11e850dbe4/tools/bata/analyze_duca_selection_quality.py#L618-L640)

## 10.3 不任意发明数值阈值

不采用固定 `+0.5 mAP`、`+10pp r0` 或“恢复20% headroom”作为通用门槛。

定义：

[
\Delta_m
=m(\text{candidate})-m(\text{uniform}),
]

[
H_m
=m(\text{D-GT canonical})-m(\text{uniform}),
]

[
\rho_m
=\frac{\Delta_m}{H_m},
\quad H_m>0.
]

从 paired video-cluster bootstrap 得到 `SE`，并针对计划的显著性与 power 计算：

[
MDE_m=
(z_{1-\alpha/2}+z_{1-\beta})SE_m.
]

未来训练所需 seed 数：

[
n_{\rm required}
================

\left\lceil
\frac{
2(z_{1-\alpha/2}+z_{1-\beta})^2\sigma_{\rm seed}^2
}{
\Delta_{\rm expected}^2
}
\right\rceil.
]

当前只有 seed-0 结果，`σ_seed` 不可估。因此任何固定 mAP 门槛都会是假精确。

## 10.4 GO 条件

`GO_TO_CARA_IMPLEMENTATION` 只在以下全部成立时触发：

1. exact-K、physical gap、uniform inclusion、metadata、hash、solver status 全部通过；
2. D physical family 的 canonical GT oracle 在预注册 lex vector 上相对 uniform 有正的 simultaneous lower confidence bound，且效应不小于 validation-derived MDE；
3. deploy-visible coarse/transition score 经同一 D-DP 解码后，相对 uniform 的关键差值 lower CI >0；
4. frozen physical-grid detector 的预注册 candidate 对 uniform 的 cls+reg loss改善或 video-level mAP改善 lower CI >0；
5. dense-to-candidate E2E saving 的 lower CI >0；
6. frontend overhead 的 upper CI 小于 heavy-backbone saving 的 lower CI；
7. 按可获得的 seed variance 推算，所需训练 seeds 不超过冻结计算预算。

## 10.5 HOLD 条件

任一以下情况触发 `HOLD_AND_REVISE_FAMILY`：

* physical cap 仍以 dense `G` 模糊表达；

## 10.6 KILL 条件

1. unrestricted E 与 gap-matched D 的 privileged physical oracle，对 uniform 的所有预注册边界/physical-grid detector效果 upper CI 都不超过 MDE；
2. D 有 GT headroom，但在充分 powered 的 held-out diagnostic 中，当前允许的 `p_action`、transition 与 temporal hidden 信息对该 headroom的可恢复量 upper CI≤0；

```python
from __future__ import annotations

from dataclasses import dataclass
from enum import Enum
from hashlib import sha256
import json
import math
from typing import Any, Iterable, Mapping, Sequence

try:
    import torch
except Exception:  # diagnostic module may be inspected without torch
    torch = None


class ContractError(ValueError):
    pass


class SolveStatus(str, Enum):
    OPTIMAL = "OPTIMAL"
    FEASIBLE = "FEASIBLE"
    TIMEOUT = "TIMEOUT"
    INFEASIBLE = "INFEASIBLE"
    UNKNOWN = "UNKNOWN"


def _tolist(value: Any) -> list[Any]:
    """Accept CPU/GPU tensors, numpy arrays and Python sequences."""
    if torch is not None and torch.is_tensor(value):
        value = value.detach().cpu().reshape(-1).tolist()
    elif hasattr(value, "tolist"):
        value = value.tolist()
    return list(value)


def valid_prefix_length(mask: Any) -> int:
    values = _tolist(mask)
    bits: list[bool] = []
    for value in values:
        if isinstance(value, bool):
            bits.append(value)
        elif value in (0, 1):
            bits.append(bool(value))
        else:
            raise ContractError("valid_mask must contain booleans only")

    length = sum(bits)
    expected = [True] * length + [False] * (len(bits) - length)
    if bits != expected:
        raise ContractError("valid_mask must be one contiguous prefix")
    return length


def exact_uniform(L: int, K: int) -> tuple[int, ...]:
    L, K = int(L), int(K)
    if not (1 <= L <= 768 and 0 <= K <= min(384, L)):
        raise ContractError("require 1<=L<=768 and 0<=K<=min(384,L)")
    if K == 0:
        return ()
    if K == 1:
        return (0,)

    denominator = K - 1
    anchors = []
    for index in range(K):
        quotient, remainder = divmod(index * (L - 1), denominator)
        if (
            2 * remainder > denominator
            or (2 * remainder == denominator and quotient % 2 == 1)
        ):
            quotient += 1
        anchors.append(quotient)

    if len(set(anchors)) != K:
        raise ContractError("exact-uniform anchors are not unique")
    return tuple(anchors)


def uniform_cells(L: int, K: int) -> tuple[tuple[int, ...], ...]:
    anchors = exact_uniform(L, K)
    if not anchors:
        return ()

    starts = [0] * K
    ends = [L] * K
    for j in range(1, K):
        starts[j] = (anchors[j - 1] + anchors[j]) // 2 + 1
        ends[j - 1] = starts[j]

    cells = tuple(
        tuple(range(starts[j], ends[j]))
        for j in range(K)
    )
    if any(anchors[j] not in cells[j] for j in range(K)):
        raise ContractError("anchor escaped its Voronoi cell")
    return cells


@dataclass(frozen=True)
class PhysicalAxis:
    original_frames: tuple[float, ...]
    seconds: tuple[float, ...]

    @classmethod
    def build(
        cls,
        original_frames: Any,
        seconds: Any,
        valid_mask: Any,
    ) -> "PhysicalAxis":
        L = valid_prefix_length(valid_mask)
        frames = tuple(float(v) for v in _tolist(original_frames)[:L])
        times = tuple(float(v) for v in _tolist(seconds)[:L])

        if L < 1 or len(frames) != L or len(times) != L:
            raise ContractError("coordinates must cover the valid prefix")

        for name, values in (("frames", frames), ("seconds", times)):
            if not all(math.isfinite(v) for v in values):
                raise ContractError(f"{name} must be finite")
            if any(b <= a for a, b in zip(values, values[1:])):
                raise ContractError(f"{name} must be strictly increasing")

        return cls(frames, times)

    @property
    def L(self) -> int:
        return len(self.original_frames)


def _selection(
    selected: Any,
    L: int,
    K: int,
) -> tuple[int, ...]:
    values = tuple(sorted(int(v) for v in _tolist(selected)))
    if len(values) != K or len(set(values)) != K:
        raise ContractError("selection must contain exactly K unique positions")
    if any(v < 0 or v >= L for v in values):
        raise ContractError("selection escaped the valid prefix")
    return values


def physical_gap_report(
    selected: Any,
    axis: PhysicalAxis,
    K: int,
) -> dict[str, Any]:
    selected = _selection(selected, axis.L, K)

    if K == 0:
        return {
            "coverage_defined": False,
            "max_unselected_index_hole": axis.L,
            "max_original_frame_interval": None,
            "max_seconds_interval": None,
        }

    left_hole = selected[0]
    right_hole = axis.L - 1 - selected[-1]
    interior_holes = [
        right - left - 1
        for left, right in zip(selected, selected[1:])
    ]

    frame_intervals = [
        axis.original_frames[selected[0]] - axis.original_frames[0],
        *(
            axis.original_frames[right] - axis.original_frames[left]
            for left, right in zip(selected, selected[1:])
        ),
        axis.original_frames[-1] - axis.original_frames[selected[-1]],
    ]

    second_intervals = [
        axis.seconds[selected[0]] - axis.seconds[0],
        *(
            axis.seconds[right] - axis.seconds[left]
            for left, right in zip(selected, selected[1:])
        ),
        axis.seconds[-1] - axis.seconds[selected[-1]],
    ]

    return {
        "coverage_defined": True,
        "left_index_hole": left_hole,
        "interior_max_index_hole": max(interior_holes, default=0),
        "right_index_hole": right_hole,
        "max_unselected_index_hole": max(
            [left_hole, right_hole, *interior_holes]
        ),
        "max_original_frame_interval": max(frame_intervals),
        "max_seconds_interval": max(second_intervals),
    }


def validate_physical_cap(
    selected: Any,
    axis: PhysicalAxis,
    K: int,
    *,
    max_original_frame_interval: float,
) -> dict[str, Any]:
    report = physical_gap_report(selected, axis, K)
    if not report["coverage_defined"]:
        raise ContractError("finite physical cap is infeasible for K=0")

    observed = float(report["max_original_frame_interval"])
    if observed > float(max_original_frame_interval) + 1e-9:
        raise ContractError(
            f"physical gap violation: observed={observed}, "
            f"cap={max_original_frame_interval}"
        )
    return report


def solve_one_per_cell(
    scores: Any,
    L: int,
    K: int,
) -> tuple[int, ...]:
    values = [float(v) for v in _tolist(scores)[:L]]
    if len(values) != L or not all(math.isfinite(v) for v in values):
        raise ContractError("scores must be finite and length L")

    anchors = exact_uniform(L, K)
    selected = []
    for anchor, cell in zip(anchors, uniform_cells(L, K)):
        selected.append(
            min(
                cell,
                key=lambda t: (
                    -values[t],
                    abs(t - anchor),
                    t,
                ),
            )
        )
    return tuple(selected)


def minimum_scaffold(
    candidates: Iterable[int],
    axis: PhysicalAxis,
    *,
    max_original_frame_interval: float,
) -> tuple[int, ...]:
    """Exact minimum-cardinality source-to-sink path; lexicographic tie."""
    candidates = sorted(set(int(v) for v in candidates))
    if (
        not candidates
        or any(v < 0 or v >= axis.L for v in candidates)
    ):
        raise ContractError("invalid scaffold candidates")

    cap = float(max_original_frame_interval)
    best: list[tuple[int, tuple[int, ...]] | None] = [
        None
    ] * len(candidates)

    for j, position in enumerate(candidates):
        options: list[tuple[int, tuple[int, ...]]] = []

        if (
            axis.original_frames[position]
            - axis.original_frames[0]
            <= cap + 1e-9
        ):
            options.append((1, (position,)))

        for i in range(j):
            if (
                best[i] is not None
                and axis.original_frames[position]
                - axis.original_frames[candidates[i]]
                <= cap + 1e-9
            ):
                count, path = best[i]
                options.append((count + 1, path + (position,)))

        if options:
            best[j] = min(options, key=lambda item: (item[0], item[1]))

    terminal = [
        best[j]
        for j, position in enumerate(candidates)
        if (
            best[j] is not None
            and axis.original_frames[-1]
            - axis.original_frames[position]
            <= cap + 1e-9
        )
    ]

    if not terminal:
        raise ContractError("no scaffold satisfies the physical cap")

    return min(terminal, key=lambda item: (item[0], item[1]))[1]


def solve_coverage_residual(
    scores: Any,
    axis: PhysicalAxis,
    K: int,
    scaffold: Sequence[int],
    *,
    max_original_frame_interval: float,
) -> tuple[int, ...]:
    scaffold = _selection(scaffold, axis.L, len(scaffold))
    validate_physical_cap(
        scaffold,
        axis,
        len(scaffold),
        max_original_frame_interval=max_original_frame_interval,
    )
    if len(scaffold) > K:
        raise ContractError("scaffold exceeds K")

    values = [float(v) for v in _tolist(scores)[:axis.L]]
    scaffold_set = set(scaffold)
    remaining = [
        t for t in range(axis.L)
        if t not in scaffold_set
    ]

    # Deterministic: larger score first, then smaller dense index.
    residual = sorted(
        remaining,
        key=lambda t: (-values[t], t),
    )[:K - len(scaffold)]

    selected = tuple(sorted((*scaffold, *residual)))
    validate_physical_cap(
        selected,
        axis,
        K,
        max_original_frame_interval=max_original_frame_interval,
    )
    return selected


def solve_global_exact_k(
    scores: Any,
    axis: PhysicalAxis,
    K: int,
    *,
    max_original_frame_interval: float,
    score_scale: int = 1_000_000,
) -> tuple[int, ...]:
    """Exact additive-score DAG DP with deterministic lexicographic ties."""
    L = axis.L
    cap = float(max_original_frame_interval)

    if not 0 <= K <= min(384, L):
        raise ContractError("invalid K")
    if K == 0:
        raise ContractError("finite physical cap is infeasible for K=0")

    raw_scores = [float(v) for v in _tolist(scores)[:L]]
    if (
        len(raw_scores) != L
        or not all(math.isfinite(v) for v in raw_scores)
    ):
        raise ContractError("scores must be finite and length L")

    integer_scores = [
        int(round(value * score_scale))
        for value in raw_scores
    ]

    neg_inf = -(10**100)
    prev_score = [neg_inf] * L
    prev_rank = [10**18] * L
    parents = [[-1] * L for _ in range(K + 1)]

    first_layer = []
    for j in range(L):
        if (
            axis.original_frames[j]
            - axis.original_frames[0]
            <= cap + 1e-9
        ):
            prev_score[j] = integer_scores[j]
            first_layer.append(j)

    for rank, j in enumerate(first_layer):
        prev_rank[j] = rank

    for count in range(2, K + 1):
        current_score = [neg_inf] * L
        current_parent = [-1] * L

        for j in range(L):
            best_score = neg_inf
            best_parent_rank = 10**18
            best_parent = -1

            # Coordinates are sorted, so break once the cap is exceeded.
            for i in range(j - 1, -1, -1):
                if (
                    axis.original_frames[j]
                    - axis.original_frames[i]
                    > cap + 1e-9
                ):
                    break
                if prev_score[i] == neg_inf:
                    continue

                candidate_score = (
                    prev_score[i] + integer_scores[j]
                )
                if (
                    candidate_score > best_score
                    or (
                        candidate_score == best_score
                        and prev_rank[i] < best_parent_rank
                    )
                ):
                    best_score = candidate_score
                    best_parent_rank = prev_rank[i]
                    best_parent = i

            if best_parent >= 0:
                current_score[j] = best_score
                current_parent[j] = best_parent

        parents[count] = current_parent

        reachable = [
            j for j in range(L)
            if current_parent[j] >= 0
        ]
        current_rank = [10**18] * L
        for rank, j in enumerate(
            sorted(
                reachable,
                key=lambda j: (
                    prev_rank[current_parent[j]],
                    j,
                ),
            )
        ):
            current_rank[j] = rank

        prev_score = current_score
        prev_rank = current_rank

    terminal = [
        j
        for j in range(L)
        if (
            prev_score[j] != neg_inf
            and axis.original_frames[-1]
            - axis.original_frames[j]
            <= cap + 1e-9
        )
    ]
    if not terminal:
        raise ContractError(
            "global exact-K/max-interval family is infeasible"
        )

    end = min(
        terminal,
        key=lambda j: (
            -prev_score[j],
            prev_rank[j],
        ),
    )

    path = [end]
    for count in range(K, 1, -1):
        end = parents[count][end]
        path.append(end)

    selected = tuple(reversed(path))
    validate_physical_cap(
        selected,
        axis,
        K,
        max_original_frame_interval=cap,
    )
    return selected


def require_exact_status(

    *,
    exact_claim: bool,
) -> None:
    if exact_claim and status is not SolveStatus.OPTIMAL:
        raise ContractError(
            f"exact claim requires OPTIMAL; got {status.value}"

        sort_keys=True,

        ensure_ascii=True,
```

## 12.2 CP-SAT path model 与 canonical pinning

```python
from ortools.sat.python import cp_model


def build_physical_path_model(
    axis: PhysicalAxis,
    K: int,
    cap_frames: int,
):
    if K <= 0:
        raise ContractError("finite-cap CP-SAT path requires K>0")

    model = cp_model.CpModel()
    x = [
        model.NewBoolVar(f"x_{t}")
        for t in range(axis.L)
    ]

    source = {}
    sink = {}
    between = {}

    for j in range(axis.L):
        if (
            axis.original_frames[j]
            - axis.original_frames[0]
            <= cap_frames
        ):
            source[j] = model.NewBoolVar(f"a_src_{j}")

        if (
            axis.original_frames[-1]
            - axis.original_frames[j]
            <= cap_frames
        ):
            sink[j] = model.NewBoolVar(f"a_{j}_sink")

    for i in range(axis.L):
        for j in range(i + 1, axis.L):
            delta = (
                axis.original_frames[j]
                - axis.original_frames[i]
            )
            if delta > cap_frames:
                break
            between[i, j] = model.NewBoolVar(
                f"a_{i}_{j}"
            )

    model.Add(sum(source.values()) == 1)
    model.Add(sum(sink.values()) == 1)
    model.Add(sum(x) == K)

    for j in range(axis.L):
        incoming = []
        outgoing = []

        if j in source:
            incoming.append(source[j])
        if j in sink:
            outgoing.append(sink[j])

        incoming.extend(
            arc for (i, k), arc in between.items()
            if k == j
        )
        outgoing.extend(
            arc for (i, k), arc in between.items()
            if i == j
        )

        model.Add(sum(incoming) == x[j])
        model.Add(sum(outgoing) == x[j])

    return model, x


def solve_and_pin(
    model: cp_model.CpModel,
    solver: cp_model.CpSolver,
    expression,
    *,
    maximize: bool,
) -> int:
    if maximize:
        model.Maximize(expression)
    else:
        model.Minimize(expression)

    status = solver.Solve(model)
    if status != cp_model.OPTIMAL:
        raise ContractError(
            f"canonical oracle requires OPTIMAL; "
            f"status={solver.StatusName(status)}"
        )

    optimum = int(round(solver.ObjectiveValue()))
    model.Add(expression == optimum)
    model.ClearObjective()
    return optimum


def endpoint_hit_var(
    model: cp_model.CpModel,
    x,
    positions: Sequence[int],
    name: str,
):
    hit = model.NewBoolVar(name)
    if not positions:
        model.Add(hit == 0)
        return hit

    mass = sum(x[t] for t in positions)
    model.Add(mass >= hit)
    model.Add(mass <= len(positions) * hit)
    return hit


def canonical_gt_oracle(
    axis: PhysicalAxis,
    K: int,
    cap_frames: int,
    gt_segments: Sequence[tuple[float, float]],
    exact_uniform_positions: Sequence[int],
):
    model, x = build_physical_path_model(
        axis,
        K,
        cap_frames,
    )

    solver = cp_model.CpSolver()
    solver.parameters.num_search_workers = 1
    solver.parameters.random_seed = 0

    both_by_radius = {}
    any_by_radius = {}

    for radius in (0, 1, 2, 4):
        endpoint_hits = []
        both_hits = []

        for index, (start, end) in enumerate(gt_segments):
            start_positions = [
                t for t in range(axis.L)
                if abs(t - start) <= radius
            ]
            end_positions = [
                t for t in range(axis.L)
                if abs(t - min(axis.L - 1, end)) <= radius
            ]

            start_hit = endpoint_hit_var(
                model,
                x,
                start_positions,
                f"start_{index}_r{radius}",
            )
            end_hit = endpoint_hit_var(
                model,
                x,
                end_positions,
                f"end_{index}_r{radius}",
            )

            both = model.NewBoolVar(
                f"both_{index}_r{radius}"
            )
            model.Add(both <= start_hit)
            model.Add(both <= end_hit)
            model.Add(
                both >= start_hit + end_hit - 1
            )

            endpoint_hits.extend([start_hit, end_hit])
            both_hits.append(both)

        both_by_radius[radius] = sum(both_hits)
        any_by_radius[radius] = sum(endpoint_hits)

    # Strict-to-loose canonical order.
    objective_vector = {}
    for radius in (0, 1, 2, 4):
        objective_vector[f"both_r{radius}"] = solve_and_pin(
            model,
            solver,
            both_by_radius[radius],
            maximize=True,
        )

    for radius in (0, 1, 2, 4):
        objective_vector[f"endpoint_r{radius}"] = solve_and_pin(
            model,
            solver,
            any_by_radius[radius],
            maximize=True,
        )

    # Empty-GT/equal-objective fallback: preserve uniform when feasible.
    uniform_overlap = sum(
        x[t] for t in exact_uniform_positions
    )
    objective_vector["uniform_overlap"] = solve_and_pin(
        model,
        solver,
        uniform_overlap,
        maximize=True,
    )

    # Exact lexicographically smallest selected tuple:
    # prefer x[0]=1, then x[1]=1, ...
    for t in range(axis.L):
        solve_and_pin(
            model,
            solver,
            x[t],
            maximize=True,
        )

    status = solver.Solve(model)
    if status != cp_model.OPTIMAL:
        raise ContractError("final pinned solve is not OPTIMAL")

    selected = tuple(
        t for t in range(axis.L)
        if solver.Value(x[t])
    )
    return {
        "status": "OPTIMAL",
        "selected_positions": selected,
        "objective_vector": objective_vector,
    }
```

生产版本还应在 uniform-overlap 之前加入：

* endpoint-nearest-selected distance；
* short-action support；
* background count。

这些应使用整数 frame distances，不使用浮点 objective。

```python
def authorize_gt_access(
    *,
    mode: str,
    split: str,
    preregistration_sha256: str | None,
    tuning: bool,

    if mode == "deployment":
        raise ContractError(
            "deployment selector must never receive GT"
        )

            raise ContractError(
                "test GT requires frozen_evaluation mode"
```
