**审计裁决**

1. S1 已闭合 source-uint8 crop、共享 VideoMAE 实例、`6×6/8×8` token grid、`[B,384,768]` detector 输入和双分支梯度连通，但明确没有 crop mAP、完整成本、GO/KILL、learned policy 或论文证据。

3. global/local 共用同一个 `self.model.backbone`，但 wrapper 顺序执行两次 `_encode_view`；固定均值发生在两个 `[B,384,384]` feature stream 之后。共享权重不等于一次计算。
4. 当前 S1 config 明确禁止 detector training、`tools/train.py`、map、teacher、oracle、learned policy 和 official test，因此 S2 不得直接解除该 config 的 gate；必须新增独立 S2 config 与注册。
5. 历史 `e2e_thumos_videomae_s_768x1_160_adapter.py` 的 train path 包含 `RandomResizedCrop`，val/test path 包含 resize 后 `CenterCrop(160)`；它不是保留完整画面的 matched full-frame dense160。S2 的正式 `matched dense160` 因而冻结为 **decoded source full-frame letterbox160**，而不是复用该旧空间 pipeline。旧文件只提供 VideoMAE、optimizer、scheduler、head 和 NMS 继承依据。
6. 正式模型保持原 projection、FPN、ActionFormer head、loss 和 sliding-window NMS。当前推理先产生 per-window 结果，sliding population 汇总后再运行 NMS；S2 reference 必须在该汇总 NMS 之前选择 window candidate。
7. official mAP evaluator 按 score 降序、逐类逐 tIoU 贪心锁定 GT；零长度 proposal 不会被预先删除，tIoU 为零时继续作为 false positive。S2 analyzer 必须复现该行为。
8. `return_feat_map=True` 绕过分类出口 `fc_norm`；历史 gate 只允许这两个参数无梯度。S2 不再保留“trainable 但 disconnected”的例外，而是在模型构建后显式冻结 `fc_norm.{weight,bias}`。
9. 所有 formal training 使用一个进程、一个 Slurm-visible GPU、strict deterministic、无 resume、无 `--cfg-options`，AMP overflow 最多重试 8 次；scheduler、EMA 和 successful-update counter 只能在成功 optimizer step 后推进。现有训练入口已经具备这些事务语义，S2 仅增加独立 binding。

## 2. 唯一研究命题与 estimand

**唯一命题 H1**

> 对冻结的 THUMOS14 development fit/gate、完整 768 点时间轴、同一 VideoMAE-S/AdaTAD-derived ActionFormer detector、同一训练预算和 official evaluator，一个由 21 个静态、source-native、`128×128` local crop 构成并具有明确几何 coverage certificate 的有限 library，是否存在一个非部署、GT 可见的 library-conditional reference，使 `global96 + selected-local128` 在 Avg-mAP、高 tIoU、短动作和边界保护上与 full-frame letterbox160 等效，同时相对固定中心、确定性随机和最佳固定位置保留足够的选择 headroom，并使单 local-candidate 的真实 full-stack 路径显著低于 dense160 成本。

H1 是一个交集命题；第 11 节的全部 coverage、准确率、headroom、成本和种子稳定性条件必须同时满足，才允许 `GO_TO_LEARNED_POLICY`。

**Primary estimand**

令：

* (M_{s,\mathrm{REF}})：seed (s) 下 `NC2-GL-LIB-REF` 在 40 个 gate 视频上的 official Avg-mAP；
* (M_{s,\mathrm{D160}})：同 seed 下 `NC2-D160` 的 official Avg-mAP；
* seeds (S={3407,3408,3409})。

冻结 primary estimand 为：

[
\Delta_{\mathrm{Avg}}
=====================

\frac{1}{3}
\sum_{s\in S}
\left(
M_{s,\mathrm{REF}}-M_{s,\mathrm{D160}}
\right).
]

单位为 percentage points。`NC2-GL-LIB-REF` 是有限 21-candidate、per-window、GT-visible reference；它不是可部署模型，也不是连续空间或 global-mAP oracle。

## 3. 允许主张与禁止主张

**S2 通过后唯一允许主张**

> 在冻结的 21-candidate、static local128 library、global96 context、fixed-mean fusion、VideoMAE-S/AdaTAD-derived ActionFormer、development fit/gate 和注册成本环境下，存在足以保护已注册 TAD 指标且具有选择 headroom 的 source-native local views；该证据仅授权启动一个独立预注册的 learned candidate-selection 研究阶段。

同时允许报告：

* library 的几何覆盖率和 minimum same-size crop IoU certificate；
* library-union proposal coverage；
* center、deterministic random、fit-selected best-fixed 和 GT-visible reference 的 paired margins；
* matched dense160、dense224、dense256 的同提交 development 结果；
* 单 global+单 local 路径与 dense160 的 warm-serial full-stack 成本；
* non-deployable exhaustive reference-search 成本，且必须单独列示。

**始终禁止主张**

* 禁止把 S2 称为 learned ROI、learned crop policy、强化学习、动态 budget 或时变 tracking 方法。
* 禁止把 `global96`、dense160/224/256 full-frame letterbox 称为空间裁剪。
* 禁止虚构 THUMOS14 空间框、actor box、spatial GT 或“ground-truth crop”。
* 禁止把 reference 称为连续空间 oracle、mAP oracle、真实部署策略或 paper method。
* 禁止从 S2 推出 learned policy 必然可训练、必然低成本或必然优于 reference。
* 禁止把 matched view pixels、token 数或理论 FLOPs 当成实测延时、显存或能耗。
* 禁止把共享 VideoMAE 参数写成一次 backbone forward。
* 禁止使用 historical R0 数字填充正式矩阵。
* 禁止把 development gate 结果称为 official-test 结果。
* 禁止把 GO 写成论文贡献成立、跨 detector 泛化成立或 continuous-crop 路线成立。
* `KILL_THIS_LIBRARY` 只否定第 5 节冻结的 21 个 static local128 candidate 及其 registered use，不得否定全部 continuous-crop 研究。
* `INCONCLUSIVE_COVERAGE` 不得授权 learned policy，也不得 KILL continuous crop。

## 5. 冻结 candidate library 与 coverage certificate

**Library identity**

* Schema：`native_crop_s2_candidate_library_v1`
* Library ID：`NC2-L128-STATIC-7X3-V1`
* local crop：`128×128`
* coordinate convention：decoded source RGB frame 上的 half-open `xyxy`
* source geometry：runtime 必须与 geometry cache 一致；当前冻结 population 为 `W=320,H=180`
* temporal behavior：static
* knots：空集合
* temporal interpolation：`NONE`
* horizontal/vertical velocity：精确为零
* acceleration、jitter、smoothing：精确为零
* candidates/window：21
* scale candidates：只有 `128×128`
* aspect-ratio candidates：只有 `1:1`

**坐标公式**

令 (C=128)、(J_x=6)、(J_y=2)，定义确定性 half-up rounding：

[
\operatorname{RH}(a,b)
======================

\left\lfloor
\frac{2a+b}{2b}
\right\rfloor .
]

对 (j\in{0,\ldots,6})、(k\in{0,1,2})：

[
x_j=\operatorname{RH}\big(j(W-C),J_x\big),\qquad
y_k=\operatorname{RH}\big(k(H-C),J_y\big).
]

candidate box 为：

[
B_{j,k}=[x_j,y_k,x_j+C,y_k+C).
]

在 `320×180` 上：

* (x_0) 集合：`[0,32,64,96,128,160,192]`
* (y_0) 集合：`[0,26,52]`
* center candidate：`j=3,k=1`，box `[96,26,224,154)`
* stable linear index：(q=7k+j)，范围 `0..20`
* stable ID：`NC2-L128-S-J{j:02d}-K{k:02d}`

**越界、平移和 padding**

* 上述公式在 (W,H\ge128) 时必定给出 in-bounds box。
* runtime 重新根据 `(j,k,W,H)` 计算坐标；cached absolute box 只用于一致性验证。
* 若外部或损坏 cache 给出越界 box，先按保持 `128×128` 的 rigid translation 计算可行 box，但 formal validator 要求 translation delta 精确为 `[0,0]`；非零即拒绝，不能静默修复。
* 若 `W<128` 或 `H<128`，formal S2 禁止 padding，整个 campaign 在 coverage 前置门失败。
* local crop 不执行 resize、resample、interpolation、mask pooling 或 float materialization。
* full-frame global/dense views执行独立 letterbox；不得在 full-frame resize 后再取 local crop。

**Candidate cache population**

* 664 development sliding windows × 21 = `13,944` rows；
* 535 fit windows × 21 = `11,235` rows；
* 129 gate windows × 21 = `2,709` rows；
* 每行绑定 source geometry、window ID、candidate ID 和 exact box；
* 不缓存 RGB pixels、float tensor、feature 或 model prediction。

**稳定 window ID**

```text
window_id :=
  video_id
  + "|"
  + zero_pad(window_start_frame, 10)
  + "|"
  + zero_pad(valid_temporal_points, 4)
```

**几何 coverage certificate**

对任意 admissible continuous same-size crop top-left：

[
(u,v)\in[0,W-C]\times[0,H-C],
]

其最近 library candidate 满足：

[
|u-x_j|\le16,\qquad |v-y_k|\le13.
]

因此最坏 equal-size box IoU 下界为：

[
\operatorname{IoU}_{\min}
=========================

\frac{(128-16)(128-13)}
{2\cdot128^2-(128-16)(128-13)}
==============================

# \frac{12880}{19888}

0.6476267095736.
]

正式 certificate 必须同时证明：

* `min_same_size_crop_iou >= 0.6476267095736`；
* 逐个枚举 `193×53=10,229` 个 integer top-left，结果不低于解析下界；
* 21 个 crop 的 source-pixel union 覆盖 `320×180` 的 100%；
* 所有 13,944 rows 都 in-bounds；
* padding rate 为 0；
* translation delta 全为 0；
* candidate count/window 精确为 21；
* stable ID、index、coordinates 无重复；
* 任意 runtime geometry 与 cache geometry 不一致时 fail-closed。

**模型条件下的 candidate coverage**

对 `NC2-GL-LIB` final EMA，每个 candidate 保留其 top-200 pre-NMS proposals，按 proposal 的最大 class score 排序。对每个 GT (g)：

[
h(g,\tau)=
\mathbf 1\left[
\exists c,p:
\operatorname{label}(p)=\operatorname{label}(g),
\operatorname{tIoU}(p,g)\ge\tau
\right].
]

注册 coverage 指标为：

* overall `CandidateUnionRecall@0.7`；
* Short-Q1 `CandidateUnionRecall@0.7`；
* 同时报告 `@0.5`、per-class、per-duration quartile；
* 它们使用 21 candidates 的 union，但不组成可部署预测。

**生成与验证工具**

* 生成：`tools/bata/build_native_crop_s2_candidate_cache.py`
* 验证：`tools/bata/validate_native_crop_s2_candidate_cache.py`
* 几何 certificate：`tools/bata/native_crop_s2_coverage.py`
* 输出：`candidate_library.json`、`candidate_rows.jsonl`、`coverage_certificate.json`

## 6. 冻结 library-conditional reference

**Reference identity**

* Schema：`native_crop_s2_detector_objective_reference_v1`
* 模型：对应 seed 的 `NC2-GL-LIB` final EMA
* candidate set：第 5 节的 21 个 static local128 boxes
* selection granularity：每个 768-point sliding window一个 candidate
* GT visibility：fit/gate 均允许，但仅在 detached reference utility 阶段
* teacher：无
* spatial GT：无
* reference cache 进入 raw model prediction：禁止
* reference selection 进入 deployable cell：禁止

**Raw candidate prediction**

对每个 window 和 candidate：

1. decode source frames 一次；
2. 生成一个 global96 和 21 个 source-native local128；
3. global branch feature 只计算一次；
4. 每个 local branch feature 计算一次；
5. 对每个 candidate 与同一 global feature fixed-mean fusion；
6. projection/FPN/head 产生未聚合、未 sliding-NMS 的 proposal 与 class score；
7. 该 raw forward 不接收 GT、target cache、teacher、reference ID 或其它 candidate 的结果。

**注册 utility**

令 (G_w) 为 window (w) 的 temporal GT，(P_{w,c}) 为 candidate (c) 的 official-domain、pre-sliding-NMS predictions。预测采用原路径的 `pre_nms_thresh=0.001` 和 `pre_nms_topk=2000`，但 utility 使用未 round 的 float tensor。

对 (g\in G_w)：

[
b_\tau(g,c)
===========

\max_{\substack{p\in P_{w,c}\
\operatorname{label}(p)=\operatorname{label}(g)}}
\operatorname{tIoU}(p,g),
]

空集合取 0。

[
n_\tau(c,w)
===========

\sum_{g\in G_w}
\mathbf 1[b_\tau(g,c)\ge\tau].
]

[
q(c,w)
======

\sum_{g\in G_w}
\max_{\substack{p\in P_{w,c}\
\operatorname{label}(p)=\operatorname{label}(g)}}
\left[
\operatorname{score}(p)\operatorname{tIoU}(p,g)
\right].
]

定义 false-evidence set：

[
F_{w,c}
=======

\left{
p\in P_{w,c}:
\max_{\substack{g\in G_w\
\operatorname{label}(g)=\operatorname{label}(p)}}
\operatorname{tIoU}(p,g)<0.3
\right}.
]

按 score 降序取前 50 个，不足补零：

[
f(c,w)
======

\frac{1}{50}
\sum_{p\in\operatorname{Top50}(F_{w,c})}
\operatorname{score}(p).
]

再计算原 ActionFormer head 的 evaluation-mode detector objective：

[
L_{\mathrm{det}}(c,w)
=====================

L_{\mathrm{cls}}(c,w)+L_{\mathrm{reg}}(c,w).
]

`model.eval()` 时，当前 head 使用 per-window `max(num_pos,1)`，不会更新训练期 EMA loss normalizer。

Reference utility 是下列 tuple 的 lexicographic maximum：

[
V(c,w)
======

\left(
n_{0.7},
n_{0.5},
q,
-f,
-L_{\mathrm{det}},
-q_{\mathrm{index}}
\right).
]

因此 reference 首先最大化 high-IoU GT proposal coverage，然后最大化 0.5 coverage 和 score-weighted overlap，再最小化 false evidence、detector loss 和 candidate index。无 GT window 的前三项精确为零，选择由 false evidence、detector loss 和 ID 决定。

**Tie-break**

lexicographic tuple 完全相同时，选择最小 candidate index。禁止 epsilon tie、近似 tie、随机 tie 或基于 gate aggregate mAP 的二次选择。

**Fit 与 gate 计算**

* Fit：

  * 对 535 个 fixed sliding windows 完成全 21-candidate sweep；
  * 计算同一 per-window reference；
  * 只用于 fit/reference diagnostic 和 `BESTFIXED` control；
  * 不改变模型、candidate library、阈值或 checkpoint。
* Gate：

  * 对 129 windows 完成全 candidate sweep；
  * raw outputs 全部哈希并关闭后，才允许读取 gate target cache；
  * 计算 per-window reference ID；
  * 选择该 candidate 的 per-window official result；
  * 之后调用原 sliding aggregation/NMS 和 evaluator。

**BESTFIXED control**

对每个 seed：

1. 在 fit 535 windows 上，为每个 candidate ID 分别组成一个全-fit fixed-position预测集；
2. 用 official evaluator 计算 Avg-mAP；
3. 最大 Avg-mAP 胜出；
4. tie 时依次比较 mAP@0.7、mAP@0.6、较小 candidate ID；
5. 得到一个 fit-selected candidate ID；
6. gate 上所有 window 使用该同一 ID；
7. gate GT 不参与该选择。

**为何不是 continuous spatial oracle**

* 仅有 21 个 box；
* crop size 固定为 128；
* aspect ratio 固定为 1:1；
* 无 scale search；
* 无 trajectory；
* 无 sub-grid coordinates；

* 它不是 global official mAP 的组合优化 oracle；
* 它不能证明 library 外不存在更好 crop。

**Cache 是否进入模型推理**

## 7. 冻结模型与训练配置

**共同模型**

* 时间轴：768
* chunk count：48
* clip length：16
* tubelet：2
* intermediate temporal feature：384
* detector input：`[B,384,768]`
* VideoMAE-S：

  * patch size 16；
  * embed dim 384；
  * depth 12；
  * heads 6；
  * 12 个 temporal adapters；
  * activation checkpointing 开启；
  * runtime spatial position interpolation。
* Detector：

  * 原 ActionFormer projection；
  * 原 FPN；
  * 原 ActionFormer head；
  * 原 focal classification loss、DIoU regression loss；
  * 原 soft-NMS；
  * 不增加 detector parameter、loss 或 post-processing repair。

现有 dense config 已冻结 backbone、optimizer、scheduler、NMS 等具体参数。

**输入视图**

* `D160/D224/D256`：decoded source 的完整 frame，分别 letterbox 到 `160/224/256`；不是 local crop。
* `G96`：完整 frame letterbox96。

\frac{F_{\mathrm{global}}(t)+F_{\mathrm{local}}(t)}{2}.
]

* fusion 位置：384-point、384-channel feature level；
* fusion 参数：零；

**初始化**

* pretrained filename：`vit-small-p16_videomae-k400-pre_16x4x1_kinetics-400_my.pth`

* checkpoint state tensors：163
* backbone core tensors：161
* core parameters：22,482,048

* adapters、projection、FPN、head 的随机初始化由 seed 唯一决定；
* 不从历史 S1/R0 trained checkpoint 初始化。

**Trainable/frozen parameters**

Trainable：

* 12 个 VideoMAE temporal adapters；
* projection；
* FPN；
* ActionFormer classification/regression towers；

Frozen：

* `backbone.model.backbone.fc_norm.bias`；
* fusion，无参数。

**Optimizer**

* type：AdamW
* detector base LR：`1.0e-4`

**Seeds**

`3407`, `3408`, `3409`，且只允许这三个 seeds。

**GL-LIB training schedule**

1. 将 160 个 fit IDs 按
   `SHA256("NC2-TRAIN-V1|" + seed + "|" + epoch + "|" + video_id)` 排序；

[
L=L_{\mathrm{cls}}+L_{\mathrm{reg}}

* active global branch feature；

* shared adapter parameters；
* projection；
* FPN；
* RPN/head。

* per-class AP；
* prediction count；
* zero-length proposal count；
* score-tie count。

[
\mathrm{Avg\text{-}mAP}
=======================

\frac{
\mathrm{mAP}*{0.3}+
\mathrm{mAP}*{0.4}+
\mathrm{mAP}*{0.5}+
\mathrm{mAP}*{0.6}+
\mathrm{mAP}_{0.7}
}{5}.
]

**Short-duration Q1**

报告：

* Short-Q1 same-class detection recall@0.5；
* Short-Q1 same-class detection recall@0.7；
* Short-Q1 start/end boundary error；
* Short-Q1 count、class support 和 duration range。

最终 prediction domain 使用 official post-NMS predictions；一个 Q1 GT 在存在同 class prediction 且 tIoU 达阈值时计为 hit。

**Boundary metrics**

按 official class-wise score order 和 tIoU 0.5 TP matching 得到每个 GT 的匹配 prediction。对 duration (d_g=e_g-s_g)：

[
E_{\mathrm{start}}(g)=
\begin{cases}
\min\left(1,\frac{|\hat s_g-s_g|}{d_g}\right),&\text{matched}\
1,&\text{missed}
\end{cases}
]

[
E_{\mathrm{end}}(g)=
\begin{cases}
\min\left(1,\frac{|\hat e_g-e_g|}{d_g}\right),&\text{matched}\
1,&\text{missed}.
\end{cases}
]

报告：

* miss-penalized normalized start error；
* miss-penalized normalized end error；
* matched-only start MAE seconds；
* matched-only end MAE seconds；
* overall 与 Short-Q1。

**Proposal recall**

使用 class-agnostic proposal、score 为最大 class score，报告：

* AR@100、AR@200；
* tIoU 0.5、0.7；
* overall、Short-Q1、per-duration quartile；
* candidate-union recall 单独报告，不与可部署 cell 混合。

**Selector paired margins**

同一 seed、同一 40 gate videos、同一 bootstrap replicate 下报告：

* `REF − GL-LIB-C`；
* `REF − GL-LIB-R`；
* `REF − GL-LIB-BF`；
* `GL-LIB-C − GL-C`，用于观察 library-balanced training effect；
* 每个 contrast 的 Avg-mAP、mAP@0.7、Q1 recall 和 boundary metrics。

**Seed pooling**

* 不将三个 checkpoints 做 prediction ensemble；
* 先计算每个 seed 的完整指标；
* point estimate 为三个 seed 指标或 paired contrast 的算术平均；
* bootstrap 中进行 hierarchical seed resampling。

**Paired Bayesian video-cluster bootstrap**

* replicates：10,000
* random seed：`20260720`
* 每个 replicate 对 40 个 gate videos 独立抽取 (w_v\sim\mathrm{Exp}(1))；
* 同一 replicate 的 video weights 对所有 cells、candidates 和 metrics 完全配对；
* 以 replacement 从三个 training seeds 抽取三个 seed indices；
* 对每个抽到的 seed 计算 weighted metric，再取均值；
* prediction、TP、FP 和 GT contribution 均继承所属 video 的 (w_v)；
* 正权重保证原 gate class support 不被 bootstrap replicate 人为删除；
* 不得拒绝 rare-class replicate。

**Class support**

* standard mAP 使用 gate 中至少有一个 GT 的全部类；
* class list 在 cache stage 冻结；
* all-one video weights 时 weighted evaluator 必须精确复现 official evaluator；
* Short-Q1 单独记录支持类；少于 8 类时转 `INCONCLUSIVE_COVERAGE`。

**Simultaneous correction**

所有第 11 节定义的 14 个“越大越好”决策 score 使用同一个 one-sided 95% studentized max-T bound。

令 observed score 为 (\hat\theta_j)，bootstrap score 为 (\hat\theta_{b,j})，标准误为 (se_j)：

[
T_b=
\max_j
\frac{\hat\theta_j-\hat\theta_{b,j}}{se_j}.
]

令 (q_{0.95}) 为 (T_b) 的 95th percentile：

[
LCB_j=
\hat\theta_j-q_{0.95}se_j.
]

* (se_j=0) 时 `LCB_j=observed_score_j`；
* 非有限 score、SE、quantile 或 LCB 使 analyzer fail-closed；
* 同时报告每项普通 two-sided 95% percentile CI；
* GO 判断只读 simultaneous LCB。

**Zero-length proposals**

* 不删除；
* 不修改 start/end；
* 不给予 epsilon length；
* 按 official tIoU 和 score ordering 作为 FP 或未匹配 proposal；
* analyzer 必须报告数量及其 AP 影响。

**Official evaluator parity**

在 all-one weights、无 subgroup filter 时，新 analyzer 必须满足：

* Avg-mAP 与 original `opentad.evaluations.mAP` 精确一致；
* 五个 threshold mAP 精确一致；
* per-class AP 精确一致；
* TP/FP rank trace 精确一致；
* prediction count 精确一致；
* tolerance 为零；
* Python user-site 禁用，NumPy 固定为 1.23.5，以保留当前 tied-score ordering。

  * GL-LIB-R block；
  * D160 block；
* 每个 block 均独立 50 warmups + 129 measurements；
* 其余 cell 每 seed 一个 block；
* 所有 blocks 在一个 Slurm allocation、一个 physical GPU、一个 inner step 中 serial 执行；
* cell order 固定为 seed ascending、experiment ID ascending，ABBA block 保持相邻；
* 不跨 job、step、GPU 或 node 拼接。

**Latency**

报告每 stage 和 total 的：

* mean；
* p50；
* p95；
* max；
* per-window raw trace；
* seed-specific 与 pooled summaries。

正式 cost reduction 只使用 end-to-end total。

**Peak memory**

每个 block 报告：

* `torch.cuda.max_memory_allocated`；
* `torch.cuda.max_memory_reserved`；
* process RSS；
* cgroup peak/current；
* reference exhaustive runner 另报 candidate search peak。

**Gross GPU energy**

* 独立 NVML sidecar process；
* 通过 Slurm-visible logical `cuda:0` 对应的 GPU UUID 获取 handle；
* target sampling period：20 ms；
* maximum allowed observed gap：100 ms；
* clock：`time.monotonic_ns`；
* raw trace 含 sequence number、timestamp、power、temperature、SM/memory clock、utilization、UUID；
* energy 用 trapezoidal integration；
* 从 decode marker 前开始，到 NMS marker 后结束；
* 不减 idle baseline；
* 表述仅为 gross GPU energy；
* 不声称 CPU、storage、network 或 full-node energy；
* trace/report 必须互相绑定 file hash 和 self-hash。

**理论 descriptors**

每个 window 报告：

| Cell             | Spatial tokens/tubelet | Tokens/16-frame chunk | View pixels/frame |
| ---------------- | ---------------------: | --------------------: | ----------------: |
| D160             |                    100 |                   800 |            25,600 |
| G96              |                     36 |                   288 |             9,216 |
| L128             |                     64 |                   512 |            16,384 |
| GL one-candidate |                36 + 64 |             288 + 512 |            25,600 |
| Reference search |     36 + 21×64 = 1,380 |                11,040 |           353,280 |
| D224             |                    196 |                 1,568 |            50,176 |
| D256             |                    256 |                 2,048 |            65,536 |

理论 FLOPs：

* 由 runtime shape hooks 对 Conv3d、Conv1d、Linear、attention matmul、MLP 和 detector ops 计数；
* 一次 multiply-add 计 2 FLOPs；
* 分别报告 core、adapter、projection/head 和总数；
* reference search 计 1 global + 21 local；
* theoretical FLOPs 不替代 measured cost。

**公平性**

* 同 node、同 GPU UUID、同 driver/CUDA/PyTorch/Conda；
* 同 power limit、默认 clock policy；
* 4 个 detector CPUs + 1 个 sidecar CPU；
* inner step memory `96,000 MiB`，且 cgroup finite limit 不低于 `90,000 MiB`；
* outer allocation 允许因 N16R4 memory topology 申请两张 GPU，但 inner step 只暴露一张 GPU；空闲 GPU 不参与模型、profile 或成本描述；
* 不覆盖 `CUDA_VISIBLE_DEVICES`；
* 进程内设备始终 `cuda:0`；
* `PYTHONNOUSERSITE=1`；
* 任一 trace sampling gap 超过 100 ms、UUID 不一致、CPU affinity 不完整或 profile block 缺 window 时，整个 profile stage 失败。

## 11. 数值 GO/KILL 规则

所有 mAP/recall 数值在公式中使用 `[0,1]`；`pp` 阈值按 percentage points 解释。

**Coverage 前置条件**

以下全部满足才定义 `coverage_pass=true`：

1. 13,944 candidate rows 全部存在并通过 hash/provenance；
2. 每个 window 精确 21 candidates；
3. padding rate = 0；
4. translation delta 全零；
5. source-area union coverage = 1.0；
6. minimum same-size crop IoU certificate
   (\ge0.6476267095736)；
7. gate Short-Q1 GT ≥30 且 class support ≥8；
8. simultaneous LCB：

[
R^{\mathrm{union}}_{0.7,\mathrm{all}}-0.95\ge0;
]

9. simultaneous LCB：

[
R^{\mathrm{union}}_{0.7,\mathrm{Q1}}-0.90\ge0.
]

任一 coverage 条件失败，机械结果为 `INCONCLUSIVE_COVERAGE`；其它性能或成本结果不得覆盖该状态。

**准确率等效 scores**

[
S_{\mathrm{Avg}}
================

\Delta_{\mathrm{Avg}}+0.010.
]

[
S_{0.7}
=======

\Delta_{\mathrm{mAP@0.7}}+0.015.
]

[
S_{\mathrm{Q1}}
===============

\Delta_{\mathrm{Q1Recall@0.7}}+0.020.
]

[
S_{\mathrm{Start}}
==================

1.15E_{\mathrm{Start,D160}}-E_{\mathrm{Start,REF}}.
]

[
S_{\mathrm{End}}
================

1.15E_{\mathrm{End,D160}}-E_{\mathrm{End,REF}}.
]

五项 simultaneous LCB 必须均不小于零。

**选择 headroom scores**

[
S_{\mathrm{BF,Avg}}
===================

M_{\mathrm{REF}}-M_{\mathrm{BESTFIXED}}-0.005.
]

[
S_{\mathrm{BF,0.7}}
===================

M_{\mathrm{REF},0.7}-M_{\mathrm{BESTFIXED},0.7}-0.0025.
]

[
S_{\mathrm{Center}}
===================

M_{\mathrm{REF}}-M_{\mathrm{LIBCENTER}}-0.0075.
]

[
S_{\mathrm{Random}}
===================

M_{\mathrm{REF}}-M_{\mathrm{RANDOM}}-0.005.
]

四项 simultaneous LCB 必须均不小于零。该条件防止仅因一个固定非中心 crop 足够而错误授权 learned policy。

**Full-stack cost scores**

令 policy-shaped cell 为 `NC2-GL-LIB-R`：

[
S_{\mathrm{Lat50}}
==================

1-
\frac{\mathrm{p50}*{\mathrm{RANDOM}}}
{\mathrm{p50}*{\mathrm{D160}}}
-0.10.
]

[
S_{\mathrm{Lat95}}
==================

1-
\frac{\mathrm{p95}*{\mathrm{RANDOM}}}
{\mathrm{p95}*{\mathrm{D160}}}
-0.05.
]

[
S_{\mathrm{Energy}}
===================

1-
\frac{\mathrm{Energy}*{\mathrm{RANDOM}}}
{\mathrm{Energy}*{\mathrm{D160}}}
-0.08.
]

三项 simultaneous LCB 必须均不小于零。

此外，每个 seed 必须满足：

[
\frac{\mathrm{PeakMemory}*{\mathrm{RANDOM}}}
{\mathrm{PeakMemory}*{\mathrm{D160}}}
\le1.10.
]

**Simultaneous decision family**

同一个 max-T family 精确包含 14 项：

1. overall candidate-union coverage；
2. Q1 candidate-union coverage；
3. Avg-mAP equivalence；
4. mAP@0.7 equivalence；
5. Q1 recall equivalence；
6. start-boundary protection；
7. end-boundary protection；
8. REF versus BESTFIXED Avg；
9. REF versus BESTFIXED mAP@0.7；
10. REF versus LIBCENTER Avg；
11. REF versus RANDOM Avg；
12. p50 latency reduction；
13. p95 latency reduction；
14. gross energy reduction。

GO 要求 14 个 simultaneous LCB 全部 `>=0`。

**Seed 稳定性**

同时要求：

* 每个 seed 的 `REF − D160 Avg-mAP >= -2.00 pp`；
* 三个 seed 的该 contrast range `<=2.00 pp`；
* 每个 seed 的 `REF − BESTFIXED Avg-mAP >=0`；
* 每个 seed 的 `GL-LIB-R` p50 latency reduction `>0`；
* 每个训练 cell 精确 4,800 successful updates；
* 三个 seed 均具有完整 inference、profile 和 hash closure。

**机械状态规则**

```text
if evidence_or_provenance_invalid:
    emit no decision receipt

elif coverage_pass is false:
    decision = INCONCLUSIVE_COVERAGE

elif all 14 simultaneous LCBs >= 0
     and peak-memory rule passes for all seeds
     and all seed-stability rules pass:
    decision = GO_TO_LEARNED_POLICY

else:
    decision = KILL_THIS_LIBRARY
```

禁止人工 override、near-pass、rounding-up、删除 outlier、减少 simultaneous family、改变 margin 或基于 dense224/256 ceiling 进行补救。

**Candidate generation 伪代码**

```python
C = 128
JX = 6
JY = 2

def round_half_up_fraction(numerator: int, denominator: int) -> int:
    return (2 * numerator + denominator) // (2 * denominator)

def candidate_box(width: int, height: int, j: int, k: int):
    assert width >= C and height >= C
    assert 0 <= j <= JX and 0 <= k <= JY

    x0 = round_half_up_fraction(j * (width - C), JX)
    y0 = round_half_up_fraction(k * (height - C), JY)
    box = [x0, y0, x0 + C, y0 + C]

    assert 0 <= box[0] < box[2] <= width
    assert 0 <= box[1] < box[3] <= height
    return box

for window in frozen_664_windows:
    for k in range(3):
        for j in range(7):
            q = 7 * k + j
            emit_immutable_row(
                window_id=window.id,
                candidate_id=f"NC2-L128-S-J{j:02d}-K{k:02d}",
                candidate_index=q,
                box=candidate_box(window.width, window.height, j, k),
                padding=[0, 0, 0, 0],
                trajectory="static",
            )
```

## 14. Slurm Job DAG

```text
static tests
-> CUDA gate
-> candidate/reference cache
-> training matrix
-> development gate inference
-> serial full-stack profile
-> frozen analyzer
-> GO/KILL receipt
```

**统一资源纪律**

* 禁止固定 physical GPU index；
* 禁止覆盖 Slurm 的 `CUDA_VISIBLE_DEVICES`；
* inner process 使用 `cuda:0`；
* GPU stages 在一个 exact inner step 中使用 1 GPU、5 CPUs、96,000 MiB；
* 4 CPUs 给 detector/data path，1 CPU 给 power sidecar；
* N16R4 outer job 允许申请 2 GPUs/8 CPUs 获取 memory headroom，但只有 inner-step GPU 参与计算；
* `PYTHONNOUSERSITE=1`；
* 每个 job name 同时绑定 `campaign_id`；
* `sbatch --parsable` 返回值只写入 submission receipt，不在协议中虚构 Job ID。

| 阶段        | Job name           |    Array | 资源                                                    | Dependency            | 输入                                    | 输出/receipt                                                                              |
| --------- | ------------------ | -------: | ----------------------------------------------------- | --------------------- | ------------------------------------- | --------------------------------------------------------------------------------------- |

**幂等与 failure handling**

* 每个 campaign namespace 单次使用；
* stage 开始使用 `O_EXCL` persistent lock；
* 已存在且 hash-valid 的 PASS receipt 只允许 validator 返回成功，不重写；
* partial、FAIL 或 hash-invalid namespace 永久关闭；
* 不删除 lock；
* 不 resume checkpoint；
* 不覆盖 prediction/profile/trace；
* retry 必须使用新 code commit、新 campaign ID 和新全部 DAG；
* submission script 在再次 `sbatch` 前按 job name、campaign ID 和 accounting receipt 检索已存在 job；发现已提交 job 时只执行 reconciliation，不重复提交；
* downstream dependency 只接受完整 array completion receipt，而非文件数量。

**Canonicalization**

* UTF-8；
* object keys lexicographic sort；
* compact separators；
* 禁止 NaN、Infinity、duplicate key；
* timestamp 不参与 scientific content hash，但参与 file receipt hash；
* self-hash 计算时只删除自身 hash 字段；
* internal hash 与 file hash 分开；
* artifact 使用 `lstat`、`O_NOFOLLOW`、regular-file 检查；
* parent directory 和 inode 记录；
* 原子临时文件写入、`fsync`、hard-link/O_EXCL 发布；
* 发布后 chmod read-only；
* 任何已存在 canonical path 不得覆盖。

**一次性 gate decision receipt**

* 同一 campaign ID 只能存在一个 decision receipt；
* receipt 生成前重新验证全部 parent evidence；
* decision receipt 一经发布，任何新训练、重算 cache、改变阈值、改变 bootstrap、补 cell 或替换 profile 均必须使用新协议版本和新 campaign；
* official test 在所有三种 decision 下均继续 sealed。

## 16. 协议执行后的唯一合法结论

`GO_TO_LEARNED_POLICY` 的含义仅为：

* 第 5 节的 21-candidate static local128 library 通过 coverage；
* finite-library reference 在注册 TAD 指标上达到 dense160 等效；
* reference 相对 center、random 和 best-fixed 存在 simultaneous headroom；
* 单-candidate dual-view full-stack 路径达到注册成本改善；
* 三个 seeds 稳定；
* 因而允许另立、另行预注册 learned candidate-selection 研究。

它不表示 learned policy 已实现、已通过、可部署或可发表。

`KILL_THIS_LIBRARY` 的含义仅为：

* coverage 已充分；
* 但该 `21×static×local128×global96×fixed-mean×VideoMAE-S/ActionFormer` 注册对象未同时满足性能、选择 headroom、成本或稳定性门槛；
* 不授权 learned policy；
* 不得外推为 continuous crop、其它尺度、轨迹或其它 detector 的失败。

`INCONCLUSIVE_COVERAGE` 的含义仅为：

* 几何、subgroup support 或 candidate-union proposal coverage 不足以将失败归因于 library sufficiency；
* 不授权 learned policy；
* 不得 KILL continuous-crop 路线；
* 不得用性能或成本的表面通过覆盖 coverage 失败。

在正式 evidence 产生前，本协议不提前宣布任何决策。

DECISION := GO_TO_LEARNED_POLICY
| KILL_THIS_LIBRARY
| INCONCLUSIVE_COVERAGE
