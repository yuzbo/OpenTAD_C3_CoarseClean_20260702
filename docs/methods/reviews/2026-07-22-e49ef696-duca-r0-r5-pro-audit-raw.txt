## 3. `CODE_AND_GRADIENT_MAP`

### 3.1 前向数据流

```text
dense RGB X: [B, N, C, T=768, H, W]
    │
    ├─ 下采样到 64×64
    │
    ▼
Official-ASFormer coarse probe
    ├─ action logits a_t
    ├─ p_action = sigmoid(a_t)
    └─ encoder hidden h_t
          │
          ▼
transition descriptors z_t
    = [Δa_t, |Δa_t|,
       ΔH(p_t), |ΔH(p_t)|,
       Δh_t, |Δh_t|,
       1-cos(h_t,h_{t-1})]
          │
          ▼
shared transition scorer
    ├─ center score s_t
    └─ offset logits o_{t,-R:R}
          │
          ▼
burst utility
    center softmax × top-Q offset inclusion
    → overlap saturation 1-exp(-mass)
    + weak exact-uniform context reference
          │
          ▼
global exact-K / max-hole decoder
    hard: Viterbi(s.detach())
    soft: same-family forward-backward marginals
          │
          ▼
selected positions I=[i_1,...,i_K]
          │
          ▼
real hard gather X[:, :, :, I, :, :]
          │
          ▼
VideoMAE → projection/neck → ActionFormer or TemporalMaxer
          │
          ▼
selected-axis predictions
          │
          ▼
piecewise-linear inverse map → true dense-time → NMS/evaluator
```

[CODE_FACT] Transition scorer 输入没有绝对 hidden；它使用相邻 logits/entropy/hidden 的变化和 hidden cosine change。`actionness_logits` 在 transition descriptor 路径中被 detach。

[CODE_FACT] action source 确实生成 `p_action`、uncertainty、entropy、`delta_p_action` 等字段，但最终 learnable center scorer 并没有直接拼接 absolute `p_action` 或 `uncertainty_peak`；它看到的是上述变化描述符。因此准确表述应是：

> “由二分类状态模型产生的变化证据驱动 transition scorer”，

而不是：

> “selector 直接联合消费全部 p_action/uncertainty 字段”。

[CODE_FACT] Hard path 在 `policy_logits.detach()` 上运行 Viterbi；soft path是在同一个 exact-K/max-hole 可行域上运行 forward-backward。不存在对整数索引直接求导。

[CODE_FACT] detector 数值前向只消费真实 hard gather。G1/G2 的 protected bridge 保持 hard-selected 前向值不变，反向使用：

[
\Delta X_k^{\text{proxy}}
=========================

\operatorname{stopgrad}
\left(
\frac{X_{i_k+1}-X_{i_k-1}}{2}
\right)
\left(
\mathbb E_{\pi_k}[t]-
\operatorname{stopgrad}(\mathbb E_{\pi_k}[t])
\right),
]

再构造

[
X_k^{\text{detector}}
=====================

X_{i_k}^{\text{hard}}
+\lambda,\Delta X_k^{\text{proxy}}.
]

源码明确称其为 surrogate，并要求真实 hard-swap alignment 后才能进入正式训练。

### 3.3 坐标合同

[CODE_FACT] `TrueTimeMap` 要求 selected positions 有限、严格递增、位于 valid length 内；GT 在训练时由 true-time 映射到 selected-axis，预测在 postprocess 前由 selected-axis 映射回 true-time。缺失 inverse-map metadata 会直接报错。

[CODE_FACT] TemporalMaxer 是真实第二后端：它运行 live selector、VideoMAE backbone、projection、neck 和自身 RPN head，并验证 selected-axis GT 与 inverse map，不是 ActionFormer 名称替换。

### H1. R2Q3/R4Q5 是软 burst 偏置，不是 hard bilateral/quota 保证

* **标签**：[CODE_FACT]
* **位置**：

  * `opentad/models/duca/transition_only.py:469-602`
  * `opentad/models/duca/transition_only.py:715-817`
  * `opentad/models/duca/structured_selection.py:1278-1320`
  * `tools/bata/duca_exact_physical_solver.py:181-238`
* **触发条件**：offset head 将 top-Q offsets 全压在左侧或右侧；多个 center 重叠；global DP 为满足高 utility 选择了并不覆盖预测 center 的点。
* **代码事实**：

  * offset inclusion 对整个 `[-R,R]` 直接 top-Q，没有 left/right 各一的 hard partition；
  * bilateral、quota、fairness 都是 soft occupancy loss；
  * 最终 hard DP 只约束 exact-K 和 max-hole；
  * R0 MILP 则硬约束 center、邻域 quota、适用时 left≥1/right≥1。
* **后果**：

  * `[INFERENCE]` 当前 R2Q3/R4Q5 名称容易被理解成 hard family，但实现只能保证“期望形成双侧微簇”；
  * `[CODE_FACT]` R0 projected Oracle 不是 learned hard decoder 的同一可行族，也不是 learned selector 的严格数学上界。
* **最小修复**：

  1. 当前 e49 不改训练：论文和 aggregate 将其称为 **soft bilateral burst objective**；
  2. 下一版若要保留“保证”表述，加入 mandatory-set constrained exact-K decoder。
* **必须测试**：

  * one-sided offset adversary；
  * 窗口首尾 center；
  * 两个 endpoint 邻域重叠；
  * mandatory union 接近 K；
  * hard 输出逐 endpoint 检查 center、left、right、quota、exact-K、max-hole。

### Medium

### M1. “间接边界定位”不等于“无直接边界监督”

[CODE_FACT] 推理时 scorer 只接收状态变化证据，不接收 GT；但训练构造了 GT start/end event、Gaussian transition target、endpoint/bilateral/quota losses。准确方法描述是：

> **GT-supervised transition discovery from indirect state-change evidence**

而不是无边界监督或无 GT transition supervision。

**修复**：论文方法节明确区分 input modality、training supervision 和 inference dependency。

---

### M2. P0 的 transition 目标没有改善 coarse hidden 的边界可分性

[CODE_FACT] P0 关闭 hidden-to-transition gradient；action BCE 独立训练 coarse ASFormer，transition/burst loss 只训练 scorer/offset head。

[INFERENCE] 若动作二分类 hidden 对精确状态转变不敏感，后端 scorer 只能从固定低质量差分中重排，可能解释历史 learned sampling 落后 uniform。

**测试**：记录 P0 中 action AP、transition AP、GT endpoint 附近 hidden-change AUC；做仅允许最后一个 ASFormer encoder layer 接收小比例 transition 梯度的单变量对照。

---

### M3. selected-axis 反映射修复输出坐标，但没有修复 detector 内部时间度量

[CODE_FACT] VideoMAE/ActionFormer/TemporalMaxer 按 selected rank 处理序列；`TrueTimeMap` 用于 GT 映射和输出逆映射。

[INFERENCE] 两个 rank-adjacent token 在真实时间上可能相隔 4、8、12 或 16 帧，卷积/相对位置编码仍将其视为等距。这可能使“边界几何更好”无法转化为 detector mAP。

### M4. G2 是训练分布干预，不只是梯度归一化开关

[CODE_FACT] 50% batch rows 在 detector forward 中被替换为 exact-uniform；learned rows 的 bridge 乘 (B/N_L)，推理仍只用 learned。

[INFERENCE] 论文必须把 G2 称为 **uniform-companion detector training**，不能包装成与 G1 完全同分布的优化细节。

### M5. max-hole 没有把策略强制回 uniform，但限制了可迁移预算尺度

[CODE_FACT] 可行性条件为：

[
T-K\le (K+1)G.
]

令 (y_0,\dots,y_K) 为 K 个选择前后及之间的未选 run，则：

[
0\le y_i\le G,\qquad \sum_i y_i=T-K.
]

* K384/G2：384 个未选位置分配到 385 个 gaps；
* K256/G3：512 个未选位置分配到 257 个 gaps。

[INFERENCE] 两者都有真实跨区域转移自由度：连续选帧对应某些 (y_i=0)，由其他区域较大的 (y_j) 补偿。它们不是 one-frame-per-cell。

[INFERENCE] 但若 candidate grid stride=4，最大相邻 selected source center 间距分别约为 12 和 16 原始帧；策略无法通过长期空置一个区域把大量预算转移到单个复杂事件。

[INFERENCE] 这避免了 test 调参，但同一 internal holdout 同时承担 family 和 candidate checkpoint 选择，可能高估 P0 diagnostics。最终 R3/R5 test 仍能消除这一偏差，但论文不应把 P0 指标当泛化结果。

## 6. `WHY_LEARNED_SAMPLING_HAS_LAGGED_UNIFORM`

[EXPERIMENT_FACT] 用户给定历史 matched V5 terminal：

* uniform：64.4580
* direct：63.7102
* homotopy：63.0601
* companion：63.6931

说明过去 learned policy 的问题不是单一训练噪声，而是至少在三种学习路线中都没有把非均匀几何转化为 detector utility。

### 6.1 粗分类质量

[INFERENCE] 动作/背景 BCE 优化的是内部动作占据，不是 endpoint discrimination。高 action AP 可以与低 transition AP 同时出现。

**可证伪诊断**：

* action AP/AUC；
* GT endpoint ±r 内 `|Δp|` AP；
* hidden-change AP；
* learned scorer 相对 `abs(delta p)` 的条件增益；
* 按 action duration、boundary truncation、动作密度分层。

若 action AP 高而 transition AP 低，问题位于 coarse representation，而非 decoder。

### 6.2 间接定位存在相位偏移与不对称

[INFERENCE] 二分类概率往往在动作已持续若干帧后才跨阈值；start/end 的响应形状也未必对称。绝对 delta 能找到变化，却不保证中心与真实 endpoint 同位。

**诊断**：

[
e_b=\arg\max_{t\in[b-r,b+r]}s_t-b
]

分别统计 start/end 的 mean、median、p90 signed error；不要只报无符号最近距离。

### 6.3 Burst 分配的 hard realization 可能与 soft loss 脱节

[CODE_FACT] soft loss要求 center、双侧、quota、公平；hard DP只看最终 utility。

**诊断**：

* hard center hit rate；
* hard left/right satisfaction；
* hard total quota satisfaction；
* endpoint-wise min satisfaction；
* overlapping endpoints 的 dedup loss；
* boundary budget actual/target；
* residual context count；
  -最长 selected run。

若 soft loss下降但 hard satisfaction 不升，优先修 decoder，不要继续调 loss 权重。

### 6.4 Detector/selector 梯度目标不同

[CODE_FACT] G0 没有 detector→selector 梯度；G1 的梯度是局部时间斜率 surrogate，不是真实离散 detector loss。

[INFERENCE] VideoMAE 对换入一帧的效用可能由动作语义、运动、上下文和 normalization 共同决定，与 RGB 局部斜率方向不一致。

**诊断**：

* R4 sign accuracy；
* Spearman；
* utility magnitude calibration；
* 按 swap distance、boundary quartile、action/background role 分层；
* 单 swap 与双 swap 非加性残差。

### 6.5 Selected-axis 表示压缩了真实时间间隔

[INFERENCE] uniform 的 interval 近常数，rank-axis detector 与 true-time 基本一致；learned policy 的 interval 变化大，detector 内部却仍按等距 token 处理。因此 uniform 享有隐含架构匹配优势。

**诊断**：

* 固定相同 hard positions，只切换 true-time embedding；
* 按 interval coefficient of variation 分桶比较 mAP；
* 比较 boundary geometry 改善与 detector loss/mAP 的相关性。

### 6.6 课程训练引入 detector covariate shift

[CODE_FACT] detector 先在 uniform 上预热，再随 policy alpha 过渡到 learned。G2 通过训练期 uniform companion 缓解这一 shift。

[INFERENCE] 若 selector 持续移动，detector 同时追逐变化中的输入分布，可能使 selector 和 detector 互相破坏。

**诊断**：

* 固定 detector，仅替换 hard selections；
* 固定 selector，仅继续 detector；
* 每 250 successful updates 记录 hard-set Jaccard、detector loss、selected interval 分布；
* 比较 G1 与 G2 的 learned-row mAP，而不仅比较总训练 loss。

### 6.7 可行域既非 uniform，也并非无限自由

[CODE_FACT] K384/G2 与 K256/G3 允许真实预算转移，但 max-hole 禁止大范围放弃背景或动作内部。

[INFERENCE] 如果 detector 真正需要的是长动作内部远距离证据，而不是 endpoint 周边多帧，burst policy 的可用转移尺度可能不足；反之放宽 G 又可能破坏上下文。

**诊断**：

* 同一 scorer 下 G=min-feasible、当前 G、G+1；
* oracle detector utility vs G；
* 选择集到 uniform 的 Hamming/Jaccard；
* 每窗口可移动 budget 数和最大 cluster size。

## 7. `MODEL_IMPROVEMENT_OPTIONS`

以下均保持 pre-backbone、固定总预算 K、单一部署模型，不换 detector。

### Option 1：Mandatory-set hard bilateral decoder

**数学定义**

先从 center scores 得到经过 temporal NMS 的候选中心 (C)。对每个保留中心 (c)，构造：

[
M_c=
{c,\arg\max_{t\in[c-R,c-1]}o_{c,t},
\arg\max_{t\in[c+1,c+R]}o_{c,t}}
\cup \text{Top}_{Q-3}.
]

对 deduplicated mandatory set (M=\cup_c M_c) 求：

[
\max_{x\in{0,1}^T}\sum_t u_tx_t
]

subject to

[
\sum_tx_t=K,\quad \max\text{-hole}(x)\le G,\quad x_t=1,\ \forall t\in M.
]

若 (|M|>K) 或不可行，按 center score 从低到高丢弃整个 center group，禁止静默破坏左右配额。

**接入位置**

* `transition_only.py::build_boundary_burst_utility`
* `structured_selection.py::global_structured_topk`
* 新增 `mandatory_mask` 参数。

**梯度**

* hard mandatory index 不求导；
* center/offset 继续由 transition/burst losses 训练；
* detector surrogate 仍须通过 hard-swap gate。

**推理成本**

* 额外 temporal NMS 和 mandatory feasibility；
* DP 状态规模基本不变，mandatory position 处禁止 skip。

**预期收益**

* R2Q3/R4Q5 语义与 hard output 一致；
* 消除 soft bilateral loss 与 hard selector 脱节。

**失败模式**

* center 太多造成上下文预算枯竭；
* endpoint 预测错误时被强制浪费 Q 帧；
* 邻近 endpoints 过度 dedup。

**最小验证**

仅在 sealed P0 holdout 上比较：

* hard bilateral satisfaction；
* detector frozen loss；
* exact-K/G；
* residual context；
* solver latency。

---

### Option 2：Legal hard-swap detector-utility distillation

**数学定义**

对当前 hard set (I) 和合法 swap (I-i+j)：

[
u_{i\rightarrow j}
==================

L_{\mathrm{det}}(I)-L_{\mathrm{det}}(I-i+j),
]

训练：

[
L_{\mathrm{rank}}
=================

\sum_{(i,j)}
w_{ij}
\log\left(
1+\exp
\left[
-\frac{\operatorname{sign}(u_{ij})(s_j-s_i)}{\tau}
\right]
\right),
]

其中 (w_{ij}=\min(|u_{ij}|,w_{\max}))，utility 全部 detach。

**接入位置**

* 复用 `duca_boundary_burst_hard_swap_alignment.py` 的 legal-swap 枚举；
* 作为 train-only teacher，接到 transition scorer，不进入推理。

**梯度**

* 只更新 scorer/burst；
* detector frozen teacher；
* 不声称梯度穿过 hard index。

**推理成本**

* 零新增成本。

**预期收益**

* 直接对齐 detector utility，而不是仅对齐 endpoint geometry；
* 能解释并修复“边界更近但 detector loss 更差”。

**失败模式**

* 单 swap utility 强非加性；
* teacher 计算昂贵；
* utility 噪声被过拟合。

**最小验证**

先做 48-window/576-swap 交叉拟合：训练窗口与 R4 audit 窗口严格分离；只有 held-out sign/Spearman 提升才进入完整训练。

---

### Option 3：受保护的 ASFormer 最后一层 transition adaptation

**数学定义**

保持 action logits 对 scorer detach，只允许最后一个 encoder layer 接收比例 (\gamma) 的 transition gradient：

[
h^{\mathrm{policy}}
===================

\operatorname{sg}(h)
+
\gamma(h-\operatorname{sg}(h)),
\qquad \gamma\in(0,1).
]

加入 semantic retention：

[
L_{\mathrm{retain}}
===================

\operatorname{KL}
\left(
p_{\mathrm{action}}^{\mathrm{P0\ frozen}}
\parallel
p_{\mathrm{action}}^{\mathrm{adapted}}
\right).
]

**接入位置**

* `transition_utility_paths`
* official ASFormer last encoder layer parameter group。

**梯度**

* transition loss只到最后一个 encoder layer；
* spatial stem、早期 encoder、action head由 BCE/retention保护；
* detector feedback仍不进入 coarse branch。

**推理成本**

* 无新增模块；同一 ASFormer。

**预期收益**

* 让 hidden change 真正对 endpoint 敏感；
* 保留“轻模型先学二分类语义”的主路线。

**失败模式**

* 破坏 action calibration；
* transition target 过窄导致过拟合。

**最小验证**

单 seed P0：

* action AP/recall 不下降；
* transition AP、signed endpoint error、hard burst satisfaction改善；
* 只改变 `policy_hidden_gradient_scale` 与 retention loss。

---

### Option 4：True-time-aware selected-axis adapter

**数学定义**

对 selected positions (\tau_i) 构造：

[
e_i=
\operatorname{MLP}
\left[
\frac{\tau_i}{T},
\log(1+\tau_i-\tau_{i-1}),
\log(1+\tau_{i+1}-\tau_i)
\right],
\qquad
f_i'=f_i+W e_i.
]

**接入位置**

* VideoMAE temporal reduction 后、ActionFormer/TemporalMaxer projection 前；
* detector 本体和 head 不变。

**梯度**

* 普通 detector loss更新 adapter；
* 不反传到整数 (\tau_i)；
* selector 仍由原有 losses/bridge 更新。

**推理成本**

* 每 token 一个小 MLP，远低于 VideoMAE。

**预期收益**

* 修复 learned irregular sampling 对 detector 的时间度量破坏；
* uniform arm 几乎退化为常量 interval embedding。

**失败模式**

* detector 学会依赖特定 selector 分布；
* TemporalMaxer/ActionFormer 对 embedding 的敏感性不同。

**最小验证**

固定同一批 hard selected RGB，不重新训练 selector，仅比较 detector with/without time adapter；这是最干净的 representation sufficiency 试验。

---

### Option 5：固定总 K 下的 adaptive burst/residual split

**数学定义**

不改变总预算，只预测 burst fraction：

[
\rho
====

\operatorname{clip}
\left(
\rho_0+
a,H(q_{\mathrm{center}})
-b,O_{\mathrm{overlap}},
\rho_{\min},
\rho_{\max}
\right),
]

[
K_b=\operatorname{round}(\rho K),\qquad
K_c=K-K_b.
]

其中 (K_b) 分配给 center bursts，(K_c) 由 exact-uniform context reference 和 scorer residual 共同分配。

**接入位置**

* `build_boundary_burst_utility`
* 不改 total K/G decoder。

**梯度**

* burst fraction 由 center posterior/overlap 的连续统计得到；
* 可加 context starvation penalty；
* 不需要第二模型。

**推理成本**

* O(T) 标量统计。

**预期收益**

* 动作稀疏窗口不再固定浪费 25% 给不存在或低置信度边界；
* 多动作窗口可获得更多 burst budget。

**失败模式**

* fraction predictor 与 scorer 共振，导致全 burst 或全 context；
* hard rounding 带来不稳定。

**最小验证**

先用 frozen-detector Oracle 对每窗口搜索最优 (K_b)，确认 adaptive split 有可测 headroom，再实现 learnable 版本。

6. **若 learned 不胜 uniform，只运行一轮决定性诊断**：

   * hard bilateral realization 失败 → 只实现 Option 1；
   * hard geometry好但 swap utility 不对齐 → 只实现 Option 2；
   * transition descriptors本身弱 → 只实现 Option 3；
   * geometry和swap都好但 detector mAP差 → 只实现 Option 4；
     -窗口间最佳 burst fraction差异大 → 只实现 Option 5。
7. **一次只引入一个结构变量**，重新跑 matched U/learned；不同时叠加新 decoder、hidden adaptation 和 time adapter。

### Patch H4：成本 fingerprint 与 paired-session 门

```python
# [PROPOSAL] aggregate_duca_r5_paper_matrix.py

COMPARABILITY_KEYS = (
    "hardware_fingerprint",
    "host_fingerprint",
    "software_fingerprint",
    "source_dataset_fingerprint",
    "inference_fingerprint",
    "batch_size",
    "loader_workers",
    "warmup_samples",
    "amp",
    "uses_ema",
    "power_sampling_enabled",
    "power_interval_ms",
)

def _cost_comparability_payload(profile):
    return {key: profile.get(key) for key in COMPARABILITY_KEYS}


def _require_paired_comparable(candidate, dense):
    for key in COMPARABILITY_KEYS:
        _require(
            candidate.get(key) == dense.get(key),
            f"cost profile mismatch: {key}",
        )

    _require(
        candidate["profile_pair_id"] == dense["profile_pair_id"],
        "candidate and dense are not a paired profile",
    )
    _require(
        candidate["profile_session_id"] == dense["profile_session_id"],
        "candidate and dense were not measured in one allocation/session",
    )
    _require(
        {candidate["profile_order_position"], dense["profile_order_position"]}
        == {0, 1},
        "paired order must contain one dense and one candidate run",
    )
```

**最终裁决**：

[INFERENCE] e49 已经是一个相当接近逻辑闭合的 **heavy-backbone-compute-saving、hard-observation、fixed-budget offline TAD sampler**；它尚不是一个已证明有效、hard-bilateral 保证成立、K-only 高分辨率 I/O、成本比较完全可信的论文成品。
