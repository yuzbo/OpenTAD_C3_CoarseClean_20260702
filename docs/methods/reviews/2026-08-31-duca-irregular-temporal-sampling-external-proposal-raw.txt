   一、 DUCA 核心瓶颈与机理诊断

  从前期对 DUCA 代码库与实验数据（H65: 65.13 vs 端到端: 58.39，连续块 49.89，PJST 64.59）的审计来看，DUCA
  面临的核心矛盾并非“选帧准不准”，而是非等间隔采样后的物理时序失真与下游 3D 骨干 / 检测头假设之间的数学失配：

    [原始长视频] ──(非等间隔采样)──► [离散稀疏帧序列] ──► [3D VideoMAE] ──► [时序插值] ──► [ActionFormer]
           ▲                                 │                     │                │
           │                                 ▼                     ▼                ▼
    [等时间步假设 Δt=1]             【失配1: 帧对速度畸变】   【失配2: 跨度失真】   【失配3: 线性混叠】

  1. Tubelet 内部瞬时速度畸变（Pairing Distortion）：
      • VideoMAE-S 依赖 3D Patch Embedding（tubelet_size=2）。如果帧选择器选出非连续的两帧（例如 t₁ = 10,t₂ =
      25），将其强行配对为同一个 Tubelet，3D 卷积核提取的本质上是 Δt = 15 的跳跃差分，却被当成了 Δt = 1
      的瞬时运动，导致骨干提取出虚假的运动梯度与高频噪声。
  2. 位置编码的时序尺度失真（Rank-based PE Aliasing）：
      • 骨干 Transformer 如果使用基于秩（Rank-based: 0,1,2,…,K - 1）的位置编码，会将“相隔 0.1 秒的两帧”和“相隔 10
      秒的两帧”赋予完全相同的相对距离，使得模型彻底丧失对动作真实物理持续时长（Duration）与速度的感知能力。
  3. 稀疏-密集重构的插值混叠（Interpolation Aliasing）：
      • 骨干处理完 K = 384 帧后，当前通过 _interpolate_irregular_time（一维线性插值）投射回 768
      密集网格。线性插值在背景跳变大、帧间隔远（Gap 较大）的区域会引入大面积平滑伪影，污染 ActionFormer 多尺度 FPN
      的边界响应。
  4. 端到端训练中的“梯度断层”（E2E 鸿沟 58.39 vs H65 65.13）：
      • Gumbel-TopK
      或硬选择在早期产生的梯度方差极高，导致前端选择器和后端检测头陷入相互破坏表征的恶性循环（选择器乱选 → 检测器学坏
      → 检测器梯度乱传 → 选择器更乱）。

  ### 1. 采样元结构：Native Micro-Pair（原子微对采样）

  • 原理：不以“单帧”为最小采样单元，而是以VideoMAE 的物理 Tubelet（连续 2 帧 (2k,2k + 1)）作为不可分割的采样原子。
  • 收益：彻底保障 3D Patch Embedding 内部的 Δt ≡ 1 物理一致性，消灭 Tubelet 内部的运动伪影；同时保留 Tubelet
  之间的灵活非等间隔跳跃。

  ### 2. 几何时间表达：Continuous-Time Rotary Position Embedding (CT-RoPE)

  • 原理：将帧的绝对物理时间戳 τ ∈ ℝ（单位：秒或归一化视频时间）直接参数化进旋转矩阵：

                       top
    R(τᵢ)qᵢ·R(τⱼ)kⱼ = q   R(τⱼ - τᵢ)kⱼ
                       i

  • 收益：注意力权重直接由两帧之间的真实物理时差 Δτ = τⱼ - τᵢ
  决定，而非序列索引序号。当两帧跨越较长背景时，注意力自然按物理时间距离衰减；高密度采样的边界区则获得高频相对几何信
  息。

  ### 3. 特征映射：Continuous Gaussian Temporal Splatting (连续时间高斯时序散射)

  • 原理：放弃产生梯形平滑伪影的线性插值，将每个稀疏特征视为一个时序高斯基元 (zₖ,τₖ,σₖ)，向密集时间轴散射投射：

           k=1        ⎝    2σ²ₖ   ⎠     k=1      ⎝    2σ²ₖ   ⎠

  由局部采样密度自适应决定。

  • 收益：高密度采样区（动作起止边界）形成极高锐度的特征峰值，稀疏采样区（背景）自然平滑过渡，为 ActionFormer
  提供干净且梯度连续的多尺度金字塔。

  ### 模块 1：Dual-Stream 语义真采样引擎（解决“选什么”的问题）

  将时序采样解耦为高精度微对流（High-Frequency Micro-Pairs）与全局低频锚点流（Low-Frequency Anchors）：

  1. Stream A（边界与动作核心 - 密集微对）：
      • 目标：抓取高 tIoU 定位所需的起止跳变。
      • 规则：根据融合评分 S(u) = 0.70·Boundary + 0.30·Action，选出 Top-M 个最关键的 Tubelet 槽位，每个槽位采样连续 2
      帧 (2u,2u + 1)。
  2. Stream B（全局背景与上下文 - 自适应稀疏锚点）：
      • 目标：防止大范围背景区域出现“时序盲区”，提供长程依赖。
      • 规则：在未被 Stream A 覆盖的空洞区间内，以动态步长（Stride propto 1/Redundancy）均匀抽取低频锚点 Tubelet。

  ### 模块 2：物理时间感知骨干网络（解决“如何输入与理解”的问题）

  #### (1) Patch Embedding 物理一致性

  由于输入严格为 192 个 Native Tubelet（每个包含 2 帧物理连续图像），VideoMAE 的 3D Patch Embedding (kernel_size=(2,
  16, 16)) 在时序维度上的卷积完全处于标准物理步长下，彻底规避伪运动噪声。

  #### (2) Continuous-Time RoPE (CT-RoPE)

  在骨干的所有 Self-Attention 层中，替换原有绝对位置编码，注入物理时间相对旋转量：

    def apply_continuous_rope(q, k, timestamps, dim_theta=64):
        """
        timestamps: [B, N_tubelets], 记录每个 tubelet 的物理中心时间 (秒)
        q, k: [B, num_heads, N_tubelets, head_dim]
        """
        # 计算波长频率
        inv_freq = 1.0 / (10000 ** (torch.arange(0, dim_theta, 2).float() / dim_theta))
        # 计算物理时序相角: [B, N_tubelets, dim_theta/2]
        angles = timestamps.unsqueeze(-1) * inv_freq.unsqueeze(0).unsqueeze(0)
        sin, cos = torch.sin(angles), torch.cos(angles)

        # 对 Query 和 Key 应用连续时间旋转嵌入
        q_rot = rotate_half(q, sin, cos)
        k_rot = rotate_half(k, sin, cos)
        return q_rot, k_rot
