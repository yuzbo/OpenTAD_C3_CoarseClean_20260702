### Coarse probe 的准确命名

代码只复用了**官方 ASFormer temporal module**。RGB spatial stem、二分类输入/输出适配、单 decoder 配置、逐样本循环和 encoder forward hook 都是本仓库实现。官方 ASFormer 原本接收时序特征，并通过 encoder 与多个 decoder refinement 进行 action segmentation；当前构造为一个 decoder、每部分两层。

因此诚实名称应为：

> **custom low-resolution spatial stem + official ASFormer temporal module adapted for binary actionness**

不能把整个模块称作“official ASFormer coarse probe”。ASFormer 论文的原始任务是动作分割而不是 raw-RGB TAD pre-backbone selection。([arXiv][1])

## 3.2 Loss 与梯度所有权

| Loss                                      |             更新 scorer | 更新 spatial stem | 更新 ASFormer encoder |   更新 decoder/action head |    更新 detector |
| ----------------------------------------- | --------------------: | --------------: | ------------------: | -----------------------: | -------------: |
| `actionness BCE`                          |                     否 |               是 |                   是 |                        是 |              否 |
| `transition distribution`                 |                     是 |               是 |                   是 | 否；action logits 已 detach |              否 |
| `local transition coverage`               |                     是 |               否 |                   否 |                        否 |              否 |
| detector loss 经 `structured_zero_forward` |                     是 |               否 |                   否 |                        否 | detector 自身也更新 |
| ActionFormer `cls/reg`                    | 仅通过 bridge 间接到 scorer |               否 |                   否 |                        否 |              是 |

`transition_utility_paths()` 的代码事实是：

```python
descriptors = build_transition_descriptors(actionness_logits.detach(), hidden, valid)
policy_scores = scorer(descriptors.detach())
auxiliary_scores = scorer(descriptors)
```

所以：

* transition auxiliary route 可更新 scorer、ASFormer encoder 和 spatial stem；
* detector/policy route只更新 scorer；
* action head不会被 transition 或 detector route 更新。

### 是否可称为“联合协同训练”

可以称：

> **single-checkpoint joint multi-loss training with protected gradient routing**

不能称：

> **fully end-to-end detector–coarse representation co-adaptation**

因为 detector signal 不会改变 coarse representation，只会改变最后的 utility scorer。它是“task-adapted acquisition score”，不是“detector-adapted coarse representation”。

## 3.3 Detector loss 是否漏加或重复加

没有发现实际 `cls_loss/reg_loss` 漏加或重复加。

* selector 中名为 `detector_loss` 的项是零值占位；
* 真实 detector losses 在 `ActionFormer.forward_train()` 中由 RPN head 返回；
* selector losses 与 RPN losses 合并；
* 最终 `cost` 对所有 leaf losses 求和。

但零占位及配置中的 `loss_weights.detector=1.0` 容易制造审计歧义。应删除占位，或重命名为明确的 `selector_detector_bridge_regularizer`。

## 3.4 优化器事实

优化器覆盖逻辑是当前实现中相对可靠的一部分：

* 所有 `requires_grad=True` 参数必须且只能出现一次；
* missing、frozen、stale、duplicate 参数会 fail closed；
* scorer、coarse trunk、action head 的 component LR 按参数名前缀真实分组；
* 当前配置对应：

  * scorer：`1e-4`
  * action heads：`5e-5`
  * coarse trunk：`2.5e-5`
  * detector non-backbone：`1e-4`
  * VideoMAE adapters：`2e-4`
  * 其余 backbone 参数冻结。

AMP overflow 时，selector schedule、LR scheduler 和 EMA 不推进；“successful optimizer step 后推进”的代码合同成立。

## 3.5 坐标事实

当前有三个轴：

1. **dense/original axis**：`t∈[0,767]`
2. **selected axis**：第 `k` 个选中帧，`k∈[0,K-1]`
3. **seconds axis**：最终视频时间

训练时：

```text
GT original axis
  -> piecewise inverse map
  -> selected-axis GT
  -> ActionFormer loss
```

推理时：

```text
ActionFormer selected-axis predictions
  -> piecewise forward map
  -> original axis
  -> seconds
```

映射函数本身是单调且可逆的 piecewise-linear coordinate adapter。

但 **ActionFormer 内部的卷积、局部 receptive field、feature pyramid point stride、regression range 和 center sampling 仍把 selected rank 当等间隔时间**。后处理反变换不能撤销这种内部几何失真。

## 3.6 成本事实

当前方法是在模型图上 pre-backbone，但不是 pre-decode/pre-resize/pre-H2D：

* 数据管线先解码 768 帧并缩放为 160×160；
* selector 收到完整高分辨率 tensor 后，才在模型内缩到 64×64。

因此它目前只明确减少 **VideoMAE heavy backbone compute**，不自动节省：

* 全帧视频解码；
* 160×160 dense augmentation/resize；
* dense CPU memory traffic；
* 通常也不节省 768 帧 H2D。

# 5. Uniform 缺陷复核

## 5.1 `transition_only` 修复本身成立

新实现使用：

```python
targets = torch.linspace(0, valid_count - 1, steps=effective_k).round()
values = -distance_to_nearest_target
```

在 `T=768,K=384` 且 target positions 唯一时，正好有 384 个最高分位置；exact-K MAP 被迫选择全部 rounded endpoint linspace positions。formal gate 与 unit test 也新增了逐点相等和 `max_rank_error==0`。

所以：

* `transition_only._uniform_reference_scores()` 的原 midpoint bug 已修；
* transition-only alpha=0 endpoint 的合同是正确的；
* old `1159414` 不再代表新实现。

## 5.2 修复**不完整覆盖整个仓库**

发现同类残留：

```python
# acquisition.py legacy/direct stable_selection
targets = (
    (torch.arange(effective_k) + 0.5)
    * valid_count / effective_k
    - 0.5
)
```

它位于 `acquisition.py:1584–1592`。

而 direct/non-transition route 在：

* warmup `progress<=0` 时必走 `stable_selection`；
* transition 阶段按 step/modulo 交替使用 stable path。

因此：

> `direct-a5` 确实“不调用 transition-only 的旧函数”，但它调用了另一个同类 midpoint implementation。

这意味着 `1159415` 不能被视为已证明干净的 matched direct control。它仍可作为旧代码行为诊断，但 corrected matrix 必须连 direct route 一起修复和重跑。

## 5.3 仍需补的 uniform tests

必须增加：

1. transition alpha=0，`T=768,K=384`
2. direct stable warmup，`T=768,K=384`
3. short prefix，`T=401,K=384`
4. `effectiveK=valid_count<K`
5. AMP 下输入 logits 为 fp16/bf16，但 reference 内部 float32
6. repo-wide 禁止 midpoint reference 的静态测试
7. random tie-breaking 不得影响 exact rounded positions
8. common helper 的 source hash 必须写入 gate manifest

`26 passed, 2 skipped` 只能证明已有合同；它不能替代 corrected CUDA gate，更不能替代 full train。

* balanced BCE 约 0.93–0.96 **不能**说明 actionness 好或坏，因为动态 `pos_weight` 改变了 loss 尺度；

# 8. 三个互斥方案

## 8.1 路线 A：最小修复 Shared-ASFormer Transition-Only

### 定义

* 输入：`x:[B,1,3,768,160,160]`
* coarse：当前 stem + official ASFormer
* descriptor：`[B,768,197]`
* utility：当前单 scalar scorer
* policy：当前 exact-K/G DP
* detector：AdaTAD/ActionFormer
* 保留 soft DP 与 zero-forward bridge

### 必改

* 修复所有 midpoint reference；
* score-level alpha interpolation 改成 batch-level hard path exposure；
* DP 全程 float32；
* 增加 confidence/margin logging；
* 启用 physical-grid detector 或 physical-time reconstruction；
* beta>0 仅在 one-swap correlation 通过后解锁。

### 梯度

```text
L_action -> full coarse probe
L_transition -> coarse encoder + scorer
L_detector through soft RGB -> scorer only
L_detector -> detector
```

### 目标

[
L=L_D+L_{\text{act}}+0.5L_{\text{tr}}+0.25L_{\text{cov}}.
]

beta 不再先验固定为 0.25；根据 scorer 上 detector-gradient 与 transition-gradient EMA norm 做 cap：

[
\beta_s=
\operatorname{clip}\left(
\rho\frac{\bar g_{\mathrm{tr}}}{\bar g_D+\epsilon},
0,0.25
\right),\qquad \rho=0.5.
]

### Train/eval

* 训练 detector 输入仍为 hard selected RGB；
* soft RGB 只提供 backward；
* 推理完全 hard。

### 预期成本

* 推理与当前相近；
* training bridge 在正式形状下极重；
* 仍需要完整 dense input 常驻 GPU。

### 最大风险

即使数值更稳定，soft RGB derivative 仍可能与 hard replacement utility 无关。

### 一周 kill test

* one-swap Spearman LCB 必须大于 0；
* beta>0 对 beta=0 的短跑增益必须方向一致；
* 否则路线 A 立即终止。

### 与已有工作的关系

Perturb-and-MAP 能将离散 optimizer 平滑化并复用原求解器；SoftSort/Gumbel 类方法则提供排序或离散变量松弛。它们解决“如何产生梯度”，并不自动证明梯度对应 TAD hard replacement utility。([arXiv][2])

**评价：最省代码，但科学风险最高，不推荐作为最终 DUCA。**

## 8.2 路线 B：DUCA-FSU——Transition-Prior Feasible-Swap Utility Distillation

这是我的唯一推荐路线。

### 精确输入输出

* dense low-resolution probe input：`[B,T,3,64,64]`
* high-resolution candidate frames：`[B,3,T,160,160]`
* `T=768`
* ASFormer hidden：`[B,T,96]`
* transition descriptor：`[B,T,197]`
* utility：`u∈R[B,T]`
* hard positions：`S∈N[B,K]`
* `K=384,G=15`
* physical-time reconstructed detector input：`[B,3,K,160,160]`

### 核心机制

不对 detector loss 通过软像素反传，而是在训练时构造真实 hard feasible swap：

[
S' = S-{s_j}+{t}, \qquad S,S'\in\mathcal F_{K,G}.
]

计算真实 detector loss gain：

[
\Delta^{D}_{j,t}
================

\operatorname{stopgrad}
\left[
\ell_D(S)-\ell_D(S')
\right].
]

由于 additive policy objective 的 swap gain 恰为：

[
\Delta^{u}*{j,t}=u_t-u*{s_j},
]

直接训练二者方向一致：

[
L_{\mathrm{swap}}
=================

\sum_{(j,t)}
w_{j,t}
\operatorname{softplus}
\left(
-\operatorname{sign}(\Delta^{D}*{j,t})
\frac{u_t-u*{s_j}}{\tau_{\mathrm{swap}}}
\right).
]

这不是用“非零梯度”代理 utility，而是用实际 hard replacement 结果监督 utility difference。

### 删除

* `structured_zero_forward`
* soft raw-pixel mixture
* beta schedule
* detector gradient 进入 coarse trunk 的所有路径
* score-level alpha homotopy
* selected-axis GT remap作为主路径
* `local_boundary_coverage_loss` 主损失
* selector 内零 detector-loss 占位

### 复用

* official ASFormer temporal module
* transition descriptors
* single utility scorer
* hard exact-K/max-gap DP
* OpenTAD/AdaTAD detector
* existing optimizer coverage和测试基础设施

### 梯度

```text
L_action:
  spatial stem + ASFormer encoder/decoder + action head

L_transition:
  spatial stem + ASFormer encoder + utility scorer
  action logits stop-gradient

L_swap:
  utility scorer only
  coarse hidden stop-gradient
  detector stop-gradient

L_detector:
  AdaTAD/ActionFormer only
```

这是有意的保护性设计：

> coarse representation 负责学习动作/背景及转换语义；detector task signal 负责学习“在这些语义变化中哪些对 detector 真有用”。

不需要 PCGrad，因为 detector utility 与 semantic losses 不共享 coarse trunk。GradNorm只能调节梯度大小，不能解决错误 surrogate 的方向问题；PCGrad只有在任务确实共享参数且存在冲突时才有意义。([arXiv][3])

### Train/eval 同构

* 主 detector 每次只看到 hard policy 产生的真实/确定性重建输入；
* counterfactual branches 只是 train-only target；
* test 不执行 counterfactual；
* 没有 soft/hard detector input mismatch。

### 推理可见信息

仅：

* 当前完整离线窗口的低分辨率 RGB；
* coarse action logits/hidden；
* selector parameters；
* hard DP；
* 选中高分辨率帧。

不读取：

* GT；
* teacher；
* oracle；
* ledger；
* prediction cache；
* JSONL；
* test-time calibration labels。

### 预期成本

* 推理删除昂贵 bridge；
* proposed depthwise stem 将 spatial MAC 从约 36.69 降至约 2.68 GMAC/B=2；
* one-swap 只增加训练成本；
* 每 16 个成功 step 评估 4 个 no-grad swaps，粗略增加 25%–50% detector forward compute，必须实测。

### 最大失败风险

Detector loss 可能高度非加性，单帧 one-swap gain 不可由 `u_t-u_s` 预测。如果发生，这不是调参问题，而是 additive per-frame utility 假设失败。

### 一周决定性实验

在固定 detector checkpoint 上：

* 每窗口 4–8 个 feasible swaps；
* ≥500 个窗口；
* scorer difference vs detector gain：

  * window-cluster bootstrap Spearman LCB > 0；
  * sign agreement ≥60%；
  * top-quartile gain recall ≥50%。

未达到即停止该路线。

### 与近期工作的区别

自适应视频采样已有明显拥挤：

* AdaFrame 学习 recognition 场景的 sequential frame utility；
* SCSampler 学习长视频 salient clips；
* MGSampler 依据 motion distribution 做可解释采样。([arXiv][4])
* 2024 年工作已研究为固定视频分类器独立估计 per-frame value；
* 2026 年 PEEK 也已将强 teacher 的 frame relevance ranking 蒸馏到轻量模型。([arXiv][5])

所以可发表的新意不能写成“轻量模型预测 frame importance”，而必须是：

> **在 exact-K/max-gap TAD policy 中，以真实 feasible hard swap 的 detector localization loss 为训练合同，使 additive utility difference 与 counterfactual detector gain 一致，并保持物理时间 detector 几何。**

## 8.3 路线 C：假设失败后的 Residual-Innovation Multigrid

### 输入输出

* low-res frames：`[B,T,3,32,32]`
* tiny spatial features：`[B,T,32]`
* interval residual/curvature：`r∈R[B,T]`
* hierarchical knots：`[B,K]`

### 删除

* actionness BCE
* ASFormer
* GT transition Gaussian
* transition scorer
* detector-gradient bridge
* semantic boundary claim

### 方法

对低分辨率特征构造时间插值残差：

[
r_t=\left|f_t-\operatorname{Interp}(f_l,f_r;t)\right|_2^2.
]

从全区间开始，反复切分 residual 最大的区间，直到获得 K 个 knots；或者把 interval risk 转化为 exact-K DP utility。

### 梯度

* self-supervised reconstruction/innovation loss 更新 tiny encoder；
* detector loss不穿过离散 selection；
* detector独立训练。

### Train/eval

完全同构；推理只使用视觉 innovation，不使用 GT 语义。

### 成本

通常远低于 ASFormer probe，约 `O(TD+K log T)`；没有 soft bridge。

### 最大风险

相机运动、cut、背景变化可能比动作边界产生更强 residual；它可能只是 motion sampler。

### 一周 kill test

固定 detector、固定 K、physical-time geometry：

* uniform
* cumulative motion
* residual multigrid
* transition-only

比较 boundary recall、short-action recall、mAP@0.7。若 residual 方法只提高 motion-rich 类而不提高整体定位，应放弃。

### 与已有工作的区别

MGSampler 已经用 motion saliency 和 cumulative motion distribution进行 sampling；因此路线 C 只有在“多尺度重建风险/物理时间 mesh”而非普通 motion magnitude 上表现出不可替代性时才有论文价值。([arXiv][6])

# 9. 唯一推荐最终模型：DUCA-FSU-384

## 9.1 文字框图

```text
Dense low-res RGB, T=768
        │
Depthwise-separable spatial stem
        │
Official ASFormer temporal module
        ├── binary action logits
        └── encoder hidden
        │
Transition-only descriptors
        │
Shared utility scorer
        │
Hard exact-K/max-gap DP
        │
Selected high-res temporal knots, K=384
        │
Physical-time uniform reconstruction, length=384
        │
Official AdaTAD / ActionFormer active detector path
        │
Original-time predictions

Train only:
feasible hard one-swap detector loss
        └── supervises utility-score differences
```

## 9.2 Coarse spatial stem

替换当前第二个 full Conv：

```text
Conv2d 3→32, 3×3, stride 2
BN + SiLU
Depthwise Conv2d 32→32, 3×3, stride 2
BN + SiLU
Pointwise Conv2d 32→96, 1×1
BN + SiLU
AdaptiveAvgPool2d(1)
```

输出仍是 `[B,T,96]`，官方 ASFormer temporal module完全复用。

对 `B=2,T=768,S=64`：

* 当前 stem：约 36.69 GMAC/batch；
* 建议 stem：约 2.68 GMAC/batch；
* spatial MAC 降约 92.7%。

这只是解析估计，论文必须用 operator profiler 和真实 latency 复核。

## 9.3 Descriptor 与 utility

[
d_t\in\mathbb R^{197}
]

保持当前定义，不加入：

* absolute hidden；
* absolute actionness；
* RGB mean；
* direct start/end/context heads。

Scorer继续使用当前：

```text
LayerNorm(197)
Linear(197,64)
GELU
Linear(64,1)
```

不再逐窗 z-normalize后与 uniform score混合。hard policy直接使用 float32 utility logits。

## 9.4 Feasible family

对于有效前缀长度 (V)：

[
\mathcal F_{K,G}(V)=
\left{
y\in{0,1}^{V}:
\sum_t y_t=\min(K,V),
\ \text{任意连续未选中区间长度}\le G
\right}.
]

主实验固定：

* `T=768`
* `K=384`
* `G=15`

不在 fixed-384 通过前改 dynamic budget。

## 9.5 Physical-time uniform reconstruction

给定选中位置：

[
s_1<\cdots<s_{K'}
]

和 detector uniform grid：

[
q_j=\frac{j(V-1)}{K-1},\quad j=0,\dots,K-1,
]

找相邻 knots (s_l\le q_j\le s_r)，构造：

[
\tilde x_j
==========

(1-\lambda)x_{s_l}
+
\lambda x_{s_r},
\qquad
\lambda=\frac{q_j-s_l}{s_r-s_l}.
]

边界外采用 nearest hold。

结果：

```text
selected observations: K' ≤ K
detector processed slots: exactly K
detector temporal axis: uniform in original physical time
```

GT 只需线性变换：

[
g^{det}=\frac{K-1}{V-1}g^{orig}.
]

预测反变换：

[
\hat g^{orig}=\frac{V-1}{K-1}\hat g^{det}.
]

这样：

* VideoMAE、projection、ActionFormer internal geometry都重新变成等物理时间；
* 不再对不规则 selected rank 做 GT remap；
* `ActionFormerHead` active semantics可保持官方路径；
* short windows不再用黑帧 padding。

## 9.6 Loss

### Actionness

[
L_{\mathrm{act}}
================

\frac{1}{|M|}
\sum_{t\in M}
\operatorname{BCEWithLogits}
(a_t,r_t;w_+).
]

保留动态 positive weight，但同时报告无权重 AUROC/AUPRC/ECE。

### Transition prior

[
q_t
===

\frac{1}{2N_{\mathrm{inst}}}
\sum_i
\left[
\mathcal G_\sigma(t-s_i)
+
\mathcal G_\sigma(t-e_i)
\right],
]

保持当前 equal-mass、fixed-sigma、truncated Gaussian。

[
L_{\mathrm{tr}}
===============

-\sum_t q_t
\log\operatorname{softmax}(u^{aux}/\tau_{\mathrm{tr}})_t.
]

### Feasible-swap utility

[
L_{\mathrm{swap}}
=================

\frac{\sum_{(j,t)}w_{j,t}
\operatorname{softplus}
\left[
-\operatorname{sign}(\Delta^D_{j,t})
(u_t-u_{s_j})/\tau_{\mathrm{swap}}
\right]}
{\sum w_{j,t}+\epsilon}.
]

其中：

[
w_{j,t}
=======

\min\left(
2,\frac{|\Delta^D_{j,t}|}
{\operatorname{MAD}(\Delta^D)+\epsilon}
\right).
]

忽略低于数值噪声阈值的 swap。

### Detector

保持官方 `cls_loss + reg_loss` 和 NMS。

### 总目标

普通 step：

[
L_{\mathrm{normal}}
===================

L_D+L_{\mathrm{act}}+\lambda_{\mathrm{tr}}L_{\mathrm{tr}}.
]

counterfactual step：

[
L_{\mathrm{cf}}
===============

L_D+L_{\mathrm{act}}+\lambda_{\mathrm{tr}}L_{\mathrm{tr}}
+\lambda_{\mathrm{swap}}L_{\mathrm{swap}}.
]

权重不使用任意 beta。每 64 个成功 step，以 EMA gradient norm 更新：

[
\lambda_{\mathrm{tr}}
=====================

\operatorname{clip}
\left(
0.5
\frac{\bar g_{\mathrm{act,enc}}}
{\bar g_{\mathrm{tr,enc}}+\epsilon},
0.1,1.0
\right),
]

[
\lambda_{\mathrm{swap}}
=======================

\operatorname{clip}
\left(
\frac{\bar g_{\mathrm{tr,scorer}}}
{\bar g_{\mathrm{swap,scorer}}+\epsilon},
0.25,2.0
\right).
]

p_{\mathrm{learned}}(s)

\frac12-

\left(

# 10. 核心代码

## 10.1 唯一 uniform reference

```python
from __future__ import annotations

import torch


def rounded_endpoint_reference_scores(
    *,
    valid_count: int,
    k: int,
    device: torch.device,
    dtype: torch.dtype,
) -> torch.Tensor:
    """Return [valid_count] logits whose exact-K MAP is round(linspace)."""
    valid_count = int(valid_count)
    effective_k = min(max(int(k), 0), valid_count)

    if valid_count < 0:
        raise ValueError("valid_count must be non-negative")
    if effective_k == 0:
        return torch.zeros(valid_count, device=device, dtype=dtype)

    positions = torch.arange(valid_count, device=device, dtype=torch.float32)
    if effective_k == 1:
        targets = positions.new_zeros(1)
    else:
        targets = torch.linspace(
            0.0,
            float(valid_count - 1),
            steps=effective_k,
            device=device,
            dtype=torch.float32,
        ).round()

    if torch.unique(targets).numel() != effective_k:
        raise RuntimeError("rounded endpoint reference contains duplicate targets")

    scores = -(positions[:, None] - targets[None, :]).abs().amin(dim=1)
    return scores.to(dtype=dtype)
```

该 helper 必须同时替换 transition 和 direct stable route。

## 10.2 Physical-time reconstruction

```python
import torch
import torch.nn.functional as F


def reconstruct_uniform_time_grid(
    dense_frames: torch.Tensor,      # [B,C,T,H,W]
    selected_positions: torch.Tensor,  # [B,Kmax], -1 padded
    valid_lengths: torch.Tensor,     # [B]
    output_len: int,
) -> torch.Tensor:
    """Piecewise-linear reconstruction using selected observations only."""
    if dense_frames.ndim != 5:
        raise ValueError("dense_frames must be [B,C,T,H,W]")
    if selected_positions.ndim != 2:
        raise ValueError("selected_positions must be [B,Kmax]")

    batch, channels, temporal_len, height, width = dense_frames.shape
    output_rows = []

    for b in range(batch):
        valid_len = int(valid_lengths[b].item())
        if not 1 <= valid_len <= temporal_len:
            raise ValueError(f"invalid valid_len={valid_len}")

        pos = selected_positions[b]
        pos = pos[(pos >= 0) & (pos < valid_len)].long()
        if pos.numel() == 0:
            raise RuntimeError("at least one selected observation is required")
        if pos.numel() > 1 and not torch.all(pos[1:] > pos[:-1]):
            raise RuntimeError("selected positions must be strictly increasing")

        query = torch.linspace(
            0.0,
            float(valid_len - 1),
            steps=int(output_len),
            device=dense_frames.device,
            dtype=torch.float32,
        )

        pos_f = pos.float()
        right = torch.searchsorted(pos_f, query, right=False)
        right = right.clamp(0, pos.numel() - 1)
        left = (right - 1).clamp(0, pos.numel() - 1)

        left_pos = pos_f[left]
        right_pos = pos_f[right]
        denom = (right_pos - left_pos).clamp_min(1.0)
        weight = ((query - left_pos) / denom).clamp(0.0, 1.0)

        x_left = dense_frames[b, :, pos[left], :, :]
        x_right = dense_frames[b, :, pos[right], :, :]
        reconstructed = (
            x_left * (1.0 - weight)[None, :, None, None]
            + x_right * weight[None, :, None, None]
        )
        output_rows.append(reconstructed)

    return torch.stack(output_rows, dim=0)  # [B,C,K,H,W]
```

## 10.3 Feasible-swap loss

```python
def feasible_swap_rank_loss(
    utility: torch.Tensor,          # [B,T]
    selected_positions: torch.Tensor,  # [B,K]
    swap_pairs: torch.Tensor,       # [B,M,2]: (selected_slot, candidate_time)
    detector_gain: torch.Tensor,    # [B,M], positive means swap improves detector
    *,
    temperature: float = 0.5,
    min_gain: float = 1e-4,
) -> torch.Tensor:
    if utility.ndim != 2:
        raise ValueError("utility must be [B,T]")
    if swap_pairs.ndim != 3 or swap_pairs.shape[-1] != 2:
        raise ValueError("swap_pairs must be [B,M,2]")
    if detector_gain.shape != swap_pairs.shape[:2]:
        raise ValueError("detector_gain must align with swap_pairs")

    selected_slot = swap_pairs[..., 0].long()
    candidate_time = swap_pairs[..., 1].long()

    selected_time = selected_positions.gather(1, selected_slot)
    selected_u = utility.gather(1, selected_time)
    candidate_u = utility.gather(1, candidate_time)
    predicted_gain = candidate_u - selected_u

    target_sign = detector_gain.detach().sign()
    active = detector_gain.detach().abs() > float(min_gain)
    if not active.any():
        return utility.sum() * 0.0

    active_gain = detector_gain.detach().abs()[active]
    mad = (active_gain - active_gain.median()).abs().median().clamp_min(1e-6)
    weight = (detector_gain.detach().abs() / mad).clamp(max=2.0)

    loss = F.softplus(
        -target_sign * predicted_gain / float(temperature)
    )
    return (loss * weight)[active].mean()
```

## 10.4 Hard exposure，而不是 score interpolation

```python
import math
import hashlib


def learned_policy_probability(step: int) -> float:
    if step <= 660:
        return 0.0
    if step >= 4620:
        return 1.0
    progress = (step - 660) / 3960.0
    return 0.5 - 0.5 * math.cos(math.pi * progress)


def deterministic_use_learned(
    *,
    step: int,
    sample_uid: str,
    seed: int,
) -> bool:
    probability = learned_policy_probability(step)
    payload = f"{seed}:{step}:{sample_uid}".encode("utf-8")
    value = int.from_bytes(hashlib.sha256(payload).digest()[:8], "big")
    uniform01 = value / float(2**64 - 1)
    return uniform01 < probability
```

每个 sample 只走：

```python
policy_logits = learned_utility if use_learned else exact_uniform_logits
positions = hard_structured_map(policy_logits)
```

不存在 `(1-alpha)score_uniform + alpha score_learned`。

## 11.3 统计协议

所有主变体：

* 至少 3 seeds；
* 相同 train window manifests；
* 相同初始化 checkpoint；
* 相同 optimizer step 数；
* 相同 eval epochs；
* 视频/窗口级 paired bootstrap；
* 主指标：

  * Avg mAP
  * mAP@0.7
  * shortest-duration-quartile mAP@0.7
  * selected-to-boundary distance
  * boundary recall within ±2/±4/±8
  * unique selected observations
  * full-stack latency/energy。

建议 fixed-384 通过门：

[
\Delta\text{Avg}_{\mathrm{FSU-uniform}}\ge 0.5
]

且 paired CI lower bound > 0，同时：

[
\Delta \text{mAP@0.7}\ge 0,
]

short-Q1 drop 不得超过 1.0 absolute。

只有满足后才解锁：

1. `K=256`
2. `K=128`
3. dynamic budget
4. 第二 detector。

# 12. 真实成本核算模板与 break-even

## 12.1 当前 bridge 的解析下界

正式 shape：

```text
B=2, N=1, C=3, T=768, H=W=160, K=384
```

soft-slot RGB einsum：

[
BNC,T,HW,K
==========

45.30\text{ GMAC/batch}
]

约：

[
90.60\text{ GFLOP/batch}
]

仅 soft output：

```text
[B,1,3,384,160,160]
```

float32 约 **225 MiB**。

如果 dense input 仍是 uint8 并因 bridge 转为 float32，额外 dense copy 约 **450 MiB**。slot assignment 本身约 2.25 MiB；尚未包括 autograd saved tensors、temporary buffers和 allocator fragmentation。代码自己的 profile 也明确把这个数标成 lower bound，而非完整 memory accounting。

这足以说明：

> `structured_zero_forward` 可以作为研究诊断，但不适合在没有 utility-correlation 证据时长期占用正式训练预算。

## 12.2 全栈计时组件

每个方法必须报告：

[
L_{\mathrm{total}}=
L_{\mathrm{decode}}
+L_{\mathrm{resize}}
+L_{\mathrm{H2D}}
+L_{\mathrm{probe}}
+L_{\mathrm{DP}}
+L_{\mathrm{gather}}
+L_{\mathrm{reconstruct}}
+L_{\mathrm{backbone}}
+L_{\mathrm{projection}}
+L_{\mathrm{head}}
+L_{\mathrm{NMS}}.
]

至少报告：

* batch=1 p50/p95；
* batch=2 throughput；
* windows/s；
* video minutes/s；
* peak allocated/reserved GPU memory；
* CPU peak RSS；
* bytes transferred H2D；
* joules/window；
* detector-only 与 full-stack 两套数字；
* 200 warmup + ≥2000 matched windows；
* 固定 GPU clocks/power limit；
* CUDA synchronize；
* matched precision、NMS、data workers。

## 12.3 Dense break-even

相对于 dense-768：

[
C_{\mathrm{probe}}
+C_{\mathrm{select}}
+C_{\mathrm{reconstruct}}
+C_{\mathrm{IO,DUCA}}
+C_D(384)
<
C_{\mathrm{IO,dense}}
+C_D(768).
]

gross detector saving：

[
S_{\mathrm{gross}}
==================

C_D(768)-C_D(384).
]

建议要求：

[
C_{\mathrm{probe}}+C_{\mathrm{select}}+C_{\mathrm{reconstruct}}
\le 0.4S_{\mathrm{gross}}.
]

且 full-stack：

* p50 saving ≥20%
* p95 saving ≥15%
* energy saving ≥15%。

## 12.4 Uniform break-even

在相同 `K=384` 下：

[
C_{\mathrm{DUCA}}(384)
======================

C_{\mathrm{uniform}}(384)
+
C_{\mathrm{probe}}
+
C_{\mathrm{select}}
+
C_{\mathrm{reconstruct}}.
]

因此 DUCA 在同 K 下**不可能比 no-probe uniform 更便宜**。它必须做到：

* 同 K 精度显著更高；或
* 在较小 K 达到 cost-matched uniform 较大 K 的精度。

真实 Pareto 比较应是：

```text
uniform K=128/256/384/512
vs
DUCA K=128/256/384
```

按实测 total latency 对齐，而不是只按帧数对齐。

# 13. 论文可发表性裁决

## 13.1 当前 `0ea4e15` 能 claim 什么

可以：

1. 提出了一个 offline、full-window、fixed-budget 的 transition-only acquisition candidate；
2. selector 输入限定为 actionness/entropy/hidden 的相邻变化；
3. train-only GT endpoint Gaussian 用于 transition supervision；
4. inference 主配置禁止 GT、teacher、ledger、prediction cache；
5. exact-K/max-gap hard/soft DP 在正常数值范围内共享同一 feasible family；
6. optimizer coverage、AMP successful-step schedule 有较强 fail-closed 合同；
7. `ActionFormerHead` 文件与固定上游版本相同，但 wrapper/base code 已扩展。

## 13.2 当前不能 claim 什么

不能：

* 优于 exact uniform；
* detector gradient 提高了 utility；
* beta=0.25 有效；
* high-tIoU 被保护；
* full-stack 加速或节能；
* dynamic budget；
* detector-agnostic plugin；
* 整个 coarse probe 是 official ASFormer；
* detector 源码完全未改；
* causal/online TAD；
* score-continuous 等于 policy-continuous；
* 测试通过等于方法成立。

## 13.3 当前组合的创新性

当前形式：

```text
custom low-res probe
+ ASFormer temporal module
+ transition descriptors
+ exact-K structured top-k
+ ST raw-pixel bridge
+ ActionFormer wrapper
```

更接近**有工程强度的组合式系统**，不足以单独形成稳固的 CVPR 方法贡献。

原因是：

* 自适应 frame/clip selection 在 recognition 中已有 AdaFrame、SCSampler、MGSampler 等成熟先例；([arXiv][4])
* differentiable discrete optimization 已有 Gumbel、SoftSort、perturbed optimizer 和 Fenchel–Young 框架；([arXiv][7])
* ActionFormer 本身按多尺度时序特征分类 moment 并回归边界，非均匀 selected rank 会直接影响其时间几何；([arXiv][8])
* AdaTAD 的核心是通过 temporal-informative adapters 扩展长视频 end-to-end TAD；DUCA若要成立，必须证明采样收益，而不能只依赖 AdaTAD 强后端。([arXiv][9])
* OpenTAD 强调统一协议和公平比较；当前 corrected same-commit baseline 缺失正是论文证据链中的核心缺口。([arXiv][10])

## 13.4 推荐路线的论文价值

DUCA-FSU 只有在以下三项同时成立时，才有潜在 CVPR 主会价值：

1. **科学机制成立**
   feasible one-swap detector gain 可被 transition-derived utility difference 预测。

2. **定位性能成立**
   在 exact same protocol 下显著优于 uniform、periodic、random 和 direct boundary，尤其是 @0.7 与短动作。

3. **系统价值成立**
   把 probe、decode、H2D、reconstruction 全部计入后仍形成 accuracy–total-cost Pareto。

此时论文中心应是：

> **Detector counterfactual consistency for constrained physical-time video acquisition**

而不是：

> “ASFormer 预测 transition，然后 structured top-k 选帧。”

前者是可证伪的学习原则；后者容易被视为模块组合。

# 14. 停止条件

以下任一硬条件出现，都不应继续堆 loss 或扩大网格。

## 14.1 立即终止当前 raw-pixel bridge

* one-swap gain 与 surrogate gradient 的 cluster-bootstrap Spearman LCB ≤ 0；
* sign agreement ≤55%；
* beta>0 三个 seed 平均不优于 beta=0；
* bridge overhead超过训练时间的 25%，但没有稳定增益。

## 14.2 终止 transition-only semantic hypothesis

* coarse actionness AUPRC 相对 prevalence lift <1.5×；
* transition peak recall 不高于随机/运动 baseline；
* learned utility 与 score-shuffle/random-G15 的选帧质量无显著差异；
* no-transition-supervision ablation 与完整方法相同或更好；
* corrected three-seed transition beta=0 不能超过 exact uniform。

## 14.3 终止 additive utility / DUCA-FSU

* feasible-swap score difference 对 detector gain 的 median Spearman <0.2；
* pooled/window-cluster bootstrap LCB ≤0；
* gain sign agreement <60%；
* FSU 不优于 transition-only scorer；
* 大量 detector gain 只能由成对或高阶 frame interactions解释，单帧 swap不可预测。

此时应直接转向路线 C 或其他非加性 interval/chunk utility，而不是增加更多 per-frame heads。

## 14.4 终止论文效率 claim

* full-stack p50 saving 相对 dense <15%；
* p95 saving <10%；
* probe/select/reconstruction overhead > gross heavy saving 的 50%；
* dense decode/H2D 无法从部署路径移除；
* 同成本下 uniform Pareto 不劣于 DUCA；
* energy 无节省或峰值显存更高。

## 14.5 终止 fixed-384 后续扩展

若 fixed-384 未同时满足：

* three-seed Avg mAP gain ≥0.5；
* paired CI lower >0；
* mAP@0.7 不下降；
* short-Q1 drop ≤1.0；
* total-cost Pareto成立；

则禁止继续：

* K=256/128；
* dynamic budget；
* 第二 detector；
* 更复杂 probe；
* 新的 selector loss；
* 大规模 hyperparameter search。

**最终裁决：保留研究问题，冻结当前论文主张；先修复 repo-wide uniform 残留，并用 one-swap、same-selected-frames geometry 和 corrected exact-uniform 三个决定性实验裁决。若继续，唯一值得实现的最终模型是 DUCA-FSU，而不是继续调 `structured_zero_forward beta`。**
