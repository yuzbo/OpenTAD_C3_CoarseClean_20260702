当前 spatial stem 是两个标准 3×3 卷积，不是 MobileNet。wrapper 构造的 ASFormer 使用一个 decoder、默认两层、96 维和二分类输出。更关键的是，当前 `return_hidden=True` 返回的是进入 ASFormer 之前的 stem feature，而不是 ASFormer encoder 或 decoder hidden。

selector 确实把 raw descriptor、7 维状态特征和 absolute coarse hidden 拼接；随后独立预测 start、end、context 和 utility，并把这些概率直接加进中心选择分数。

## 3.2 GT 进入位置与泄漏裁决

训练时，GT segments 被转换为：

* binary action/background target；
* start target；
* end target；
* context target；
* boundary coverage target；
* `0.45 start + 0.45 end + 0.10 context` 的归一化 utility proxy。

这些 target 在 `_forward_select()` 完成后才加入 selector outputs 并计算 loss；随后 GT 才被映射到 selected axis 供检测头训练。

因此：

* **[仓库事实] 推理决策没有直接读取 GT。**
* **[仓库事实] val/test 拒绝外部 actionness、ledger、prediction cache 和 train-only target payload。**
* **[裁决] 没有传统意义上的 inference leakage。**
* **[裁决] 但存在科学假设绕过：train-only GT 直接训练多个 boundary heads，使联合 selector 本身成为一个小型直接边界预测器。**

“GT 用于训练”不是泄漏；问题是它改变了所声称的学习机制。

## 3.3 hard/soft 选择的准确裁决

当前 `global_structured_topk`：

1. 先验证 exact-K/max-unselected-hole 可行性；
2. hard 路径显式调用 `policy_logits.detach()`；
3. soft 路径在同一个 `(time, selected_count, current_hole)` 动态规划状态空间上做 log-sum-exp forward-backward；
4. ordered slot marginals 每个 slot 的质量为 1，总 occupancy 质量为 K；
5. 训练时构造 `hard + soft - soft.detach()`。

所以：

> **当前 main fixed-K 的 hard MAP 与 soft marginals 属于同一个 exact-K/max-gap feasible family。**

这一点是 **PASS**，不是当前失败点。

但这只说明 relaxation 的**约束同构**，并不说明其梯度方向等于真实 hard replacement detector utility。

## 3.4 detector loss 的实际梯度接收者

在非 warm-up 阶段，标准 detector loss 通过 raw-pixel soft-slot bridge 可以到达：

| 参数集合                                   |                                      是否有图路径 |                         是否确定 optimizer 更新 |
| -------------------------------------- | ------------------------------------------: | ----------------------------------------: |
| ActionFormer head / projection / neck  |                                           是 |                  是，属于 non-backbone groups |
| VideoMAE adapters                      |                                           是 | 按 base config 的 custom adapter group，意图上是 |
| VideoMAE base backbone                 |                                      有可能算梯度 |     配置将 backbone 主体排除或置零学习率；完整实例化覆盖未被测试证明 |
| selector MLP / center head             |                                           是 |                                         是 |
| direct start/end/context/utility heads |         detector loss 间接取决于其进入 center score |                                         是 |
| spatial stem                           | 是，经 absolute hidden 与 action-state features |                       是，位于 frame selector |
| official ASFormer trunk                |                是，经 logits→state descriptors |                                         是 |
| ASFormer binary output heads           |                         是，经 logits/p_action |                                         是 |

现有 optimizer test 只证明所有 `frame_selector.*` 可训练参数进入了 `ActionFormer.get_optim_groups()`，没有证明**整个实例化模型**所有 `requires_grad=True` 参数恰好进入一个 optimizer group。

`optimizer.py` 对 backbone 使用 custom/exclude 分组；被 exclude 的参数不会进入 optimizer，但代码没有自动把它们设为 `requires_grad=False`。因此可能存在“计算梯度但永不更新”的参数。

结论：

> **selector optimizer coverage 已测试；full-model optimizer coverage 尚未闭环。**

> coarse ASFormer 本身没有直接 start/end head，但 **“absolute stem feature + GT-supervised endpoint heads + utility head”组成的整体 selector 已经绕过了“粗分类状态变化间接定位边界”**。

这不是措辞问题，而是方法身份发生了改变。

关于用户提供的 loss 解释还需两点校正：

1. `0.034 / 0.05 ≈ 0.68` 接近 `log 2≈0.693`，但只有在 action/background 接近均衡时才能直接解释为随机二分类。THUMOS 的逐帧正负比例未必均衡，因此它是强烈警报，不是严格 chance-level 证明。

2. distribution loss `6.38` 不等于 `log(768)=6.64`；它更接近 `log(590)=6.38`。若平均有效长度约 590，则与均匀分布一致；若有效长度更长，则略好于均匀。必须按每个样本的 `log(valid_count)` 归一化后报告：

```text
normalized_excess_CE = raw_CE - mean(log(valid_count))
```

# 6. 三种候选架构

## 6.1 候选比较

| 候选                                                                 | 结构                                                                           | 优点                                                  | 主要风险                                           | 粗略 frontend 成本                                 |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------- | --------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| A. 保留 current stem+ASFormer，只修 optimizer/schedule                  | 当前 2-layer stem、ASFormer、absolute hidden、direct heads                        | 改动最小，便于复现 70aa                                      | 仍违背间接边界假设；直接 heads 和 shortcut 未消除              | 当前 stem 约 **18.35G MAC/window**，未含 ASFormer    |
| B. **共享 official ASFormer state trunk + transition-only selector** | 当前 stem→official ASFormer；提取真实 encoder hidden；selector 只看变化量；删除 direct heads | 最小化科学变量，直接检验核心假设；单模型、单 checkpoint                   | current stem 可能成本不低；状态变化假设可能本身不成立              | 约 18.35G MAC + ASFormer，需实测                    |
| C. MobileNetV3-only coarse classifier + transition selector        | MobileNet frame feature/logit→pairwise change；不再用 ASFormer                   | 有预训练空间语义，结构简单                                       | 缺少显式全窗口 temporal state modeling；偏离 ASFormer 合同 | 仓库估算约 **3.54G MAC/window**，但 kernel latency 未知 |
| D. MobileNetV3 替换 current stem + shared official ASFormer          | MobileNet spatial feature→official ASFormer→transition-only selector         | 预训练空间语义与 temporal state 兼具；静态 MAC 可能低于 current stem | 变量和成本同时变化；未经证据容易成为“加模型补救”                      | MobileNet约3.54G + ASFormer，必须实测                |

当前 stem 的静态 MAC 可直接由两层卷积估算：

```text
per frame:
32×32×3×96×3×3
+ 16×16×96×96×3×3
≈ 23.89M MAC

768 frames:
≈ 18.35G MAC
```

因此不能把它不经测量地称为“极轻 stem”。MobileNetV3-small 按仓库中 224→64 的面积缩放估算约为 4.61M MAC/frame，即约 3.54G MAC/window；但这种缩放不能替代真实 batched-kernel p50/p95 测量。

## 6.2 强制选择

### **选择 B：Shared-ASFormer Transition-Only DUCA**

具体版本：

```text
64×64 full-window RGB
→ current two-layer spatial stem
→ official ASFormer
→ actual ASFormer encoder state h_t
→ Δhidden / semantic-change / Δlogit / Δentropy descriptors
→ single transition-utility scorer
→ exact-K/max-gap hard structured policy
→ selected expensive observations
→ official-derived AdaTAD
```

选择 B 的原因不是认定 current stem 最优，而是：

1. 它最小化结构变量，能够直接证伪“粗状态变化是否足以支持高 tIoU 选帧”；
2. 先修复当前 hidden 取错、absolute bypass、直接 boundary heads 和错误梯度路由；
3. 在这些问题未修复前加入 MobileNet，无法判断收益来自状态变化假设还是额外预训练容量；
4. MobileNet 保留为独立的 frontend A/B，只有 B 的科学机制通过、但 coarse health 或成本仍失败时才能晋升。

**不允许把 MobileNet 叠加在 current stem 前后。** 若采用 D，应当是替换 stem，而不是额外堆叠。

# 7. 最终架构与数学目标

## 7.1 模块职责

设：

* `θ_sp`：两层 spatial stem；
* `θ_tr`：ASFormer encoder/temporal trunk，不含二分类 `conv_out`；
* `θ_act`：ASFormer binary action/background output layers；
* `θ_sel`：单一 transition-utility scorer；
* `θ_det`：VideoMAE adapters、projection、neck、ActionFormerHead；
* `T=768`；
* `K_i=min(384, valid_len_i)`；
* `G=15` 最大未选择 hole。

### Coarse state

```math
h_{1:T}, a_{1:T}
=
\operatorname{ASFormer}_{\theta_{sp},\theta_{tr},\theta_{act}}(x^{low}_{1:T})
```

其中：

* `a_t` 是 binary action logit；
* `h_t` 必须是 **ASFormer encoder hidden**；
* 不再把 pre-ASFormer stem feature 冒充 temporal state。

### Transition descriptors

主方法禁止 raw RGB mean 和 absolute hidden：

```math
\Delta h_t = h_t-h_{t-1}
```

```math
\Delta a_t = a_t-a_{t-1}
```

```math
H_t = -p_t\log p_t-(1-p_t)\log(1-p_t)
```

```math
d_t =
[
\Delta a_t,\ |\Delta a_t|,
\Delta H_t,\ |\Delta H_t|,
\Delta h_t,\ |\Delta h_t|,
1-\cos(h_t,h_{t-1})
]
```

边界处或 invalid pair 置零。

不输入：

```text
h_t
RGB_mean_t
start probability
end probability
absolute actionness additive score
```

因此 selector 不能仅靠静态 appearance 直接拟合 GT boundary。

### 双路径同权重 scorer

```math
s^{aux}_t=f_{\theta_{sel}}(d_t)
```

```math
s^{policy}_t=f_{\theta_{sel}}(\operatorname{sg}(d_t))
```

两者数值相同，但梯度路由不同：

* `s_aux` 让 transition supervision 更新 ASFormer state trunk；
* `s_policy` 让 detector/coverage gradient 更新 selector，而不破坏 coarse calibration。

scorer 中禁止 dropout，训练时断言：

```python
torch.allclose(s_aux.detach(), s_policy.detach(), atol=1e-6)
```

## 7.2 连续 homotopy

构造确定性的 uniform reference scores `r_t`，并对两种 score 在有效位置做标准化：

```math
\tilde s_t(\alpha)
=
(1-\alpha)\operatorname{norm}(r_t)
+
\alpha\operatorname{norm}(s^{policy}_t)
```

而不是当前按 batch 在 uniform-like 与 learned hard policy 之间跳变。

建议总训练长度：

```text
max_optimizer_steps = 13200
```

调度：

| optimizer steps  | α：learned policy | β：detector→selector bridge |
| ---------------- | ---------------: | -------------------------: |
| 0–660，0–5%       |                0 |                          0 |
| 660–4620，5–35%   |       cosine 0→1 |                          0 |
| 4620–7920，35–60% |                1 |              cosine 0→0.25 |
| 7920–13200       |                1 |                       0.25 |

所有模块从 step 0 就存在于同一个模型和 optimizer 中。这是单次联合训练，不是 checkpoint handoff 或三阶段训练。

## 7.3 hard/soft policy

可行集合：

```math
\mathcal Z(K_i,G)
=
\{
z\in\{0,1\}^{T_i}:
\sum_t z_t=K_i,\ 
\operatorname{maxhole}(z)\le G
\}
```

hard forward：

```math
z^{hard}
=
\arg\max_{z\in\mathcal Z(K_i,G)}
\sum_t z_t\tilde s_t
```

soft marginals：

```math
\mu_t
=
\mathbb E_{q_\tau(z\mid\tilde s)}[z_t],
\quad
q_\tau(z)
\propto
\exp
\left(
\frac{\sum_t z_t\tilde s_t}{\tau}
\right),
\ z\in\mathcal Z(K_i,G)
```

ST：

```math
z^{ST}
=
z^{hard}+\mu-\operatorname{sg}(\mu)
```

当前 `structured_selection.py` 已基本正确实现这一部分，不应替换为 unconstrained dense top-k surrogate。

## 7.4 训练目标

### 1. Binary action calibration

```math
L_{act}
=
\operatorname{BCEWithLogits}(a,y;\operatorname{pos\_weight})
```

建议：

```text
pos_weight = clip(N_negative / N_positive, 1, 8)
weight = 1.0
```

不再把 raw BCE 乘到 0.05。

### 2. 间接 transition supervision

对每个动作实例的 start/end，各分配相同质量的对称 Gaussian：

```math
q_t
=
\frac{1}{2M}
\sum_{m=1}^M
[
G_\sigma(t-s_m)+G_\sigma(t-e_m)
]
```

建议：

```text
σ = 2 dense observations
truncate radius = 4
```

单一目标：

```math
L_{tr}
=
-\sum_t q_t
\log \operatorname{softmax}(s^{aux}/\tau_b)_t
```

它监督的是 transition utility score，不产生 start/end identity heads。

### 3. Soft boundary coverage

```math
L_{cov}
=
-\frac{1}{2M}
\sum_{b\in\{s_m,e_m\}}
\log
\left[
\epsilon+
\sum_{|t-b|\le r}\mu_t
\right]
```

DP 已经严格满足 K 和 max-gap，因此 fixed-K 主方法中删除：

```text
budget_loss
max_gap_hole_loss
radius_loss
direct start/end/context loss
utility proxy loss
teacher utility loss
```

### 4. Detector loss

```math
L_{det}
=
L_{cls}+L_{reg}
```

检测器参数始终接收完整 detector loss。`β` 只控制 detector loss 通过 soft-slot bridge 到 selector 的梯度大小，不缩小 detector 自身训练信号。

## 7.5 梯度接收者合同

| 参数集合                          | `L_act` | `L_tr` | `L_cov` | `L_det` |
| ----------------------------- | ------: | -----: | ------: | ------: |
| `θ_act` binary output layers  |       ✓ |      ✗ |       ✗ |       ✗ |
| `θ_sp` spatial stem           |       ✓ |      ✓ |       ✗ |       ✗ |
| `θ_tr` ASFormer encoder trunk |       ✓ |      ✓ |       ✗ |       ✗ |
| `θ_sel` transition scorer     |       ✗ |      ✓ |       ✓ |     `β` |
| `θ_det` detector              |       ✗ |      ✗ |       ✗ |       ✓ |

这样可以保证：

* actionness head 只由 binary action objective 直接训练；
* ASFormer trunk 学 action state 和 transition；
* detector 不破坏 coarse calibration；
* detector utility 是否有用可以通过 `β=0` 对照单独裁决。

## 7.6 默认 loss 权重与优化器

```text
L_act coefficient       = 1.0
L_tr coefficient        = 0.5
L_cov coefficient       = 0.25
detector loss           = unchanged
detector bridge β_max   = 0.25
structured temperature  = 0.7
```

建议学习率：

| 参数                                   |                    LR |
| ------------------------------------ | --------------------: |
| spatial stem + ASFormer encoder      |              `2.5e-5` |
| ASFormer binary output layers        |                `5e-5` |
| transition scorer                    |                `1e-4` |
| projection / neck / ActionFormerHead |                `1e-4` |
| VideoMAE adapters                    |                `2e-4` |
| VideoMAE base parameters             | `requires_grad=False` |

scheduler 必须以真实 optimizer step 为单位：

```text
5% linear warm-up
cosine decay to step 13200
```

当前训练引擎已经只在 AMP 未跳过 optimizer step 时推进 scheduler 和 DUCA hook，这一点可以保留。

不建议一开始引入 PCGrad/GradNorm。先做显式 gradient routing；只有当：

```text
超过 25% 的采样更新中
cos(g_act, g_transition) < -0.2
且 coarse health 同步恶化
```

才把 trunk-only PCGrad 作为消融，而不是默认主方法。

## 7.7 checkpoint 选择

候选 checkpoint 必须先通过 health gates，再按 detection metric 排序：

```text
coarse AUROC ≥ 0.65
coarse AUPRC ≥ positive prevalence + 0.10
ECE ≤ 0.12
transition recall@4 ≥ exact-uniform + 5 percentage points
exact-K / max-hole violations = 0
no NaN / skipped optimizer anomaly
```

health-pass checkpoint 中：

1. 最大化 validation Avg-mAP；
2. 差值小于 0.1 时，以 mAP@0.7 决胜；
3. test set 不参与 checkpoint 选择。

```python
import torch
import torch.nn.functional as F


def _forward_official_asformer_with_state(
    self,
    features: torch.Tensor,  # [B,C,T]
    mask: torch.Tensor,      # [B,1,T]
) -> tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """Preserve official logits while exposing encoder/decoder states."""

    out, encoder_hidden = self.official_temporal.encoder(features, mask)
    stage_logits = [out]
    previous_hidden = encoder_hidden

    for decoder in self.official_temporal.decoders:
        decoder_input = F.softmax(out, dim=1) * mask[:, 0:1, :]
        out, previous_hidden = decoder(
            decoder_input,
            previous_hidden * mask[:, 0:1, :],
            mask,
        )
        stage_logits.append(out)

    outputs = torch.stack(stage_logits, dim=0)  # [S,B,2,T]
    decoder_hidden = previous_hidden
    return outputs, encoder_hidden, decoder_hidden
```

## 8.2 transition-only scorer

修改或新建：


核心代码：

```python
from __future__ import annotations

import torch
import torch.nn as nn
import torch.nn.functional as F


def _binary_entropy_from_logits(logits: torch.Tensor) -> torch.Tensor:
    p = torch.sigmoid(logits).clamp(1e-6, 1.0 - 1e-6)
    return -(p * p.log() + (1.0 - p) * (1.0 - p).log())


def build_transition_descriptors(
    logits: torch.Tensor,         # [B,T]
    hidden: torch.Tensor,         # [B,T,D], actual ASFormer encoder state
    valid_mask: torch.Tensor,     # [B,T]
) -> torch.Tensor:
    if logits.ndim != 2 or hidden.ndim != 3:
        raise ValueError("expected logits [B,T] and hidden [B,T,D]")
    if hidden.shape[:2] != logits.shape or valid_mask.shape != logits.shape:
        raise ValueError("transition input shape mismatch")

    previous_logits = torch.roll(logits, shifts=1, dims=1)
    previous_hidden = torch.roll(hidden, shifts=1, dims=1)

    entropy = _binary_entropy_from_logits(logits)
    previous_entropy = torch.roll(entropy, shifts=1, dims=1)

    delta_logits = logits - previous_logits
    delta_entropy = entropy - previous_entropy
    delta_hidden = hidden - previous_hidden

    h_now = F.normalize(hidden.float(), dim=-1, eps=1e-6)
    h_prev = F.normalize(previous_hidden.float(), dim=-1, eps=1e-6)
    semantic_change = 1.0 - (h_now * h_prev).sum(dim=-1, keepdim=True)

    descriptors = torch.cat(
        [
            delta_logits[..., None],
            delta_logits.abs()[..., None],
            delta_entropy[..., None],
            delta_entropy.abs()[..., None],
            delta_hidden,
            delta_hidden.abs(),
            semantic_change.to(delta_hidden.dtype),
        ],
        dim=-1,
    )

    pair_valid = valid_mask & torch.roll(valid_mask, shifts=1, dims=1)
    pair_valid[:, 0] = False
    return descriptors.masked_fill(~pair_valid[..., None], 0.0)


class DucaTransitionUtilityAdapter(nn.Module):
    def __init__(self, hidden_dim: int, selector_dim: int = 64) -> None:
        super().__init__()
        descriptor_dim = 2 * int(hidden_dim) + 5
        self.score_head = nn.Sequential(
            nn.LayerNorm(descriptor_dim),
            nn.Linear(descriptor_dim, selector_dim),
            nn.GELU(),
            nn.Linear(selector_dim, selector_dim),
            nn.GELU(),
            nn.Linear(selector_dim, 1),
        )

    def forward(
        self,
        logits: torch.Tensor,
        hidden: torch.Tensor,
        valid_mask: torch.Tensor,
    ) -> dict[str, torch.Tensor]:
        # p/logits used in descriptors are detached so detector/transition
        # losses cannot alter binary output heads through this branch.
        descriptors = build_transition_descriptors(
            logits=logits.detach(),
            hidden=hidden,
            valid_mask=valid_mask,
        )

        auxiliary_scores = self.score_head(descriptors).squeeze(-1)
        policy_scores = self.score_head(descriptors.detach()).squeeze(-1)

        if self.training and not torch.allclose(
            auxiliary_scores.detach(),
            policy_scores.detach(),
            atol=1e-6,
            rtol=1e-5,
        ):
            raise RuntimeError("auxiliary and policy scores must be numerically identical")

        neg = torch.finfo(policy_scores.dtype).min / 4.0
        return {
            "transition_descriptors": descriptors,
            "auxiliary_scores": auxiliary_scores.masked_fill(~valid_mask, neg),
            "policy_scores": policy_scores.masked_fill(~valid_mask, neg),
        }
```

删除或在 main variant 中禁止：

```text

start_head
end_head
context_head
utility_head
radius_head
use_coarse_hidden_features

```

保留一个 score head 即可。

```python
def normalize_valid_scores(scores: torch.Tensor, valid: torch.Tensor) -> torch.Tensor:
    values = scores.masked_fill(~valid, 0.0)
    count = valid.sum(dim=1, keepdim=True).clamp_min(1)
    mean = values.sum(dim=1, keepdim=True) / count
    variance = ((values - mean).square() * valid).sum(dim=1, keepdim=True) / count
    return ((values - mean) / variance.add(1e-6).sqrt()).masked_fill(~valid, 0.0)


def uniform_reference_scores(
    valid_mask: torch.Tensor,
    effective_budget: torch.Tensor,
    dtype: torch.dtype,
) -> torch.Tensor:
    batch, temporal_len = valid_mask.shape
    rows = []

    for batch_idx in range(batch):
        valid_len = int(valid_mask[batch_idx].sum().item())
        k = int(effective_budget[batch_idx].item())
        positions = torch.arange(valid_len, device=valid_mask.device, dtype=dtype)

        if k == 0:
            row = positions.new_zeros(valid_len)
        else:
            targets = (
                (torch.arange(k, device=valid_mask.device, dtype=dtype) + 0.5)
                * float(valid_len)
                / float(k)
                - 0.5
            )
            row = -(positions[:, None] - targets[None, :]).abs().min(dim=1).values

        padded = torch.zeros(temporal_len, device=valid_mask.device, dtype=dtype)
        padded[:valid_len] = row
        rows.append(padded)

    return torch.stack(rows, dim=0)


reference = uniform_reference_scores(valid, effective_k, learned_scores.dtype)
mixed_scores = (
    (1.0 - alpha) * normalize_valid_scores(reference, valid)
    + alpha * normalize_valid_scores(policy_scores, valid)
)

structured = global_structured_topk(
    mixed_scores[:, :valid_len],
    k=effective_k,
    max_unselected_hole=self.max_unselected_hole,
    temperature=self.structured_temperature,
    training=self.training,
)
```

必须满足：

```python
torch.equal(detector_inputs.detach(), hard_gathered_inputs)
```

并且不得退回 unconstrained distance/radius dense resampling。

## 8.6 optimizer coverage 修复

修改：

```text
opentad/cores/optimizer.py
get_backbone_optim_groups()
build_optimizer()
```

被 exclude 且非 custom 的参数应真正冻结：

```python
if is_custom:
    continue

if is_exclude:
    param.requires_grad_(False)
    continue
```

optimizer 构造完成后执行全模型 ID 审计：

```python
def assert_optimizer_exact_coverage(
    model: torch.nn.Module,
    optimizer: torch.optim.Optimizer,
) -> None:
    grouped_ids: list[int] = [
        id(param)
        for group in optimizer.param_groups
        for param in group["params"]
    ]
    grouped_set = set(grouped_ids)

    duplicate_ids = {
        param_id for param_id in grouped_set
        if grouped_ids.count(param_id) > 1
    }
    missing = [
        name
        for name, param in model.named_parameters()
        if param.requires_grad and id(param) not in grouped_set
    ]
    stale = [
        name
        for name, param in model.named_parameters()
        if not param.requires_grad and id(param) in grouped_set
    ]

    if duplicate_ids or missing or stale:
        raise RuntimeError(
            "optimizer coverage failure: "
            f"missing={missing}, stale={stale}, duplicates={len(duplicate_ids)}"
        )
```

这必须在实际 DDP-wrapped full model 上运行，而不是只构造一个带 selector 和 linear head 的测试替身。

## 8.7 one-swap 审计脚本

新增：

```text
tools/bata/audit_duca_one_swap_alignment.py
```

核心定义：

```python
# Base hard set S and detector loss.
loss_base = detector_loss_for_hard_positions(sample, selected_positions)

# Gradient of actual detector loss through the ST bridge.
grad_scores = torch.autograd.grad(
    loss_st,
    policy_scores,
    retain_graph=False,
)[0]

rows = []
for remove_pos, add_pos in feasible_one_swaps(
    selected_positions,
    valid_len=valid_len,
    max_hole=max_unselected_hole,
):
    swapped = sorted(
        (set(selected_positions) - {remove_pos}) | {add_pos}
    )
    loss_swap = detector_loss_for_hard_positions(sample, swapped)

    actual_improvement = float(loss_base - loss_swap)
    predicted_improvement = float(
        grad_scores[remove_pos] - grad_scores[add_pos]
    )

    rows.append(
        {
            "remove": remove_pos,
            "add": add_pos,
            "actual_improvement": actual_improvement,
            "predicted_improvement": predicted_improvement,
        }
    )
```

```text
hierarchical bootstrap CI
```

对照分数：

```text

GT boundary proxy
random
```

其中 GT proxy 只用于诊断上限，不能作为推理方案。

## 10.7 same-selected-frames 几何对照

固定同一个 checkpoint 和同一批 selected positions：

| Geometry                          | heavy frames | detector axis                                       | 目的                      |
| --------------------------------- | ------------ | --------------------------------------------------- | ----------------------- |
| G0 current rank                   | 相同           | K-rank                                              | 当前实现                    |
| G1 physical point centers only    | 相同           | conv 仍是 rank，point/stride 使用 true time              | 判断仅修 assignment 是否够     |
| G2 post-backbone true-time regrid | 相同           | heavy features 插值/splat 到 T=768，再用原 projection/head | 判断 detector geometry 上限 |

G2 最小实现：

```text
selected VideoMAE features [B,C,K]
+ original selected positions
→ linear interpolation / normalized splat to [B,C,T]
→ original official projection / neck / head
→ GT 保持 true-time axis
```

它保留 expensive VideoMAE 的 K 预算，但 projection/head 恢复 dense 计算。必须计入其额外成本。

如果 G2 只提升 @0.6/@0.7，而几乎不改变 @0.3，几何问题基本坐实。

## 10.8 正式全栈成本

当前实现观察完整 768 RGB 后才选择，因此不能声称节省：

```text
bitstream decode
完整窗口数据读取
当前实现下的 full-window H2D
```

只能潜在节省：

```text
heavy VideoMAE
部分 projection/head
GPU activation memory
```

同一硬件、batch=1、固定 warm-up 下分阶段测量：

```text
decode
resize/crop/normalization
collate
H2D
coarse spatial frontend
ASFormer
transition scorer
structured DP
hard gather
VideoMAE
projection
neck
head
true-time remap
NMS/postprocess
end-to-end p50/p95
GPU energy
peak GPU memory
peak host memory
```

break-even：

```math
C_{probe}(T)+C_{selector}(T)+C_{gather}
<
C_{heavy}(T)-C_{heavy}(K)
```

建议成本通过门：

```text
end-to-end p50 saving ≥ 15%
end-to-end p95 saving ≥ 10%
GPU energy saving ≥ 10%
frontend overhead ≤ 40% of saved heavy-backbone latency
peak GPU memory materially lower
```

若 frontend 吞掉 80% 以上 heavy saving，或者 p95/energy 无收益，应否决部署 claim。

# 11. 结果到 claim 矩阵

## 11.1 当前创新性裁决

“低成本浏览全视频→选择少量帧→昂贵模型处理”的一般范式已有广泛先例：AdaFrame、SCSampler、SMART、AR-Net 和 FrameExit 分别覆盖了自适应观察、全视频 salient clip sampling、joint frame selection、端到端资源选择和动态退出。([arXiv][1])

AdaTAD 本身已经把高效端到端 TAD 和大型 VideoMAE backbone 适配作为核心问题；平滑动态规划得到 differentiable top-k/knapsack 也不是新的通用优化原语。([arXiv][2])

因此，当前组合不能依靠以下内容构成 CVPR/ICCV 主创新：

```text
低分辨率 probe
learned frame selection
hard top-k + ST
联合训练
接入 AdaTAD
```

可能成立的独特贡献只能是：

> **面向高 tIoU TAD 的、由 coarse action-state transition 间接驱动的、exact-budget/max-gap 结构化 pre-backbone acquisition，并通过 hard counterfactual utility、物理时间几何和完整系统成本实证证明。**

而当前代码恰恰通过 absolute stem hidden 和 direct endpoint heads 绕过了这条核心假设。因此：

> **当前 `70aa/a5e` 组合的创新性不足以作为 CVPR/ICCV main method。**

这是窄范围 novelty-collision 裁决，不等于已经完成所有 2026 论文的系统综述；但已足以否定“模块组合本身就是贡献”。

## 11.2 结果—claim 对应表

| 最终结果                                                                                 | 允许 claim                                                                             | 不允许 claim                                         |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ | ------------------------------------------------- |
| transition-only 在 3 seeds 上显著超过 exact-uniform，@0.7 提升，one-swap 与成本都过门，并迁移第二 detector | transition-guided、task-aware、structured pre-backbone acquisition；可能 detector-general | 绝对实时、免 decode 成本、streaming                        |
| 只在 AdaTAD 有效                                                                         | AdaTAD-specific acquisition plugin                                                   | model-agnostic / detector-agnostic                |

| `β=0` 与 protected bridge 持平或更好                                                       | boundary-supervised transition selector                                              | detector-utility-calibrated selection             |

# 12. 最终 kill criteria

## 12.1 继续 DUCA 主线

必须同时满足：

1. **matched accuracy**

   ```text
   3-seed ΔAvg-mAP ≥ +0.75 vs exact-uniform
   3-seed ΔmAP@0.7 ≥ +1.0
   paired bootstrap 95% CI lower bound > 0
   ```

2. **coarse/transition health**

   ```text
   AUROC ≥ 0.65
   AUPRC ≥ prevalence + 0.10
   ECE ≤ 0.12
   transition recall@4 ≥ uniform + 5 pp
   ```

3. **gradient validity**

   ```text
   one-swap median Spearman ≥ 0.15
   CI lower bound > 0
   top-10 enrichment ≥ 2× random
   ```

4. **geometry protection**

   ```text
   short-action recall degradation ≤ 1 pp
   @0.7 不出现系统性下降
   max-hole violations = 0
   ```

5. **deployment**

   ```text
   p50 saving ≥ 15%
   p95 saving ≥ 10%
   energy saving ≥ 10%
   frontend ≤ 40% of saved heavy latency
   ```

## 12.2 降级而不完全停止

出现以下情况时降级：

| 结果                                               | 动作                                                         |
| ------------------------------------------------ | ---------------------------------------------------------- |
| no-detector-gradient 持平或更好                       | 永久删除 detector-gradient bridge                              |
| transition-only 有效，但 absolute/direct heads 无额外收益 | 删除所有 direct heads，保留简单 residual transition selection       |
| 只有 regrid 后高 tIoU 才恢复                            | 方法必须包含 physical-time regrid，不得继续称 current selected-axis 正确 |
| 只有 AdaTAD 有效                                     | 收缩为 AdaTAD-specific                                        |
| 精度不优于 uniform，但系统成本显著更低且不劣性成立                    | 改为 accuracy-preserving efficiency 工作                       |
| MobileNet 替换 stem 后才健康且成本过门                      | 将 MobileNet 作为 stem replacement，重新从 fixed-384 完整验证；不能沿用旧结论 |

## 12.3 终止 DUCA 主方法

任一条件满足即停止继续调 loss 或增加 head：

1. 在同 loader、同 13200 updates、同 K_i、同几何下，transition-only 仍：

   ```text
   ΔAvg ≤ -1.0
   或 ΔmAP@0.7 ≤ -1.5
   ```

   相对 exact-uniform，且三 seed 一致。

2. one-swap：

   ```text
   median Spearman ≤ 0
   或 ST top-k 不优于 random/简单 transition
   ```

3. coarse action state经过公平训练仍：

   ```text
   AUROC/AUPRC 接近无信息基线
   transition recall 不优于 uniform
   ```

4. 只有 absolute hidden 或 direct endpoint heads 才能工作。此时应明确写：

   > “粗状态变化足以支持高 tIoU 选帧”的原始科学假设被证伪。

5. full-stack profiler显示：

   ```text
   frontend 消耗 ≥ 80% heavy-backbone saving
   或 p95/energy 无改善
   ```

6. 三 seed 标准差超过约 1.5 Avg-mAP，且不稳定来自 selector policy 而非 evaluator。

7. fixed-384 未形成 accuracy–latency Pareto，却仍试图用 fixed-256/128 或 MUST 掩盖失败。

---

最终技术决定是：

> **把 `a5e1774` 冻结为 current direct-boundary joint baseline；下一版只实现“真实 ASFormer encoder state + transition-only scorer + protected gradient routing + continuous exact-DP homotopy”。在 matched uniform、one-swap、same-selected geometry 和 trained full-stack cost 四项通过前，不启动 dynamic MUST，不增加 MobileNet，不继续添加 selector heads。**
