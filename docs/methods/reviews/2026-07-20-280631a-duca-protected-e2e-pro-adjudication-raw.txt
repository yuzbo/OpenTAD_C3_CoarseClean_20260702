### 3.3 当前 `detach()` 所有权路径是清楚的

`opentad/models/duca/transition_only.py:168–203` 的 `transition_utility_paths` 实际执行：

```python

    actionness_logits.detach(),
```

因此：

* `policy_scores` 对动作 logits 和 ASFormer hidden 都断梯度，只更新 scorer；
* `auxiliary_scores` 对动作 logits 断梯度，但对 hidden 保留梯度，更新 ASFormer trunk 和 scorer；
* 两条路径前向数值被强制要求完全相等。

这是正确的保护基础，但当前没有独立命名的 selector adapter，检测梯度也没有被接通。

### 3.4 当前 `soft_to_hard_resample` 不符合全局可行域

`opentad/models/selectors/duca_online_frame_selector.py:153–196` 中，每个 hard slot 独立地以其已选位置为中心计算局部 softmax：

```python

```

该 `weights[B,K,T]` 没有共同编码：

* slot 间严格单调；
* 同一帧至多被一个 slot 占用；
* exact-K 路径；
* 全局物理最大间隔；
* source-to-first 和 last-to-sink 的边缘覆盖。

多个 slot 的软质量可以落到同一帧，且每个 slot 的局部邻域取决于 detached hard position。它不是 hard 全局选择问题的松弛。

### 3.5 旧 `structured_zero_forward` 不能恢复

### 3.6 可复用的正确张量桥已经存在，但未接入正式路径

`opentad/models/duca/acquisition.py:2119–2186` 已支持真正的全局 slot assignment：


它检查 assignment 形状为 `[B,K,T]`，前向使用 hard gather，反向可经 assignment 传播。

`opentad/models/duca/structured_selection.py:231–360` 也已经包含 exact-K/max-hole 的 hard Viterbi 和同一状态空间上的 soft forward-backward 雏形。hard 路径回溯得到严格 K 个位置，soft 路径计算 slot marginals。

### 5.4 `rho` 臂只开放 ASFormer 最后一个时序块

冻结：

```text
rho = 0.01
```

令 `z_prev` 为最后一个 ASFormer 时序块的输入，`z` 为正常动作/transition 前向输出。第四臂使用：

```python

z_policy = (
    z.detach()
    + 0.01 * (z_replay - z_replay.detach())

```

其前向数值严格等于 `z.detach()`，detector 梯度只进入共享的最后一个时序块参数，不进入更早 block。重放最后 block 时必须通过 `torch.random.fork_rng` 重用冻结 RNG 状态，不能额外推进全局 RNG。

`a_policy=a.detach()` 在第四臂也不改变。

### 5.6 物理 exact-K 可行域

对样本 (b)，由 dense candidate metadata 得到：

```text
candidate ordinal c_t
decoded source frame f_t
physical time q_t = f_t / decoder_fps
```

三种单位均记录，但**秒是规范约束单位**。

先生成精确均匀位置 (U_b)，定义包括左右边缘在内的均匀参考最大物理间隔：

[
G_b=\max \left(
q_{u_1}-q_0,;
\max_k(q_{u_{k+1}}-q_{u_k}),;
q_{L_b-1}-q_{u_K}
\right).
]

合法集合：

[
\mathcal F_b =
\left{
i_1<\cdots<i_{K_{\mathrm{eff}}}:
q_{i_1}-q_0\le G_b,;
q_{i_{k+1}}-q_{i_k}\le G_b,;
q_{L_b-1}-q_{i_K}\le G_b
\right}.
]

因此：

* exact-K：由路径层数保证；
* 唯一：路径不能重复节点；
* 有序：DAG 只允许前向边；
* 最大物理间隔：由 source、内部边和 sink 边共同保证；
* exact-uniform：按 (G_b) 的定义必为显式合法成员；
* 跨区域预算转移：没有“一格一帧”约束，只要全局物理 cap 满足，就可在某一区域选择更密、在另一处以最大合法间隔补偿。

仓库现有 Allocation-Ceiling 已经提供 `PhysicalAxis`、source-frame/seconds cap、三单位 gap report 和 exact-budget validator，应直接复用。

短视频规则冻结为：

```text
valid_len >= 384: 精确选择 384 个不同位置
valid_len < 384: 选择全部 valid frames 一次，K_eff=valid_len；
                 其余 slot 填 -1，mask=False
```

严禁复制帧来凑 K。

### 5.7 唯一批准的 hard/soft 分配：物理 exact-K DAG 的 Gibbs marginals

选择 Prompt 的第二种实现：

> **新建受约束软分配，但复用现有 structured-selection 张量、网格和正式检测路径。**

对同一物理 DAG：

[
P(S)\propto
\exp\left(\sum_{t\in S}\log p_t/\tau_{\text{path}}\right),
\quad S\in\mathcal F_b.
]

hard 路径：

```text
Viterbi argmax over the physical exact-K DAG
```

soft 路径：

```text
forward-backward log-sum-exp over the same DAG
```

输出：

```text
hard_positions Hpos: [B, K]
hard_onehot H:        [B, K, L]
soft_assignment A:    [B, K, L]
```

其中：

[
A_{k,t}=P(i_k=t).
]

必须满足：

```text
A[b,k,:].sum() = 1              对每个 active slot
A.sum(dim=1) <= 1 + 1e-5        每帧期望占用不超过 1
A 对 padding/invalid 位置为 0
E_A[i_k] < E_A[i_{k+1}]         slot 顺序严格单调
A 的支持只来自合法 exact-K 物理路径
```

复杂度为 (O(BKE))，其中 (E) 是物理 cap 下合法 DAG 边数；不采用 (O(BKL^2)) 的全连接传输。

### 5.8 hard-forward/soft-backward

```python
hard = gather_time(dense_video, hard_positions)       # [B,C,K,H,W]
soft = constrained_resample(dense_video, A)           # [B,C,K,H,W]

selected = hard + (soft.to(hard.dtype) -
                   soft.to(hard.dtype).detach())
```

必须满足：

```python
torch.equal(selected.detach(), hard.detach()) is True
```

detector 前向只消费真实 hard 帧；反向通过 `A→log p→s` 更新 selector adapter/scorer。

这直接复用 `acquisition.py` 已有的 `[B,K,T]` assignment 和 `einsum` 接口，不再调用 selector 中的旧局部 resample。

```python
frame_selector.remap_gt_to_selected_axis = False

model.rpn_head.physical_grid_actionformer = dict(
    enabled=True,
    required=True,
    strict=True,
)
```

GT、target assignment、regression decode、proposal、NMS 和 evaluator 全部保持 dense/native physical coordinate。禁止在 head 后再次执行 selected-axis inverse remap。

projection/neck 仍在有序 sparse slot 序列上计算局部特征，这是模型语义的一部分；不得把它宣传为“projection 本身完全物理时间感知”。物理 head 修复的是 target/decode 坐标合同，不是重造检测器。

### 5.10 单阶段总损失

四臂共同的辅助损失权重冻结为：

[
L =
L_{\mathrm{cls}}+
L_{\mathrm{reg}}+
1.0L_{\mathrm{action}}+
0.5L_{\mathrm{transition}}+
0.25L_{\mathrm{transition-boundary}}.
]

受保护臂中，`L_cls+L_reg` 经约束软桥更新 selector。

冻结为 0：

```text
counterfactual utility teacher loss
detector utility distillation loss
soft max-gap penalty
post-hoc repair loss
entropy tuning loss
learnable lambda
policy homotopy/ramp
detector-gradient warmup/ramp
```

硬覆盖由可行域保证；soft 覆盖项不承担合法性，避免再次出现“soft loss 看似通过、hard 决策非法”。

## 10. `P3_HARD_SOFT_ALIGNMENT_GATE`

### 10.1 固定审查状态

P3 在 official-60 前执行，使用：

```text
代码 = 冻结实现提交
配置 = protected_e2e 主配置
模型 = seed 3407 的正式初始化
VideoMAE = 正式预训练权重
detector mode = train objective
optimizer step = 0
loss normalizer = 冻结
数据 = train split only
```

不读取 val/test，不保存可被误认为训练结果的 checkpoint。

### 10.2 固定窗口人口

按以下规则确定 48 个训练窗口：

1. 计算每个窗口最短正 GT action duration；
2. 分为：

   * short：`duration <= 16`
   * medium：`16 < duration <= 64`
   * long：`duration > 64`
3. 每层按
   `SHA256("20260720|video_id|window_start")`
   升序选择 16 个；
4. 同一视频最多贡献 4 个窗口；
5. 若某层不足 16 个，`P3_FAIL`。

GT 只用于 gate 分层和解释，不进入 selector 决策。

### 10.3 软梯度预测

对每个窗口：

1. 执行正式 hard selection (S)；
2. 计算：

[
g_t=\frac{\partial(L_{\mathrm{cls}}+L_{\mathrm{reg}})}{\partial s_t};
]

3. 枚举所有合法单帧交换：

[
S' = S-{i}+{j},
]

要求：

* (i\in S)；
* (j\notin S)；
* exact-K；
* 唯一、有序；
* source/internal/sink 物理 cap 全部满足。

预测方向：

[
\widehat{\Delta}_{i\rightarrow j}=g_j-g_i.
]

负值表示软梯度预测该交换降低 detector loss。

### 10.4 决定性候选采样

对每个窗口将所有合法交换按 (\widehat{\Delta}) 排序，从四个四分位区间各取 3 个：

```text
12 swaps / window
48 windows
576 preregistered swaps
```

每个区间内按
`SHA256(video_id|window_start|i|j|20260720)`
选取，不允许人工挑选。

全零预测、实际 hard set 未变化或非法交换不能计入有效样本，但必须写入排除 ledger。

### 10.5 真实 hard finite difference

对每个交换：

```python
L0 = official_cls_reg_loss(hard_gather(S))
L1 = official_cls_reg_loss(hard_gather(S_prime))
delta_hard = L1 - L0
```

每次候选前恢复：

```text
模型参数
所有 buffer
loss normalizer
CPU RNG
CUDA RNG
Python RNG
NumPy RNG
autocast 状态
```

必须确认：

```text
hard gather 已真实重新执行
detector 输入等于 S' 的 hard tensor
physical target/decode 已执行
没有 soft tensor进入前向值
```

### 10.6 分层报告

每个交换记录：

* action duration stratum；
* incoming `j` 到最近 GT endpoint 的距离：

  * near：`<=4`
  * mid：`5–16`
  * far：`>16`
* full/padded window；
* removed/added frame；
  -三单位物理 gap；
* (\widehat{\Delta})；
* (\Delta_{\mathrm{hard}})。

边界距离每层至少 96 个有效交换；否则 `P3_FAIL`。

### 10.7 统计方法

* 有效总体样本至少 `512`；
* 每个 action-duration 层至少 `128`；
* 按 video 做 cluster bootstrap；
* bootstrap `2,000` 次；
* seed `20260720`；
* 双侧 95% CI；
* 相关性使用每窗口 Spearman，再对窗口中位数做 cluster bootstrap；
* 符号一致只计算预测和实际变化均超过容差者：

```text
abs(predicted_delta) > 1e-10
abs(actual_delta) > 1e-8
```

必须同时满足：

   所有 48 个 base window 和所有 576 个 swapped window：

```text
official-60 forbidden
```

不得降低阈值、换窗口、删除困难层或改用总 loss。

### 10.9 为什么该代理比旧代理可信

新代理的 hard 和 soft 路径共享：

```text
同一 node score
同一 exact-K
同一 physical DAG
同一 source/sink edge
同一合法路径集合
```

soft assignment 是合法 hard 路径分布的 slot marginal；旧局部 bridge 则是围绕 detached hard slot 独立做 softmax，既可能重复帧，也不编码全局 coverage。新代理仍不是离散决策的数学等价梯度，所以 P3 不是形式主义测试，而是必须通过的经验方向门禁。
