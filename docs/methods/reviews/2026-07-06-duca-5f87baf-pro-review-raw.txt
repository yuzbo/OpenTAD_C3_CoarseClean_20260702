## D. P0 / P1 / P2 Findings

### P0 — 必须先修，否则不能 claim

**P0-1 — detector forward 没有接入 TrueTime selector。**
`opentad/models/detectors/single_stage.py:70-110`，`opentad/models/detectors/two_stage.py:70-115`。`forward_train` 仍然是 `inputs -> backbone -> projection -> neck -> rpn/roi head`；`forward_test` 也是直接前向，没有 `build_selector`、没有 selector call、没有 selector loss merge。影响：**不能称为 end-to-end，不能称 detector loss backpropagates to selector。** 修复：在 detector 初始化中构建 selector，在 `forward_train/forward_test` 最前面调用 selector，并将 selector losses 与 detector losses 合并。([GitHub][11])

**P0-2 — selected-axis proposal 没有在 post-processing 前强制 remap 到 physical/true time。**
`single_stage.py:147` 附近、`two_stage.py:post_processing`。当前 `segments = convert_to_seconds(segments, metas[i])` 直接使用 head 输出 segments；若 head 输出仍是 selected-rank / selected-axis 坐标，NMS 与 mAP 会在错误时间轴上评估。影响：**high-IoU mAP 结论不可信。** 修复：在 NMS 前做 `selected_axis -> true_time_dense_index -> seconds` 的显式 roundtrip，并加 validator。([GitHub][11])

**P0-3 — TrueTime metadata 写错 selected valid length。**
`opentad/models/selectors/truetime_joint_selector.py:1406-1427`。代码写入 `irregular_selected_valid_len = dense_valid_len`，但 selected valid len 应该是 `len(positions)` 或 selected mask 的有效长度；dense valid len 应作为另一字段保留。影响：下游 point generator / mask / decoder 若读取 selected valid len，会把稀疏序列当成 dense 长度，产生 assignment/decode 错误。修复：

```python
meta["irregular_dense_valid_len"] = dense_valid_len
meta["irregular_selected_valid_len"] = len(positions)
meta["irregular_selected_count"] = len(positions)
```

## E. Leakage Audit

当前代码有明显的 fail-closed 意识：teacher utility 训练要求 `split_scope=train_only`，Stage4 validator 要求 claim locks 和 leakage locks，TrueTime selector 也拒绝 GT/teacher metadata 进入 eval selection。([GitHub][12])

但仍有 P0 泄漏风险：deploy strip/check 不是递归的，且 forbidden keys 不完整。`signed_frame_utility` 可以作为 top-level 字段存在；`teacher_scores`、`teacher_proposals`、`actionformer_*`、`prediction_cache` 也没有在 detector-aware deploy list 中统一出现。必须改成递归扫描：

```python
FORBIDDEN_PATTERNS = (
    "gt", "ground_truth", "oracle",
    "teacher", "utility", "signed_frame_utility",
    "proposal", "logit", "prediction", "prediction_cache",
    "raw_prediction", "dense_teacher",
)

def assert_no_forbidden_payload(obj, path="root"):
    if isinstance(obj, dict):
        for k, v in obj.items():
            lk = str(k).lower()
            if any(tok in lk for tok in FORBIDDEN_PATTERNS):
                raise ValueError(f"forbidden key at {path}.{k}")
            assert_no_forbidden_payload(v, f"{path}.{k}")
    elif isinstance(obj, list):
        for i, v in enumerate(obj):
            assert_no_forbidden_payload(v, f"{path}[{i}]")
```

## F. Time-coordinate Audit

当前最大风险不是 selector 本身，而是 **selector 输出稀疏 selected-axis 后，detector 的 assignment/decode/NMS/mAP 是否仍在 physical time 上**。`TrueTimeRelaxedHardTopKSelector` 明确保存 `selected_axis_to_true_time_dense_index` 和 `detector_prediction_inverse_map_required=True`，这是好方向；但 detector post-processing 仍直接 `convert_to_seconds(segments, metas[i])`，没有看到 inverse map 在 NMS 前被调用。([GitHub][10])

必须新增一个强制 remap 函数，并在 head decode 后、NMS 前执行：

```python
def selected_axis_segments_to_true_time(segments, meta):
    mapping = meta.get("selected_axis_to_true_time_dense_index")
    if mapping is None:
        if meta.get("detector_prediction_inverse_map_required"):
            raise ValueError("missing selected_axis_to_true_time_dense_index")
        return segments

    map_t = torch.as_tensor(mapping, dtype=segments.dtype, device=segments.device)
    max_rank = len(mapping) - 1
    left = segments[:, 0].clamp(0, max_rank)
    right = segments[:, 1].clamp(0, max_rank)

    def interp(x):
        lo = torch.floor(x).long()
        hi = torch.ceil(x).long()
        w = x - lo.to(x.dtype)
        return map_t[lo] * (1 - w) + map_t[hi] * w

    out = torch.stack([interp(left), interp(right)], dim=-1)
    if bool((out[:, 1] < out[:, 0]).any()):
        raise ValueError("invalid remapped segment order")
    return out
```

## G. Budget / Dynamic Policy Audit

当前 dynamic budget 只能叫 **rank-derived dynamic bucket**，不能叫 calibrated dynamic budget。训练端 target 是每个视频内部 utility 排序后覆盖 80% mass；应用端又通过 `decode_budget_from_scores` 选 bucket。这会导致预算随视频内部分布变化，而不是根据跨视频可比较的 marginal utility threshold 变化。([GitHub][12])

建议改成：

```python
@dataclass
class BudgetCalibrator:
    thresholds: dict[int, float]   # budget -> marginal gain threshold
    split: str = "train"

def fit_budget_calibrator(train_rows, buckets):
    # 只用 train split teacher utility
    examples = []
    for row in train_rows:
        u = row["signed_frame_utility"]
        gains = sorted([max(x, 0.0) for x in u], reverse=True)
        for b in buckets:
            examples.append((b, gains[min(b - 1, len(gains) - 1)]))
    return BudgetCalibrator(
        thresholds={b: float(np.median([v for bb, v in examples if bb == b])) for b in buckets}
    )

def decode_calibrated_budget(predicted_gain_curve, calibrator, buckets):
    # val/test/deploy 只能用模型预测，不读 teacher
    for b in sorted(buckets):
        if predicted_gain_curve[b - 1] < calibrator.thresholds[b]:
            return b
    return max(buckets)
```

### 3. detector-aware selector loss

```python
def detector_aware_selector_loss(outputs, target, valid):
    pred_u = outputs["utility_pred"]
    pred_gain = outputs["gain_pred"]
    pos = target["positive_observation_gain"]
    neg = target["negative_observation_risk"]

    mask = valid.float()
    utility_loss = ((pred_u - target["signed_frame_utility"]) ** 2 * mask).sum() / mask.sum().clamp_min(1)
    gain_loss = F.smooth_l1_loss(pred_gain[valid], pos[valid], reduction="mean")

    selected = outputs["hard_mask"]
    selected_pos_gain = -(selected * pos * mask).sum(dim=1).mean()
    selected_neg_risk = (selected * neg * mask).sum(dim=1).mean()

    budget_loss = F.cross_entropy(outputs["budget_logits"], target["budget_class"])
    return utility_loss + gain_loss + selected_pos_gain + 0.5 * selected_neg_risk + 0.25 * budget_loss
```

```python
def sparse_detector_distill_loss(sparse_out, dense_out, meta):
    sparse_segments_true = remap_selected_axis_segments(sparse_out["segments"], meta)
    dense_segments_true = dense_out["segments"].detach()

    cls_kl = F.kl_div(
        F.log_softmax(sparse_out["logits"], dim=-1),
        F.softmax(dense_out["logits"].detach(), dim=-1),
        reduction="batchmean",
    )

    boundary_l1 = match_and_l1(sparse_segments_true, dense_segments_true)
    quality_loss = F.mse_loss(sparse_out["quality"], dense_out["quality"].detach())
    return cls_kl + boundary_l1 + 0.5 * quality_loss
```

### 5. result-to-claim validator

```python
def validate_claim_unlock(result):
    required = ["dense_adatad", "uniform_384", "random_384_seeded", "duca_384", "duca_dynamic"]
    for key in required:
        if key not in result:
            raise ValueError(f"missing experiment: {key}")

    if result["duca_384"]["map_0_7"] < result["uniform_384"]["map_0_7"] - 0.5:
        raise ValueError("high-IoU localization not protected")

    if result["duca_dynamic"]["flops"] >= result["dense_adatad"]["flops"]:
        raise ValueError("compute reduction not demonstrated")

    return {
        "sparse_acquisition_improves_tad_map_claim_allowed": True,
        "high_iou_protected_claim_allowed": True,
    }
```

## L. Final Claim Gate

| Claim                               |              当前能否说 | 解锁条件                                                                                                     |
| ----------------------------------- | -----------------: | -------------------------------------------------------------------------------------------------------- |
| sparse acquisition improves TAD mAP |             **不能** | 完整 dense/uniform/random/GAS-VT/detector-aware mAP matrix，多 seed，含 mAP@0.6/0.7。                           |
| detector-aware acquisition          | **只能弱称 prototype** | 真实 AdaTAD dense teacher utility export，train-only，observable-only selector 显著优于 p_action/GAS-VT。         |
| end-to-end                          |             **不能** | selector 接入 detector forward，真实 detector loss backward，selector grad_norm > 0，full detector training 可跑。 |
| dynamic budget                      | **不能称 calibrated** | train-only global calibration，val/test/deploy 冻结 threshold，rank-only dynamic ablation。                   |
| CVPR-ready                          |             **不能** | 需要完整实验、消融、计算收益、高 IoU 保护、泄漏审计、统计显著性。                                                                      |
| high-IoU localization protected     |             **不能** | mAP@0.6/0.7 不低于 strong uniform/random baseline，且有边界 support / short action breakdown。                    |

论文故事可以成立，但当前版本还没到。最合理的故事是：

**TAD 的 pre-backbone sparse acquisition 不能只学 actionness，因为 TAD 的价值不等于“哪里像动作”：边界、短动作、易混背景、false positive suppression、上下文 disambiguation 都可能对 high-IoU localization 更重要。DUCA 的创新点应是用 dense detector 的 train-only observation utility 教 selector 预测 detector-specific value，再用 TrueTime sparse detector 保持物理时间坐标。**

若 mAP 不提升，可以收缩为 negative study：证明 actionness/p_action sparse acquisition 对 high-IoU TAD 不充分，并给出 detector-utility、时间坐标、budget calibration 的诊断协议。若 mAP 提升，主贡献才应写成：**detector-utility-calibrated temporal acquisition with true-time sparse detection for compute-efficient high-IoU TAD**。
