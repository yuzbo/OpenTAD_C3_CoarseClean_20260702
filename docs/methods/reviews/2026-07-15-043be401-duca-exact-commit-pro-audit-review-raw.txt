# C. 真实模型结构与训练/推理数据流

## C.1 输入与粗模型

配置首先解码完整的 768 帧窗口，而不是只解码 384 帧；训练和测试 pipeline 都在 selector 之前执行 Decord 解码、resize/crop 和 tensor 化。因此当前方法只可能节省重 backbone 计算，**不节省视频解码和完整 768 帧图像预处理成本**。

典型张量：

```text
输入 RGB:
    x_dense: [B, 1, 3, 768, 160, 160]
    mask:    [B, 768]

coarse probe view:
    [B, 768, 3, 64, 64]

spatial stem:
    [B, 96, 768]

ASFormer:
    actionness_logits a: [B, 768]
    encoder_hidden h:    [B, 768, 96]
```

粗模型由本仓库自定义的两层卷积 spatial stem，加外部 ASFormer `MyTransformer` 组成；ASFormer 被构造为两类逐时刻输出，`actionness_logit = class_1_logit - class_0_logit`。encoder hidden 通过 forward hook 取得。

## C.2 transition descriptor

`H=96` 时，每个时刻的 transition descriptor 为 `2H+5=197` 维：

[
d_t =
[
\Delta a_t,\ |\Delta a_t|,\
\Delta H(p_t),\ |\Delta H(p_t)|,\
\Delta h_t,\ |\Delta h_t|,\
1-\cos(h_t,h_{t-1})
].
]

其中：

* `a_t` 是 actionness logit；
* `p_t = sigmoid(a_t)`；
* `H(p_t)` 是二元熵；
* `h_t` 是 ASFormer encoder hidden；
* 不包含 absolute hidden；
* 不包含 raw RGB mean；
* 不包含直接 start/end logits。

关键 stop-gradient：

```text
a_t ── detach ──→ descriptor
h_t ────────────→ auxiliary descriptor
descriptor ── detach ──→ policy scorer route
descriptor live ───────→ auxiliary transition route
```

因此：

* transition loss 不回传到 actionness logits；
* transition auxiliary loss可回传到 ASFormer hidden trunk；
  -实际选帧 policy 路径只更新 transition scorer，不通过 policy loss直接更新粗模型。

## C.3 “是否只有二分类状态”裁决

**不是严格意义上的“粗模型只学习二分类状态”。**

代码确实没有启用 direct-a5 的 `start_logits/end_logits/context_logits`，但 transition-only 每个训练样本仍由 GT segment 的起点和终点生成固定 `σ=2、truncate_radius=4` 的 Gaussian transition density，并对 transition auxiliary score施加分布损失；同时对结构化 soft occupancy 施加 boundary-mass coverage loss。

准确表述应为：

> 粗 actionness head 只做动作/背景二分类；共享 ASFormer hidden 和 transition scorer 另外接受 train-only GT endpoint-density supervision，但不直接预测可部署的 start/end 坐标。

不得写成：

> 整个低成本模型只学习二分类状态、没有任何边界监督。

后者与代码不符。

## C.4 selector 实际输入与梯度

| 信息                              |        selector 是否看到 | 用途                          | 梯度                                            |
| ------------------------------- | -------------------: | --------------------------- | --------------------------------------------- |
| `p_action`                      |                   间接 | 由 logits 构造 entropy         | action logit 在 transition descriptor 前 detach |
| `Δ actionness logit`            |                    是 | descriptor                  | policy 路径只到 scorer；aux 路径不回 action head       |
| `abs Δ logit`                   |                    是 | descriptor                  | 同上                                            |
| entropy delta/abs-delta         |                    是 | descriptor                  | 同上                                            |
| ASFormer hidden delta/abs-delta |                    是 | descriptor                  | aux transition loss可更新 ASFormer trunk         |
| hidden cosine change            |                    是 | descriptor                  | 同上                                            |
| absolute hidden                 |                    否 | 明确禁止                        | 无                                             |
| raw RGB descriptor              |    transition-only 否 | 仅 coarse spatial stem读取 RGB | transition scorer 不直接读取                       |
| GT start/end                    |    训练时通过 target 间接看到 | transition density/coverage | 不用于推理 decision                                |
| detector one-swap utility       | counterfactual 训练臂看到 | detached distillation       | 只更新 scorer                                    |
| teacher/oracle/cache            |                  推理否 | fail-closed                 | 无                                             |

## C.5 结构化选择

每个样本单独计算：

```text
V_b     = valid prefix length
K_eff,b = min(384, V_b)
G       = max_unselected_hole = 15
```

硬解码：

[
S_b^\star =
\arg\max_{S\subseteq{0,\ldots,V_b-1}}
\sum_{t\in S}\ell_t,
\quad
|S|=K_{\mathrm{eff},b},
\quad
\max \text{hole}(S)\le 15.
]

soft forward-backward 使用相同的：

* `V_b`
* `K_eff,b`
* `G=15`
* exact-K/max-gap feasible family。

当前提交专门修复了 short-window 下 soft slots 使用 requested `K=384` 而非 `K_eff` 的问题。无效 slots 被严格清零。

因此问题 5 的答案是：

> **是，当前 commit 的 hard decode 与 relaxed DP 在每个样本上共享相同 valid prefix、effective K、max-hole 和 feasible family。**

## C.6 exact-uniform

uniform anchor 明确由：

[
u_j = \operatorname{round}
\left(
j\frac{V-1}{K_{\mathrm{eff}}-1}
\right),\quad
j=0,\ldots,K_{\mathrm{eff}}-1
]

生成，并转换为到 anchor 的 reference score；不是依赖 DP tie-break 偶然得到的“近似均匀”。`K_eff=V` 时选全部有效时刻。

因此问题 6 的答案是：

> **是，当前 exact-uniform 对每个有效长度对应明确的 endpoint rounded-linspace reference。**

formal gate validator也明确要求 `round_linspace_endpoints`、exact equality 和 rank error 0。

## C.7 `structured_zero_forward`

其数学形式是：

[
x_{\text{out}}
==============

x_{\text{hard}}
+
\beta
\left(
x_{\text{soft}}-
\operatorname{sg}(x_{\text{soft}})
\right).
]

前向值精确等于硬选帧；反向梯度按 soft slot assignment传播。

但是代码本身已把它标为：

> legacy local surrogate；不能作为 detector-utility evidence。

正式 transition beta0 和 counterfactual 配置均令 `detector_gradient.end=0`，并使用 `st_sparse_gather`，所以 detector loss 不经过该桥更新 scorer。

准确术语：

* direct-a5：后期使用 local straight-through detector surrogate；
* transition beta0：无 detector-derived selector learning；
* transition counterfactual：**detached detector-derived one-swap utility distillation**；
* 不能把 counterfactual 写成“detector gradient directly backpropagates into selector”。

## C.8 Counterfactual teacher

实际集成路径是：

```text
先完成 hard selector
→ 构造最多 4 个可行 one-swap candidate/样本
→ 保存 detector 非 selector buffers、CPU/CUDA RNG
→ freeze ActionFormer loss_normalizer
→ no_grad + AMP cache_disabled
→ 对 baseline selection 重跑完整 detector train objective
→ 对每个 candidate 重跑完整 detector train objective
→ utility = baseline_cls_reg_loss - candidate_cls_reg_loss
→ restore buffers/RNG
→ detached utility distill 到 add_score - remove_score
→ 再建立正常主 detector autograd 图
```

utility 符号本身正确：

[
U_m=L_{\mathrm{base}}-L_{\mathrm{swap},m}.
]

正值表示 swap 降低 detector loss。

teacher objective只包含 `cls_loss + reg_loss`，不包含 selector losses。其 buffer、随机数状态、loss normalizer 和 autocast cache处理是严谨的。

但蒸馏损失存在 P1，见 F/K。

## C.9 真正被 detector 消费的内容

是原始 RGB 的硬 gather：

```text
x_selected = gather(x_dense, selected_positions)
```

而不是缓存 backbone feature、逻辑 mask 或伪 sparse grid。选中后才进入 VideoMAE。ActionFormer 主路径为 selector→backbone→projection→neck→head。

但是 detector 几何是：

1. GT segment 从 dense true-time axis 映射到 compressed selected-axis；
2. ActionFormer 卷积、attention、FPN、point assignment 和回归在单位间隔 selected-axis 上执行；
3. proposal 在 NMS 前再线性映射回 true-time。

映射代码严格检查 selected positions 单调、有效，并使用 piecewise-linear true↔selected map。

所以：

* target 与 prediction 坐标前后是一致的；
* 但 detector 感受野和 assignment 的物理时间跨度会随局部采样密度变化；
* 这不是 remap bug，而是当前方法的重要机制混杂。

## F.2 P1-01：官方 test split被重复用于中间评估，primary checkpoint未冻结

**位置**

**复现条件**

* workflow每 5 epoch进行一次 mAP eval；
* post-run contract允许：
  `same_workflow_best_or_final_declared`；

* 即使四臂采用同一规则，也不能消除 test leakage；
* 当前代码不自动根据 mAP保存 best，但合同允许事后“best or final declared”，人为选择空间未封死。

**裁决**

* 当前作业无需取消；
* 必须在首次 mAP出现前冻结：**唯一 primary result = epoch 132 的 EMA state**；
* 所有中间 mAP只能标为 diagnostic，不得参与 checkpoint selection；
* 推荐补丁见 K.1。

## F.3 P1-02：counterfactual 蒸馏没有 no-op baseline，丢失 utility 的正负号

**位置**

```text
opentad/models/duca/counterfactual_utility.py:130-154
opentad/models/selectors/duca_online_frame_selector.py:720-768
```

当前损失只在候选 swaps之间执行：

[
\operatorname{CE}
\left(
\operatorname{softmax}(U_1,\ldots,U_M),
\operatorname{softmax}(\Delta s_1,\ldots,\Delta s_M)
\right).
]

没有加入 `U_0=0` 的“保留 baseline、不进行 swap”类。

**复现条件**

例如所有候选都有害：

```text
U = [-2.0, -1.0]
```

当前 target softmax仍要求 student偏好第二个有害 swap，而不是把两个 swap都压到 baseline以下。

**影响**

* loss只学习“候选之间谁相对较少有害”；
* 不学习“这个 swap是否应该相对 baseline被接受”；
* `counterfactual detector utility` 的 signed semantics不成立；
* 当前 C4只能解释为：

> relative hard-swap ranking distillation

不能解释为：

> 学习 detector loss reduction 的有符号 utility。

**裁决**

* 当前 counterfactual作业仍是一个可解释的 ranking arm，不必取消；
* 若 C4要成为论文主贡献，必须使用带 no-op anchor的下一提交重跑；
* 补丁见 K.2。

**复现**

开启 formal transition config，即固定生成 GT endpoint Gaussian并施加 transition distribution和coverage loss。

**影响**

这是 claim错误而非运行错误。论文必须称为：

```text
binary action-state supervision
+ endpoint-derived transition-density supervision
```

而不是纯 binary-state-only。

## F.5 P2-02：selected-axis detector geometry是重要机制混杂

**位置**

```text
opentad/models/selectors/duca_online_frame_selector.py:1698-1732
opentad/models/utils/truetime_geometry.py:48-131
opentad/models/dense_heads/anchor_free_head.py:209-250
configs/.../duca_transition_only...py:166-210
```

**复现**

构造局部稀疏和局部密集的 selected positions。GT被映射到 `[0,K)`，而 ActionFormer 的卷积、FPN stride和center sampling仍按 selected-axis单位执行。

**影响**

learned selector即使更接近真实边界，也可能因局部非均匀采样扭曲 detector receptive field和assignment，反而输给均匀采样。这可以解释 oracle–uniform–learned gap的一部分。

**否证诊断**

同一 selection固定不变，比较：

1. selected-axis现有头；
2. physical-time-aware point/stride head；
3. uniform selection。

若 learned selector只在 physical-time头上恢复，问题在 detector geometry，不在 selector rank本身。

## F.6 P2-03：`transition_boundary_coverage_loss` 不是精确“至少命中一个边界”的概率

**位置**

```text
opentad/models/duca/transition_only.py:312-365
opentad/models/duca/acquisition.py:2853-2879
```

实际为：

[
L_{\text{mass}}
===============

\sum_t \bar q_t
\exp
\left[
-\sum_{|i-t|\le r}\pi_i
\right].
]

这是局部 occupancy mass 的 Poisson-style surrogate，不是：

[
P(\exists i\in \mathcal N(t):i\text{ selected}).
]

**影响**

* 在 `K/T≈0.5` 时容易快速饱和；
* transition target自身截断半径4，coverage又用半径4，单个 endpoint对最远约8格的 soft occupancy产生作用；
* 可能鼓励宽泛局部质量而非精确边界命中。

当前实现可以使用，但命名和论文解释必须准确。

## F.7 P2-04：四臂训练计算量严重不等，尤其是 counterfactual 和 direct

**位置**

```text
opentad/models/detectors/actionformer.py:303-376
opentad/models/selectors/duca_online_frame_selector.py:1260-1427
configs/.../duca_direct_boundary...py:45-59
```

### Counterfactual 上界

`B=2`、每样本最多4个候选时：

```text
每样本：1 baseline + 最多4 candidate
整个 batch：最多10个 singleton detector forward
再加1个正常 B=2 main forward
```

按 sample-forward计：

```text
counterfactual: 最多 12 sample-forwards
beta0:          2 sample-forwards
上界约 6× detector training sample compute
```

这不是推理成本，但必须单列训练成本。

### Direct-a5

direct继承 `structured_zero_forward` 并将 detector-gradient weight从0升到1。该桥对 dense raw video做 `[B,K,T]` soft slot resampling，代码自己将复杂度记录为：

```text
O(numel(dense_raw_video) × K)
```

这显著高于 transition beta0，不能用“相同 optimizer steps”代替“相同训练计算”。

所以 C4 **只能识别当前 ranking objective，不能识别更强的“detector utility learning”主张**。

> 面向 TAD 的结构化选帧工程系统，以及对旧 DUCA失败机制的严谨修复。

# J. 推荐的唯一主方案及完整目标

## J.1 唯一推荐

**保留当前 transition-only 主体，但将 counterfactual 改为带 no-op baseline 的 signed hard-swap distillation；不恢复 direct detector ST bridge，不引入 dynamic budget。**

部署 score：

[
s_t=g_\theta!\left(\operatorname{sg}(d_t)\right).
]

训练 auxiliary score：

[
\tilde s_t=g_\theta(d_t^{\text{aux}}),
]

其中 actionness logit仍 detach，ASFormer hidden可接收transition auxiliary gradient。

policy homotopy：

[
\ell_t(\alpha)
==============

(1-\alpha),\operatorname{zscore}(u_t)
+
\alpha,\operatorname{zscore}(s_t).
]

hard policy：

[
S^\star=\arg\max_{S\in\mathcal F(V,K,G)}
\sum_{t\in S}\ell_t.
]

## J.2 当前保留的监督

动作状态：

[
L_{\text{act}}
==============

\frac{1}{|\mathcal V|}
\sum_{t\in\mathcal V}
\operatorname{BCEWithLogits}(a_t,y_t).
]

transition distribution：

[
L_{\text{tr}}
=============

-\sum_t q_t
\log
\operatorname{softmax}\left(\frac{\tilde s}{\tau_{\text{tr}}}\right)_t.
]

soft occupancy coverage：

[
L_{\text{cov}}
==============

\sum_t\bar q_t
\exp
\left(
-\sum_{|i-t|\le r}\pi_i
\right).
]

## J.3 推荐的 anchored counterfactual

候选 `m`：

[
U_m
===

\operatorname{sg}
\left[
L_{\mathrm{AF}}(S^\star)
------------------------

L_{\mathrm{AF}}(S_m)
\right],
]

[
\Delta s_m=s_{\mathrm{add}(m)}-s_{\mathrm{remove}(m)}.
]

加入 no-op：

[
U_0=0,\qquad \Delta s_0=0.
]

[
L_{\text{CF}}
=============

\operatorname{CE}
\left(
\operatorname{softmax}\frac{[0,U_1,\ldots,U_M]}{\tau_{\text{CF}}},
\operatorname{softmax}\frac{[0,\Delta s_1,\ldots,\Delta s_M]}{\tau_{\text{CF}}}
\right).
]

这样：

* 所有 swaps有害时，student被训练为把所有 swap score压到 no-op以下；
* 所有 swaps有益时，student会提升有效 swap；
* utility正负语义被保留；
* 仍然没有 detector gradient estimator的虚假主张。

总目标：

[
\boxed{
L =
L_{\mathrm{AF,cls}}
+
L_{\mathrm{AF,reg}}
+
L_{\mathrm{act}}
+
0.5L_{\mathrm{tr}}
+
\lambda_{\mathrm{cov}}L_{\mathrm{cov}}
+
0.25L_{\mathrm{CF}}
}
]

其中：

* `λ_cov` 当前在第一个成功step后基本为0.25；
* `α` 在660步 uniform warmup后，用3960步 cosine ramp到1；
* counterfactual teacher仍只在训练时存在；
* inference只执行 coarse probe、scorer、hard DP和一次 detector。

## M.2 当前四臂跑完后的 seed-0 gate

### C3：transition beta0 − exact-uniform

进入三种子正式验证需同时满足：

[
\Delta \mathrm{Avg\ mAP}\ge +0.5
]

且：

[
\Delta \mathrm{mAP@0.7}\ge 0
]

* 短动作 mAP不下降超过1个百分点；
* endpoint r1 recall不下降超过2个百分点；
* paired-video bootstrap 中 `P(ΔAvg>0) ≥ 0.95`。

若：

```text
ΔAvg <= 0 且 ΔmAP@0.7 <= 0
```

则 **KILL 当前 learned transition主路线**，不进行温度/权重/半径网格搜索。

只允许一个机制诊断：

```text
non-learned abs-delta + entropy + cosine proxy
```

用来判断失败来自 scorer优化还是母假设本身。

### C4：counterfactual − beta0

当前 ranking arm进入下一步需：

[
\Delta \mathrm{Avg\ mAP}\ge +0.3,
\qquad
\Delta \mathrm{mAP@0.7}\ge 0.
]

同时要求：

* utility与student pair score的 Spearman为正；
* informative candidate比例足够；
* candidate utility不是几乎全零；
* wall-clock和峰值显存完整报告。

* 不扫 temperature、candidate count、weight；
* 只运行一次 K.2 的 anchored signed-CF修正版；
