### 9.6 P1：direct public API 的 lexical path closure 不完整

`_validate_registered_source_file` 只检查最终 leaf：

```python
if path.is_symlink() or not path.is_file():
```

随后直接 `path.read_bytes()`。

而 `_validate_repository_context` 一开始：

```python
root = Path(repository_root).resolve()
```

这会洗掉 caller 提供的 lexical parent symlink。

**攻击**

```text
/tmp/alias_repo -> /real/registered_repo
validate_pre_gate1_registration(repository_root="/tmp/alias_repo", ...)
        ↓
.resolve() => /real/registered_repo
        ↓
lexical alias provenance 消失
```

更严重的是，`root/subdir -> outside` 时，`root/subdir/file.py` 的 leaf 自身不是 symlink，`is_file()` 为真。若外部字节与 Git blob 相同，当前 leaf 检查无法证明所有 parent components 都是 regular directories。

### 12.4 全局 seed-cluster 反例

## 14. Runtime / AdaTAD / VideoMAE Upstream Matrix

### 14.1 768-point data flow

```text
dataset window: 768 frames
→ decode / preprocess / H2D
→ VideoMAE patch embedding
→ 48 independent 16-frame clips
→ tubelet=2, internal 384 temporal points
→ 12 VideoMAE blocks grouped [0:4]/[4:8]/[8:12]
→ per clip×group action:
    RECOMPUTE: original heavy attention+MLP
    HOLD: cached latest pre-adapter heavy output
    TRANSPORT: T(latest_detached, current, age_cap)
→ reconstruct complete row tensor
→ AdaTAD temporal adapter over all rows
→ backbone output
→ interpolation/projection/ActionFormer
→ external detector grid 768
→ official postprocess/NMS
```

### 14.2 Action semantics

| Action    | Heavy path            | Cache                                             | Current-row gradient                 | 下一 block       |
| --------- | --------------------- | ------------------------------------------------- | ------------------------------------ | -------------- |
| RECOMPUTE | 执行                    | anchor/latest 更新为 detached live output；age=0      | live                                 | adapter output |
| HOLD      | 跳过                    | latest 不变；age+1                                   | 历史 cache detached，无当前 heavy gradient | adapter output |
| TRANSPORT | 跳过 heavy，执行 transport | latest 更新为 detached transported live output；age+1 | 当前 transport row live                | adapter output |

Cache 的 hard validity 47 与 age embedding cap 8 已分离。

Transport 使用：

```text
innovation = current - cached
down_proj + age_embedding + norm/GELU
bounded residual
return cached + tanh(gate) * correction
```

### 14.3 Upstream classification

| 组件                                             | 分类                      | 说明                                                         |
| ---------------------------------------------- | ----------------------- | ---------------------------------------------------------- |
| VideoMAE patch embedding                       | `WRAPPED`               | CT 构造在 fork backbone 内                                     |
| VideoMAE heavy blocks                          | `STRUCTURALLY_MODIFIED` | mixed CT path gather/skip/transport；forced dense 直接原 block |
| AdaTAD adapter                                 | `WRAPPED`               | mixed path 重建全 rows 后调用 adapter                            |
| Projection                                     | `WRAPPED`               | fork 中继续执行                                                 |
| ActionFormer head                              | `WRAPPED`               | fork head；Stage-C 尚未暴露 per-window vector                   |
| ChronoTransport cache/transport/risk/scheduler | `CUSTOM`                | 项目新增                                                       |
| 官方 upstream exact tree equality                | `CANNOT_VERIFY`         | 本轮没有对三个 upstream commits 做完整 tree diff                     |

ViT integration 当前确实在 backbone forward 内调用唯一 `ChronoTransportRuntime`。

## 17. Adversarial Counterexamples and RED Tests

### 17.1 Stage percentile 相加是假 total p95

```text
sample 1: decode=10, model=0, total=10
sample 2: decode=0,  model=10, total=10
```

各 stage p95 约为 10，相加得 20；真实 total distribution 的 p95 始终是 10。

### 17.2 requested cost 冒充 repaired executed cost

```text
requested schedule cost = 5 ms
budget = 10 ms
runtime repairs to dense
executed dense cost = 20 ms
```

用 requested cost 会得到假 budget success；必须用 executed identity/cost，并将 repaired formal evidence 标 invalid。

### 17.3 Seed cluster 被错误平均

见第 12.4 节。每 window 重抽 seed 可把真实 cluster-level FAIL 变为假 PASS。

### 17.4 Equal-score AP

见第 15.3 节。自写 tie handling 可把 AP 0.5 变成 1.0。

### 17.5 A4 forward count

```text
required: model_forwards == 2
current invariant: model_forwards == 1
```

不存在兼容解释。

### 17.6 A3 normalizer transaction

假设：

```text
before = 100
dense forward → 91
restore → 100
CF forward → 91
success persists → 91
```

当前 success buffer equality要求最终仍为 100，因此合法更新被拒绝。overflow则必须回到 100，只允许 scaler backoff保留。

### 17.7 Parent symlink

```text
repo/subdir -> /tmp/external
repo/subdir/file.py has exact registered bytes
```

leaf `file.py` 不是 symlink，`is_file()` 为真；没有逐 component `openat(O_NOFOLLOW)` 就无法证明 lexical path。


这是已正确封闭的攻击，不应削弱。

### 21.4 Stage-C A3/A4 production bridge

```python
from dataclasses import dataclass
from typing import Mapping
import torch
from torch import Tensor


@dataclass(frozen=True)
class ActionFormerPerWindowTrainOutput:
    loss_dict: Mapping[str, Tensor]
    per_window_task_loss: Tensor
    detector_features: Tensor

    def validate(self, *, expected_batch: int = 2) -> None:
        if set(self.loss_dict) != {"cls_loss", "reg_loss", "cost"}:
```

```text
snapshot state/RNG/normalizer
dense:

    dense_task_loss.shape == [2]

counterfactual:
    differentiable model forward exactly once
    cf_task_loss.shape == [2]
    detector_loss = unchanged official batch reduction
risk:
    target = clamp(cf_task_loss.detach() - dense_task_loss.detach(), min=0)

success:
```
