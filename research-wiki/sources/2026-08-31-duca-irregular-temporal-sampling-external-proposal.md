# DUCA 非等间隔时序采样外部提案：完整吸收与证据边界

日期：2026-08-31  
来源：用户在当前 Codex 对话中提供的外部研究提案  
原文归档：`docs/methods/reviews/2026-08-31-duca-irregular-temporal-sampling-external-proposal-raw.txt`  
来源身份边界：材料正文完整可见，但其外部模型身份、所谓“最新突破”、文献对应关系和预计收益尚未独立核验

## 记录结论

这份材料已作为一组未来可证伪的机制假说和结构候选完整吸收，但不作为已证实根因、当前 Pro 裁决或实验授权。

材料最有价值的部分，是把非等间隔重型观察可能引起的问题拆成四个可分别验证的层次：

1. 非连续原始帧被组成 VideoMAE tubelet 时，局部运动表征可能与预训练时的连续帧分布不一致；
2. 仅按被选中位置的序号编码时间，可能丢失真实采样间隔；
3. 稀疏特征恢复到密集检测网格时，重构核可能影响边界响应；
4. 硬选择、稀疏重型骨干和检测器同时训练时，优化过程可能不稳定。

这些问题与项目已有的原生 tubelet、物理时间映射和端到端训练差距研究相交，但材料没有证明其中任何一项是当前性能差距的主因，也没有证明四项必须联合修改。

## 原提案的完整机制清单

### 提案所引用的项目数值

材料以以下数值作为动机：

- H65：Avg-mAP 65.13；
- 端到端联合训练：Avg-mAP 58.39；
- 连续块选择：Avg-mAP 49.89；
- PJST：Avg-mAP 64.59。

其中 H65 65.13 和端到端 58.39 与项目长期记录一致。其余数字仍应通过对应正式实验记录和精确配置解释，不能仅凭本材料形成论文主张。

### 四项失配诊断

1. **Tubelet 配对失真**：若 VideoMAE-S 的 `tubelet_size=2` 接收到原始时间不连续的相邻输入帧，3D patch embedding 可能把长时间跨度误当作局部运动。
2. **基于被选序号的位置编码混叠**：若模型只看到 `0,1,...,K-1`，不同真实时间间隔可能得到相同的序列距离。
3. **稀疏到密集重构混叠**：材料认为一维线性插值可能在大间隔区域产生过度平滑，并影响 ActionFormer 的多尺度边界表征。
4. **端到端优化不稳定**：材料把 58.39 与 65.13 的差距部分归因于硬选择或 Gumbel 近似的高方差梯度，以及选择器和检测器的相互扰动。

### “智能真采样”系统提案

材料提出一个名为 DUCA-ITS 的组合系统：

- 以连续两帧组成的原生 tubelet 作为不可分割的重型采样单元；
- Scout 输出动作性、边界概率和语义特征；
- 双流选择器将 192 个 tubelet 分成 144 个动作/边界 micro-pair 和 48 个背景/上下文 anchor；
- 动作/边界流使用 `0.70 * boundary + 0.30 * action` 排序；
- 背景流在未覆盖区间按与冗余度相关的步长补充锚点；
- VideoMAE-S 内引入连续时间旋转位置编码；
- 用自适应高斯时序散射替换线性插值；
- 保持总输入为 384 帧，即 192 个连续 tubelet。

### 连续时间旋转位置编码

提案希望用真实时间戳而不是被选序号生成旋转相位，使注意力显式依赖物理时间差。材料给出了在 Query 和 Key 上施加连续时间旋转的 PyTorch 示意代码，但没有说明：

- 当前 VideoMAE 预训练位置编码如何安全迁移；
- 时间单位、归一化尺度和频率基底如何冻结；
- 空间 token 与时间 token 的展开方式；
- 是否需要重训全部骨干；
- 与项目已有物理时间特征路径相比新增了什么可辨识变量。

因此它目前是结构候选，不是可直接合入的补丁。

### 高斯时序散射

提案把每个稀疏特征视为带中心时间和带宽的高斯基元，并按归一化核权重恢复密集时间网格。带宽由相邻采样时间间隔估计并截断到上下界。该建议把“重构核是否影响高时间交并比定位”变成了一个可检验问题，但当前材料没有提供：

- 与线性插值的同配置配对结果；
- 边界误差、频响或重构误差；
- 对短动作、长空洞和视频边界的行为；
- 实际显存与计算成本；
- 高斯平滑相对线性平滑为何必然更锐利的证明。

因此“无伪影”或“梯度极为平滑”不能当作已证实结论。

### 三阶段训练课程

材料提出：

1. Epoch 0--25：Scout 与检测器分别预热；
2. Epoch 26--55：Gumbel-Softmax 软选择，温度从 2.0 退火到 0.5，并使用 H65 特征蒸馏；
3. Epoch 56--90：切换到 hard exact-K，以 1e-5 学习率联合微调连续时间位置编码和高斯重构。

这同时改变了预热方式、选择器、梯度估计、教师、训练时长、位置编码和重构核，不能作为单一因果实验。H65 也不能在没有严格教师身份和表示对齐定义时被默认视为正确的密集特征教师。

### 原提案的实施优先级与性能目标

材料建议：

- P0-1：原生连续 tubelet，预计 Avg-mAP 增加 0.8--1.5 个百分点；
- P0-2：连续时间旋转位置编码，目标是改善高时间交并比结果；
- P1-1：高斯时序桥接，目标是改善边界特征；
- P1-2：H65 特征蒸馏，预计把端到端 Avg-mAP 从 58.39 提升到至少 64.5；
- P2：评估 K in {128,192,256,320,384} 的性能—计算曲线。

这些数值全部是提案目标，不是实验结果、置信区间或可引用性能承诺。

## 与已有项目证据的关系

### 已有证据支持继续保留的问题

- H65 30+60 的正式点值为 Avg-mAP 65.13%、mAP@0.7 43.31%。
- 固定 K=384 的原生 tubelet 均匀选择得到 64.13%、42.45%；任务状态 coreset 得到 62.81%、40.56%。这说明原生连续 tubelet 路径可运行，但现有任务状态分配没有超过 H65。
- 项目已经研究过被选轴、物理时间逆映射和真实时间位置问题；这些历史工作说明物理时间表达值得审查，但不证明连续时间旋转位置编码是唯一或最佳修复。
- H65 相比共享 Dense AdaTAD 的 Avg-mAP 参考点低约 3.60 个百分点，但这不是严格单变量因果差距，不能全部归因于 tubelet 配对、位置编码或插值。
- 当前三档预算的 704 个整视频转移候选没有通过联合门，最强未验证解释是跨预算表示不匹配。该证据不支持直接把失败归因于 Gumbel、插值或非连续 tubelet。

### 必须纠正或保持未知的表述

- H65 不是普通全局 Top-K；它使用由优先级调制、带均匀覆盖下限的预算校准系统采样。
- “非连续 tubelet 必然制造虚假运动”“线性插值必然污染边界”“连续时间旋转会自然按距离衰减”“高斯散射会形成更锐利边界”都是待验证机制陈述。
- 连续时间旋转位置编码本身不保证长距离注意力衰减；旋转相位改变相对几何，但注意力幅度仍由学习到的 Query、Key 和频率设计决定。
- 自适应高斯核在稀疏区域会更宽，这同样可能加重平滑，而不是自动消除混叠。
- Gumbel-Softmax 不是当前动态预算上限诊断失败的解释；该诊断没有训练控制器，项目也已有 hard exact-K 与受保护梯度路径。
- “真实削减 50% 骨干端到端算力”尚未由本材料证明。当前可以准确陈述的是重型输入观察数量从 768 降到 384；端到端时延、FLOPs、吞吐量、显存和能耗仍需同硬件实测。
- “单卡、无泄漏、逼近或匹敌 Dense”是研究目标，不是当前证据。

## 吸收后的可证伪研究问题

如果未来 Pro 在当前正式数据协议和多预算单变量实验之外重新开放此方向，应把组合系统拆成彼此独立的判断：

1. **采样单元问题**：在选择得分、预算、训练和后端全部匹配时，连续原生 tubelet 是否优于非连续帧配对？
2. **时间编码问题**：在原生 tubelet 与重构方法冻结时，显式物理时间编码是否改善高时间交并比定位和短动作边界？
3. **重构核问题**：在稀疏特征与检测器冻结时，高斯核、线性核或其他局部核的差异是否能由边界误差和正式 mAP 复现？
4. **优化问题**：在架构冻结时，分阶段训练或蒸馏是否改善端到端收敛，并且不改变推理机制和真实成本？
5. **分配问题**：只有上述单项证据成立后，才检验 144/48 双流预算是否优于 H65 的预算校准系统采样。

每个问题都需要独立对照、完整训练、完整留出评估、保存预测和不确定性分析，不能把五项变化合并后再事后解释。

## 历史尝试核验与防重复结论

### 1. 原生连续 tubelet：已有多次实现与训练，但“配对连续性”尚未被单独归因

- 连续 16 帧 cliplet 路线已经实现并通过局部准入，提交 `8be817bba7a906c9b58446749d58c1752e1d5b6c`、作业
  `1245927` 证明连续采集、selected-only VideoMAE 和物理时间重构可以运行；该作业只完成 Scout 阶段，没有
  AdaTAD 正式 mAP，不能回答定位质量。
- 更直接的原生 tubelet 正式实验已在提交 `b33391126eac05e3353d322b973dda91741f0732` 上完成：768 帧组成
  384 个原生两帧 tubelet，再固定选择 192 个 tubelet。Uniform 与 task-state coreset 的完整 60 轮结果分别为
  64.13/42.45 和 62.81/40.56（Avg-mAP/mAP@0.7）。两臂都使用原生 tubelet，因此该结果检验的是选择方法，
  不是“连续配对对比非连续配对”。预测也未保存，缺少配对区间。
- `FZ_CONTIG/JT_CONTIG` 的固定 M=24 连续 bundle 也完成过完整训练，Avg-mAP 为 49.89/47.24，但它同时改变了
  采集与打包系统，不能作为只改变 tubelet 配对的单变量证据。
- 因此不得重跑已有 native-tubelet uniform/coreset 或 CONTIG bundle。尚未完成的严格问题是：固定相同 RGB
  位置、K、Scout、重构、检测器和训练预算，只改变 VideoMAE 内相邻帧是否来自连续物理时间。

### 2. 显式物理时间编码：已有充分历史，结论混合但存在正向单变量证据

- 早期 PhysTime v1 完整训练为负：selected-axis、physical-grid、PhysTime 的 Avg-mAP 分别为
  63.61、59.14、57.21，mAP@0.7 为 41.87、32.34、34.96。
- 后续匹配的 physical-metric full60 实验在特定低性能架构中得到 selected-axis 41.28 对 physical-time 57.57
  Avg-mAP，但该架构不能直接与 H65 或 Dense 作公平性能比较。
- 最接近当前问题的 RankPack/TrueTime 匹配实验固定相同 RGB、K、Scout、课程、检测器和评价器，只让 TrueTime
  在首次重型时序混合前使用物理位置；结果为 61.5722 对 62.1930 Avg-mAP，TrueTime 提高 0.6208 个百分点，
  高 tIoU 亦有正向点估计。该结果是单种子、配对 bootstrap 与完整证据包未闭合，因此只能算部分机制支持。
- 连续时间旋转位置编码尚未实现。不得从头重复一般性的 selected-axis 对 physical-time；若以后研究新的
  连续时间编码，必须说明它与既有 TrueTime 的差异，并做单变量、完整留出评估。

### 3. 稀疏到密集重构核：线性重构已实现，边界质量的核对照尚未执行

- 当前代码历史已有隐藏特征线性插值到 768 点的稀疏到密集桥，提交 `dd3c97cf...` 的聚焦测试与 CUDA Gate
  `1180556` 证明形状、有限值、梯度和计算量路径可运行。
- 后续正式 suite 因验证器和运行变体映射问题在官方训练结果前停止；没有产生 60 轮 TAD mAP，也没有保存可用于
  边界误差比较的完整预测。
- Wiki 只把 nearest 作为控制建议，没有找到 nearest、linear、Gaussian 在相同稀疏特征与检测器下的正式单变量
  比较；外部提案的 Gaussian temporal splatting 也未实现。
- 因此不要重复搭建或仅验证现有线性桥。真正未做的是冻结稀疏输入和检测器，单独比较重构核，并用正式 mAP、
  mAP@0.7、起止点误差和配对不确定性回答边界质量。

### 4. 分阶段训练与蒸馏：尝试很多，但尚无严格等预算的因果闭环

- 两阶段 coarse/selector warmup 与 joint training 已实现；早期作业 `1178480/1178487` 是工程失败，`1178591`
  运行到 epoch 8/step 700 后因隐藏损失、监督泄漏和 optimizer/EMA 等未被隔离而停止，只能作为诊断。
- 历史 H65 的 30 轮 uniform + 60 轮 joint 课程在作业 `1191957` 得到 65.385724 Avg-mAP，较 60 轮 uniform
  参考高约 0.896 个百分点，高 tIoU 点估计也更高；但它总计 90 轮，训练预算不匹配，不能把收益归因于课程。
- selected-axis homotopy/soft-to-hard 的已完成学习臂全部低于 exact uniform；CellCF detector-derived detached utility
  distillation 为 64.0610，低于 transition-beta0 的 64.2755。两者均不应原样重复。
- 外部提案的 H65 feature-MSE teacher、Gumbel 三阶段课程尚未实施。真正缺失的是架构与推理机制完全冻结、成功
  update 总数一致的 scratch 对短 warmup 对照；任何新蒸馏还必须与无蒸馏臂严格匹配，不能与新 selector、时间编码
  或重构核同时引入。

## 当前科学与执行处置

1. 完整保留原提案及其公式、代码示意、训练日程、优先级和性能目标，便于未来回溯。
2. 将原生 tubelet、物理时间编码、稀疏到密集重构和训练稳定性收录为四组未来机制假说。
3. 不创建 DUCA-ITS 模型、分支、Builder、PRE_RUN、GPU 或训练任务；不把 144/48、连续时间旋转位置编码、高斯散射或三阶段蒸馏写入当前方法定义。
4. 当前唯一授权任务仍是 THUMOS14 完整训练/留出评估协议下的 211/212 数据身份审计。身份审计、独立 Critic、CPU Evaluator 和 Pro 数据准入之前，不启动模型工作。
5. 数据身份准入后，当前 Pro 冻结的第一项模型问题仍是固定 K384 对照与嵌套 K256/K384/K512 多预算检测器适应的单变量比较。任何改变 selector、位置编码、重构核或训练课程的路线都需要新的 Pro 裁决。
6. 本次摄取不修改 `PAPER_PROGRESS.md` 或科学决策历史，因为它没有产生新实验结果或新的 Pro 科学裁决。

## 对论文叙事的保留边界

“物理时间一致的连续时序获取”可以作为未来论文问题的候选表述，但当前不能声称已经发现非均匀 TAD 的根本缺陷，也不能声称 DUCA-ITS 已经解决该问题。论文可在证据出现后分别讨论局部 tubelet 连续性、全局物理时间度量和稀疏特征重构；在此之前，它们只属于设计假说。
