# DUCA 连续密度传输选帧

## 状态

- `designed`
- 尚未实现、测试或部署，不能写成当前 DUCA 已有能力。
- 2026-07-23 已检索当前关键提交与历史 DUCA 树；没有发现采样密度头、逆 CDF/分位点传输或等价实现。

## 为什么提出

当前 `K=384, max_unselected_hole=2` 的结构化 Top-K 只能在近似均匀覆盖上做小幅调整。R2Q3/R4Q5
还把部分预算固定成局部微簇配额，难以把长背景中的冗余预算连续搬运到多个动作起止边界。目标不是取消真实
取帧，而是让学习模块只预测平滑、全局可解释的采样密度，再由无参数解码得到 K 个真实帧。

## 推荐方案：逆 CDF 单调传输

粗分类时序特征、动作概率、状态变化和不确定性经过轻量 density head 得到时间密度 logits。令

```text
q_i = eps / T + (1 - eps) * softmax(logit_i / tau)
F_i = sum_{j <= i} q_j
u_k = (k + 0.5) / K
x_k = F^{-1}(u_k)
```

`x_k` 是 K 个连续、单调递增的采样坐标。边界附近密度越高，落入该区域的分位点越多，因此可以形成
Oracle 式边界微簇；背景密度越低，分位点越少，因此允许跨区域转移预算。推理时再把连续坐标投影成唯一、
有序的整数帧位置。该投影是确定性的部署步骤，不再学习 Top-K 分数。

## 覆盖与离散化

- 不再使用 local-cell，也不要求每两帧选一帧。
- 将最大采样间隔放宽到 10 或 15 个候选帧；若代码参数表示“最大连续未选帧数”，对应值分别是 9 或 14。
- 使用全局单调唯一投影：最小化整数位置与连续分位点的位移，同时满足 exact-K、顺序、唯一性和宽松最大间隔。
- 密度加入小的均匀下限 `eps`，避免整段背景密度严格为零；硬最大间隔只作部署保险，不应再次构成主采样骨架。

## 监督与端到端梯度

第一阶段保持项目初心：粗模型学习动作/背景二分类与状态转变，density head 学习把概率质量分配到 GT 起止
边界两侧及必要上下文。推荐损失为：

- 动作二分类损失；
- 状态转变分布损失；
- 预测密度与 Oracle 边界-上下文目标之间的 CDF/Wasserstein 损失；
- 每个边界窗口的质量配额、左右平衡和多边界公平损失；
- 只抑制高频噪声的二阶平滑损失，禁止把真实边界峰抹平。

第二阶段使用 hard-forward/soft-backward：前向由整数位置提取真实 RGB 帧并进入 VideoMAE/AdaTAD；反向使用
连续分位坐标上的可微线性采样梯度回传到 density head。检测梯度首先只允许更新 density head 与时序 trunk
末层，保护动作二分类 head 和低层粗特征；证据稳定后再以更低学习率有限解冻。这样检测损失真正影响采样
密度，但不会在训练早期摧毁粗分类语义。

## 与当前模型的区别

| 当前 R2Q3/R4Q5 | 连续密度传输 |
|---|---|
| 每点分数 + 结构化硬 Top-K | 预测整条时间轴的概率密度 |
| `max-hole=2` 近似均匀 | 最大间隔 10/15，允许大范围预算转移 |
| 固定半径与固定微簇配额 | 峰宽和局部采样数由密度质量自动决定 |
| 检测梯度当前权重为 0 | hard-forward/soft-backward 直接接收检测损失 |
| selected-axis 不知道真实间距 | 后续配合零初始化 T1 时间间隔残差，不立即改物理时间检测头 |

## 备选方案

1. **推荐：逆 CDF 单调传输。** exact-K、单调、有直观概率质量解释，实现和计算最简。
2. **可学习间隔/危险率模型。** 直接预测下一次采样间隔，适合动态 K，但误差会累积，训练较不稳定。
3. **熵正则最优传输。** 从均匀 K 个 token 到时间密度做 Sinkhorn，梯度更平滑，但计算和实现明显更重。

## 最小决定性实验

1. exact-uniform；
2. density transport，只有动作/转变/边界密度监督；
3. 2 + hard-forward/soft-backward 检测梯度；
4. 3 + 零初始化 T1 时间间隔残差；
5. GT density 上界，仅作诊断。

先在 K384 比较最大间隔 3、6、10、15 对可达边界微簇、上下文覆盖和 official mAP 的影响；模型方向确定后只保留
一个宽松间隔进入 K256。每 10 epoch 的 mAP 只用于诊断学习曲线，论文主结果仍使用预注册终点 EMA。

## 成功与停止条件

- 必须在相同 backend、K、seed、终点 EMA 下超过 exact-uniform，且高 tIoU 不下降。
- 选帧分布必须表现为多个真实边界附近密度升高，而不是只围绕最强单一峰塌缩。
- 粗扫描、density head、离散投影和 detector 的总成本必须低于被省去的重 backbone 成本。
- 若 GT density 上界在宽松间隔下仍不能提高官方 mAP，应停止优化 density head，转向检测器时间几何或任务可达性问题。

## 2026-07-27 pure-plugin correction

连续密度传输仍是首选数学骨架，但主论文不再把真实时间特征注入投影层或检测头。主方法
冻结为 detector-compatible pre-backbone plugin：后续 backbone、projection、head、
assignment、cls/reg loss 与 NMS 均不改；只允许 detector 外侧的通用单调时间重参数化和
预测逆映射。物理时间检测头只保留为诊断或增强版。

下一版密度模型必须把均匀采样作为严格 identity path，并对累计质量偏移或局部采样间隔
施加可解释的扭曲上界。目标是允许有限的跨区域预算搬运，同时避免当前 unrestricted
selected-rank time 把局部时间尺度任意拉伸。贡献监督优先从绝对 `|x*grad|` 回归改为
归一化排序或质量传输；检测梯度必须先通过真实 hard-swap 方向/排序对齐。

当前该“有界、均匀可退化、检测器不改”的版本仍为 `designed`，尚未实现或获得 mAP。
