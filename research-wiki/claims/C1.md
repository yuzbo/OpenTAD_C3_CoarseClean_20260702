# C1: 低成本粗分类信号能支持有用的稀疏选择

## Statement

相对无语义采样，低成本 p_action、状态变化或隐藏特征能提高边界敏感选帧与下游 TAD。

## Current evidence

PAction 历史表现与 70aa 可训练性提供部分支持；但 a5e current selector 使用 absolute stem
feature 和 direct boundary heads，不能作为“状态变化间接定位”证据。transition-only 版本
尚未实现。

## Evidence still required

真实 ASFormer state、transition-only selector、matched baseline、probe/transition quality
分解和多 seed。

## 2026-07-12 audit correction

Transition-only is implemented and focused-tested in commit `0ea4e15`; the
older statement that it was unimplemented is stale. However, the running
`8bfc0e5` P0 matrix used a defective alpha=0 uniform reference, so it cannot
upgrade this claim. Corrected matched training and probe/transition diagnostics
remain required.
