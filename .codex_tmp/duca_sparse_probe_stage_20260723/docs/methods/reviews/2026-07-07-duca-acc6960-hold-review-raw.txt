### P0-2：Stage2 “detector-aware utility”还不是强意义 detector utility

不能 claim：

**判定：P0 scientific blocker。**

* per-point positive assignment responsibility；

### 7.1 online dense-sparse co-training forward

```python
class DucaDenseSparseTrainer(nn.Module):
    def __init__(self, dense_detector, sparse_detector, selector, ema_teacher=None):
        super().__init__()
        self.dense_detector = dense_detector
        self.sparse_detector = sparse_detector
        self.selector = selector
        self.ema_teacher = ema_teacher

    def forward_train(self, frames, masks, gt_segments, gt_labels, metas):
        # 1. dense / EMA branch: train-only critic
        with torch.no_grad():
            teacher = self.ema_teacher or self.dense_detector
            dense_out = teacher.forward_train(
                frames, masks, gt_segments, gt_labels, metas,
                return_point_diagnostics=True,
            )
            utility = extract_signed_detector_utility(dense_out, metas)

        # 2. selector branch
        sel = self.selector.forward_train(
            frames,
            masks,
            metas=metas,
            train_teacher_utility=utility.detach(),
        )

        sparse_frames = sel["selected_inputs"]
        sparse_masks = sel["selected_masks"]
        sparse_metas = sel["metas"]

        # 3. sparse detector branch: real detector loss must hit selector
        sparse_loss = self.sparse_detector.forward_train(
            sparse_frames,
            sparse_masks,
            gt_segments,
            gt_labels,
            sparse_metas,
        )

        # 4. auxiliary selector losses
        loss_budget = budget_loss(sel["selected_count"], target_budget=sel["target_budget"])
        loss_gap = cvar_max_hole_loss(sel["selected_positions"], metas)
        loss_bracket = boundary_bracket_loss(sel["selected_positions"], gt_segments, metas)
        loss_distill = sparse_dense_distill_loss(sparse_loss, dense_out)

        total = (
            sparse_loss["cost"]
            + 0.1 * loss_budget
            + 0.1 * loss_gap
            + 0.1 * loss_bracket
            + 0.5 * loss_distill
        )

        return {
            "cost": total,
            **{f"sparse_{k}": v for k, v in sparse_loss.items()},
            "loss_budget": loss_budget,
            "loss_gap": loss_gap,
            "loss_bracket": loss_bracket,
            "loss_distill": loss_distill,
            "selector_entropy": sel["entropy"].detach(),
        }
```

核心要求：dense branch 只能 train-time 用；inference 只能走 selector + sparse detector。

### 7.2 ST / Gumbel hard top-k selector

```python
def st_gumbel_topk(logits, k, tau=1.0, training=True):
    if training:
        g = -torch.empty_like(logits).exponential_().log()
        noisy = (logits + g) / tau
    else:
        noisy = logits

    _, idx = torch.topk(noisy, k=k, dim=-1)
    hard = torch.zeros_like(logits).scatter_(-1, idx, 1.0)

    soft = torch.softmax(noisy, dim=-1) * float(k)
    soft = soft.clamp(0.0, 1.0)

    # straight-through
    mask = hard + soft - soft.detach()
    return mask, idx
```

### 7.3 selected-axis 到 true-time remap

```python
def remap_segments_selected_to_true_time(segments, selected_positions):
    """
    segments: [N, 2] in selected-axis coordinates.
    selected_positions: [K] dense-time physical indices, strictly increasing.
    """
    assert selected_positions.ndim == 1
    assert torch.all(selected_positions[1:] > selected_positions[:-1])

    k = selected_positions.numel()
    x = torch.arange(k, device=segments.device, dtype=segments.dtype)
    y = selected_positions.to(device=segments.device, dtype=segments.dtype)

    def interp(v):
        v = v.clamp(0, k - 1)
        lo = torch.floor(v).long()
        hi = torch.ceil(v).long()
        alpha = v - lo.to(v.dtype)
        return y[lo] * (1 - alpha) + y[hi] * alpha

    out = torch.stack([interp(segments[:, 0]), interp(segments[:, 1])], dim=-1)
    return out
```

你仓库里已经有更完整的 `TrueTimeMap` 和 `remap_selected_axis_segments_to_true_time()`，这个 patch 的重点是：**所有 NMS 与 seconds conversion 前必须先 remap 到 physical time**。

### 7.4 更强 detector utility extraction

```python
def extract_signed_detector_utility(head_debug, gt_segments, gt_labels):
    """
    Required head_debug fields:
      - points: [L, T, 4]
      - cls_logits
      - reg_preds
      - assigned_gt_idx
      - cls_loss_per_point
      - reg_loss_per_point
      - proposal_scores_after_nms_optional
    """
    assigned = head_debug["assigned_gt_idx"] >= 0

    cls_gain = -head_debug["cls_loss_per_point"].detach()
    reg_gain = -head_debug["reg_loss_per_point"].detach()

    pos_resp = assigned.float()
    signed = pos_resp * (cls_gain + reg_gain)

    # harmful confident false positives should become negative utility
    fp_conf = head_debug["cls_logits"].sigmoid().max(dim=-1).values
    signed = torch.where(assigned, signed, -fp_conf.detach())

    return signed
```

这比当前 proposal-center score utility 更接近“detector utility”。

### 7.5 dynamic budget calibration

```python
def fit_budget_calibrator(train_rows, budget_buckets=(384, 512, 768), target_avg_k=512):
    gains = []
    for row in train_rows:
        signed = torch.tensor(row["signed_frame_utility"])
        cost = torch.ones_like(signed)
        marginal = signed / cost
        gains.append(marginal)

    all_gain = torch.cat(gains)
    thresholds = torch.quantile(all_gain, torch.linspace(0.05, 0.95, 91))

    best = None
    for th in thresholds:
        ks = []
        for g in gains:
            raw_k = int((g >= th).sum().item())
            bucket = min(budget_buckets, key=lambda b: abs(b - raw_k))
            ks.append(bucket)
        avg_k = sum(ks) / len(ks)
        err = abs(avg_k - target_avg_k)
        if best is None or err < best["err"]:
            best = {"threshold": float(th), "avg_k": avg_k, "err": err}

    return {
        "calibration_fitted": True,
        "fit_split": "train",
        "semantics": "calibrated_marginal_gain",
        "scope": "cross_video_comparable",
        "target_source": "positive_observation_gain_from_signed_detector_utility",
        "threshold": best["threshold"],
        "target_avg_k": target_avg_k,
        "fit_avg_k": best["avg_k"],
        "budget_buckets": list(budget_buckets),
    }
```

### 7.6 recursive no-leakage validator

FORBIDDEN_KEYS = {
    "gt", "ground_truth", "teacher", "oracle",
    "raw_prediction", "prediction_cache", "proposal_cache",
    "dense_teacher", "evaluator_output",
    "marginal_gain_frame_utility",

def scan_no_leakage(obj, path="", split="val"):
    if isinstance(obj, dict):
        for k, v in obj.items():
            lk = str(k).lower()
            if split != "train":
                for bad in FORBIDDEN_KEYS:
                    if bad in lk:
                        raise ValueError(f"Leakage key `{k}` at {path}")
            scan_no_leakage(v, f"{path}.{k}", split=split)

    elif isinstance(obj, list):
        for i, v in enumerate(obj):
            scan_no_leakage(v, f"{path}[{i}]", split=split)

    elif isinstance(obj, str):
        lv = obj.lower()
        if split != "train":
            for bad in FORBIDDEN_KEYS:
                if bad in lv:
                    raise ValueError(f"Leakage value `{obj}` at {path}")

def prove_selector_gradient(model, batch, proof_meta):
    loss_dict = model.forward_train(**batch)
    loss = loss_dict["cost"]
    loss.backward()

    grad_norm = 0.0
    for name, p in model.named_parameters():
        if "selector" in name and p.grad is not None:
            grad_norm += float(p.grad.detach().abs().sum().item())

    assert grad_norm > 1e-8, "No selector gradient from detector loss"

    return {
        "decision": "PASS",
        "selector_grad_norm": grad_norm,
        "loss_keys": sorted(loss_dict.keys()),
        "commit": proof_meta["commit"],
        "config_sha256": proof_meta["config_sha256"],
        "dataset_manifest_sha256": proof_meta["dataset_manifest_sha256"],
        "script_sha256": proof_meta["script_sha256"],
        "proof_scope": "real_actionformer_forward_train_cost_backward",

### 7.8 Stage3 full-run gate hash binding

```python
def validate_fullrun_gate(summary, expected):
    required = [
        "decision",
        "commit",
        "config_sha256",
        "script_sha256",
        "proof_json_sha256",
        "selector_grad_norm",
        "proof_scope",
    ]
    for k in required:
        if k not in summary:
            raise ValueError(f"Missing precheck field: {k}")

    if summary["decision"] != "PASS":
        raise ValueError("Precheck did not PASS")

    for k, v in expected.items():
        if summary.get(k) != v:
            raise ValueError(f"Precheck mismatch: {k}: {summary.get(k)} != {v}")

    if summary["selector_grad_norm"] <= 1e-8:
        raise ValueError("Selector gradient proof too weak")

    if summary["proof_scope"] != "real_actionformer_forward_train_cost_backward":
        raise ValueError("Invalid proof scope")
```

---

## 8. 论文故事建议

当前最稳的 CVPR-style story 不应该写成“我们已经实现 detector-aware end-to-end sparse TAD”。现在证据还不够。

更稳的故事是：

> Temporal Action Detection 的高成本来自密集 temporal observation。简单 uniform/random/p_action selection 会保住低 IoU recall，但容易破坏高 IoU boundary localization。我们提出 DUCA-TAD：一个 detector-utility-calibrated temporal acquisition framework，通过 true-time sparse sampling、gap-aware value transport、train-only detector utility、以及 ST hard selector，把 observation acquisition 变成 detector-aware optimization 问题。核心不是学 actionness，而是学哪些 observations 对 detector 的定位损失和高 IoU proposal 质量有边际价值。

需要证明的 evidence tree：

1. **Uniform/random 不够**：同 K 下高 IoU 掉点、boundary gap 上升。
2. **p_action 不够**：actionness 只覆盖 interior，不能稳定保护 boundary。
3. **GAS-VT 有用但有限**：gap/boundary priors 改善 ledger metrics 和部分 mAP。
4. **Detector utility 更强**：Stage2 utility-supervised selector 超过 p_action/GAS-VT。
5. **True-time 必要**：selected-axis naive head vs true-time physical-grid head，高 IoU 差异显著。
6. **End-to-end 更强**：Stage3 joint training 进一步提升或在相同 mAP 下更省 compute。
7. **Dynamic budget 有意义**：相同 average K 下，dynamic > fixed，且不是 rank trick。
8. **Deploy path clean**：val/test/deploy 不含 teacher/GT/cache。

---

## 最终裁决

**HOLD，允许继续工程推进，但禁止论文 claim 解锁。**

当前 commit 的正面点：

* 固定 commit 可见；
* Stage3 wrapper/precheck 合同有实质修复；
* ST selector + true-time metadata + physical-grid ActionFormer 路径已经比旧 smoke 更接近真实端到端；
* Stage2 signed utility 与 train-only provenance gate 明显更严；
* 多处 claim locks 写得诚实。

当前 blocking 点：

* 没有完整 detector mAP matrix；
* Stage2 teacher utility 还不够“detector utility”；
* dense teacher/export 未完成；
* Stage3 只是 synthetic real-ActionFormer gradient precheck，不是 THUMOS end-to-end result；
* dynamic budget calibration 仍弱；
* Stage4 只是 gate，不是 curriculum implementation；
* high-IoU localization 还没有被实验证明。

**Accepted decision：`HOLD_FOR_MORE_EVIDENCE`**
