## 2. 当前缺失或不足的分析能力清单

### 2.1 对 “是否集中在动作边界附近” 的证据不足

当前 validator 的 `boundary_support@r` 是有用的，但它只是 **boundary recall**，不是 **selected-frame concentration**。换句话说：

* `boundary_support@r` 高，只说明很多 boundary 附近至少有一个 selected frame；
* 它不能说明 selected frames 的主体是否集中在 boundary；
* 它不能区分 “少量点命中 boundary，但大部分点仍在 action interior” 和 “整体分布确实向 boundary 聚集”。

因此，当前代码还缺少以下核心指标：

1. **selected frame 到最近 GT boundary 的距离分布**
   需要 frame、second、normalized action length 三个单位。

2. **selected-frame region share**
   每个方法的 selected frames 有多少比例落在：

   * boundary band；
   * action interior；
   * background；
   * padding/invalid，理论上应为 0。

3. **per-action endpoint coverage**
   对每个 GT action，分别统计：

   * start covered@r；
   * end covered@r；
   * both start/end covered@r；
   * neither covered@r。

4. **region-specific holes**
   当前 hole/gap 更多是全局统计；需要分别统计：

   * whole video；
   * action interior；
   * boundary band；
   * background；
   * long action；
   * short action。

5. **normalized action-time density**
   需要把每个 action 归一化成 `[0,1]`，并额外保留 pre-start 和 post-end 区间，看 selected density 是否在 0 和 1 附近升高。

6. **score calibration**
   需要证明高 `p_action`、高 uncertainty、high change、teacher utility score 到底对应 boundary、interior 还是 background。

### 2.2 对 “PAction learned 为什么比 GAS-VT 更好” 的证据不足

当前文档显示 PAction learned 在一些 boundary/hole 指标上强于 GAS-VT，但仓库还没有一个统一分析接口，把下面这些因素拆开：

* p_action score 本身；
* decoder；
* budget allocation；
* gap repair；
* uniform scaffold/fill；
* lattice replacement；
* AdaTAD detector setting；
* matched train/test split；
* matched budget；
* matched selected-count policy；
* matched short-video handling。

因此，现在不能严肃声称：

> PAction learned 比 GAS-VT 好，是因为它更 boundary-aware。

最多只能说：

> 在已有 ledger summary 里，PAction learned 显示出更好的若干 boundary/hole 诊断指标；原因仍需 matched ablation 和可视化确认。

### 2.3 Stage2/Stage3 detector-aware claim 暂时 HOLD

当前分支有 Stage2/Stage3 相关 validation 和 config gate，但缺少能够直观看出 “detector utility 改变了选帧位置” 的 dashboard。已有 full-train config validator 会检查 variants、ledger subsample method、selected count、GT remap、forbidden flags 等，这对工程防漏是有价值的，但不等价于证明 Stage2/Stage3 学到了 detector-aware selection。([GitHub][6])

Stage2/Stage3 至少还需要：

* 与 p_action-only 的 per-video side-by-side timeline；
* 与 teacher utility high-score regions 的 overlap；
* detector loss/utility rank vs selected probability calibration；
* high-IoU improvement 与 endpoint coverage improvement 的相关性；
* matched-budget mAP + geometry 双表。

## 3. 关键代码正确性风险

### 3.1 坐标轴 contract 不够强

当前 validator 能检查 selected positions 的排序、唯一性、非负、in-range、expected count、target length 等，这是好的。([GitHub][4])

但 boundary analysis 仍然默认 `selected_positions`、`gt_segments`、`action_target`、`p_action` 在同一个 dense axis 上。这个假设必须被写进 schema，并在脚本里强制校验：

```json
{
  "coordinate_system": "dense_frame_index",
  "axis": "pre_backbone_dense_768",
  "fps": 30.0,
  "frame_stride": 1,
  "valid_len": 768,
  "selected_positions_are_centers": true,
  "gt_segment_convention": "half_open_[start,end)"
}
```

没有这个 contract，最容易出现 frame index、feature index、timestamp、clip index 混用，最后把 interior coverage 误判成 boundary coverage。

### 3.2 off-by-one 风险：segment end inclusive

`_is_inside_any_segment` 当前使用类似 `start <= position <= end` 的 inclusive 判断。([GitHub][3])

这在 TAD 里必须显式定义。如果 GT segment 是 `[start, end)` 半开区间，那么 inclusive end 会把 action 后一个边界点算进 action 内部；如果 GT segment 是连续时间秒数，转成 frame index 后也必须说明 boundary frame 是 floor、round、ceil 还是 frame center。否则 boundary band、interior、background 三分区会有系统性偏差。

建议统一为：

* 内部离散帧轴：`[start_idx, end_idx)`；
* start boundary：`start_idx`；
* end boundary：`end_idx - 1` 或连续时间 `end_time`，二者必须分别命名；
* 所有 radius 使用 “frame center distance”。

### 3.3 boundary support 不是 selected concentration

当前 validator 计算 boundary hits/support，这是 boundary recall 口径；它不能证明 selected frames 主体靠近 boundary。([GitHub][4])

必须新增 selected-centric 指标：

```text
P(selected frame within r of nearest GT boundary)
median / p75 / p90 / p95 distance_to_boundary
selected density near start/end vs interior
```

否则论文里写 “concentrates around boundaries” 会被审稿人抓住。

### 3.4 bracket support 的定义需要修正或文档化

当前 validator 里 boundary bracket support 使用 “boundary 左右各有点” 的逻辑；如果 selected frame 正好等于 boundary，它可能不被当作 left/right bracketing。([GitHub][4])

这不一定是 bug，但必须拆成两个指标：

* `boundary_hit@r`: radius 内至少一个点；
* `boundary_bracket@r`: boundary 两侧各至少一个点；
* `boundary_exact_hit`: selected position 正好落在 boundary center。

否则 exact boundary 命中反而可能在 bracket 指标上吃亏。

### 3.5 action coverage 容易被误读

当前 `action_positive_coverage` 更像 action-positive frame coverage，不是 per-action instance coverage。([GitHub][4])

论文里不能把它写成 “每个动作都被覆盖”。必须新增：

```text
per_action_any_selected
per_action_start_hit@r
per_action_end_hit@r
per_action_both_endpoints_hit@r
per_action_interior_selected_count
```

### 3.6 图像复现链路缺失

当前仓库没有成体系 `plot_*.py` 入口；这意味着即使有 notebook 或聊天记录里的图，固定 commit 也无法复现。这个问题对论文非常严重。([GitHub][2])

## 7. 关键实现代码框架

下面代码是应该进入仓库的核心实现骨架。重点是先把 geometry statistics 做对，再谈论文 claim。

### 7.1 boundary distance、region label、coverage@r

```python
# tools/bata/selector_geometry_core.py

from __future__ import annotations

from dataclasses import dataclass
from typing import Iterable, Mapping, Sequence

import math
import numpy as np
import pandas as pd


@dataclass(frozen=True)
class Segment:
    video_id: str
    start: int          # dense frame index, inclusive
    end: int            # dense frame index, exclusive
    label: str | None = None
    instance_id: str | None = None

    @property
    def length(self) -> int:
        return max(0, self.end - self.start)

    def contains(self, frame_idx: int) -> bool:
        return self.start <= frame_idx < self.end


def _require_sorted_unique_nonnegative(values: Sequence[int], name: str) -> np.ndarray:
    arr = np.asarray(values, dtype=np.int64)
    if arr.ndim != 1:
        raise ValueError(f"{name} must be 1D, got shape={arr.shape}")
    if len(arr) and int(arr.min()) < 0:
        raise ValueError(f"{name} contains negative positions")
    if len(arr) and np.any(arr[1:] <= arr[:-1]):
        raise ValueError(f"{name} must be strictly sorted and unique")
    return arr


def boundary_points(segments: Sequence[Segment]) -> list[dict]:
    """Return start/end boundary points on the same dense frame axis.

    Convention:
      - segment interval is half-open [start, end)
      - start boundary point is start
      - end boundary point is end - 1 for discrete frame-center analysis
    """
    out: list[dict] = []
    for k, seg in enumerate(segments):
        if seg.length <= 0:
            continue
        instance_id = seg.instance_id or f"{seg.video_id}:{k}"
        out.append({
            "video_id": seg.video_id,
            "instance_id": instance_id,
            "label": seg.label,
            "boundary_type": "start",
            "boundary_frame": int(seg.start),
            "action_start": int(seg.start),
            "action_end": int(seg.end),
            "action_len": int(seg.length),
        })
        out.append({
            "video_id": seg.video_id,
            "instance_id": instance_id,
            "label": seg.label,
            "boundary_type": "end",
            "boundary_frame": int(seg.end - 1),
            "action_start": int(seg.start),
            "action_end": int(seg.end),
            "action_len": int(seg.length),
        })
    return out


def nearest_boundary_rows(
    *,
    video_id: str,
    method: str,
    selected_positions: Sequence[int],
    segments: Sequence[Segment],
    frame_stride_seconds: float,
) -> pd.DataFrame:
    selected = _require_sorted_unique_nonnegative(selected_positions, "selected_positions")
    b_rows = boundary_points(segments)

    if not len(selected):
        return pd.DataFrame()

    if not b_rows:
        return pd.DataFrame({
            "video_id": video_id,
            "method": method,
            "selected_frame": selected,
            "nearest_boundary_frame": np.nan,
            "nearest_boundary_distance_frame": np.nan,
            "nearest_boundary_distance_seconds": np.nan,
            "nearest_boundary_distance_norm_action": np.nan,
            "nearest_boundary_type": None,
            "nearest_instance_id": None,
            "nearest_label": None,
        })

    b_frames = np.asarray([r["boundary_frame"] for r in b_rows], dtype=np.int64)

    rows = []
    for f in selected:
        d = np.abs(b_frames - int(f))
        j = int(np.argmin(d))
        br = b_rows[j]
        dist_frame = int(d[j])
        action_len = max(1, int(br["action_len"]))
        rows.append({
            "video_id": video_id,
            "method": method,
            "selected_frame": int(f),
            "nearest_boundary_frame": int(br["boundary_frame"]),
            "nearest_boundary_distance_frame": dist_frame,
            "nearest_boundary_distance_seconds": float(dist_frame * frame_stride_seconds),
            "nearest_boundary_distance_norm_action": float(dist_frame / action_len),
            "nearest_boundary_type": br["boundary_type"],
            "nearest_instance_id": br["instance_id"],
            "nearest_label": br["label"],
        })

    return pd.DataFrame(rows)


def label_selected_regions(
    *,
    selected_positions: Sequence[int],
    segments: Sequence[Segment],
    boundary_radius: int,
) -> pd.Series:
    """Priority: boundary_band > action_interior > background."""
    selected = _require_sorted_unique_nonnegative(selected_positions, "selected_positions")
    b_frames = np.asarray([r["boundary_frame"] for r in boundary_points(segments)], dtype=np.int64)

    labels: list[str] = []
    for f in selected:
        near_boundary = bool(len(b_frames) and np.min(np.abs(b_frames - int(f))) <= boundary_radius)
        inside_action = any(seg.contains(int(f)) for seg in segments)

        if near_boundary:
            labels.append("boundary_band")
        elif inside_action:
            labels.append("action_interior")
        else:
            labels.append("background")

    return pd.Series(labels, name="selected_region")


def boundary_recall_at_r(
    *,
    selected_positions: Sequence[int],
    segments: Sequence[Segment],
    radii: Sequence[int],
) -> pd.DataFrame:
    selected = _require_sorted_unique_nonnegative(selected_positions, "selected_positions")
    b_rows = boundary_points(segments)

    rows = []
    for r in radii:
        hit = 0
        total = 0
        start_hit = 0
        start_total = 0
        end_hit = 0
        end_total = 0

        for br in b_rows:
            total += 1
            covered = bool(len(selected) and np.min(np.abs(selected - br["boundary_frame"])) <= r)
            hit += int(covered)

            if br["boundary_type"] == "start":
                start_total += 1
                start_hit += int(covered)
            else:
                end_total += 1
                end_hit += int(covered)

        rows.append({
            "radius_frame": int(r),
            "boundary_total": int(total),
            "boundary_hit": int(hit),
            "boundary_recall": float(hit / total) if total else math.nan,
            "start_total": int(start_total),
            "start_hit": int(start_hit),
            "start_recall": float(start_hit / start_total) if start_total else math.nan,
            "end_total": int(end_total),
            "end_hit": int(end_hit),
            "end_recall": float(end_hit / end_total) if end_total else math.nan,
        })

    return pd.DataFrame(rows)


def per_action_endpoint_coverage(
    *,
    video_id: str,
    method: str,
    selected_positions: Sequence[int],
    segments: Sequence[Segment],
    radii: Sequence[int],
) -> pd.DataFrame:
    selected = _require_sorted_unique_nonnegative(selected_positions, "selected_positions")
    rows = []

    for k, seg in enumerate(segments):
        if seg.length <= 0:
            continue

        instance_id = seg.instance_id or f"{video_id}:{k}"
        start_b = int(seg.start)
        end_b = int(seg.end - 1)

        for r in radii:
            start_hit = bool(len(selected) and np.min(np.abs(selected - start_b)) <= r)
            end_hit = bool(len(selected) and np.min(np.abs(selected - end_b)) <= r)
            any_inside = bool(np.any((selected >= seg.start) & (selected < seg.end)))

            rows.append({
                "video_id": video_id,
                "method": method,
                "instance_id": instance_id,
                "label": seg.label,
                "action_start": int(seg.start),
                "action_end": int(seg.end),
                "action_len": int(seg.length),
                "radius_frame": int(r),
                "start_hit": int(start_hit),
                "end_hit": int(end_hit),
                "both_endpoint_hit": int(start_hit and end_hit),
                "any_endpoint_hit": int(start_hit or end_hit),
                "any_selected_inside_action": int(any_inside),
            })

    return pd.DataFrame(rows)


def unselected_holes_by_mask(
    *,
    valid_len: int,
    selected_positions: Sequence[int],
    mask: np.ndarray,
) -> list[int]:
    """Lengths of consecutive unselected valid positions inside a boolean mask."""
    selected = set(int(x) for x in selected_positions)
    if mask.shape != (valid_len,):
        raise ValueError(f"mask shape {mask.shape} != valid_len {valid_len}")

    holes: list[int] = []
    run = 0

    for i in range(valid_len):
        if not bool(mask[i]):
            if run:
                holes.append(run)
                run = 0
            continue

        if i in selected:
            if run:
                holes.append(run)
                run = 0
        else:
            run += 1

    if run:
        holes.append(run)

    return holes


def region_masks(valid_len: int, segments: Sequence[Segment], boundary_radius: int) -> dict[str, np.ndarray]:
    action = np.zeros(valid_len, dtype=bool)
    boundary = np.zeros(valid_len, dtype=bool)

    for seg in segments:
        s = max(0, int(seg.start))
        e = min(valid_len, int(seg.end))
        if e > s:
            action[s:e] = True

    for br in boundary_points(segments):
        b = int(br["boundary_frame"])
        lo = max(0, b - boundary_radius)
        hi = min(valid_len, b + boundary_radius + 1)
        boundary[lo:hi] = True

    interior = action & ~boundary
    background = ~action & ~boundary

    return {
        "whole_video": np.ones(valid_len, dtype=bool),
        "boundary_band": boundary,
        "action_interior": interior,
        "background": background,
    }


def summarize_holes_by_region(
    *,
    valid_len: int,
    selected_positions: Sequence[int],
    segments: Sequence[Segment],
    boundary_radius: int,
) -> pd.DataFrame:
    masks = region_masks(valid_len, segments, boundary_radius)
    rows = []

    for region, mask in masks.items():
        holes = unselected_holes_by_mask(
            valid_len=valid_len,
            selected_positions=selected_positions,
            mask=mask,
        )
        rows.append({
            "region": region,
            "num_holes": len(holes),
            "max_unselected_hole": int(max(holes)) if holes else 0,
            "p95_unselected_hole": float(np.percentile(holes, 95)) if holes else 0.0,
            "mean_unselected_hole": float(np.mean(holes)) if holes else 0.0,
        })

    return pd.DataFrame(rows)
```

### 7.2 p_action calibration：高分是否靠近 boundary

```python
def paction_boundary_calibration(
    *,
    video_id: str,
    p_action: Sequence[float],
    segments: Sequence[Segment],
    frame_stride_seconds: float,
    quantiles: Sequence[float] = (0.5, 0.7, 0.8, 0.9, 0.95),
) -> pd.DataFrame:
    scores = np.asarray(p_action, dtype=np.float64)
    if scores.ndim != 1:
        raise ValueError("p_action must be 1D")

    valid_len = len(scores)
    all_positions = np.arange(valid_len, dtype=np.int64)
    dist_df = nearest_boundary_rows(
        video_id=video_id,
        method="p_action_all_positions",
        selected_positions=all_positions,
        segments=segments,
        frame_stride_seconds=frame_stride_seconds,
    )

    rows = []
    for q in quantiles:
        threshold = float(np.quantile(scores, q))
        keep = scores >= threshold
        kept_positions = all_positions[keep]
        kept_dist = dist_df.loc[keep, "nearest_boundary_distance_frame"].dropna().to_numpy()

        rows.append({
            "video_id": video_id,
            "score_quantile": float(q),
            "threshold": threshold,
            "num_positions": int(keep.sum()),
            "mean_distance_frame": float(np.mean(kept_dist)) if len(kept_dist) else np.nan,
            "median_distance_frame": float(np.median(kept_dist)) if len(kept_dist) else np.nan,
            "p90_distance_frame": float(np.percentile(kept_dist, 90)) if len(kept_dist) else np.nan,
            "frac_within_4_frames": float(np.mean(kept_dist <= 4)) if len(kept_dist) else np.nan,
            "frac_within_8_frames": float(np.mean(kept_dist <= 8)) if len(kept_dist) else np.nan,
        })

    return pd.DataFrame(rows)
```

# tools/bata/plot_selector_timeline.py

from __future__ import annotations

from pathlib import Path
from typing import Mapping, Sequence

import numpy as np
import matplotlib.pyplot as plt


def plot_timeline_raster(
    *,
    video_id: str,
    valid_len: int,
    segments: Sequence[Segment],
    selected_by_method: Mapping[str, Sequence[int]],
    p_action: Sequence[float] | None,
    boundary_radius: int,
    out_path: str | Path,
) -> None:
    methods = list(selected_by_method.keys())
    height = 1.8 + 0.45 * len(methods)
    fig, ax = plt.subplots(figsize=(14, height))

    # GT action segments
    gt_y = len(methods) + 0.7
    for seg in segments:
        if seg.length <= 0:
            continue
        ax.broken_barh(
            [(seg.start, seg.length)],
            (gt_y, 0.25),
            alpha=0.35,
        )
        ax.text(seg.start, gt_y + 0.30, seg.label or "action", fontsize=7, rotation=0)

        # boundary bands
        for b in (seg.start, seg.end - 1):
            lo = max(0, b - boundary_radius)
            width = min(valid_len, b + boundary_radius + 1) - lo
            ax.broken_barh([(lo, width)], (gt_y - 0.12, 0.08), alpha=0.25)

    # selected ticks per method
    for row, method in enumerate(methods):
        y = row
        selected = np.asarray(selected_by_method[method], dtype=np.int64)
        ax.vlines(selected, y, y + 0.35, linewidth=0.6)
        ax.text(-0.01 * valid_len, y + 0.12, method, ha="right", va="center", fontsize=8)

    # p_action curve
    if p_action is not None:
        scores = np.asarray(p_action, dtype=np.float64)
        if len(scores) != valid_len:
            raise ValueError(f"p_action length {len(scores)} != valid_len {valid_len}")
        s_min = float(np.min(scores))
        s_max = float(np.max(scores))
        denom = max(1e-12, s_max - s_min)
        scaled = (scores - s_min) / denom
        curve_y = len(methods) + 0.05 + 0.45 * scaled
        ax.plot(np.arange(valid_len), curve_y, linewidth=0.8)
        ax.text(-0.01 * valid_len, len(methods) + 0.25, "p_action", ha="right", va="center", fontsize=8)

    ax.set_xlim(0, valid_len - 1)
    ax.set_ylim(-0.2, len(methods) + 1.4)
    ax.set_xlabel("dense frame index")
    ax.set_title(f"Selector timeline raster: {video_id}")
    ax.set_yticks([])
    ax.grid(axis="x", alpha=0.2)

    out_path = Path(out_path)
    out_path.parent.mkdir(parents=True, exist_ok=True)
    fig.tight_layout()
    fig.savefig(out_path)
    plt.close(fig)

## 9. 当前路线偏移点与修正路线

### 偏移点

当前分支的工程重点已经大量转向：

* ledger pipeline；
* provenance inference；
* fail-closed gate；
* config validation；
* full-train variants；
* no-leakage checks；
* selected count / gap / hole validation。

这些是必要工程基础，但它们**不是**最终研究问题本身。你的研究目标是证明：

> indirect selector 是否真的把有限预算放在对 TAD 定位最有价值的位置，尤其是动作边界、状态转换、不确定性、detector utility 高的位置。

当前仓库还没有把这个问题变成一个完整、可复现、可视化、可审计的 geometry analysis suite。仓库文档自己也承认当前 PAction/GAS-VT 解释还不是最终因果证明。([GitHub][5])

### 修正路线

第一步，不再继续只加训练 variant。先冻结一个 analysis contract：

```text
ledger JSONL schema
sample JSONL schema
annotation schema
coordinate convention
valid_len / padded_len convention
selected_positions convention
score axis convention
```

第二步，新增 `analyze_selector_geometry.py`，把所有方法统一导出到同一套 frame/action/video/method 表。

第三步，新增 `plot_selector_geometry.py`、`plot_selector_timeline.py`、`plot_selector_dashboard.py`、`generate_selector_failure_gallery.py`，让任何人可以从 fixed commit + ledger paths 一键复现所有图。

第四步，做 matched-budget ablation。不要再用不同 repair、不同 short-video count、不同 lattice、不同 config 混着比较 PAction 和 GAS-VT。

第五步，只有在 geometry 指标与 mAP 指标同时支持时，才允许写强 claim：

```text
PAction learned improves high-IoU TAD because it increases endpoint coverage and reduces boundary-region holes under matched sparse budget.
```

如果 geometry 指标不支持，只能写弱 claim：

```text
PAction learned is a stronger empirical selector than GAS-VT under this implementation, but its advantage is not yet proven to arise from boundary concentration.
```

## 最终审查结论

**A. GitHub 可见性和复现性：WARN/PARTIAL PASS**
代码可见，commit 固定成功；validator 有 CLI 和 summary 输出；但缺少完整绘图入口、统一 geometry schema、固定 RUN_TAG 图表复现 runbook。

**B. “选帧是否集中在动作边界附近”：HOLD**
当前 `boundary_support@r` 不足以支撑 concentration claim。必须新增 selected-distance distribution、region share、endpoint coverage、normalized action density。

**C. PAction/GAS-VT/Stage2/Stage3 差异分析：HOLD**
已有 ledger summary 能做初步对比，但没有统一 dashboard、matched-budget geometry matrix、score calibration、failure gallery，不能解释因果机制。

**D. 代码正确性：WARN**
最大风险是 coordinate convention、inclusive/exclusive boundary、boundary recall 被误读成 selected concentration、action coverage 被误读成 per-action coverage、short-video selected count 与 “fixed 384” claim 混淆。

**E. 论文 claim 支撑：HOLD**
当前仓库可以支持 “我们有严格 ledger validation 和初步诊断统计”，但还不能支持 “方法真正集中在动作边界附近” 或 “Stage2/Stage3 已 detector-aware”。需要先补齐 selector geometry analysis suite。
